### **Шаг 1.3: Интеграция камеры от первого лица.**

**Задача:** Добавить в игру камеру от первого лица (FP) и реализовать плавное переключение между ней и уже существующей камерой от третьего лица (TP). Это предоставит игроку выбор стиля игры: обзор и планирование в TP или полное погружение и точность в FP, что особенно важно при взаимодействии с мелкими объектами или во время напряженных моментов.

**Философия:** Вместо того чтобы пытаться переместить существующую TP камеру, мы добавим вторую, отдельную `UCameraComponent` специально для вида от первого лица. Этот подход чище и дает больше контроля:
1.  **Точное Позиционирование:** Мы прикрепим FP-камеру напрямую к "голове" скелета персонажа, что обеспечит максимально естественное и предсказуемое положение.
2.  **Независимые Настройки:** Каждая камера может иметь свои уникальные настройки (например, поле зрения - Field of View), что позволяет сделать вид от первого лица более "широким" для лучшего ощущения присутствия.
3.  **Чистое Переключение:** Мы будем просто активировать одну камеру и деактивировать другую, что является стандартным и надежным способом переключения видов в Unreal Engine.
4.  **Корректное Поведение Персонажа:** При переключении вида мы также должны изменить логику вращения персонажа. В TP-виде персонаж поворачивается в сторону движения. В FP-виде он должен мгновенно поворачиваться вместе с камерой (с мышью).

### **Подробная Реализация Шага**

#### **1. Добавление Компонента Камеры от Первого Лица (C++)**

Сначала добавим новый компонент камеры в наш C++ класс `FF_Character`.

1.  **Откройте `FF_Character.h`:**
    Добавьте объявление нового компонента камеры и геттер для него.

    ```cpp
    // FaunaLocus/Source/FaunaLocus/Character/FF_Character.h
    
    // ... (после UInteractionComponent)
    
    UCLASS()
    class FAUNALOCUS_API AFF_Character : public ACharacter
    {
    	GENERATED_BODY()
    
    public:
    	// Конструктор
    	AFF_Character();
    
    protected:
    	// ... (существующие компоненты: SpringArmComponent, CameraComponent, etc.)

    	// Камера от первого лица.
    	UPROPERTY(VisibleAnywhere, BlueprintReadOnly, Category = "Camera", meta = (AllowPrivateAccess = "true"))
    	TObjectPtr<UCameraComponent> FPCameraComponent;
    
        // ...
    
    public:	
    	// ... (существующие функции и геттеры)
    
    	// Геттер для камеры от первого лица
    	FORCEINLINE UCameraComponent* GetFPCameraComponent() const { return FPCameraComponent; }
    };
    ```

2.  **Откройте `FF_Character.cpp`:**
    Теперь создадим этот компонент в конструкторе и правильно его настроим.

    ```cpp
    // FaunaLocus/Source/FaunaLocus/Character/FF_Character.cpp
    
    // ... (включите заголовок для CameraComponent, если его еще нет)
    #include "Camera/CameraComponent.h"
    
    AFF_Character::AFF_Character()
    {
        // ... (существующий код для Tick, CharacterMovement, TP Camera)
    
        // 3. Создаем камеру от первого лица (FP Camera)
        FPCameraComponent = CreateDefaultSubobject<UCameraComponent>(TEXT("FPCameraComponent"));
        // Прикрепляем камеру к МЕШУ персонажа, чтобы она двигалась вместе с анимациями (например, приседанием).
        FPCameraComponent->SetupAttachment(GetMesh());
        // Включаем использование вращения контроллера, чтобы камера напрямую следовала за движением мыши.
        FPCameraComponent->bUsePawnControlRotation = true;
        // По умолчанию деактивируем ее, так как игра начинается в режиме от третьего лица.
        FPCameraComponent->bAutoActivate = false;
    
        // ... (код для создания будущих компонентов)
    }
    ```
    **Ключевые моменты здесь:**
    *   `SetupAttachment(GetMesh())`: Мы прикрепляем камеру к скелетному мешу, а не к капсуле. Это позволит нам позже привязать ее к конкретной кости (голове).
    *   `bUsePawnControlRotation = true`: Это критически важно для FP-камеры. Она должна смотреть точно туда, куда смотрит игрок (его контроллер).
    *   `bAutoActivate = false`: Игра начинается в TP-виде, поэтому FP-камера изначально выключена.

#### **2. Создание Логики Переключения Видов**

Теперь создадим механизм, который будет переключать камеры по нажатию кнопки.

1.  **Создайте новый Input Action:**
    *   Перейдите в `Content/Input/Actions`.
    *   Создайте новый **Input Action** с именем `IA_ToggleView`.
    *   **Value Type**: `Digital (bool)`.

2.  **Обновите Input Mapping Context:**
    *   Откройте `IMC_Default`.
    *   Добавьте новый маппинг для `IA_ToggleView`.
    *   Назначьте ему удобную клавишу, например **V**.

3.  **Реализуйте логику в `FF_Character`:**

    *   **В `FF_Character.h`:**
        Добавьте переменную для хранения текущего вида, ссылку на новый Input Action и объявление функции-обработчика.

        ```cpp
        // ... (внутри класса AFF_Character)
        protected:
            // --- Ссылки на Input Action ассеты ---
            // ... (существующие IA)
            UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category = "Input")
            TObjectPtr<class UInputAction> ToggleViewAction;
        
            // --- Функции-обработчики ввода ---
            void Move(const FInputActionValue& Value);
            void Look(const FInputActionValue& Value);
            void StartSprint();
            void StopSprint();
            void ToggleView(); // Новая функция
        
            // Обновляет состояние камер и персонажа в зависимости от текущего вида
            void UpdateCameraView();
        
            // Хранит текущее состояние вида
            bool bIsFirstPersonView = false;
        
            // ...
        ```

    *   **В `FF_Character.cpp`:**
        Реализуйте новые функции и обновите `SetupPlayerInputComponent`.

        ```cpp
        // ... (внутри AFF_Character::SetupPlayerInputComponent)
            EnhancedInputComponent->BindAction(SprintAction, ETriggerEvent::Completed, this, &AFF_Character::StopSprint);
            // Привязываем новую функцию к действию переключения вида
            EnhancedInputComponent->BindAction(ToggleViewAction, ETriggerEvent::Started, this, &AFF_Character::ToggleView);
        }
        
        // ... (существующие функции Move, Look, Sprint)
        
        void AFF_Character::ToggleView()
        {
            // Инвертируем флаг вида
            bIsFirstPersonView = !bIsFirstPersonView;
            UpdateCameraView();
        }
        
        void AFF_Character::UpdateCameraView()
        {
            if (bIsFirstPersonView)
            {
                // --- ПЕРЕКЛЮЧАЕМСЯ В РЕЖИМ ОТ ПЕРВОГО ЛИЦА ---
                FPCameraComponent->Activate();
                CameraComponent->Deactivate(); // Деактивируем TP камеру
        
                // Персонаж должен поворачиваться вместе с камерой
                bUseControllerRotationYaw = true;
                GetCharacterMovement()->bOrientRotationToMovement = false;
        
                // Скрываем меш персонажа от "своей" камеры, чтобы он не загораживал вид
                GetMesh()->SetOwnerNoSee(true);
            }
            else
            {
                // --- ПЕРЕКЛЮЧАЕМСЯ В РЕЖИМ ОТ ТРЕТЬЕГО ЛИЦА ---
                FPCameraComponent->Deactivate();
                CameraComponent->Activate(); // Активируем TP камеру
        
                // Возвращаем настройки вращения для TP вида
                bUseControllerRotationYaw = false;
                GetCharacterMovement()->bOrientRotationToMovement = true;
        
                // Снова делаем меш видимым для своей камеры
                GetMesh()->SetOwnerNoSee(false);
            }
        }
        
        // В BeginPlay добавим вызов, чтобы установить начальное состояние
        void AFF_Character::BeginPlay()
        {
            Super::BeginPlay();
        
            // Устанавливаем правильный вид при старте игры
            UpdateCameraView();
        }
        ```
    **Разбор логики в `UpdateCameraView`:**
    *   **Активация/Деактивация:** Мы явно включаем нужную камеру и выключаем ненужную. Это самый правильный способ.
    *   **Вращение персонажа:**
        *   В FP (`bUseControllerRotationYaw = true`, `bOrientRotationToMovement = false`): Капсула персонажа и, следовательно, его меш, теперь вращаются вместе с мышью. Он больше не "пятится" назад, а разворачивается лицом.
        *   В TP: Возвращаем все как было. Персонаж смотрит в сторону движения.
    *   **Видимость меша (`SetOwnerNoSee`):** Это специальная функция, которая скрывает меш только для камеры, принадлежащей этому персонажу, но оставляет его видимым для других игроков в мультиплеере или для отражений. Это именно то, что нужно.

#### **3. Финальная Настройка в Blueprint (`BP_Character`)**

Последние штрихи делаются в редакторе.

1.  **Скомпилируйте проект** из Visual Studio/Rider или через кнопку `Compile` в редакторе.
2.  **Откройте `BP_Character`**.
3.  **Назначьте Input Action:**
    *   Перейдите в **Class Defaults**.
    *   Найдите поле **Toggle View Action** и выберите созданный ассет `IA_ToggleView`.
4.  **Привяжите FP-камеру к голове:**
    *   В панели **Components** выберите `FPCameraComponent`.
    *   В панели **Details** найдите секцию **Socket**.
    *   В поле **Parent Socket** нажмите на лупу и найдите в списке кость `head`.
    *   Теперь камера привязана к голове персонажа.
5.  **Настройте положение FP-камеры:**
    *   Выбрав `FPCameraComponent`, во вьюпорте вы увидите ее расположение. Скорее всего, она будет находиться в центре головы.
    *   В панели **Details**, в секции **Transform**, измените **Location**, чтобы сдвинуть камеру на уровень глаз (например, X=10, Z=0). Поэкспериментируйте, чтобы найти идеальное положение.
    *   **Скомпилируйте и сохраните** Blueprint.
