#### **Шаг 1.2: Настройка перемещения (ходьба, бег, прыжок) с использованием Enhanced Input.**

**Задача:** Заменить устаревшую систему ввода (Action/Axis Mappings в Project Settings) на современную **Enhanced Input System (EIS)**. Это позволит нам создавать более гибкие и контекстно-зависимые схемы управления, которые легко расширять и изменять в будущем (например, разное управление на земле, в воде или в меню).

**Философия:** Мы определим абстрактные *действия* (Input Actions), которые игрок может совершать, а затем создадим *контекст* (Input Mapping Context), который связывает эти действия с конкретными физическими кнопками (W, A, S, D, Пробел и т.д.).

---

### **Подробная Реализация Шага**

#### **Предварительный Шаг: Активация Enhanced Input System**

Прежде чем начать, убедимся, что система активна в проекте.

1.  Перейдите в **Edit -> Plugins**.
2.  Найдите в поиске `Enhanced Input` и убедитесь, что плагин включен. Если нет, включите его и перезапустите редактор.
3.  Перейдите в **Edit -> Project Settings -> Engine -> Input**.
4.  В секции **Default Classes** измените:
    *   **Default Player Input Class** на `EnhancedPlayerInput`.
    *   **Default Input Component Class** на `EnhancedInputComponent`.

Это переключит весь проект на использование новой системы.

#### **1. Создание Ассетов Ввода (Input Actions)**

Input Actions (IA) — это ассеты, которые представляют собой абстрактное действие, например, "Двигаться" или "Прыгнуть". Они не привязаны к кнопкам.

1.  В **Content Browser** создайте новую папку: `Content/Input`. Внутри нее создайте папку `Actions`.
2.  Кликните правой кнопкой мыши в папке `Actions`, выберите **Input -> Input Action**.
3.  Создайте следующие ассеты:
    *   `IA_Move`: Для перемещения вперед-назад и влево-вправо.
        *   Откройте ассет. В `Details` установите **Value Type** на `Axis2D (Vector 2D)`. Это значит, что действие будет возвращать две координаты (X и Y).
    *   `IA_Look`: Для вращения камеры мышью.
        *   **Value Type**: `Axis2D (Vector 2D)`.
    *   `IA_Jump`: Для прыжка.
        *   **Value Type**: `Digital (bool)`. Это простое действие "включено/выключено".
    *   `IA_Sprint`: Для бега.
        *   **Value Type**: `Digital (bool)`.



#### **2. Создание Контекста Привязки (Input Mapping Context)**

Input Mapping Context (IMC) — это ассет, который связывает физические кнопки с нашими Input Actions.

1.  В папке `Content/Input` создайте новый ассет: **Input -> Input Mapping Context**. Назовите его `IMC_Default`.
2.  Откройте `IMC_Default`. Вы увидите список **Mappings**. Нажмите `+`, чтобы добавить новую привязку.
3.  **Настройте привязки:**
    *   **Для `IA_Move`:**
        *   Добавьте маппинг, выберите `IA_Move`.
        *   Нажмите `+` рядом с иконкой клавиатуры и назначьте кнопку **W**.
        *   В секции **Modifiers** для W добавьте `Swizzle Input Axis Values`. Это заставит W влиять на ось Y, а не X.
        *   Добавьте еще одну кнопку к `IA_Move` - **S**. Добавьте ей два модификатора: `Swizzle Input Axis Values` и `Negate`.
        *   Добавьте кнопку **A**. Добавьте ей модификатор `Negate`.
        *   Добавьте кнопку **D**.
    *   **Для `IA_Look`:**
        *   Добавьте маппинг, выберите `IA_Look`.
        *   Назначьте кнопку **Mouse XY**. Это одна "кнопка" для обеих осей мыши.
    *   **Для `IA_Jump`:**
        *   Добавьте маппинг, выберите `IA_Jump`.
        *   Назначьте кнопку **Space Bar**.
    *   **Для `IA_Sprint`:**
        *   Добавьте маппинг, выберите `IA_Sprint`.
        *   Назначьте кнопку **Left Shift**.

#### **3. Применение Контекста в Player Controller**

Контекст нужно "активировать" для игрока. Лучшее место для этого — `PlayerController`.

1.  Создайте новый C++ класс `FF_PlayerController`, унаследованный от `APlayerController`. Поместите его в `FaunaLocus/Core/`.
2.  **В `FF_PlayerController.h`:**
    ```cpp
    // FaunaLocus/Source/FaunaLocus/Core/FF_PlayerController.h
    
    #pragma once
    
    #include "CoreMinimal.h"
    #include "GameFramework/PlayerController.h"
    #include "FF_PlayerController.generated.h"
    
    class UInputMappingContext;
    
    UCLASS()
    class FAUNALOCUS_API AFF_PlayerController : public APlayerController
    {
    	GENERATED_BODY()
    
    protected:
    	// Ссылка на наш ассет Input Mapping Context
    	UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category = "Input")
    	TObjectPtr<UInputMappingContext> DefaultMappingContext;
    
    	virtual void BeginPlay() override;
    };
    ```
3.  **В `FF_PlayerController.cpp`:**
    ```cpp
    // FaunaLocus/Source/FaunaLocus/Core/FF_PlayerController.cpp
    
    #include "Core/FF_PlayerController.h"
    #include "EnhancedInputSubsystems.h"
    
    void AFF_PlayerController::BeginPlay()
    {
    	Super::BeginPlay();
    
    	// Получаем локальную подсистему Enhanced Input
    	if (UEnhancedInputLocalPlayerSubsystem* Subsystem = ULocalPlayer::GetSubsystem<UEnhancedInputLocalPlayerSubsystem>(GetLocalPlayer()))
    	{
    		// Добавляем наш контекст. Приоритет 0 - самый низкий.
    		Subsystem->AddMappingContext(DefaultMappingContext, 0);
    	}
    }
    ```
4.  **Скомпилируйте код.**
5.  Создайте Blueprint-наследника `BP_PlayerController` от `FF_PlayerController` в папке `Content/Blueprints/Core/`.
6.  Откройте `BP_PlayerController` и в панели **Class Defaults** установите **Default Mapping Context** в наш `IMC_Default`.
7.  В **Project Settings -> Maps & Modes** установите **Player Controller Class** на ваш `BP_PlayerController`.

#### **4. Привязка Действий к Функциям в Персонаже**

Теперь, когда система настроена, мы можем "слушать" наши Input Actions в классе персонажа и вызывать соответствующие функции.

1.  **В `FF_Character.h`:**
    ```cpp
    // ... (внутри класса AFF_Character)
    
    protected:
    	// --- Ссылки на Input Action ассеты ---
    	UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category = "Input")
    	TObjectPtr<class UInputAction> MoveAction;
    
    	UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category = "Input")
    	TObjectPtr<class UInputAction> LookAction;
    
    	UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category = "Input")
    	TObjectPtr<class UInputAction> JumpAction;
    
    	UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category = "Input")
    	TObjectPtr<class UInputAction> SprintAction;
    
    	// --- Функции-обработчики ввода ---
    	void Move(const FInputActionValue& Value);
    	void Look(const FInputActionValue& Value);
    	void StartSprint();
    	void StopSprint();
    
    	// Переопределяем SetupPlayerInputComponent
    	virtual void SetupPlayerInputComponent(class UInputComponent* PlayerInputComponent) override;
    ```
2.  **В `FF_Character.cpp`:**
    ```cpp
    // ... (добавьте необходимые инклюды)
    #include "InputMappingContext.h"
    #include "EnhancedInputComponent.h"
    #include "InputActionValue.h"
    
    // ...
    
    void AFF_Character::SetupPlayerInputComponent(UInputComponent* PlayerInputComponent)
    {
    	Super::SetupPlayerInputComponent(PlayerInputComponent);
    
    	// Приводим PlayerInputComponent к UEnhancedInputComponent
    	if (UEnhancedInputComponent* EnhancedInputComponent = CastChecked<UEnhancedInputComponent>(PlayerInputComponent))
    	{
    		// Привязываем наши функции к Input Actions
    		EnhancedInputComponent->BindAction(MoveAction, ETriggerEvent::Triggered, this, &AFF_Character::Move);
    		EnhancedInputComponent->BindAction(LookAction, ETriggerEvent::Triggered, this, &AFF_Character::Look);
    		EnhancedInputComponent->BindAction(JumpAction, ETriggerEvent::Started, this, &ACharacter::Jump);
    		EnhancedInputComponent->BindAction(SprintAction, ETriggerEvent::Started, this, &AFF_Character::StartSprint);
    		EnhancedInputComponent->BindAction(SprintAction, ETriggerEvent::Completed, this, &AFF_Character::StopSprint);
    	}
    }
    
    void AFF_Character::Move(const FInputActionValue& Value)
    {
    	// Получаем вектор из FInputActionValue
    	const FVector2D MovementVector = Value.Get<FVector2D>();
    
    	if (Controller != nullptr)
    	{
    		// Находим направление "вперед" относительно поворота контроллера
    		const FRotator Rotation = Controller->GetControlRotation();
    		const FRotator YawRotation(0, Rotation.Yaw, 0);
    
    		// Получаем векторы
    		const FVector ForwardDirection = FRotationMatrix(YawRotation).GetUnitAxis(EAxis::X);
    		const FVector RightDirection = FRotationMatrix(YawRotation).GetUnitAxis(EAxis::Y);
    
    		// Добавляем движение
    		AddMovementInput(ForwardDirection, MovementVector.Y);
    		AddMovementInput(RightDirection, MovementVector.X);
    	}
    }
    
    void AFF_Character::Look(const FInputActionValue& Value)
    {
    	const FVector2D LookAxisVector = Value.Get<FVector2D>();
    
    	if (Controller != nullptr)
    	{
    		// Добавляем вращение контроллера
    		AddControllerYawInput(LookAxisVector.X);
    		AddControllerPitchInput(LookAxisVector.Y);
    	}
    }
    
    void AFF_Character::StartSprint()
    {
    	// Увеличиваем скорость
    	GetCharacterMovement()->MaxWalkSpeed = 600.0f; 
    }
    
    void AFF_Character::StopSprint()
    {
    	// Возвращаем скорость к стандартной
    	GetCharacterMovement()->MaxWalkSpeed = 300.0f;
    }
    ```
    *   **`ETriggerEvent::Triggered`:** Событие вызывается каждый кадр, пока кнопка нажата (идеально для движения и обзора).
    *   **`ETriggerEvent::Started`:** Событие вызывается один раз в момент нажатия (идеально для прыжка и начала бега).
    *   **`ETriggerEvent::Completed`:** Событие вызывается один раз в момент отпускания кнопки (идеально для прекращения бега).

3.  **Скомпилируйте код.**
4.  Откройте `BP_Character` и в панели **Class Defaults** назначьте созданные ассеты `IA_Move`, `IA_Look`, `IA_Jump`, `IA_Sprint` соответствующим полям.

Вы полностью настроили современную систему ввода для персонажа.
