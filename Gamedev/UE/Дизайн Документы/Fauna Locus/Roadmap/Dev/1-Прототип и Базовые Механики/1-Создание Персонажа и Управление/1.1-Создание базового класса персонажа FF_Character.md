### **Шаг 1.1: Создание базового класса персонажа (C++ `FF_Character`)**

**Задача:** Создать основной C++ класс для нашего персонажа с видом от первого лица. Этот класс будет служить фундаментом, на котором мы построим всю дальнейшую логику: передвижение, взаимодействие с миром, выживание и боевую систему. Мы сразу заложим в него необходимые компоненты, такие как камера от первого лица и меш для рук, а также оставим "заглушки" для будущих систем.

**Почему C++?** Основные компоненты и базовая логика передвижения реализуются в C++, чтобы обеспечить максимальную производительность, стабильность и чистоту архитектуры. Настройки, специфичные для визуала (меши рук, анимации), будут производиться в Blueprint-наследнике.

---

### **Подробная Реализация Шага**

#### **1. Создание C++ Класса в Unreal Editor**

1.  **Откройте ваш проект `FaunaLocus`** в Unreal Editor.
2.  В верхнем меню выберите **Tools -> New C++ Class...**.
3.  Откроется окно выбора родительского класса. Выберите **Character**. Это специальный тип Pawn, который уже включает в себя `CharacterMovementComponent` для удобной реализации передвижения "из коробки".
4.  Нажмите **Next**.
5.  В поле **Name** введите имя нашего класса: `FF_Character`. Префикс `FF_` (`FaunaLocus`) поможет избежать конфликтов имен и сделает код более организованным.
6.  В поле **Path** укажите путь для создания файлов: `FaunaLocus/Character/`.
7.  Нажмите **Create Class**.

Unreal Engine создаст два файла (`FF_Character.h` и `FF_Character.cpp`), добавит их в ваш проект Visual Studio / Rider и запустит компиляцию.

#### **2. Определение Заголовочного Файла (`FF_Character.h`)**

Теперь мы определяем компоненты специально для вида от первого лица.

```cpp
// FaunaLocus/Source/FaunaLocus/Character/FF_Character.h

#pragma once

#include "CoreMinimal.h"
#include "GameFramework/Character.h"
#include "FF_Character.generated.h"

// Прямые объявления для уменьшения времени компиляции
class UCameraComponent;
class USkeletalMeshComponent; // Для рук
class USurvivalComponent;
class UBuildingComponent;
class UInteractionComponent;

UCLASS()
class FAUNALOCUS_API AFF_Character : public ACharacter
{
	GENERATED_BODY()

public:
	// Конструктор
	AFF_Character();

protected:
	// Вызывается при старте игры
	virtual void BeginPlay() override;

	// --- Компоненты ---

	// Камера от первого лица.
	UPROPERTY(VisibleAnywhere, BlueprintReadOnly, Category = "Camera", meta = (AllowPrivateAccess = "true"))
	TObjectPtr<UCameraComponent> FPCameraComponent;

	// Меш рук от первого лица. Виден только владельцу.
	UPROPERTY(VisibleAnywhere, BlueprintReadOnly, Category = "Mesh", meta = (AllowPrivateAccess = "true"))
	TObjectPtr<USkeletalMeshComponent> FPArmsMeshComponent;


	// -- ЗАГЛУШКИ ДЛЯ БУДУЩИХ СИСТЕМ --
	
	// Компонент, управляющий показателями выживания (голод, жажда, температура).
	UPROPERTY(VisibleAnywhere, BlueprintReadOnly, Category = "Components", meta = (AllowPrivateAccess = "true"))
	TObjectPtr<USurvivalComponent> SurvivalComponent;

	// Компонент, отвечающий за логику строительства (предпросмотр, размещение).
	UPROPERTY(VisibleAnywhere, BlueprintReadOnly, Category = "Components", meta = (AllowPrivateAccess = "true"))
	TObjectPtr<UBuildingComponent> BuildingComponent;

	// Компонент, отвечающий за обнаружение интерактивных объектов в мире.
	UPROPERTY(VisibleAnywhere, BlueprintReadOnly, Category = "Components", meta = (AllowPrivateAccess = "true"))
	TObjectPtr<UInteractionComponent> InteractionComponent;


public:	
	// Вызывается каждый кадр
	virtual void Tick(float DeltaTime) override;

	// Вызывается для привязки функционала к вводу
	virtual void SetupPlayerInputComponent(class UInputComponent* PlayerInputComponent) override;

	// Геттеры для компонентов
	FORCEINLINE UCameraComponent* GetFPCameraComponent() const { return FPCameraComponent; }
	FORCEINLINE USkeletalMeshComponent* GetFPArmsMeshComponent() const { return FPArmsMeshComponent; }

};
```

**Зачем это нужно?**
*   **`UCameraComponent`:** Теперь это наша основная и единственная камера. Мы прикрепим ее прямо к капсуле персонажа.
*   **`USkeletalMeshComponent`:** Это отдельный меш для рук. В играх от первого лица полное тело персонажа обычно не рендерится для игрока, чтобы избежать проблем с камерой, проходящей сквозь меш. Вместо этого используется высокодетализированный меш рук, прикрепленный к камере.
*   **Никакого `SpringArmComponent`:** Он не нужен, так как камера не следует за персонажем на расстоянии.

#### **3. Реализация в Файле Исходного Кода (`FF_Character.cpp`)**

Здесь мы создаем и настраиваем наши новые компоненты для вида от первого лица.

```cpp
// FaunaLocus/Source/FaunaLocus/Character/FF_Character.cpp

#include "Character/FF_Character.h"
#include "Camera/CameraComponent.h"
#include "Components/SkeletalMeshComponent.h"
#include "Components/CapsuleComponent.h"
#include "GameFramework/CharacterMovementComponent.h"

// Временно закомментируем инклюды для будущих компонентов, чтобы проект компилировался
// #include "Components/SurvivalComponent.h"
// #include "Components/BuildingComponent.h"
// #include "Components/InteractionComponent.h"

AFF_Character::AFF_Character()
{
 	// Устанавливаем, чтобы этот персонаж вызывал Tick() каждый кадр.
	PrimaryActorTick.bCanEverTick = true;

	// --- Настройка Компонента Движения ---
	// Персонаж должен вращаться вместе с камерой (контроллером).
	bUseControllerRotationYaw = true;
	GetCharacterMovement()->bOrientRotationToMovement = false; // Отключаем поворот в сторону движения

	// --- Создание и Настройка Камеры от первого лица ---
	FPCameraComponent = CreateDefaultSubobject<UCameraComponent>(TEXT("FPCameraComponent"));
	// Прикрепляем камеру к капсуле коллизии на уровне глаз.
	FPCameraComponent->SetupAttachment(GetCapsuleComponent());
	FPCameraComponent->SetRelativeLocation(FVector(0.f, 0.f, 64.f)); // Позиция на уровне глаз
	FPCameraComponent->bUsePawnControlRotation = true; // Камера вращается вместе с вводом мыши

	// --- Создание и Настройка Меша Рук от первого лица ---
	FPArmsMeshComponent = CreateDefaultSubobject<USkeletalMeshComponent>(TEXT("FPArmsMeshComponent"));
	FPArmsMeshComponent->SetOnlyOwnerSee(true); // Меш виден только владельцу
	FPArmsMeshComponent->bCastDynamicShadow = false; // Отключаем тени, чтобы они не выглядели странно
	FPArmsMeshComponent->CastShadow = false;
	FPArmsMeshComponent->SetupAttachment(FPCameraComponent); // Прикрепляем руки к камере

	// --- Скрываем полное тело персонажа от вида игрока ---
	GetMesh()->SetOwnerNoSee(true);

	// --- Создание Будущих Компонентов (пока без логики) ---
    // Раскомментируйте по мере создания этих классов
	// SurvivalComponent = CreateDefaultSubobject<USurvivalComponent>(TEXT("SurvivalComponent"));
	// BuildingComponent = CreateDefaultSubobject<UBuildingComponent>(TEXT("BuildingComponent"));
	// InteractionComponent = CreateDefaultSubobject<UInteractionComponent>(TEXT("InteractionComponent"));
}

// Вызывается при старте игры
void AFF_Character::BeginPlay()
{
	Super::BeginPlay();
	
}

// Вызывается каждый кадр
void AFF_Character::Tick(float DeltaTime)
{
	Super::Tick(DeltaTime);

}

// Вызывается для привязки функционала к вводу
void AFF_Character::SetupPlayerInputComponent(UInputComponent* PlayerInputComponent)
{
	Super::SetupPlayerInputComponent(PlayerInputComponent);

    // Логика привязки ввода будет добавлена на следующем шаге
}
```

**Зачем это нужно?**
*   **`bUseControllerRotationYaw = true`:** Это ключевое отличие. Теперь вся капсула персонажа будет поворачиваться по горизонтали вместе с движением мыши.
*   **`bOrientRotationToMovement = false`:** Отключаем старое поведение. Персонаж больше не должен смотреть туда, куда бежит; он смотрит туда, куда направлена камера.
*   **`FPCameraComponent->SetupAttachment(GetCapsuleComponent())`:** Камера теперь — прямой дочерний элемент капсулы, что обеспечивает стабильность.
*   **`FPArmsMeshComponent->SetOnlyOwnerSee(true)`:** Важнейшая настройка. Другие игроки в мультиплеере будут видеть ваше полное тело (`GetMesh()`), а вы будете видеть только свои руки.
*   **`FPArmsMeshComponent->SetupAttachment(FPCameraComponent)`:** Руки "приклеены" к камере, поэтому они всегда будут перед глазами.
*   **`GetMesh()->SetOwnerNoSee(true)`:** Скрываем полное тело от камеры игрока, чтобы избежать визуальных глитчей.

#### **4. Создание Blueprint-наследника и Настройка**

1.  **Скомпилируйте проект** в Visual Studio/Rider или через кнопку `Compile` в редакторе.
2.  В Content Browser редактора перейдите в папку `Content/Blueprints/Character/` (создайте, если нужно).
3.  Найдите ваш C++ класс `FF_Character` в панели `C++ Classes` и создайте на его основе Blueprint `BP_Character`.
4.  **Откройте `BP_Character`**.
5.  **Настройте Меш Рук:**
    *   Выберите компонент **FPArmsMeshComponent**.
    *   В панели `Details` в поле **Skeletal Mesh Asset** выберите меш рук от первого лица (например, `SK_Mannequin_Arms` из стартового контента).
    *   В поле **Anim Class** выберите подходящий Animation Blueprint для рук.
    *   Настройте положение рук, чтобы они хорошо смотрелись в камере (возможно, потребуется немного опустить их по оси Z и сдвинуть вперед по оси X).
6.  **Настройте Полное Тело (для других игроков):**
    *   Выберите компонент **Mesh**.
    *   В `Details` выберите полный меш персонажа (`SKM_Manny` или `SKM_Quinn`).
    *   В поле **Anim Class** выберите соответствующий Animation Blueprint.
    *   Настройте положение полного меша внутри капсулы (опустите по Z на -90, поверните по Z на -90).
7.  **Скомпилируйте и сохраните** Blueprint.

#### **5. Назначение Персонажа по Умолчанию**

Последний шаг — сказать игре использовать нашего нового персонажа при старте.

1.  Перейдите в **Edit -> Project Settings -> Project -> Maps & Modes**.
2.  В секции **Default Modes** найдите поле **Default Pawn Class**.
3.  Нажмите на выпадающий список и выберите ваш **`BP_Character`**.
4.  Закройте настройки.
