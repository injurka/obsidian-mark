Великолепно! Система выживания теперь работает, но она изолирована от мира. Следующий шаг — связать ее с окружением, чтобы мир начал напрямую влиять на состояние игрока. Это сделает геймплей гораздо более динамичным и осмысленным.

### **Шаг 2.2: Влияние окружения на атрибуты (холод ночью, утоление жажды у воды)**

**Задача:** Реализовать две ключевые механики взаимодействия с миром:
1.  **Динамическая температура:** Температура тела игрока должна меняться в зависимости от времени суток. Ночью должно становиться холоднее, что в будущем создаст потребность в укрытии, костре и теплой одежде.
2.  **Взаимодействие с водой:** Игрок должен иметь возможность утолить жажду, взаимодействуя с источниками воды в мире.

**Философия:**
1.  **Глобальный Управляющий (GameState):** Время суток — это глобальное состояние мира, одинаковое для всех. Идеальное место для управления им — `GameState`. Мы создадим простой менеджер времени, который будет сообщать всем заинтересованным системам (например, нашему `SurvivalComponent`), когда наступил день или ночь.
2.  **Целевая Температура (Drifting Value):** Температура тела не должна меняться мгновенно. Вместо этого, окружение будет задавать *целевую температуру*, к которой показатель игрока будет плавно стремиться. Это создает более реалистичное и предсказуемое ощущение.
3.  **Контекстное Взаимодействие (Interaction Component):** Чтобы пить воду, игрок должен на нее посмотреть и нажать кнопку. Мы реализуем `UInteractionComponent`, который будет отвечать за "ощупывание" мира с помощью луча (line trace) из камеры. Этот компонент будет определять, на что смотрит игрок, и позволит ему взаимодействовать с объектами. Это невероятно мощная и расширяемая система для будущего.
4.  **Физические Материалы (Physical Materials):** Как узнать, что игрок смотрит именно на воду, а не на камень? Мы будем использовать **физические материалы**. Мы назначим специальный материал `PM_Water` всем водным поверхностям, и наш луч будет его распознавать.

### **Часть 1: Динамическая Температура и Цикл Дня/Ночи**

#### **1.1. Создание Менеджера Времени в `GameState`**

1.  В редакторе создайте новый C++ класс `FF_GameState`, унаследованный от `AGameStateBase`. Поместите его в `FaunaLocus/Core/`.
2.  **Откройте `FF_GameState.h`:**

    ```cpp
    // FaunaLocus/Source/FaunaLocus/Core/FF_GameState.h
    
    #pragma once
    
    #include "CoreMinimal.h"
    #include "GameFramework/GameStateBase.h"
    #include "FF_GameState.generated.h"
    
    // Делегат для оповещения о смене времени суток
    DECLARE_DYNAMIC_MULTICAST_DELEGATE_OneParam(FOnTimeOfDayChanged, bool, bIsNight);
    
    UCLASS()
    class FAUNALOCUS_API AFF_GameState : public AGameStateBase
    {
    	GENERATED_BODY()
    
    public:
    	AFF_GameState();
    
    	UPROPERTY(BlueprintAssignable, Category = "Events")
    	FOnTimeOfDayChanged OnTimeOfDayChanged;
    
    	virtual void Tick(float DeltaSeconds) override;
    
    protected:
    	// Длительность одного игрового дня в реальных секундах
    	UPROPERTY(EditDefaultsOnly, Category = "Time Of Day")
    	float DayDurationSeconds = 600.0f; // 10 минут
    
    	// Текущее время (0.0 - полночь, 0.25 - утро, 0.5 - полдень, 0.75 - вечер)
    	UPROPERTY(VisibleAnywhere, BlueprintReadOnly, ReplicatedUsing = OnRep_TimeOfDay, Category = "Time Of Day")
    	float TimeOfDay = 0.25f; // Начинаем утром
    
    	UPROPERTY(BlueprintReadOnly, Replicated)
    	bool bIsNight = false;
    
    	void SetIsNight(bool bNewIsNight);
    
    	UFUNCTION()
    	void OnRep_TimeOfDay();
    
    	virtual void GetLifetimeReplicatedProps(TArray<FLifetimeProperty>& OutLifetimeProps) const override;
    };
    ```

3.  **Откройте `FF_GameState.cpp`:**

    ```cpp
    // FaunaLocus/Source/FaunaLocuse/Core/FF_GameState.cpp
    
    #include "Core/FF_GameState.h"
    #include "Net/UnrealNetwork.h"
    
    AFF_GameState::AFF_GameState()
    {
    	PrimaryActorTick.bCanEverTick = true;
    }
    
    void AFF_GameState::Tick(float DeltaSeconds)
    {
    	Super::Tick(DeltaSeconds);
    
    	if (HasAuthority()) // Время двигается только на сервере
    	{
    		TimeOfDay += DeltaSeconds / DayDurationSeconds;
    		if (TimeOfDay >= 1.0f)
    		{
    			TimeOfDay = FMath::Fmod(TimeOfDay, 1.0f);
    		}
    
    		// Определяем, ночь ли сейчас (например, с 20:00 до 06:00, т.е. с 0.83 до 0.25)
    		const bool bCurrentIsNight = (TimeOfDay >= 0.83f || TimeOfDay < 0.25f);
    		if (bCurrentIsNight != bIsNight)
    		{
    			SetIsNight(bCurrentIsNight);
    		}
    	}
    }
    
    void AFF_GameState::SetIsNight(bool bNewIsNight)
    {
    	if (bIsNight != bNewIsNight)
    	{
    		bIsNight = bNewIsNight;
    		OnTimeOfDayChanged.Broadcast(bIsNight);
    	}
    }
    
    void AFF_GameState::OnRep_TimeOfDay()
    {
    	// Эта функция нужна, чтобы клиенты тоже могли обновлять визуал в будущем (например, положение солнца)
    }
    
    void AFF_GameState::GetLifetimeReplicatedProps(TArray<FLifetimeProperty>& OutLifetimeProps) const
    {
    	Super::GetLifetimeReplicatedProps(OutLifetimeProps);
    	DOREPLIFETIME(AFF_GameState, TimeOfDay);
    	DOREPLIFETIME(AFF_GameState, bIsNight);
    }
    ```

4.  **Настройте Проект:**
    *   Скомпилируйте код.
    *   Создайте Blueprint-наследника `BP_GameState` от `FF_GameState` в `Content/Blueprints/Core/`.
    *   Перейдите в **Project Settings -> Maps & Modes** и установите **Game State Class** на ваш `BP_GameState`.

#### **1.2. Обновление `SurvivalComponent` для Реакции на Температуру**

1.  **Откройте `SurvivalComponent.h`:**

    ```cpp
    // ...
    protected:
        // ...
    	// Целевая температура тела, к которой стремится текущая.
    	UPROPERTY(VisibleAnywhere, Category = "Attributes")
    	float TargetBodyTemperature = 36.6f;
    
    	// Скорость изменения температуры к целевой (градусов в секунду).
    	UPROPERTY(EditDefaultsOnly, Category = "Survival Settings")
    	float TemperatureChangeRate = 0.5f;
    
    	// Порог холода, при котором начинается получение урона.
    	UPROPERTY(EditDefaultsOnly, Category = "Survival Settings")
    	float ColdDamageTemperatureThreshold = 30.0f;
    
    	// Урон в секунду от переохлаждения.
    	UPROPERTY(EditDefaultsOnly, Category = "Survival Settings")
    	float DamagePerSecondFromCold = 1.0f;
    
    	// Функция-обработчик смены времени суток
    	UFUNCTION()
    	void HandleTimeOfDayChanged(bool bIsNight);
    // ...
    ```

2.  **Откройте `SurvivalComponent.cpp`:**

    ```cpp
    // ...
    #include "Core/FF_GameState.h" // Нужен доступ к геймстейту
    #include "Kismet/GameplayStatics.h" // Для получения геймстейта
    
    void USurvivalComponent::BeginPlay()
    {
        // ... (существующий код)
    
        // Подписываемся на событие смены времени суток
        if (AFF_GameState* GameState = Cast<AFF_GameState>(UGameplayStatics::GetGameState(this)))
        {
            GameState->OnTimeOfDayChanged.AddDynamic(this, &USurvivalComponent::HandleTimeOfDayChanged);
            // Устанавливаем начальное состояние
            HandleTimeOfDayChanged(GameState->bIsNight); 
        }
    }
    
    void USurvivalComponent::TickComponent(float DeltaTime, ELevelTick TickType, FActorComponentTickFunction* ThisTickFunction)
    {
        // ... (существующий код для голода и жажды)
    
        // --- Логика Температуры ---
        // Плавно двигаем текущую температуру к целевой
        Temperature.CurrentValue = FMath::FInterpTo(Temperature.CurrentValue, TargetBodyTemperature, DeltaTime, TemperatureChangeRate);
        OnTemperatureChanged.Broadcast(Temperature); // Оповещаем UI
    
        // Если температура упала ниже критической, наносим урон
        if (Temperature.CurrentValue < ColdDamageTemperatureThreshold)
        {
            ApplyDamage(DamagePerSecondFromCold * DeltaTime);
        }
    }
    
    void USurvivalComponent::HandleTimeOfDayChanged(bool bIsNight)
    {
        if (bIsNight)
        {
            TargetBodyTemperature = 25.0f; // Ночью холодно
        }
        else
        {
            TargetBodyTemperature = 36.6f; // Днем комфортно
        }
    }
    
    // ...
    ```

Теперь температура тела игрока будет падать ночью, и если она упадет слишком низко, игрок начнет получать урон.

### **Часть 2: Взаимодействие с Водой**

#### **2.1. Создание Физического Материала Воды**

1.  В **Content Browser** создайте папку `Content/Physics`.
2.  Кликните ПКМ -> **Physics -> Physical Material**.
3.  Назовите ассет `PM_Water`.
4.  Откройте любой водный объект на вашей сцене (если его нет, создайте `Plane` и примените к нему материал воды). В `Details` найдите секцию `Collision`. В поле **Simple Collision Physical Material** выберите ваш `PM_Water`.

#### **2.2. Создание и Реализация `InteractionComponent`**

1.  Создайте C++ класс `InteractionComponent`, унаследованный от `UActorComponent`. Поместите его в `FaunaLocus/Character/Components/`.
2.  **Откройте `InteractionComponent.h`:**
    ```cpp
    // FaunaLocus/Source/FaunaLocus/Character/Components/InteractionComponent.h

    #include "CoreMinimal.h"
    #include "Components/ActorComponent.h"
    #include "InteractionComponent.generated.h"

    	UPROPERTY(EditDefaultsOnly, Category = "Interaction")

    	UPROPERTY(EditDefaultsOnly, Category = "Interaction")

    	UPROPERTY()
    	TObjectPtr<USurvivalComponent> OwnerSurvivalComponent;

    public:
    	// TODO: Делегаты для UI (OnInteractableFound, OnInteractableLost)
    };
    ```
3.  **Откройте `InteractionComponent.cpp`:**
    ```cpp
    // FaunaLocus/Source/FaunaLocus/Character/Components/InteractionComponent.cpp
    
    #include "Character/Components/InteractionComponent.h"
    #include "Character/FF_Character.h"
    #include "Camera/CameraComponent.h"
    #include "Character/Components/SurvivalComponent.h"
    #include "PhysicalMaterials/PhysicalMaterial.h"
    
    UInteractionComponent::UInteractionComponent()
    {
    	PrimaryComponentTick.bCanEverTick = true;
    }
    
    void UInteractionComponent::TickComponent(float DeltaTime, ELevelTick TickType, FActorComponentTickFunction* ThisTickFunction)
    {
    	Super::TickComponent(DeltaTime, TickType, ThisTickFunction);
    
    	FHitResult HitResult;
    	FVector Start;
    	FRotator ViewRotation;
    
    	// Получаем точку обзора игрока
    	GetOwner()->GetActorEyesViewPoint(Start, ViewRotation);
    	FVector End = Start + ViewRotation.Vector() * InteractionDistance;
    
    	FCollisionQueryParams QueryParams;
    	QueryParams.AddIgnoredActor(GetOwner());
    	QueryParams.bReturnPhysicalMaterial = true; // Важно! Нам нужен физ. материал
    
    	bIsLookingAtWater = false; // Сбрасываем флаг каждый кадр
    
    	if (GetWorld()->LineTraceSingleByChannel(HitResult, Start, End, ECC_Visibility, QueryParams))
    	{
    		if (UPhysicalMaterial* PhysMat = HitResult.PhysMaterial.Get())
    		{
    			if (PhysMat->GetName() == "PM_Water") // Проверяем по имени (простой способ)
    			{
    				bIsLookingAtWater = true;
    				// TODO: Broadcast OnInteractableFound("Drink")
    			}
    		}
    	}
    
    	if (!bIsLookingAtWater)
    	{
    		// TODO: Broadcast OnInteractableLost()
    	}
    }
    
    void UInteractionComponent::PerformInteraction()
    {
    	if (bIsLookingAtWater)
    	{
    		if (!OwnerSurvivalComponent)
    		{
    			// Получаем компонент выживания при первой необходимости
    			OwnerSurvivalComponent = GetOwner()->FindComponentByClass<USurvivalComponent>();
    		}
    
    		if (OwnerSurvivalComponent)
    		{
    			OwnerSurvivalComponent->ApplyThirstChange(ThirstToQuench);
    		}
    	}
    }
    ```
