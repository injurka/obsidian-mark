### **Шаг 2.3: Базовая логика смерти и респавна**

**Задача:** Создать четкий и понятный механизм, который срабатывает, когда здоровье игрока падает до нуля. Этот механизм должен включать в себя:
1.  **Обработку события смерти:** Оповещение других систем (например, `GameMode`) о том, что игрок умер.
2.  **Визуальную и геймплейную реакцию:** Включение "тряпичной куклы" (Ragdoll) для тела персонажа, отключение ввода.
3.  **Таймер возрождения:** Короткая задержка перед тем, как игрок снова появится в мире.
4.  **Процесс возрождения (Респавн):** Перезапуск контроллера игрока на новом или том же персонаже с восстановленными показателями.

**Философия:**
1.  **Разделение Ответственности:**
    *   **`SurvivalComponent`** обнаруживает, что здоровье достигло нуля, и оповещает об этом. Он не должен решать, *что* делать дальше.
    *   **`FF_Character`** реагирует на смерть: включает физику, отключает коллизии и т.д.
    *   **`FF_GameMode`** (в синглплеере) или `FF_PlayerController` (для мультиплеера) отвечает за глобальный процесс: запуск таймера и перезапуск игрока. Для синглплеера `GameMode` — идеальное место, так как он управляет правилами игры на уровне.
2.  **Бесшовный Респавн:** Мы не будем перезагружать уровень. Вместо этого, `GameMode` просто уничтожит старого персонажа и создаст нового в точке старта, а затем "передаст" управление игрока (его `PlayerController`) этому новому персонажу. Это быстро и эффективно.
3.  **Использование Делегатов:** Компонент выживания будет использовать делегат, чтобы сообщить о смерти. Это сохраняет нашу архитектуру чистой и модульной.

### **Подробная Реализация Шага**

#### **1. Обновление `SurvivalComponent` для Оповещения о Смерти**

Сначала научим наш компонент "кричать", когда его владелец умирает.

1.  **Откройте `SurvivalComponent.h`:**
    Добавьте новый делегат.

    ```cpp
    // FaunaLocus/Source/FaunaLocus/Character/Components/SurvivalComponent.h
    
    // ...
    DECLARE_DYNAMIC_MULTICAST_DELEGATE(FOnOwnerDied); // Делегат без параметров
    
    UCLASS( ClassGroup=(Custom), meta=(BlueprintSpawnableComponent) )
    class FAUNALOCUS_API USurvivalComponent : public UActorComponent
    {
    	// ...
    public:	
    	// ...
    	// Делегат, который вызывается, когда здоровье владельца достигает нуля.
    	UPROPERTY(BlueprintAssignable, Category = "Events")
    	FOnOwnerDied OnOwnerDied;
    
    	// ...
    };
    ```

2.  **Откройте `SurvivalComponent.cpp`:**
    Найдите функцию `ApplyDamage` и вызовите новый делегат в нужный момент.

    ```cpp
    // FaunaLocus/Source/FaunaLocus/Character/Components/SurvivalComponent.cpp
    
    void USurvivalComponent::ApplyDamage(float DamageAmount)
    {
    	if (DamageAmount <= 0.0f || Health.CurrentValue <= 0.0f)
    	{
    		return;
    	}
    
    	const float OldHealth = Health.CurrentValue; // Запоминаем старое здоровье
    
    	Health.CurrentValue = FMath::Clamp(Health.CurrentValue - DamageAmount, 0.0f, Health.MaxValue);
    	OnHealthChanged.Broadcast(Health);
    
    	// Если здоровье БЫЛО больше нуля, а СТАЛО ноль, значит, мы только что умерли.
    	if (Health.CurrentValue <= 0.0f && OldHealth > 0.0f)
    	{
    		OnOwnerDied.Broadcast(); // Сообщаем всем подписчикам о смерти!
    	}
    }
    ```

#### **2. Реакция Персонажа (`FF_Character`) на Смерть**

Персонаж должен знать, что делать со своим телом, когда он умирает.

1.  **Откройте `FF_Character.h`:**
    Добавьте функцию-обработчик.

    ```cpp
    // FaunaLocus/Source/FaunaLocus/Character/FF_Character.h
    
    // ...
    protected:
    	// ...
    	// Вызывается, когда компонент выживания сообщает о смерти.
    	UFUNCTION()
    	void HandleDeath();
    
    public:
    	// ...
    ```

2.  **Откройте `FF_Character.cpp`:**
    Подпишитесь на событие в `BeginPlay` и реализуйте логику `HandleDeath`.

    ```cpp
    // FaunaLocus/Source/FaunaLocus/Character/FF_Character.cpp
    #include "Components/CapsuleComponent.h" // Нужен для изменения коллизий
    #include "GameFramework/CharacterMovementComponent.h" // Нужен для отключения движения
    
    // ...
    
    void AFF_Character::BeginPlay()
    {
    	Super::BeginPlay();
    
    	// Подписываемся на событие смерти
    	if (SurvivalComponent)
    	{
    		SurvivalComponent->OnOwnerDied.AddDynamic(this, &AFF_Character::HandleDeath);
    	}
    
    	UpdateCameraView();
    }
    
    void AFF_Character::HandleDeath()
    {
    	// 1. Отключаем ввод, чтобы "мертвый" персонаж не мог двигаться
    	DisableInput(nullptr);
    
    	// 2. Включаем Ragdoll
    	GetMesh()->SetSimulatePhysics(true);
    	GetMesh()->SetCollisionProfileName(TEXT("Ragdoll"));
    
    	// 3. Отключаем коллизию капсулы, чтобы она не мешала Ragdoll-телу
    	GetCapsuleComponent()->SetCollisionEnabled(ECollisionEnabled::NoCollision);
    
    	// 4. Останавливаем любое движение
    	GetCharacterMovement()->StopMovementImmediately();
    	GetCharacterMovement()->DisableMovement();
    }
    ```
    *Эта функция превращает нашего активного персонажа в безвольную физическую "тряпичную куклу".*

#### **3. Логика Респавна в `GameMode`**

`GameMode` — это дирижер, который управляет правилами игры. Он решит, что делать после смерти игрока.

1.  Создайте новый C++ класс `FF_GameMode`, унаследованный от `AGameModeBase`. Поместите его в `FaunaLocus/Core/`.
2.  **Откройте `FF_GameMode.h`:**

    ```cpp
    // FaunaLocus/Source/FaunaLocus/Core/FF_GameMode.h
    
    #pragma once
    
    #include "CoreMinimal.h"
    #include "GameFramework/GameModeBase.h"
    #include "FF_GameMode.generated.h"
    
    UCLASS()
    class FAUNALOCUS_API AFF_GameMode : public AGameModeBase
    {
    	GENERATED_BODY()
    
    public:
    	// Вызывается, когда любой игрок в игре умирает.
    	// Мы привяжем эту функцию к событию OnOwnerDied через Blueprint.
    	UFUNCTION(BlueprintCallable, Category = "Game Mode")
    	void OnPlayerDied(AController* PlayerController);
    
    protected:
    	// Задержка перед респавном в секундах.
    	UPROPERTY(EditDefaultsOnly, Category = "Respawn")
    	float RespawnDelay = 5.0f;
    
    	// Функция, которая будет вызвана по таймеру для респавна.
    	void RespawnPlayer(AController* PlayerController);
    };
    ```

3.  **Откройте `FF_GameMode.cpp`:**

    ```cpp
    // FaunaLocus/Source/FaunaLocus/Core/FF_GameMode.cpp
    
    #include "Core/FF_GameMode.h"
    #include "TimerManager.h"
    
    void AFF_GameMode::OnPlayerDied(AController* PlayerController)
    {
    	if (!PlayerController)
    	{
    		return;
    	}
    
    	// Создаем таймер для отложенного респавна.
    	FTimerHandle RespawnTimerHandle;
    	FTimerDelegate RespawnDelegate;
    
    	// Привязываем нашу функцию RespawnPlayer к делегату.
    	// FTimerDelegate::CreateUObject требует указателя на объект, делегата и аргументов.
    	RespawnDelegate.BindUObject(this, &AFF_GameMode::RespawnPlayer, PlayerController);
    
    	GetWorldTimerManager().SetTimer(RespawnTimerHandle, RespawnDelegate, RespawnDelay, false);
    }
    
    void AFF_GameMode::RespawnPlayer(AController* PlayerController)
    {
    	if (!PlayerController)
    	{
    		return;
    	}
    
    	// Находим точку старта
    	AActor* PlayerStart = FindPlayerStart(PlayerController);
    	if (!PlayerStart)
    	{
    		// Если нет PlayerStart, респавнимся на месте смерти (аварийный вариант)
    		PlayerStart = PlayerController->GetPawn();
    	}
    
    	// Перезапускаем контроллер. Движок сам уничтожит старого пешку,
    	// создаст нового в указанной точке и передаст управление.
    	RestartPlayerAtPlayerStart(PlayerController, PlayerStart);
    }
    ```

Мы создали все C++ части, теперь соединим их в редакторе.

2.  Создайте Blueprint-наследника `BP_GameMode` от `FF_GameMode` в `Content/Blueprints/Core/`.

4.  **Откройте `BP_Character`:**

    *   В графе событий, в функции `HandleDeath`, добавьте следующую логику:
        *   `Get Game Mode` -> `Cast To BP_GameMode`.
        *   Из `BP_GameMode` вызовите нашу C++ функцию `On Player Died`.
        *   В пин `Player Controller` подайте `Get Controller`.

### **Итог Шага**

Вы реализовали полный цикл смерти и возрождения, который делает игру по-настоящему завершенной с точки зрения базового геймплея.

*   **Что сделано:**
    *   `SurvivalComponent` теперь транслирует событие `OnOwnerDied`.
    *   `FF_Character` подписывается на это событие и корректно "умирает", включая Ragdoll и отключая ввод.
    *   `FF_GameMode` реализует логику отложенного респавна.
    *   В Blueprint `BP_Character` мы связали смерть персонажа с вызовом функции в `GameMode`.
    *   Движок теперь автоматически обрабатывает респавн игрока в точке `PlayerStart`.

*   **Результат:** Запустите игру. Дождитесь, пока голод или холод убьют вашего персонажа. Вы увидите, как его тело упадет в режиме Ragdoll. Через 5 секунд (или значение, которое вы установили в `BP_GameMode`) экран "моргнет", и вы появитесь в точке `PlayerStart` со свежими, полными показателями здоровья, голода и жажды, готовые к новой попытке выжить. Этот цикл является критически важным для любой игры на выживание.
