У нас есть работающая, но невидимая система инвентаря. Пришло время дать игроку возможность видеть свои сокровища и взаимодействовать с ними. Мы создадим простой, но функциональный пользовательский интерфейс (UI) для инвентаря.

### **Шаг 4.2: Реализация простого UI инвентаря**

**Задача:** Создать виджет инвентаря, который будет отображать его содержимое в виде сетки. Каждый слот в сетке должен показывать иконку предмета и его количество. Интерфейс должен открываться и закрываться по нажатию клавиши и автоматически обновляться при изменении содержимого инвентаря.

**Философия:**
1.  **Два Виджета:** Мы создадим два отдельных виджета для максимальной гибкости и переиспользования:
    *   **`WBP_InventorySlot`:** Маленький виджет, представляющий *один* слот. Он будет отвечать за отображение иконки и количества.
    *   **`WBP_InventoryGrid`:** Основной виджет, содержащий сетку (`UniformGridPanel`), которая будет динамически заполняться экземплярами `WBP_InventorySlot`.
2.  **Событийно-ориентированное Обновление:** `WBP_InventoryGrid` подпишется на делегат `OnInventoryUpdated` из нашего `InventoryComponent`. Это значит, что UI будет перерисовываться только тогда, когда это действительно необходимо, а не каждый кадр, что очень эффективно.
3.  **Динамическое Создание:** Мы не будем создавать 20-30 слотов вручную в дизайнере. Вместо этого, `WBP_InventoryGrid` будет программно создавать и добавлять виджеты слотов в сетку на основе данных из `InventoryComponent`.
4.  **Управление Видимостью:** Логика открытия/закрытия инвентаря и переключения режимов ввода (UI/Game) будет находиться в `PlayerController`, так как именно он отвечает за управление вводом.

### **Подробная Реализация Шага**

#### **1. Создание Виджета для Одного Слота (`WBP_InventorySlot`)**

Это наш строительный кирпичик для UI.

1.  В **Content Browser**, в папке `Content/UI/Widgets`, создайте новый **Widget Blueprint**. Назовите его `WBP_InventorySlot`.
2.  **Откройте `WBP_InventorySlot` и соберите его иерархию:**
    *   Корневым элементом сделайте `Size Box`. В его настройках `Width Override` и `Height Override` установите одинаковое значение, например, `80`.
    *   Внутрь `Size Box` поместите `Overlay`.
    *   Внутрь `Overlay` поместите `Image`. Назовите его `IconImage`. В настройках `Brush` -> `Image` выберите любую временную иконку.
    *   Внутрь `Overlay` (после `Image`) поместите `Text`. Назовите его `QuantityText`.
        *   Выровняйте текст по правому нижнему углу (`Anchors` -> правый нижний, `Alignment` -> X=1, Y=1).
        *   В `Details` -> `Appearance` -> `Shadow Offset` установите X=1, Y=1, чтобы текст был более читаемым.
        *   В поле `Text` напишите "99".

    Ваша иерархия должна выглядеть так:
    `[Size Box] > [Overlay] > [IconImage]`
    `                     > [QuantityText]`

3.  **Создайте логику в графе `WBP_InventorySlot`:**
    *   Перейдите на вкладку **Graph**.
    *   Создайте новую функцию `UpdateSlot`, которая принимает на вход один параметр: `SlotData` типа `FInventorySlot`.
    *   **Внутри `UpdateSlot`:**
        *   Разверните `SlotData` (`Break FInventorySlot`).
        *   Проверьте, является ли `ItemData` валидным (`Is Valid`).
        *   **Если `ItemData` валиден:**
            *   Разверните `ItemData` (`Break ItemDataAsset`).
            *   Установите `Brush` для `IconImage` из `Icon`.
            *   Установите `Text` для `QuantityText` из `Quantity`.
            *   Сделайте `QuantityText` видимым (`Set Visibility` -> `Visible`).
        *   **Если `ItemData` НЕ валиден (пустой слот):**
            *   Установите `Brush` для `IconImage` на пустой или прозрачный цвет.
            *   Сделайте `QuantityText` скрытым (`Set Visibility` -> `Hidden`).

    

#### **2. Создание Виджета Сетки Инвентаря (`WBP_InventoryGrid`)**

Это основной контейнер.

1.  Создайте новый **Widget Blueprint** `WBP_InventoryGrid`.
2.  **Соберите иерархию:**
    *   Поместите на холст `Border` для фона.
    *   Внутрь `Border` поместите `Uniform Grid Panel`. Назовите ее `InventoryGridPanel`.

3.  **Реализуйте логику в графе `WBP_InventoryGrid`:**
    *   Создайте новую функцию `RefreshInventory`.
    *   **Внутри `RefreshInventory`:**
        *   Сначала очистите все старые слоты: `InventoryGridPanel` -> `Clear Children`.
        *   Получите `Owning Player Pawn` -> `Get Inventory Component`.
        *   Из `InventoryComponent` вызовите `Get Inventory Contents`.
        *   **Запустите цикл `For Each Loop`** по массиву `InventoryContents`.
        *   **Внутри цикла:**
            *   Создайте новый виджет `Create Widget` (выберите `WBP_InventorySlot`).
            *   Из созданного виджета вызовите его функцию `UpdateSlot`, передав в нее текущий элемент из цикла.
            *   Добавьте созданный виджет в сетку: `InventoryGridPanel` -> `Add Child to Uniform Grid`.
            *   Подключите пин `Index` из цикла к пинам `Row` и `Column` на ноде `Add Child`. Чтобы сетка была не в одну линию, используйте математику:
                *   `Row` = `Index` / `NumberOfColumns` (целочисленное деление).
                *   `Column` = `Index` % `NumberOfColumns` (остаток от деления).
                *   Создайте переменную `NumberOfColumns` (тип `Integer`) и задайте ей значение, например, `5`.

    *   **В событии `Event Construct`:**
        *   Вызовите вашу функцию `RefreshInventory`, чтобы инвентарь отрисовался при первом открытии.
        *   Получите `Owning Player Pawn` -> `Get Inventory Component`.
        *   Из `InventoryComponent` вытащите ноду **Bind Event to OnInventoryUpdated**.
        *   Подключите пин `Event` к вашей функции `RefreshInventory`.

    

#### **3. Управление Открытием/Закрытием Инвентаря**

Эту логику лучше всего разместить в `PlayerController`.

1.  **Создайте Input Action** `IA_ToggleInventory` (Digital, bool).
2.  **Привяжите его к клавише `I` или `Tab`** в `IMC_Default`.
3.  **Откройте `BP_PlayerController`:**
    *   **Сначала создайте сам виджет:**
        *   В графе `Event BeginPlay` (после `Add Mapping Context`) добавьте `Create Widget` (выберите `WBP_InventoryGrid`) и сохраните результат в новую переменную `InventoryWidgetRef`. **Не добавляйте его во вьюпорт здесь!**
    *   **Реализуйте логику переключения:**
        *   Создайте кастомное событие `ToggleInventory`.
        *   Внутри `ToggleInventory`:
            *   Проверьте, добавлен ли `InventoryWidgetRef` в `Viewport` (`Is in Viewport`).
            *   **Если да (инвентарь открыт):**
                *   Удалите его: `Remove from Parent`.
                *   Верните режим ввода в игру: `Set Input Mode Game Only`.
                *   Покажите курсор мыши: `Set Show Mouse Cursor` -> `false`.
            *   **Если нет (инвентарь закрыт):**
                *   Добавьте его: `Add to Viewport`.
                *   Установите режим ввода "игра и UI": `Set Input Mode Game and UI`.
                *   Скройте курсор мыши: `Set Show Mouse Cursor` -> `true`.
4.  **Свяжите ввод с логикой в `FF_Character` (или можно прямо в `PlayerController`, если хотите):**
    *   Проще всего сделать это в `FF_Character` для единообразия.
    *   Добавьте `IA_ToggleInventory` и функцию-обработчик `ToggleInventory` в `FF_Character.h/.cpp`.
    *   Внутри `AFF_Character::ToggleInventory()`:
        ```cpp
        void AFF_Character::ToggleInventory()
        {
            if (AFF_PlayerController* PC = Cast<AFF_PlayerController>(GetController()))
            {
                // Предполагается, что в BP_PlayerController есть событие ToggleInventory
                // Для вызова из C++ его нужно сделать функцией с флагом BlueprintImplementableEvent
                // PC->ToggleInventory(); // Это более сложный путь
            }
            // Простой путь для сейчас:
            // Просто вызовите Blueprint-ноду из C++ через интерфейс или каст.
            // Но еще проще - реализовать логику прямо в BP_PlayerController.
        }
        ```
    *   **Самый простой и наглядный способ для этого шага:** Реализовать обработку `IA_ToggleInventory` прямо в `BP_PlayerController`. Удалите привязку из C++ и добавьте ее в `BP_PlayerController`.

    *   **В `BP_PlayerController`:**
        *   Добавьте ноду `Input Action IA_ToggleInventory`.
        *   По событию `Started` вызовите ваше кастомное событие `ToggleInventory`.
