У нас есть ресурсы и инвентарь для их хранения. Теперь дадим игроку возможность превращать эти сырые материалы во что-то полезное. Мы создадим систему крафта, которая будет сердцем технологического прогресса в игре.

### **Шаг 4.3: Создание базового верстака и нескольких рецептов (простые инструменты, компоненты)**

**Задача:**
1.  **Создать Архитектуру Рецептов:** Разработать структуру данных для описания рецептов крафта (необходимые ингредиенты и получаемый результат).
2.  **Создать Верстак:** Реализовать интерактивный объект в мире (верстак), который будет служить "станцией" для крафта.
3.  **Создать UI Крафта:** Разработать интерфейс, который будет показывать доступные для крафта рецепты, их стоимость и кнопку "Создать".
4.  **Реализовать Логику Крафта:** Связать все вместе: игрок открывает UI верстака, выбирает рецепт, система проверяет наличие ресурсов в его инвентаре и, если все в порядке, забирает ингредиенты и выдает готовый предмет.

**Философия:**
1.  **Data-Driven Рецепты:** Как и предметы, рецепты будут `Data Assets`. Мы создадим `URecipeDataAsset`, и каждый конкретный рецепт (топор, стена) будет его экземпляром. Это позволяет легко добавлять и балансировать крафт.
2.  **Интерактивный Актор-Станция:** Верстак (`ACraftingStation`) будет актором в мире. Взаимодействие с ним будет открывать UI крафта. Разные станции в будущем смогут предоставлять доступ к разным наборам рецептов (химическая лаборатория, сборочный стол и т.д.).
3.  **Динамический UI:** UI крафта не будет содержать жестко прописанных рецептов. Он будет считывать список доступных рецептов с верстака и динамически генерировать для них строки в списке.
4.  **Серверная Авторизация Крафта:** Процесс крафта (проверка ресурсов, списание, выдача предмета) должен полностью происходить на сервере, чтобы избежать читерства. Клиент лишь отправляет запрос: "Я хочу скрафтить вот этот рецепт".

### **Подробная Реализация Шага**

#### **1. Создание Архитектуры Рецептов**

1.  **Создайте `URecipeDataAsset`:**
    *   В редакторе создайте C++ класс `RecipeDataAsset`, унаследованный от `UPrimaryDataAsset`.
    *   Поместите его в `FaunaLocus/GameplaySystems/CraftingSystem/`.

    *   **В `RecipeDataAsset.h`:**
        ```cpp
        // FaunaLocus/Source/FaunaLocus/GameplaySystems/CraftingSystem/RecipeDataAsset.h
        #pragma once
        
        #include "CoreMinimal.h"
        #include "Engine/DataAsset.h"
        #include "Core/FF_Types.h" // Нужен доступ к FInventorySlot
        #include "RecipeDataAsset.generated.h"
        
        UCLASS(BlueprintType)
        class FAUNALOCUS_API URecipeDataAsset : public UPrimaryDataAsset
        {
        	GENERATED_BODY()
        
        public:
        	// Ингредиенты, необходимые для крафта
        	UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category = "Recipe")
        	TArray<FInventorySlot> Ingredients;
        
        	// Предмет, который получается в результате
        	UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category = "Recipe")
        	FInventorySlot Output;
        };
        ```

2.  **Создайте `WBP_CraftingMenu`:**
    *   Это основной виджет.

        *   Получите ссылку на верстак, с которым взаимодействует игрок (это нужно будет передать при создании виджета).

        *   Внутри цикла:

#### **4. Реализация Логики Крафта**

Теперь свяжем UI с бэкендом.

1.  **Обновите `InventoryComponent`:**
    *   **В `InventoryComponent.h`:**
        ```cpp
        // ...
        public:
            // ... (AddItem, RemoveItem, HasItem)
        
            // Запрашивает у сервера создание предмета по рецепту.
            UFUNCTION(BlueprintCallable, Category = "Crafting")
            void CraftItem(URecipeDataAsset* Recipe);
        
        protected:
            UFUNCTION(Server, Reliable)
            void Server_CraftItem(URecipeDataAsset* Recipe);
        ```

    *   **В `InventoryComponent.cpp`:**
        ```cpp
        #include "GameplaySystems/CraftingSystem/RecipeDataAsset.h" // Инклюд для рецептов
        // ...
        
        void UInventoryComponent::CraftItem(URecipeDataAsset* Recipe)
        {
            if (!Recipe) return;
            Server_CraftItem(Recipe);
        }
        
        void UInventoryComponent::Server_CraftItem_Implementation(URecipeDataAsset* Recipe)
        {
            if (!Recipe) return;
        
            // Этап 1: Проверяем, есть ли у нас все ингредиенты
            bool bHasAllIngredients = true;
            for (const FInventorySlot& Ingredient : Recipe->Ingredients)
            {
                if (!HasItem(Ingredient.ItemData, Ingredient.Quantity))
                {
                    bHasAllIngredients = false;
                    break;
                }
            }
        
            // Этап 2: Если есть, списываем их
            if (bHasAllIngredients)
            {
                for (const FInventorySlot& Ingredient : Recipe->Ingredients)
                {
                    RemoveItem(Ingredient.ItemData, Ingredient.Quantity);
                }
        
                // Этап 3: Добавляем результат
                AddItem(Recipe->Output.ItemData, Recipe->Output.Quantity);
            }
        }
        ```
