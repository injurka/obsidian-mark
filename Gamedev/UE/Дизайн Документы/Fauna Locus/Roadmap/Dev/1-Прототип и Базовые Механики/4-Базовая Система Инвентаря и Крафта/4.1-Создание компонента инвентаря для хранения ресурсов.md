### **Шаг 4.1: Создание компонента инвентаря для хранения ресурсов (Финализация)**

**Задача:** Превратить наш черновой `InventoryComponent` в полноценную, многоразовую и готовую к работе в сети систему. Мы реализуем более умную логику добавления/удаления предметов (с учетом стаков), обеспечим надежную репликацию и подготовим делегаты для будущего UI.

**Философия:**
1.  **Компонентная Независимость:** `UInventoryComponent` должен быть полностью самодостаточным. Его можно будет прикрепить не только к игроку, но и к сундукам, ящикам или любому другому актору, которому нужен инвентарь.
2.  **Серверная Власть:** Только сервер имеет право изменять содержимое инвентаря. Клиенты лишь отправляют запросы и получают обновления. Это золотой стандарт для сетевых игр.
3.  **Эффективное Обновление UI:** Мы будем использовать делегат `OnInventoryUpdated`. Любой виджет (например, сетка инвентаря) подпишется на него один раз и будет автоматически обновляться только тогда, когда в инвентаре произошли реальные изменения.
4.  **Умное Стаканье:** Предметы должны автоматически складываться в существующие неполные стаки, прежде чем занимать новый слот.

2.  **Откройте `InventoryComponent.cpp`:** Здесь мы реализуем умную логику.

    ```cpp
    // FaunaLocus/Source/FaunaLocus/GameplaySystems/InventorySystem/InventoryComponent.cpp
    
    #include "GameplaySystems/InventorySystem/InventoryComponent.h"
    #include "GameplaySystems/InventorySystem/ItemDataAsset.h"
    #include "Net/UnrealNetwork.h"
    
    UInventoryComponent::UInventoryComponent()
    {
        PrimaryComponentTick.bCanEverTick = false;
        SetIsReplicatedByDefault(true);
    }
    
    // Функция добавления предмета с умным стаканьем
    bool UInventoryComponent::AddItem(UItemDataAsset* ItemData, int32 Quantity)
    {
        if (!GetOwner()->HasAuthority() || !ItemData || Quantity <= 0) return false;
    
        int32 QuantityToAdd = Quantity;
    
        // Этап 1: Пытаемся добавить в существующие стаки
        for (FInventorySlot& Slot : InventoryContents)
        {
            if (Slot.ItemData == ItemData && Slot.Quantity < ItemData->MaxStackSize)
            {
                int32 CanAdd = ItemData->MaxStackSize - Slot.Quantity;
                int32 AmountToAddHere = FMath::Min(QuantityToAdd, CanAdd);
    
                Slot.Quantity += AmountToAddHere;
                QuantityToAdd -= AmountToAddHere;
    
                if (QuantityToAdd <= 0) break;
            }
        }
    
        // Этап 2: Если что-то осталось, ищем пустые слоты
        if (QuantityToAdd > 0)
        {
            while (QuantityToAdd > 0 && InventoryContents.Num() < InventorySize)
            {
                FInventorySlot NewSlot;
                NewSlot.ItemData = ItemData;
                int32 AmountToAddHere = FMath::Min(QuantityToAdd, ItemData->MaxStackSize);
                
                NewSlot.Quantity = AmountToAddHere;
                InventoryContents.Add(NewSlot);
                QuantityToAdd -= AmountToAddHere;
            }
        }
    
        // Если мы смогли добавить хотя бы часть предметов, считаем операцию успешной
        if (QuantityToAdd < Quantity)
        {
            OnInventoryUpdated.Broadcast();
            return true;
        }
    
        return false;
    }
    
    // Функция удаления, способная удалять из нескольких стаков
    bool UInventoryComponent::RemoveItem(UItemDataAsset* ItemData, int32 Quantity)
    {
        if (!GetOwner()->HasAuthority() || !ItemData || Quantity <= 0 || !HasItem(ItemData, Quantity))
        {
            return false;
        }
    
        int32 QuantityToRemove = Quantity;
    
        // Итерируем в обратном порядке, чтобы безопасно удалять пустые слоты
        for (int32 i = InventoryContents.Num() - 1; i >= 0; --i)
        {
            FInventorySlot& Slot = InventoryContents[i];
    
            if (Slot.ItemData == ItemData)
            {
                int32 AmountToRemoveFromSlot = FMath::Min(QuantityToRemove, Slot.Quantity);
                Slot.Quantity -= AmountToRemoveFromSlot;
                QuantityToRemove -= AmountToRemoveFromSlot;
    
                if (Slot.Quantity <= 0)
                {
                    InventoryContents.RemoveAt(i);
                }
    
                if (QuantityToRemove <= 0) break;
            }
        }
    
        OnInventoryUpdated.Broadcast();
        return true;
    }
    
    // ... (HasItem, OnRep_InventoryContents, GetLifetimeReplicatedProps остаются без изменений)
    ```
