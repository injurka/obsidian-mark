### **Шаг 3.1: Создание механики размещения объектов (фундаменты, стены) на неровной поверхности без ее изменения**

**Задача:** Реализовать систему, которая позволяет игроку выбирать строительный элемент, видеть его "призрачный" предпросмотр в мире и размещать его по клику мыши. Эта система должна строго следовать правилу "нулевого терраформинга": объекты должны прилипать к существующему ландшафту и другим строениям, а не выравнивать его.

**Философия:**
1.  **Компонентный Подход:** Всю логику строительства мы вынесем в `UBuildingComponent`, который мы уже запланировали. Он будет управлять текущим выбранным элементом, логикой предпросмотра и запросами на строительство.
2.  **Предпросмотр (Ghost Mesh):** Для визуализации мы будем создавать временный "призрачный" актор (`Ghost Actor`), который следует за взглядом игрока. Его материал будет полупрозрачным и будет менять цвет в зависимости от того, можно ли строить в данном месте (зеленый) или нет (красный).
3.  **Трассировка и Привязка (Line Trace & Snapping):**
    *   `BuildingComponent` будет постоянно пускать луч из камеры, чтобы определить точку в мире, куда смотрит игрок.
    *   Если луч попадает в ландшафт, "призрак" будет выравниваться по нормали поверхности.
    *   Если луч попадает в другой строительный элемент, система попытается "привязаться" к специальным точкам привязки (Snap Points). Это позволит легко строить ровные стены и полы.
4.  **Серверная Авторизация:** Фактическое создание объекта (`SpawnActor`) должно происходить на сервере, даже в синглплеере. Клиент лишь отправляет запрос "Я хочу построить вот это здесь". Это стандартная практика для предотвращения читерства и обеспечения синхронизации в будущем мультиплеере.
5.  **Архитектура Строительных Элементов:** Мы создадим базовый C++ класс `ABuildingPieceBase` для всех строительных элементов. У него будут точки привязки и логика для проверки возможности строительства.

### **Подробная Реализация Шага**

#### **1. Создание Базового Класса Строительного Элемента**

1.  Создайте новый C++ класс `BuildingPieceBase`, унаследованный от `AActor`. Поместите его в `FaunaLocus/World/Building/`.
2.  **Откройте `BuildingPieceBase.h`:**

    ```cpp
    // FaunaLocus/Source/FaunaLocus/World/Building/BuildingPieceBase.h
    
    #pragma once
    
    #include "CoreMinimal.h"
    #include "GameFramework/Actor.h"
    #include "BuildingPieceBase.generated.h"
    
    class UStaticMeshComponent;
    
    UCLASS()
    class FAUNALOCUS_API ABuildingPieceBase : public AActor
    {
    	GENERATED_BODY()
    	
    public:	
    	ABuildingPieceBase();
    
    	// Основной меш строительного блока
    	UPROPERTY(VisibleAnywhere, BlueprintReadOnly, Category = "Components")
    	TObjectPtr<UStaticMeshComponent> MeshComponent;
    
    	// Функция для проверки, можно ли разместить этот блок в данном месте
    	UFUNCTION(BlueprintNativeEvent, BlueprintCallable, Category = "Building")
    	bool CanBePlaced();
    	virtual bool CanBePlaced_Implementation();
    
    	// Функция для установки материала предпросмотра (зеленый/красный)
    	UFUNCTION(BlueprintCallable, Category = "Building")
    	void SetPlacementMaterial(bool bCanBePlaced);
    
    protected:
    	// Материал, который будет использоваться, когда размещение возможно
    	UPROPERTY(EditDefaultsOnly, Category = "Building")
    	TObjectPtr<UMaterialInterface> AllowedPlacementMaterial;
    
    	// Материал, который будет использоваться, когда размещение невозможно
    	UPROPERTY(EditDefaultsOnly, Category = "Building")
    	TObjectPtr<UMaterialInterface> DisallowedPlacementMaterial;
    };
    ```

3.  **Откройте `BuildingPieceBase.cpp`:**

    ```cpp
    // FaunaLocus/Source/FaunaLocus/World/Building/BuildingPieceBase.cpp
    
    #include "World/Building/BuildingPieceBase.h"
    #include "Components/StaticMeshComponent.h"
    
    ABuildingPieceBase::ABuildingPieceBase()
    {
    	PrimaryActorTick.bCanEverTick = false; // Строительные блоки не должны тикать после постройки
    
    	MeshComponent = CreateDefaultSubobject<UStaticMeshComponent>(TEXT("MeshComponent"));
    	RootComponent = MeshComponent;
    
    	// Включаем репликацию для актора, чтобы он появлялся у всех игроков
    	bReplicates = true;
    }
    
    bool ABuildingPieceBase::CanBePlaced_Implementation()
    {
    	// TODO: Добавить логику проверки на коллизии с другими объектами
    	return true; // Пока что всегда можно строить
    }
    
    void ABuildingPieceBase::SetPlacementMaterial(bool bCanBePlaced)
    {
    	if (bCanBePlaced)
    	{
    		MeshComponent->SetMaterial(0, AllowedPlacementMaterial);
    	}
    	else
    	{
    		MeshComponent->SetMaterial(0, DisallowedPlacementMaterial);
    	}
    }
    ```

#### **2. Реализация `BuildingComponent`**

Это мозг нашей системы.

1.  Создайте новый C++ класс `BuildingComponent`, унаследованный от `UActorComponent`. Поместите его в `FaunaLocus/Character/Components/`.
2.  **Откройте `BuildingComponent.h`:**

    ```cpp
    // FaunaLocus/Source/FaunaLocus/Character/Components/BuildingComponent.h
    
    #pragma once
    
    #include "CoreMinimal.h"
    #include "Components/ActorComponent.h"
    #include "BuildingComponent.generated.h"
    
    class ABuildingPieceBase;
    
    UCLASS( ClassGroup=(Custom), meta=(BlueprintSpawnableComponent) )
    class FAUNALOCUS_API UBuildingComponent : public UActorComponent
    {
    	GENERATED_BODY()
    
    public:	
    	UBuildingComponent();
    	virtual void TickComponent(float DeltaTime, ELevelTick TickType, FActorComponentTickFunction* ThisTickFunction) override;
    
    	// Вызывается для начала режима строительства
    	UFUNCTION(BlueprintCallable, Category = "Building")
    	void EnterBuildMode(TSubclassOf<ABuildingPieceBase> BuildingPieceClass);
    
    	// Вызывается для выхода из режима строительства
    	UFUNCTION(BlueprintCallable, Category = "Building")
    	void ExitBuildMode();
    
    	// Вызывается для попытки разместить объект
    	void PlaceBuildingPiece();
    
    protected:
    	// --- Логика на стороне сервера ---
    	UFUNCTION(Server, Reliable)
    	void Server_PlaceBuildingPiece(TSubclassOf<ABuildingPieceBase> ClassToSpawn, FTransform SpawnTransform);
    
    	// --- Логика на стороне клиента ---
    	void UpdateGhostPreview();
    
    	// Как далеко можно строить
    	UPROPERTY(EditDefaultsOnly, Category = "Building")
    	float BuildDistance = 800.0f;
    
    	bool bIsInBuildMode = false;
    
    	// Текущий "призрачный" объект предпросмотра
    	UPROPERTY()
    	TObjectPtr<ABuildingPieceBase> GhostBuildingPiece;
    
    	// Класс объекта, который мы сейчас строим
    	TSubclassOf<ABuildingPieceBase> CurrentBuildingPieceClass;
    };
    ```

3.  **Откройте `BuildingComponent.cpp`:**

    ```cpp
    // FaunaLocus/Source/FaunaLocus/Character/Components/BuildingComponent.cpp
    
    #include "Character/Components/BuildingComponent.h"
    #include "World/Building/BuildingPieceBase.h"
    #include "GameFramework/PlayerController.h"
    #include "Engine/World.h"
    
    UBuildingComponent::UBuildingComponent()
    {
    	PrimaryComponentTick.bCanEverTick = true;
    	SetIsReplicatedByDefault(true); // Компонент должен существовать на сервере
    }
    
    void UBuildingComponent::TickComponent(float DeltaTime, ELevelTick TickType, FActorComponentTickFunction* ThisTickFunction)
    {
    	Super::TickComponent(DeltaTime, TickType, ThisTickFunction);
    
    	if (bIsInBuildMode)
    	{
    		UpdateGhostPreview();
    	}
    }
    
    void UBuildingComponent::EnterBuildMode(TSubclassOf<ABuildingPieceBase> BuildingPieceClass)
    {
    	if (!BuildingPieceClass) return;
    
    	bIsInBuildMode = true;
    	CurrentBuildingPieceClass = BuildingPieceClass;
    
    	// Создаем "призрака" только на клиенте, который строит
    	if (GetOwner()->HasNetClientRole())
    	{
    		FActorSpawnParameters SpawnParams;
    		SpawnParams.SpawnCollisionHandlingOverride = ESpawnActorCollisionHandlingMethod::AlwaysSpawn;
    		GhostBuildingPiece = GetWorld()->SpawnActor<ABuildingPieceBase>(CurrentBuildingPieceClass, FTransform(), SpawnParams);
    	}
    }
    
    void UBuildingComponent::ExitBuildMode()
    {
    	bIsInBuildMode = false;
    	if (GhostBuildingPiece)
    	{
    		GhostBuildingPiece->Destroy();
    		GhostBuildingPiece = nullptr;
    	}
    }
    
    void UBuildingComponent::PlaceBuildingPiece()
    {
    	if (bIsInBuildMode && GhostBuildingPiece && GhostBuildingPiece->CanBePlaced())
    	{
    		// Отправляем запрос на сервер
    		Server_PlaceBuildingPiece(CurrentBuildingPieceClass, GhostBuildingPiece->GetActorTransform());
    	}
    }
    
    void UBuildingComponent::Server_PlaceBuildingPiece_Implementation(TSubclassOf<ABuildingPieceBase> ClassToSpawn, FTransform SpawnTransform)
    {
    	if (ClassToSpawn)
    	{
    		FActorSpawnParameters SpawnParams;
    		SpawnParams.SpawnCollisionHandlingOverride = ESpawnActorCollisionHandlingMethod::AdjustIfPossibleButAlwaysSpawn;
    		GetWorld()->SpawnActor<ABuildingPieceBase>(ClassToSpawn, SpawnTransform, SpawnParams);
    	}
    }
    
    void UBuildingComponent::UpdateGhostPreview()
    {
    	if (!GhostBuildingPiece) return;
    
    	FHitResult HitResult;
    	FVector Start;
    	FRotator ViewRotation;
    
    	APlayerController* PC = Cast<APlayerController>(GetOwner()->GetInstigatorController());
    	if (!PC) return;
    
    	PC->GetPlayerViewPoint(Start, ViewRotation);
    	FVector End = Start + ViewRotation.Vector() * BuildDistance;
    
    	FCollisionQueryParams QueryParams;
    	QueryParams.AddIgnoredActor(GetOwner());
    	QueryParams.AddIgnoredActor(GhostBuildingPiece);
    
    	if (GetWorld()->LineTraceSingleByChannel(HitResult, Start, End, ECC_Visibility, QueryParams))
    	{
    		// Создаем новую трансформацию, выравнивая по нормали поверхности
    		FTransform GhostTransform;
    		// TODO: Добавить логику привязки (snapping)
    		FRotator AlignedRotation = FRotationMatrix::MakeFromZ(HitResult.ImpactNormal).Rotator();
    		GhostTransform.SetLocation(HitResult.Location);
    		GhostTransform.SetRotation(AlignedRotation.Quaternion());
    
    		GhostBuildingPiece->SetActorTransform(GhostTransform);
    
    		// Проверяем, можно ли здесь строить, и обновляем материал
    		const bool bCanBePlaced = GhostBuildingPiece->CanBePlaced();
    		GhostBuildingPiece->SetPlacementMaterial(bCanBePlaced);
    	}
    }
    ```

#### **3. Интеграция в `FF_Character` и Управление**

1.  **Интегрируйте `BuildingComponent` в `FF_Character`** (раскомментируйте в `.h` и `.cpp`).
2.  **Создайте Input Actions:**
    *   `IA_PlaceBuilding` (Digital, bool)
    *   `IA_BuildMode_Foundation` (Digital, bool) - для выбора фундамента
    *   `IA_BuildMode_Wall` (Digital, bool) - для выбора стены
3.  **Привяжите их к клавишам в `IMC_Default`:**
    *   `IA_PlaceBuilding` -> `Левая кнопка мыши`
    *   `IA_BuildMode_Foundation` -> `1`
    *   `IA_BuildMode_Wall` -> `2`
4.  **Обновите `FF_Character`:**

    *   **В `FF_Character.h`:**
        ```cpp
        // ...
        protected:
            // ... (ссылки на новые IA)
            TObjectPtr<class UInputAction> PlaceBuildingAction;
            TObjectPtr<class UInputAction> SelectFoundationAction;
            // ...
        
            // ... (объявления функций)
            void PlaceBuilding();
            void SelectFoundation();
            // ...
        
            // --- Переменные для строительства ---
            // Здесь мы будем хранить классы наших строительных блоков, которые можно будет задать в Blueprint.
            UPROPERTY(EditDefaultsOnly, Category = "Building")
            TSubclassOf<ABuildingPieceBase> FoundationClass;
        
            UPROPERTY(EditDefaultsOnly, Category = "Building")
            TSubclassOf<ABuildingPieceBase> WallClass;
        ```
    *   **В `FF_Character.cpp` (в `SetupPlayerInputComponent`):**
        ```cpp
        EnhancedInputComponent->BindAction(PlaceBuildingAction, ETriggerEvent::Started, this, &AFF_Character::PlaceBuilding);
        EnhancedInputComponent->BindAction(SelectFoundationAction, ETriggerEvent::Started, this, &AFF_Character::SelectFoundation);
        ```
    *   **Реализуйте новые функции в `FF_Character.cpp`:**
        ```cpp
        void AFF_Character::PlaceBuilding()
        {
            if (BuildingComponent)
            {
                BuildingComponent->PlaceBuildingPiece();
            }
        }
        
        void AFF_Character::SelectFoundation()
        {
            if (BuildingComponent && FoundationClass)
            {
                BuildingComponent->EnterBuildMode(FoundationClass);
            }
        }
        // Аналогично для SelectWall и т.д.
        ```

#### **4. Настройка в Blueprint**

1.  **Скомпилируйте код.**
2.  **Создайте материалы предпросмотра:**
    *   В `Content/Art/Materials/` создайте два простых материала: `M_Placement_Allowed` (полупрозрачный зеленый) и `M_Placement_Disallowed` (полупрозрачный красный). Убедитесь, что в их настройках `Blend Mode` стоит `Translucent`.
3.  **Создайте BP-наследников строительных блоков:**
    *   В `Content/Blueprints/World/Building/` создайте `BP_Foundation` (наследник `BuildingPieceBase`).
    *   Откройте `BP_Foundation`. В `MeshComponent` выберите меш фундамента (например, куб).
    *   В **Class Defaults** назначьте ваши материалы `M_Placement_Allowed` и `M_Placement_Disallowed`.
4.  **Настройте `BP_Character`:**
    *   Назначьте все новые Input Actions в **Class Defaults**.
    *   В поле **Foundation Class** выберите ваш `BP_Foundation`.
