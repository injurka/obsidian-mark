### **Шаг 3: Реализация инструментов "Генетический Сборщик" и "Ботанический Анализатор"**

**Задача:**
1.  **Создать "Генетический Сборщик":** Инструмент, который при использовании на диком растении (`AFloraBase`) будет давать игроку предмет-семена.
2.  **Создать "Ботанический Анализатор":** Интерактивная станция (актор), в которую можно поместить семена для получения подробной информации о растении (его потребности, время роста и т.д.).
3.  **Разработать UI Анализатора:** Интерфейс, который будет наглядно отображать данные из `FloraDataAsset` анализируемого растения.

**Философия:**
1.  **Инструменты как Предметы:** "Генетический Сборщик" будет обычным предметом (`ItemDataAsset`) в инвентаре. В будущем мы добавим систему экипировки, но пока будем считать, что если он есть в инвентаре, им можно пользоваться.
2.  **Анализатор как Станция:** "Ботанический Анализатор" будет стационарным объектом, как и верстак. Это создает необходимость вернуться на базу для изучения находок, укрепляя цикл "исследование -> анализ -> применение".
3.  **Контекстное Взаимодействие:** Мы расширим наш `InteractionComponent` для определения, что игрок смотрит на дикое растение, и будем вызывать соответствующую логику сбора.
4.  **UI как Окно в Данные:** UI Анализатора не будет содержать никакой логики, кроме отображения. Он будет просто считывать данные из `FloraDataAsset`, связанного с помещенными в него семенами.
