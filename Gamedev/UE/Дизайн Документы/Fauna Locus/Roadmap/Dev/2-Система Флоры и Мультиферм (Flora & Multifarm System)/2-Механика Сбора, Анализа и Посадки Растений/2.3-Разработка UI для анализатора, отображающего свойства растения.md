Мы научились собирать семена, но пока они — "кот в мешке". Игрок не знает, что с ними делать. Сейчас мы создадим интерфейс для "Ботанического Анализатора", который прольет свет на тайны собранных образцов и даст игроку всю необходимую информацию для их культивации.

### **Шаг 4: Разработка UI для анализатора, отображающего свойства растения**

**Задача:**
1.  **Создать UI-макет:** Разработать визуальную структуру виджета для анализатора, включающую слот для предмета и панель с подробной информацией о растении.
2.  **Динамическое Отображение:** Реализовать логику, которая считывает данные из `FloraDataAsset` (связанного с помещенными семенами) и динамически заполняет текстовые поля и иконки в UI.
3.  **Интерактивность:** Позволить игроку "переместить" семена из своего инвентаря в слот анализатора.
4.  **Обратная Связь:** UI должен четко показывать текущее состояние: пустой слот, анализ в процессе (в будущем), отображение результатов.

**Философия:**
1.  **UI — это просто Вид:** Виджет `WBP_AnalyzerMenu` не должен содержать сложной логики. Его единственная задача — отображать состояние актора `BP_BotanicalAnalyzer`. Все изменения (помещение семян в слот) происходят в акторе, а виджет лишь реагирует на эти изменения.
2.  **Двусторонняя Связь:**
    *   **Игрок -> UI -> Актор:** Игрок кликает на слот в своем инвентаре в UI. UI сообщает об этом актору `BP_BotanicalAnalyzer`.
    *   **Актор -> UI:** Актор `BP_BotanicalAnalyzer` изменяет свое состояние (в его `AnalysisSlot` появляются семена). Это изменение автоматически (через делегаты или RepNotify) вызывает обновление UI, который перерисовывает панель информации.
3.  **Переиспользование Компонентов:** Мы будем использовать уже созданные нами виджеты `WBP_InventoryGrid` и `WBP_InventorySlot` для отображения инвентаря игрока внутри меню анализатора. Это экономит время и обеспечивает единообразие стиля.

### **Подробная Реализация Шага**

Этот шаг в основном происходит в редакторе Unreal Engine, в UMG (Unreal Motion Graphics).

#### **1. Улучшение `ABotanicalAnalyzer` для работы с UI**

Нам нужно, чтобы наш актор мог сообщать UI о своих изменениях.

1.  **Откройте `BotanicalAnalyzer.h`:**
    *   Мы сделаем переменную `AnalysisSlot` реплицируемой с уведомлением (`RepNotify`). Это означает, что каждый раз, когда она меняется на сервере, на всех клиентах будет автоматически вызываться специальная функция. Это идеальный механизм для обновления UI.

    ```cpp

    {
    	GENERATED_BODY()
    public:
    	// ...
        // Делаем его реплицируемым с функцией-уведомлением OnRep_AnalysisSlot
    	UPROPERTY(VisibleAnywhere, BlueprintReadOnly, ReplicatedUsing=OnRep_AnalysisSlot, Category = "Analyzer")
    	FInventorySlot AnalysisSlot;
    
    	UPROPERTY(BlueprintAssignable, Category = "Analyzer")
    	FOnAnalysisSlotUpdated OnAnalysisSlotUpdated;
    
    	// Помещает предмет из инвентаря игрока в слот анализа
    	UFUNCTION(BlueprintCallable, Category = "Analyzer")
    	void PlaceItemInAnalyzer(UInventoryComponent* PlayerInventory, int32 SlotIndex);
    
    protected:
    	UFUNCTION(Server, Reliable)
    	void Server_PlaceItemInAnalyzer(UInventoryComponent* PlayerInventory, int32 SlotIndex);
    
    	UFUNCTION()
    	void OnRep_AnalysisSlot();
    
    	virtual void GetLifetimeReplicatedProps(TArray<FLifetimeProperty>& OutLifetimeProps) const override;
    
    	// Реализация интерфейса
    	virtual void OnInteract_Implementation(AActor* InteractingActor) override;
    };
    ```

    void ABotanicalAnalyzer::PlaceItemInAnalyzer(UInventoryComponent* PlayerInventory, int32 SlotIndex)
    {
    	// Запрос от клиента к серверу
    	Server_PlaceItemInAnalyzer(PlayerInventory, SlotIndex);
    }
    
    void ABotanicalAnalyzer::Server_PlaceItemInAnalyzer_Implementation(UInventoryComponent* PlayerInventory, int32 SlotIndex)
    {
    	if (!PlayerInventory || !PlayerInventory->GetInventoryContents().IsValidIndex(SlotIndex)) return;
    
    	// Если в анализаторе уже что-то есть, возвращаем это игроку
    	if (AnalysisSlot.ItemData)
    	{
    		PlayerInventory->AddItem(AnalysisSlot.ItemData, AnalysisSlot.Quantity);
    		AnalysisSlot.ItemData = nullptr;
    		AnalysisSlot.Quantity = 0;
    	}
    
    	const FInventorySlot& PlayerSlot = PlayerInventory->GetInventoryContents()[SlotIndex];
    	
    	// Проверяем, что это семена
    	if (PlayerSlot.ItemData && PlayerSlot.ItemData->FloraToPlant)
    	{
    		// Перемещаем один предмет
    		AnalysisSlot.ItemData = PlayerSlot.ItemData;
    		AnalysisSlot.Quantity = 1;
    		PlayerInventory->RemoveItem(PlayerSlot.ItemData, 1);
    		
    		// Вызываем OnRep вручную на сервере, т.к. он сам не вызывается
    		OnRep_AnalysisSlot(); 
    	}
    }
    
    void ABotanicalAnalyzer::OnRep_AnalysisSlot()
    {
    	// Транслируем событие, на которое подпишется наш UI
    	OnAnalysisSlotUpdated.Broadcast();
    }

                // передав в нее ссылку на себя (this)
            }
        }
    }
    
    void ABotanicalAnalyzer::GetLifetimeReplicatedProps(TArray<FLifetimeProperty>& OutLifetimeProps) const
    {
    	Super::GetLifetimeReplicatedProps(OutLifetimeProps);
    	DOREPLIFETIME(ABotanicalAnalyzer, AnalysisSlot);
