Мы уже наметили эту логику в предыдущем шаге, а теперь реализуем ее чисто, надежно и с заделом на будущее.

### **Шаг 4: Создание логики сбора образцов с диких растений**

**Задача:** Реализовать полный и завершенный цикл: игрок, имея в инвентаре специальный инструмент, подходит к дикому растению, взаимодействует с ним и получает в свой инвентарь соответствующий предмет-семена.

**Философия:**
1.  **Интерфейсы для Взаимодействия (`IInteractableInterface`):** Вместо того чтобы перегружать `InteractionComponent` кучей `Cast To...` для каждого типа объекта, мы будем использовать интерфейсы. Мы создадим C++ интерфейс `IInteractableInterface`, который будет иметь одну функцию, например, `OnInteract(AActor* InteractingActor)`. Любой объект, с которым можно взаимодействовать (растение, верстак, анализатор), будет реализовывать этот интерфейс. `InteractionComponent` будет просто проверять: "Есть ли у этого объекта интерфейс? Если да, вызываю его функцию `OnInteract`". Это невероятно гибкий и расширяемый подход.
2.  **Серверная Логика Сбора:** Фактическая выдача предмета должна происходить на сервере. Клиент лишь инициирует взаимодействие. Это предотвращает читерство (например, бесконечный сбор ресурсов путем отправки множества пакетов).
3.  **Четкая Обратная Связь:** Игрок должен понимать, почему он не может собрать образец. Мы добавим базовую систему оповещений (пока что в виде логов), которая скажет ему, например, "Требуется Генетический Сборщик".
4.  **Состояние Растения:** В будущем дикие растения могут быть "истощены" после сбора. Мы заложим основу для этой механики, чтобы предотвратить бесконечный сбор с одного и того же куста.

### **Подробная Реализация Шага**

#### **1. Создание Интерфейса Взаимодействия (`IInteractableInterface`)**

Это самый важный шаг для создания чистой архитектуры.

1.  В редакторе Unreal Engine выберите **Tools -> New C++ Class...**.
2.  В окне выбора родительского класса внизу справа нажмите **All Classes** и найдите в поиске **Unreal Interface**.
3.  Назовите его `InteractableInterface`. Поместите в папку `FaunaLocus/Core/Interfaces/`.
4.  **Откройте `InteractableInterface.h`:**
    *   Unreal создаст два файла: `InteractableInterface.h` и `InteractableInterface.cpp`. Файл `.cpp` нам не понадобится, можно его даже удалить. Вся магия происходит в `.h`.
    *   Отредактируйте файл так:

    ```cpp
    // FaunaLocus/Source/FaunaLocus/Core/Interfaces/InteractableInterface.h
    
    #pragma once
    
    #include "CoreMinimal.h"
    #include "UObject/Interface.h"
    #include "InteractableInterface.generated.h"
    
    // Этот класс не должен изменяться.
    UINTERFACE(MinimalAPI)
    class UInteractableInterface : public UInterface
    {
    	GENERATED_BODY()
    };
    
    /**
     * Интерфейс для всех акторов, с которыми может взаимодействовать игрок.
     */
    class FAUNALOCUS_API IInteractableInterface
    {
    	GENERATED_BODY()
    
    public:
    	// Функция, которая вызывается, когда игрок взаимодействует с объектом.
    	// Должна быть реализована в классах, наследующих этот интерфейс.
    	// BlueprintNativeEvent означает, что у нее может быть базовая C++ реализация и ее можно переопределить в Blueprint.
    	UFUNCTION(BlueprintNativeEvent, BlueprintCallable, Category = "Interaction")
    	void OnInteract(AActor* InteractingActor);
    
    	// Функция для получения текста подсказки (например, "Press E to Sample")
    	UFUNCTION(BlueprintNativeEvent, BlueprintCallable, Category = "Interaction")
    	FText GetInteractionTooltip();
    };
    ```

#### **2. Реализация Интерфейса в `AFloraBase`**

Теперь научим наши растения "отвечать" на взаимодействие.

1.  **Откройте `FloraBase.h`:**
    *   Добавьте `#include` для интерфейса и унаследуйте его.

    ```cpp
    // FaunaLocus/Source/FaunaLocus/World/Flora/FloraBase.h
    
    #pragma once
    
    #include "CoreMinimal.h"
    #include "GameFramework/Actor.h"

    #include "FloraBase.generated.h"
    
    // ...
    
    UCLASS()
    class FAUNALOCUS_API AFloraBase : public AActor, public IInteractableInterface // Добавляем наследование
    {
    	GENERATED_BODY()
    	
    public:	
    	AFloraBase();

    	// ... (существующий код)
    ```

2.  **Откройте `FloraBase.cpp`:**
    *   Реализуйте логику сбора.

    ```cpp
    // FaunaLocus/Source/FaunaLocus/World/Flora/FloraBase.cpp
    
    #include "World/Flora/FloraBase.h"
    #include "GameplaySystems/FloraSystem/FloraDataAsset.h"
    #include "GameplaySystems/InventorySystem/ItemDataAsset.h"
    #include "GameplaySystems/InventorySystem/InventoryComponent.h"
    #include "Character/FF_Character.h"
    #include "Net/UnrealNetwork.h"
    
    // ... (конструктор и OnConstruction)
    
    void AFloraBase::OnInteract_Implementation(AActor* InteractingActor)
    {
    	if (HasAuthority() && !bHasBeenSampled) // Логика выполняется на сервере и только если еще не собирали
    	{
    		AFF_Character* PlayerCharacter = Cast<AFF_Character>(InteractingActor);
    		if (!PlayerCharacter) return;
    
    		UInventoryComponent* Inventory = PlayerCharacter->FindComponentByClass<UInventoryComponent>();
    		if (!Inventory) return;
    
    		// TODO: Проверить, есть ли у игрока нужный инструмент.
    		// Пока что пропускаем для простоты теста.
    
    		if (FloraData && FloraData->SeedItem)
    		{
    			if (Inventory->AddItem(FloraData->SeedItem, FloraData->SeedYield))
    			{
    				// Если предмет успешно добавлен
    				bHasBeenSampled = true;
    				// TODO: Можно запустить таймер восстановления или изменить внешний вид растения
    			}
    		}
    	}
    }
    
    FText AFloraBase::GetInteractionTooltip_Implementation()
    {
    	if (bHasBeenSampled)
    	{
    		return FText::FromString("Already Sampled");
    	}
    	if (FloraData)
    	{
    		return FText::Format(FText::FromString("Press E to sample {0}"), FloraData->PlantName);
    	}
    	return FText();
    }
    
    void AFloraBase::GetLifetimeReplicatedProps(TArray<FLifetimeProperty>& OutLifetimeProps) const
    {
    	Super::GetLifetimeReplicatedProps(OutLifetimeProps);
    	DOREPLIFETIME(AFloraBase, bHasBeenSampled);
    }
    ```

#### **3. Переработка `InteractionComponent` для Использования Интерфейса**

Теперь упростим наш компонент взаимодействия.

1.  **Откройте `InteractionComponent.h`:**
    *   Уберем все лишние переменные (`bIsLookingAtWater`, `bIsLookingAtFlora` и т.д.) и оставим одну универсальную.

    ```cpp
    // ...
    protected:
        // ... (InteractionDistance)
    
        // Текущий объект, на который мы смотрим и с которым можем взаимодействовать
        UPROPERTY()
        TObjectPtr<AActor> FocusedActor;
    };
    ```

2.  **Откройте `InteractionComponent.cpp`:**
    *   Перепишем `TickComponent` и `PerformInteraction`.

    ```cpp
    // ...
    #include "Core/Interfaces/InteractableInterface.h"
    
    void UInteractionComponent::TickComponent(float DeltaTime, ELevelTick TickType, FActorComponentTickFunction* ThisTickFunction)
    {
    	Super::TickComponent(DeltaTime, TickType, ThisTickFunction);
    
    	FHitResult HitResult;
    	// ... (получение Start и End, как и раньше)
    
    	AActor* NewFocusedActor = nullptr;
    
    	if (GetWorld()->LineTraceSingleByChannel(HitResult, Start, End, ECC_Visibility, QueryParams))
    	{
    		AActor* HitActor = HitResult.GetActor();
    		// Проверяем, реализует ли актор наш интерфейс
    		if (HitActor && HitActor->Implements<UInteractableInterface>())
    		{
    			NewFocusedActor = HitActor;
    		}
    	}
    
    	if (NewFocusedActor != FocusedActor)
    	{
    		// TODO: Вызвать делегаты OnInteractableLost для старого и OnInteractableFound для нового
    		// чтобы обновить подсказку в UI
    		FocusedActor = NewFocusedActor;
    	}
    }
    
    void UInteractionComponent::PerformInteraction()
    {
    	// Если мы на что-то смотрим, просто вызываем его функцию OnInteract.
    	// Нам не важно, что это - растение, верстак или дверь.
    	if (FocusedActor)
    	{
    		// Вызываем серверную функцию для безопасности
    		Server_PerformInteraction(FocusedActor);
    	}
    }
    
    // Новая серверная функция
    void UInteractionComponent::Server_PerformInteraction_Implementation(AActor* ActorToInteractWith)
    {
        if (ActorToInteractWith)
        {
            // Вызываем C++ функцию интерфейса
            IInteractableInterface::Execute_OnInteract(ActorToInteractWith, GetOwner());
        }
    }
    ```
    *   Не забудьте добавить `Server_PerformInteraction` в `.h` с флагами `Server, Reliable` и реализовать `Validate` (можно оставить пустым).
