Давайте разделим их для ясности и более детально проработаем именно механику **негативных мутаций** как отдельный, осмысленный элемент геймплея. Мы уже заложили основу, а теперь сфокусируемся на том, чтобы сделать эти мутации значимыми и интересными.

### **Шаг 9 (Пересмотренный): Разработка механики негативных мутаций при ошибках в селекции**

**Задача:**
1.  **Формализовать Гены:** Превратить простые числовые модификаторы в более структурированную систему "генов", у каждого из которых есть свое назначение и диапазон нормальных значений.
2.  **Определить Триггеры Мутаций:** Установить четкие правила, когда шанс мутации повышается. Это не должно быть чисто случайным событием. "Ошибки в селекции" должны быть реальными действиями игрока.
3.  **Создать Спектр Негативных Мутаций:** Разработать несколько конкретных, нефизических негативных мутаций, которые создают проблемы для менеджмента базы (бесплодие, уязвимость к болезням, повышенное потребление ресурсов).
4.  **Визуализация в UI:** Игрок должен четко видеть в Анализаторе, что у растения есть негативная мутация.

**Философия:**
1.  **Мутация как Последствие:** Мутации — это не просто случайность, а результат рискованных действий игрока. Хочешь ускорить селекцию с помощью мутагенов? Будь готов к последствиям. Скрещиваешь близких родственников (инбридинг)? Готовься к вырождению.
2.  **Проблема, а не Блокировка:** Негативная мутация не должна быть концом пути для генетической линии. Она должна создавать интересную проблему. Например, растение с геном "хрупкости" может погибнуть, если в ферме кончится вода. Это заставляет игрока лучше следить за автоматизацией. Бесплодное растение можно скрестить со здоровым, чтобы попытаться "вылечить" ген в следующем поколении.
3.  **Гены как "Качество":** Мы введем понятие "стабильности" гена. Чем дальше значение гена от нормы (1.0), тем выше шанс, что при следующем скрещивании он мутирует еще сильнее или сломается. Это создает долгосрочную задачу по поддержанию "чистоты" генетических линий.
4.  **Информация — Ключ:** Успех игрока будет зависеть от того, насколько хорошо он анализирует геномы и понимает риски. "Ботанический Анализатор" становится его главным инструментом.

#### **2. Реализация Триггеров и Логики Мутаций в `AMultifarm`**

1.  **Откройте `Multifarm.cpp` и перепишите `Server_CrossPollinate`:**

    ```cpp
    // Функция-помощник для наследования одного гена
    FGene InheritGene(const FGene& Parent1, const FGene& Parent2, float MutationChanceMultiplier)
    {
    	FGene ChildGene;
    
    	// 1. Наследование значения
    	ChildGene.Value = (Parent1.Value + Parent2.Value) / 2.0f;
    
    	// 2. Наследование стабильности
    	ChildGene.Stability = (Parent1.Stability + Parent2.Stability) / 2.0f;
    	// Стабильность падает, если значения родителей сильно расходятся
    	ChildGene.Stability -= FMath::Abs(Parent1.Value - Parent2.Value) * 0.1f;
    
    	// 3. МУТАЦИЯ
    	const float BaseMutationChance = 0.05f; // 5% базовый шанс
    	// Шанс мутации растет, если стабильность гена низкая
    	const float FinalMutationChance = BaseMutationChance * (1.0f / ChildGene.Stability) * MutationChanceMultiplier;
    
    	if (FMath::FRand() < FinalMutationChance)
    	{
    		const float MutationMagnitude = 0.2f;
    		ChildGene.Value += FMath::RandRange(-MutationMagnitude, MutationMagnitude);
    		ChildGene.Stability -= 0.1f; // Мутация всегда немного снижает стабильность
    
    		UE_LOG(LogTemp, Warning, TEXT("MUTATION! Gene value changed. New stability: %f"), ChildGene.Stability);
    	}
    
    	// Ограничиваем значения
    	ChildGene.Value = FMath::Max(0.0f, ChildGene.Value);
    	ChildGene.Stability = FMath::Clamp(ChildGene.Stability, 0.1f, 1.0f);
    
    	return ChildGene;
    }
    
    void AMultifarm::Server_CrossPollinate_Implementation(UInventoryComponent* PlayerInventory, int32 PollinatorSeedIndex, float MutationChanceMultiplier)
    {
        // ... (проверки, как и раньше)

        FPlantGenetics Parent2_Genetics = PollinatorSeedSlot.Genetics;
        FPlantGenetics Child_Genetics;

        Child_Genetics.Yield = InheritGene(Parent1_Genetics.Yield, Parent2_Genetics.Yield, MutationChanceMultiplier);
        Child_Genetics.GrowthSpeed = InheritGene(Parent1_Genetics.GrowthSpeed, Parent2_Genetics.GrowthSpeed, MutationChanceMultiplier);
        Child_Genetics.WaterConsumption = InheritGene(Parent1_Genetics.WaterConsumption, Parent2_Genetics.WaterConsumption, MutationChanceMultiplier);
        Child_Genetics.Fertility = InheritGene(Parent1_Genetics.Fertility, Parent2_Genetics.Fertility, MutationChanceMultiplier);
    ```
