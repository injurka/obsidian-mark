Мы создали сложную систему роста, которая зависит от правильного субстрата. Но откуда игроку его брать? Сейчас мы замкнем этот цикл и дадим игроку возможность самому производить нужные почвенные смеси. Это будет первая по-настоящему многоступенчатая производственная цепочка в игре.

### **Шаг 8: Создание системы производства субстратов из органических материалов**

**Задача:**
1.  **Создать "Компостер":** Реализовать новую интерактивную станцию, которая будет перерабатывать органические отходы (листья, испорченную еду, останки существ) в базовый субстрат — "Компост".
2.  **Определить Рецепты Субстратов:** Создать рецепты для других типов субстрата (например, "Глиняная почва" = Глина + Компост). Эти рецепты будут использоваться на уже существующем верстаке.
3.  **Создать Предметы-Субстраты:** Сделать так, чтобы "Компост", "Глина" и другие субстраты были реальными предметами в инвентаре.
4.  **Интегрировать с Мультифермой:** Изменить логику Мультифермы так, чтобы она требовала от игрока физически поместить в нее предмет-субстрат из инвентаря.

**Философия:**
1.  **Компостер как Переработчик:** Компостер будет работать по принципу "вход-выход". Игрок загружает в него органику, и через некоторое время получает на выходе компост. Это знакомит игрока с машинами, работающими во времени.
2.  **Верстак как Смеситель:** Более сложные субстраты будут создаваться мгновенно на верстаке, как и другие предметы. Это разделяет типы крафта: медленная переработка и быстрое смешивание.
3.  **Субстрат как Ресурс:** Убрав магическое "выбери субстрат из списка" и заменив его на физический предмет, мы делаем управление ресурсами более глубоким и осмысленным. Игроку нужно будет планировать производство и хранение субстратов.
4.  **Замыкание Цикла:** Эта система создает первую важную петлю обратной связи. Чтобы вырастить Восковой Гриб, нужен Компост. Чтобы сделать Компост, нужны органические отходы, которые можно получить, например, со старых, ненужных растений. Игрок начинает перерабатывать продукты своей же деятельности.

        // ...

#### **2. Создание Компостера**

1.  **Создайте Актор `AComposter`:**
    *   Создайте C++ класс `Composter`, унаследованный от `AActor`. Поместите в `FaunaLocus/World/Interactables/`.
    *   **В `Composter.h`:**
        ```cpp
        UCLASS()
        class FAUNALOCUS_API AComposter : public AActor, public IInteractableInterface
        {
            // ... (конструктор, меш)
        public:
            // Функция для добавления органики
            void AddOrganicMaterial(UInventoryComponent* PlayerInventory, int32 SlotIndex);
        
        protected:
            // ... (серверная функция для добавления)
            
            // Сколько органики уже загружено
            UPROPERTY(VisibleAnywhere, Replicated)
            float CurrentOrganicValue = 0.0f;
        
            // Сколько органики нужно для создания 1 единицы компоста
            UPROPERTY(EditDefaultsOnly, Category = "Composter")
            float OrganicValuePerCompost = 100.0f;
        
            // Сколько времени занимает переработка
            UPROPERTY(EditDefaultsOnly, Category = "Composter")
            float CompostingDuration = 20.0f;
        
            // Инвентарь для готового компоста
            UPROPERTY(VisibleAnywhere, Replicated)
            TObjectPtr<UInventoryComponent> OutputInventory;
        };
        ```
    *   В `.cpp` файле создайте `OutputInventory` в конструкторе. В `Tick` реализуйте логику: если `CurrentOrganicValue` >= `OrganicValuePerCompost`, запустить таймер. По окончании таймера вычесть `OrganicValuePerCompost`, добавить 1 `DA_Item_Compost` в `OutputInventory`.

#### **4. Интеграция Предметов-Субстратов с Мультифермой**

Это ключевой шаг. Мы переделываем логику добавления субстрата.

1.  **Обновите `AMultifarm`:**
    *   **В `Multifarm.h`:**
        *   Удалите старую функцию `AddSubstrate(ESubstrateType SubstrateType)`.
        *   Добавьте новую: `void AddSubstrate(UInventoryComponent* PlayerInventory, int32 SlotIndex);`.
        *   Обновите серверную функцию: `Server_AddSubstrate(UInventoryComponent* PlayerInventory, int32 SlotIndex);`.

    *   **В `Multifarm.cpp`:**
        ```cpp
        void AMultifarm::Server_AddSubstrate_Implementation(UInventoryComponent* PlayerInventory, int32 SlotIndex)
        {
        	if (CurrentState == EMultifarmState::EMS_Empty && PlayerInventory)
        	{
        		const FInventorySlot& PlayerSlot = PlayerInventory->GetInventoryContents()[SlotIndex];
        
        		// Проверяем, что предмет является субстратом
        		if (PlayerSlot.ItemData && PlayerSlot.ItemData->SubstrateType != ESubstrateType::EST_None)
        		{
        			// Забираем 1 предмет-субстрат из инвентаря игрока
        			if (PlayerInventory->RemoveItem(PlayerSlot.ItemData, 1))
        			{
        				// Устанавливаем тип субстрата в ферме
        				CurrentSubstrate = PlayerSlot.ItemData->SubstrateType;
        				CurrentState = EMultifarmState::EMS_HasSubstrate;
        				OnRep_CurrentState();
        			}
        		}
        	}
        }
        ```

2.  **Обновите UI `WBP_MultifarmMenu`:**
    *   Теперь слот субстрата (`SubstrateSlotWidget`) должен работать так же, как мы планировали для слота семян.
    *   **Если субстрат не добавлен:** Слот показывает иконку "пусто" и кликабелен.
    *   **При клике:** Открывается меню выбора (`WBP_SubstrateSelector`, аналогичный `WBP_SeedSelector`), которое показывает все предметы-субстраты из инвентаря игрока.
    *   **При выборе субстрата:** Вызывается функция `MultifarmRef->AddSubstrate(...)`.
    *   **Если субстрат уже добавлен:** Слот показывает иконку добавленного субстрата и некликабелен.

*   **Что сделано:**

    *   Создана новая производственная станция — Компостер, которая вводит механику медленной переработки ресурсов.
    *   Система крафта на верстаке расширена для поддержки рецептов смешивания субстратов.

*   **Результат:** Игрок больше не может просто "выбрать" нужную почву. Ему нужно сначала найти органику, построить Компостер, дождаться производства Компоста. Затем, если ему нужна особая почва, ему нужно найти другие компоненты (например, глину) и смешать их на верстаке. Только после этого он может загрузить готовый субстрат в Мультиферму и начать выращивать требовательные растения. Это добавляет игре глубины, заставляет планировать наперед и вознаграждает за создание эффективных производственных линий.
