Сейчас ферма работает по упрощенной схеме: если есть вода, растение растет с фиксированной скоростью. Пришло время реализовать более глубокую и интересную симуляцию, как и было задумано в дизайн-документе. Рост будет зависеть не просто от наличия, а от *качества* условий.

### **Шаг 7: Разработка логики роста, зависящей от условий среды**

**Задача:**
1.  **Ввести Модификаторы Роста:** Переработать логику роста так, чтобы его скорость не была константой, а вычислялась каждый кадр на основе нескольких факторов (модификаторов).
2.  **Реализовать Зависимость от Субстрата:** Рост возможен только если тип субстрата в ферме совпадает с требуемым для растения.
3.  **Реализовать Зависимость от Влажности:** Ввести понятие "оптимальной влажности". Скорость роста будет максимальной при оптимальном уровне воды и снижаться, если воды слишком много или слишком мало.
4.  **Реализовать Зависимость от Освещения:** Ввести понятие "требования к свету". Растение будет расти только при достаточном освещении (пока что будем считать, что на улице всегда светло, а в пещере — темно).

**Философия:**
1.  **Формула Эффективности:** Скорость роста будет вычисляться по формуле: `БазоваяСкорость * Модификатор_Субстрата * Модификатор_Влажности * Модификатор_Освещения`.
    *   `Модификатор_Субстрата`: равен `1.0`, если субстрат правильный, и `0.0`, если нет. Это бинарный "вкл/выкл".
    *   `Модификатор_Влажности`: будет плавающим значением от `0.0` до `1.0`, зависящим от того, насколько текущий уровень воды близок к оптимальному.
    *   `Модификатор_Освещения`: `1.0` на свету, `0.0` в темноте.
2.  **Централизация Логики в `Tick`:** Вся эта сложная логика будет инкапсулирована внутри функции `TickComponent` (или `Tick` для актора) Мультифермы. Это делает систему предсказуемой и легкой для отладки.
3.  **Расширение `FloraDataAsset`:** Нам нужно добавить новые поля в наш `Data Asset` для описания всех этих новых требований (оптимальная влажность, потребность в свете).
4.  **Обратная Связь через UI:** UI должен наглядно показывать игроку, почему его растение не растет или растет медленно. Мы добавим иконки-индикаторы статуса (например, "Не хватает воды", "Неправильный субстрат").

    ```cpp
    // ...
    void AMultifarm::Tick(float DeltaTime)
    {
    	Super::Tick(DeltaTime);
    
    	// Эта логика должна выполняться только на сервере
    	if (!HasAuthority()) return;
    
    	// --- Шаг 1: Обновление условий среды ---
    	
    	// Простая проверка освещения: пускаем луч вверх, если ничего не преграждает, значит есть свет.
    	FHitResult HitResult;
    	FVector Start = GetActorLocation();
    	FVector End = Start + FVector::UpVector * 10000.0f; // Луч в небо
    	if (GetWorld()->LineTraceSingleByChannel(HitResult, Start, End, ECC_Visibility))
    	{
    		// Что-то преграждает путь к небу (например, потолок пещеры)
    		CurrentLightLevel = 0.0f;
    	}
    	else
    	{
    		CurrentLightLevel = 1.0f;
    	}
    
    	// --- Шаг 2: Вычисление скорости роста, если растение посажено ---
    
    	if (CurrentState == EMultifarmState::EMS_Growing && PlantedFloraData)
    	{
    		// --- Вычисление модификаторов ---
    		
    		// Модификатор Субстрата (0.0 или 1.0)
    		const float SubstrateModifier = (CurrentSubstrate == PlantedFloraData->RequiredSubstrate) ? 1.0f : 0.0f;
    
    		// Модификатор Освещения (0.0 или 1.0)
    		const float LightModifier = (PlantedFloraData->bRequiresSunlight) ? CurrentLightLevel : 1.0f;
    		
    		// Модификатор Влажности (от 0.0 до 1.0)
    		float WaterModifier = 0.0f;
    		if (WaterLevel >= PlantedFloraData->OptimalWaterRange.X && WaterLevel <= PlantedFloraData->OptimalWaterRange.Y)
    		{
    			// Идеальные условия
    			WaterModifier = 1.0f;
    		}
    		else if (WaterLevel > 0)
    		{
    			// Условия не идеальны, но вода есть. Рост замедлен.
    			WaterModifier = 0.25f; 
    		}
    
    		// --- Итоговая эффективность роста ---
    		const float OverallEfficiency = SubstrateModifier * LightModifier * WaterModifier;
    
    		if (OverallEfficiency > 0.0f)
    		{
    			// --- Применяем рост и потребляем ресурсы ---
    			
    			// Скорость роста зависит от эффективности
    			GrowthProgress += (DeltaTime / PlantedFloraData->GrowthDuration) * OverallEfficiency;
    
    			// Потребление воды тоже зависит от эффективности (растение "работает" интенсивнее)
    			WaterLevel -= PlantedFloraData->WaterConsumptionRate * OverallEfficiency * DeltaTime;
    			WaterLevel = FMath::Max(WaterLevel, 0.0f);
    
    			// --- Проверка на завершение роста ---
    			if (GrowthProgress >= 1.0f)
    			{
    				GrowthProgress = 1.0f;
    				CurrentState = EMultifarmState::EMS_ReadyToHarvest;
    				OnRep_CurrentState(); // Оповещаем клиентов
    			}
    		}
    	}
    }
    ```
