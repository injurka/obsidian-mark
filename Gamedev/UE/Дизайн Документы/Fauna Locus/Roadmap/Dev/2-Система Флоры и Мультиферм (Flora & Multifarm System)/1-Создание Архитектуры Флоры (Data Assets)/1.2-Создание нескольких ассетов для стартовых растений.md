Теперь давайте наполним её жизнью и дадим игроку первые цели для культивации. Создание нескольких разнообразных стартовых растений сразу продемонстрирует глубину системы и задаст первые производственные цепочки.

### **Шаг 2: Создание нескольких ассетов для стартовых растений**

**Задача:** Создать три фундаментальных стартовых растения, используя уже разработанную архитектуру `Data Assets`. Каждое растение будет выполнять свою уникальную роль в ранней игре:
1.  **Волокнистый Тростник (Fiber Reed):** Основной источник базового строительного и крафтового материала — волокон.
2.  **Питательный Корень (Nutri-Root):** Основной источник пищи для игрока на раннем этапе.
3.  **Восковой Гриб (Waxcap Mushroom):** Источник воска, который понадобится для более продвинутых рецептов (например, для водонепроницаемых компонентов или свечей).

**Философия:**
1.  **Четкая Роль:** Каждое растение должно быть полезным и решать конкретную проблему игрока. Это мотивирует его искать и культивировать их все.
2.  **Демонстрация Системы:** Эти три растения будут использовать разные типы субстрата, что сразу покажет игроку важность этой механики.
3.  **Взаимосвязь:** Продукты этих растений (волокна, воск) станут ингредиентами для крафта инструментов, необходимых для дальнейшего освоения био-инженерии. Мы создаем первые "петли" геймплея.
4.  **Полный Цикл:** Для каждого растения мы создадим всю необходимую цепочку ассетов: `ItemDataAsset` для продукта и семян -> `FloraDataAsset` для описания самого растения -> `Blueprint` для его представления в мире.
