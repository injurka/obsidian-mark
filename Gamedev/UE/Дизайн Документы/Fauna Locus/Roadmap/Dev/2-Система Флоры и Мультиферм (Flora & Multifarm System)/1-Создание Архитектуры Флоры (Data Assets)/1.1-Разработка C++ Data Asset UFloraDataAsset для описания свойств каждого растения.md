Теперь пришло время взяться за второй главный столп вашего геймплея — био-инженерию Флоры. Мы начнем с создания архитектуры, которая будет описывать все растения в вашем мире.

### **Шаг 1: Создание Архитектуры Флоры (Data Assets)**

**Задача:** Разработать C++ `Data Asset` для описания всех свойств, потребностей и продуктов каждого растения. Это позволит нам централизованно хранить данные о флоре и легко добавлять новые виды, не меняя код.

**Философия:**
1.  **Data-Driven, как и раньше:** Мы создадим один базовый C++ класс `UFloraDataAsset`, а каждое растение в игре (от простого куста до экзотического гриба) будет его экземпляром (`Data Asset`). Это дает невероятную гибкость гейм-дизайнерам.
2.  **Полное Описание:** `UFloraDataAsset` будет содержать *всю* необходимую информацию: как растение выглядит, что ему нужно для роста (субстрат, температура, вода), как долго оно растет и что игрок получает в итоге (плоды, волокна, семена).
3.  **Готовность к Будущему:** Мы сразу заложим в структуру поля для будущих механик, таких как разные стадии роста и генетические параметры, даже если пока не будем их полностью реализовывать.
4.  **Мировое Представление (`AFloraBase`):** Данные — это хорошо, но нам нужен и актер в мире, который будет эти данные использовать. Мы создадим базовый класс `AFloraBase`, который будет "физическим воплощением" нашего `Data Asset` в игровом мире.

---

### **Подробная Реализация Шага**

#### **1. Обновление Глобальных Типов (`FF_Types.h`)**

Нам нужно определить типы субстрата, которые будут использоваться в Мультифермах. `Enum` — идеальное решение для этого.

1.  **Откройте `FF_Types.h`:**

    ```cpp
    // FaunaLocus/Source/FaunaLocus/Core/FF_Types.h
    
    // ... (существующие структуры FAttribute и FInventorySlot)
    
    // Перечисление возможных типов субстрата для растений
    UENUM(BlueprintType)
    enum class ESubstrateType : uint8
    {
    	EST_None		UMETA(DisplayName = "None"),
    	EST_Soil		UMETA(DisplayName = "Soil"),
    	EST_Compost		UMETA(DisplayName = "Compost"),
    	EST_Sand		UMETA(DisplayName = "Sand"),
    	EST_Clay		UMETA(DisplayName = "Clay"),
    	EST_AcidicPeat	UMETA(DisplayName = "Acidic Peat")
    };
    ```
    *Это перечисление позволит нам в `Data Asset` растения просто выбрать из выпадающего списка, какой тип почвы ему нужен.*

#### **2. Создание `UFloraDataAsset`**

Это ядро нашей системы флоры.

1.  В редакторе создайте новый C++ класс `FloraDataAsset`, унаследованный от `UPrimaryDataAsset`.
2.  Поместите его в `FaunaLocus/GameplaySystems/FloraSystem/`.
3.  **Откройте `FloraDataAsset.h`:**

    ```cpp
    // FaunaLocus/Source/FaunaLocus/GameplaySystems/FloraSystem/FloraDataAsset.h
    
    #pragma once
    
    #include "CoreMinimal.h"
    #include "Engine/DataAsset.h"
    #include "Core/FF_Types.h"
    #include "FloraDataAsset.generated.h"
    
    class UItemDataAsset;
    class UStaticMesh;
    
    UCLASS(BlueprintType)
    class FAUNALOCUS_API UFloraDataAsset : public UPrimaryDataAsset
    {
    	GENERATED_BODY()
    
    public:
    	// --- Базовая Информация ---
    	UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category = "Flora Info")
    	FText PlantName;
    
    	UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category = "Flora Info", meta = (MultiLine = true))
    	FText PlantDescription;
    
    	// --- Визуальное Представление ---
    	// Меш полностью выросшего растения
    	UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category = "Visuals")
    	TObjectPtr<UStaticMesh> GrownMesh;
    
    	// (Задел на будущее) Меши для разных стадий роста
    	UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category = "Visuals")
    	TArray<TObjectPtr<UStaticMesh>> GrowthStageMeshes;
    
    	// --- Требования к Росту ---
    	// Как долго растет (в секундах)
    	UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category = "Growth Requirements")
    	float GrowthDuration = 300.0f;
    
    	// Необходимый тип субстрата
    	UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category = "Growth Requirements")
    	ESubstrateType RequiredSubstrate = ESubstrateType::EST_Soil;
    
    	// Оптимальная температура (в будущем - диапазон)
    	UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category = "Growth Requirements")
    	float OptimalTemperature = 25.0f;
    
    	// --- Урожай ---
    	// Предмет, который мы получаем при сборе
    	UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category = "Harvest")
    	TObjectPtr<UItemDataAsset> HarvestedItem;
    
    	// Количество получаемого предмета
    	UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category = "Harvest")
    	int32 HarvestYield = 1;
    
    	// Предмет-семена, который мы получаем при сборе
    	UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category = "Harvest")
    	TObjectPtr<UItemDataAsset> SeedItem;
    
    	// Количество получаемых семян
    	UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category = "Harvest")
    	int32 SeedYield = 2;
    };
    ```
4.  Создайте пустой `FloraDataAsset.cpp`, так как это просто контейнер данных.

#### **3. Создание Актора для Растений в Мире (`AFloraBase`)**

Теперь создадим актора, который будет использовать наш `Data Asset`.

1.  Создайте C++ класс `FloraBase`, унаследованный от `AActor`. Поместите его в `FaunaLocus/World/Flora/`.
2.  **В `FloraBase.h`:**
    ```cpp
    // FaunaLocus/Source/FaunaLocus/World/Flora/FloraBase.h
    
    #pragma once
    
    #include "CoreMinimal.h"
    #include "GameFramework/Actor.h"
    #include "FloraBase.generated.h"
    
    class UFloraDataAsset;
    
    UCLASS()
    class FAUNALOCUS_API AFloraBase : public AActor
    {
    	GENERATED_BODY()
    	
    public:	
    	AFloraBase();
    
    	// Данные, описывающие это растение
    	UPROPERTY(EditAnywhere, BlueprintReadOnly, Category = "Flora")
    	TObjectPtr<UFloraDataAsset> FloraData;
    
    protected:
    	// Вызывается при создании актора или изменении его свойств в редакторе
    	virtual void OnConstruction(const FTransform& Transform) override;
    
    	UPROPERTY(VisibleAnywhere, BlueprintReadOnly, Category = "Components")
    	TObjectPtr<UStaticMeshComponent> MeshComponent;
    };
    ```
3.  **В `FloraBase.cpp`:**
    ```cpp
    // FaunaLocus/Source/FaunaLocus/World/Flora/FloraBase.cpp
    
    #include "World/Flora/FloraBase.h"
    #include "GameplaySystems/FloraSystem/FloraDataAsset.h"
    #include "Components/StaticMeshComponent.h"
    
    AFloraBase::AFloraBase()
    {
    	PrimaryActorTick.bCanEverTick = false;
    
    	MeshComponent = CreateDefaultSubobject<UStaticMeshComponent>(TEXT("MeshComponent"));
    	RootComponent = MeshComponent;
    
    	bReplicates = true;
    }
    
    void AFloraBase::OnConstruction(const FTransform& Transform)
    {
    	Super::OnConstruction(Transform);
    
    	// Автоматически обновляем меш в редакторе при выборе Data Asset
    	if (FloraData)
    	{
    		MeshComponent->SetStaticMesh(FloraData->GrownMesh);
    	}
    }
    ```
    *`OnConstruction` — очень удобная функция. Она позволяет дизайнерам уровней сразу видеть, как будет выглядеть растение, просто выбрав нужный `Data Asset` в его свойствах.*

#### **4. Настройка Данных в Редакторе**

Теперь, когда вся C++ архитектура готова, мы можем создавать контент.

1.  **Скомпилируйте код.**
2.  **Создайте `Data Asset` для Растения:**
    *   В `Content/Data/DataAssets/Flora/` создайте новый `Data Asset` на основе вашего `FloraDataAsset`. Назовите его `DA_Flora_BerryBush`.
    *   Откройте его и заполните поля:
        *   **Plant Name:** "Berry Bush"
        *   **Grown Mesh:** Выберите подходящий меш куста.
        *   **Growth Duration:** 120 (2 минуты)
        *   **Required Substrate:** `Soil`
        *   **Harvested Item:** `DA_Item_Berries` (вам нужно будет создать этот `ItemDataAsset`).
        *   **Harvest Yield:** 5
        *   **Seed Item:** `DA_Item_BerrySeeds` (и этот `ItemDataAsset` тоже нужно создать).
        *   **Seed Yield:** 2
3.  **Создайте `Item Data Assets` для Продуктов:**
    *   В `Content/Data/DataAssets/Items/` создайте `DA_Item_Berries` и `DA_Item_BerrySeeds`.
    *   **Важный шаг:** Откройте `DA_Item_BerrySeeds`. У нас пока нет поля для связи семян с растением, которое из них вырастет. Давайте добавим его!

#### **5. Добавление Связи "Семена -> Растение"**

1.  **Откройте `ItemDataAsset.h`:**
    ```cpp
    // ...
    class UFloraDataAsset; // Прямое объявление
    
    UCLASS(BlueprintType)
    class FAUNALOCUS_API UItemDataAsset : public UPrimaryDataAsset
    {
    	// ...
    public:
    	// ...
    	// Если этот предмет является семенами, здесь указывается, какое растение из него вырастет.
    	UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category = "Item")
    	TObjectPtr<UFloraDataAsset> FloraToPlant;
    };
    ```
2.  **Скомпилируйте код еще раз.**
3.  Теперь откройте `DA_Item_BerrySeeds` в редакторе. У него появилось новое поле `Flora To Plant`. **Установите в него ваш `DA_Flora_BerryBush`**. Эта связь будет критически важна, когда мы будем сажать семена в Мультиферму.

4.  **Создайте `Blueprint` для дикого растения:**
    *   В `Content/Blueprints/World/Flora/Wild/` создайте `BP_Wild_BerryBush`, унаследованный от `AFloraBase`.
    *   Откройте его. В **Class Defaults** в поле `Flora Data` выберите ваш `DA_Flora_BerryBush`. Меш должен установиться автоматически благодаря `OnConstruction`.
    *   Разместите несколько `BP_Wild_BerryBush` на вашем уровне.

---

### **Итог Шага**

Вы создали полную, расширяемую и управляемую данными архитектуру для всей флоры в вашей игре.

*   **Что сделано:**
    *   Создана иерархия данных: `ESubstrateType` -> `UFloraDataAsset` -> `AFloraBase`.
    *   `UFloraDataAsset` теперь служит "паспортом" для каждого растения, описывая все его ключевые свойства.
    *   `AFloraBase` является физическим представлением растения в мире и автоматически настраивает свой внешний вид.
    *   Создана логическая связь между предметом-семенами и `Data Asset` растения, которое из них можно вырастить.
    *   Вся система готова к следующему шагу: созданию Мультифермы, в которую мы сможем сажать эти семена и выращивать наши растения.

*   **Результат:** У вас есть четкая и понятная структура для добавления неограниченного количества растений в игру. Вы можете размещать дикие растения на уровне, и они уже содержат всю информацию о себе. Игрок пока не может с ними взаимодействовать, но вся основа для этого уже заложена. Это прочный фундамент для одного из главных столпов вашей игры.
