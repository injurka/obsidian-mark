Игрок собрал семена, проанализировал их и знает, что им нужно для роста. Пришло время дать ему главный инструмент био-инженера — Мультиферму. Это будет не просто грядка, а технологичное устройство, которым нужно управлять.

### **Шаг 5: Реализация Мультифермы как Интерактивного Актора**

**Задача:**
1.  **Создать Актор `AMultifarm`:** Разработать C++ класс для Мультифермы, который будет содержать всю её логику и состояние.
2.  **Определить Состояние Фермы:** Заложить в актор переменные, которые будут описывать её текущее состояние: какой субстрат загружен, какое растение посажено, уровень воды, текущий прогресс роста.
3.  **Реализовать Взаимодействие:** Сделать Мультиферму интерактивным объектом, с которым игрок может взаимодействовать для посадки семян, добавления субстрата и воды.
4.  **Разработать UI:** Создать базовый интерфейс для управления фермой.

**Философия:**
1.  **Ферма как "Машина Состояний":** Мультиферма — это, по сути, конечный автомат. Она может быть в состояниях: "Пустая", "Готова к посадке" (загружен субстрат), "Растет", "Готова к сбору". Все действия игрока будут переводить ферму из одного состояния в другое.
2.  **Серверная Власть:** Вся логика роста и изменения состояния фермы (добавление воды, посадка) должна происходить на сервере. Клиенты лишь видят результат и отправляют запросы на взаимодействие.
3.  **Модульность и Данные:** Состояние фермы будет определяться `Data Assets`, которые игрок в нее помещает (`ItemDataAsset` для семян и субстрата). Это сохраняет нашу data-driven архитектуру.
4.  **Визуальная Обратная Связь:** Меш растения в ферме должен меняться по мере его роста. Мы заложим основу для этой механики.

#### **2. Реализация Логики `AMultifarm`**

    	FarmMeshComponent = CreateDefaultSubobject<UStaticMeshComponent>(TEXT("FarmMesh"));
    	RootComponent = FarmMeshComponent;
    
    	PlantMeshComponent = CreateDefaultSubobject<UStaticMeshComponent>(TEXT("PlantMesh"));
    	PlantMeshComponent->SetupAttachment(RootComponent);
    	PlantMeshComponent->SetCollisionEnabled(ECollisionEnabled::NoCollision);
    }
    
    void AMultifarm::BeginPlay() { Super::BeginPlay(); }
    
    void AMultifarm::Tick(float DeltaTime)
    {
    	Super::Tick(DeltaTime);
    
    	if (HasAuthority() && CurrentState == EMultifarmState::EMS_Growing)
    	{
    		// Проверяем условия для роста
    		if (WaterLevel > 0 && PlantedFloraData)
    		{
    			// Проверяем, правильный ли субстрат (упрощенно)
    			if (CurrentSubstrate == PlantedFloraData->RequiredSubstrate)
    			{
    				GrowthProgress += DeltaTime / PlantedFloraData->GrowthDuration;
    				WaterLevel -= 0.1f * DeltaTime; // Потребление воды
    
    				if (GrowthProgress >= 1.0f)
    				{
    					GrowthProgress = 1.0f;
    					CurrentState = EMultifarmState::EMS_ReadyToHarvest;
    					OnRep_CurrentState(); // Вызываем вручную на сервере
    				}
    			}
    		}
    	}
    }
    
    // --- Функции-запросы от клиента ---
    void AMultifarm::AddSubstrate(ESubstrateType SubstrateType) { Server_AddSubstrate(SubstrateType); }
    void AMultifarm::PlantSeeds(UItemDataAsset* SeedItem) { Server_PlantSeeds(SeedItem); }
    void AMultifarm::AddWater(float Amount) { Server_AddWater(Amount); }
    void AMultifarm::Harvest() { Server_Harvest(); }
    
    // --- Реализация на сервере ---
    void AMultifarm::Server_AddSubstrate_Implementation(ESubstrateType SubstrateType)
    {
    	if (CurrentState == EMultifarmState::EMS_Empty)
    	{
    		CurrentSubstrate = SubstrateType;
    		CurrentState = EMultifarmState::EMS_HasSubstrate;
    		OnRep_CurrentState();
    	}
    }
    
    void AMultifarm::Server_PlantSeeds_Implementation(UItemDataAsset* SeedItem)
    {
    	if (CurrentState == EMultifarmState::EMS_HasSubstrate && SeedItem && SeedItem->FloraToPlant)
    	{
    		PlantedFloraData = SeedItem->FloraToPlant;
    		CurrentState = EMultifarmState::EMS_Growing;
    		GrowthProgress = 0.0f;
    		OnRep_CurrentState();
    	}
    }
    
    void AMultifarm::Server_AddWater_Implementation(float Amount)
    {
    	WaterLevel = FMath::Clamp(WaterLevel + Amount, 0.0f, MaxWaterLevel);
    }
    
    void AMultifarm::Server_Harvest_Implementation()
    {
        if (CurrentState == EMultifarmState::EMS_ReadyToHarvest)
        {
            // TODO: Найти инвентарь игрока, который вызвал сбор, и выдать ему предметы.
            // UInventoryComponent* PlayerInv = ...
            // PlayerInv->AddItem(PlantedFloraData->HarvestedItem, PlantedFloraData->HarvestYield);
            // PlayerInv->AddItem(PlantedFloraData->SeedItem, PlantedFloraData->SeedYield);
    
            // Сбрасываем ферму
            PlantedFloraData = nullptr;
            CurrentSubstrate = ESubstrateType::EST_None; // Предполагаем, что субстрат расходуется
            CurrentState = EMultifarmState::EMS_Empty;
            GrowthProgress = 0.0f;
            OnRep_CurrentState();
        }
    }
    
    void AMultifarm::OnRep_CurrentState()
    {
    	UpdatePlantMesh();
    	OnMultifarmUpdated.Broadcast();
    }
    
    void AMultifarm::UpdatePlantMesh()
    {
    	if (CurrentState == EMultifarmState::EMS_Growing || CurrentState == EMultifarmState::EMS_ReadyToHarvest)
    	{
    		if (PlantedFloraData)
    		{
    			// TODO: Более сложная логика для выбора меша по стадии роста
    			PlantMeshComponent->SetStaticMesh(PlantedFloraData->GrownMesh);
    			PlantMeshComponent->SetVisibility(true);
    		}
    	}
    	else
    	{
    		PlantMeshComponent->SetVisibility(false);
    	}
    }

    {

    }
