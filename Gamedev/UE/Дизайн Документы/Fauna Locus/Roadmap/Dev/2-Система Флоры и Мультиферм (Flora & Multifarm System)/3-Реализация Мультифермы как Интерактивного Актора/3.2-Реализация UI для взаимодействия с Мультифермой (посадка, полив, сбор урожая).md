У нас есть работающая, но "слепая" Мультиферма. Пришло время создать для нее полноценный, интерактивный интерфейс. Игрок должен не просто видеть состояние фермы, но и активно управлять ею: выбирать семена для посадки, добавлять ресурсы и собирать урожай одним нажатием кнопки.

### **Шаг 6: Реализация UI для взаимодействия с Мультифермой**

**Задача:**
1.  **Создать Интерактивный UI:** Разработать виджет `WBP_MultifarmMenu`, который будет не только отображать состояние фермы, но и предоставлять кнопки и слоты для взаимодействия.
2.  **Реализовать Посадку Семян:** Создать механизм, позволяющий игроку выбрать семена из своего инвентаря и "посадить" их в ферму.
3.  **Реализовать Добавление Ресурсов:** Сделать возможным добавление субстрата и воды.
4.  **Реализовать Сбор Урожая:** Активировать кнопку сбора, когда растение созрело.

**Философия:**
1.  **Контекстно-Зависимые Действия:** Интерфейс должен быть умным. Кнопка "Посадить" должна быть активна только если в ферме есть правильный субстрат, а у игрока есть подходящие семена. Кнопка "Собрать" должна появляться только тогда, когда есть что собирать.
2.  **"Выбор из Инвентаря" вместо Перетаскивания:** Полноценный Drag-and-Drop — сложная система. Для начала мы реализуем более простой, но не менее функциональный подход: при клике на пустой слот семян в ферме будет открываться дополнительное окно со списком всех подходящих семян из инвентаря игрока. Игрок просто кликает на нужные семена, и они "сажаются".
3.  **UI как Пульт Управления:** Виджет остается "глупым" в плане логики. Все кнопки на нем лишь вызывают соответствующие функции на акторе `AMultifarm` (например, `Harvest()`, `PlantSeeds()`). Актор меняет свое состояние, и UI автоматически обновляется благодаря уже созданной нами системе `OnMultifarmUpdated`.

    void AMultifarm::Server_PlantSeeds_Implementation(UInventoryComponent* PlayerInventory, int32 SeedSlotIndex)

    		const FInventorySlot& SeedSlot = PlayerInventory->GetInventoryContents()[SeedSlotIndex];
    		if (SeedSlot.ItemData && SeedSlot.ItemData->FloraToPlant)
    		{
    			// Проверяем, подходит ли субстрат для этих семян

    				GrowthProgress = 0.0f;
    				OnRep_CurrentState();
    			}
    		}
    	}
    }

    		PlayerInventory->AddItem(PlantedFloraData->HarvestedItem, PlantedFloraData->HarvestYield);
    		PlayerInventory->AddItem(PlantedFloraData->SeedItem, PlantedFloraData->SeedYield);
    
    		// Сбрасываем ферму
            // ... (как и раньше)
            OnRep_CurrentState();
    	}
