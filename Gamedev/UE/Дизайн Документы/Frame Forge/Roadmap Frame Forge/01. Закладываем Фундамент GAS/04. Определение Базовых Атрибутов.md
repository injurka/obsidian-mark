**Определение Базовых Атрибутов**. На этом этапе мы наполним наш BaseAttributeSet конкретными характеристиками и реализуем базовую логику их взаимодействия и репликации.

**Задача:** В вашем базовом `UBaseAttributeSet` (C++) определить основные атрибуты (`Health`, `MaxHealth`, `Armor`, `Energy`, `MaxEnergy`, `MovementSpeed`, `Stamina`, `MaxStamina`, `AttackPower`, `CritChance`, `CritDamage`) и мета-атрибут `Damage`. Реализовать логику зажима (clamping) атрибутов и базовую обработку урона в `PostGameplayEffectExecute`.

**Зачем:** Это основа числовых характеристик Шасси. От этих значений будут зависеть выживаемость, ресурсы для способностей, мобильность и урон. Правильная обработка зависимостей (как *Health* зависит от *MaxHealth*) и урона критически важна для игрового процесса.

**GAS Компоненты:** `UAttributeSet`, `FGameplayAttributeData`, `ATTRIBUTE_ACCESSORS`, `DOREPLIFETIME_CONDITION_NOTIFY`, `GAMEPLAYATTRIBUTE_REPNOTIFY`, `PostGameplayEffectExecute`, `PreAttributeChange`, `PostAttributeBaseChange`.

    void UBaseAttributeSet::ClampAttribute(const FGameplayAttribute& Attribute, float& NewValue) const
    {
        if (Attribute == GetHealthAttribute())
        {
            // Зажимаем Здоровье между 0 и MaxHealth
            NewValue = FMath::Clamp(NewValue, 0.0f, GetMaxHealth());
        }
        else if (Attribute == GetMaxHealthAttribute())
        {
            // Минимальное MaxHealth = 1, чтобы избежать деления на ноль и других проблем
            NewValue = FMath::Max(NewValue, 1.0f);
        }
        else if (Attribute == GetEnergyAttribute())
        {
            NewValue = FMath::Clamp(NewValue, 0.0f, GetMaxEnergy());
        }
        else if (Attribute == GetMaxEnergyAttribute())
        {
            NewValue = FMath::Max(NewValue, 0.0f); // MaxEnergy может быть 0
        }
         else if (Attribute == GetStaminaAttribute())
        {
            NewValue = FMath::Clamp(NewValue, 0.0f, GetMaxStamina());
        }
        else if (Attribute == GetMaxStaminaAttribute())
        {
            NewValue = FMath::Max(NewValue, 0.0f); // MaxStamina может быть 0
        }
        else if (Attribute == GetArmorAttribute())
        {
             NewValue = FMath::Max(NewValue, 0.0f); // Броня не может быть отрицательной
        }
         else if (Attribute == GetMovementSpeedAttribute())
        {
             NewValue = FMath::Max(NewValue, 0.0f); // Скорость не может быть отрицательной
        }
         else if (Attribute == GetAttackPowerAttribute())
        {
             NewValue = FMath::Max(NewValue, 0.0f); // Сила атаки не может быть отрицательной
        }
         else if (Attribute == GetCritChanceAttribute())
        {
             NewValue = FMath::Max(NewValue, 0.0f); // Шанс крита не может быть отрицательным (может быть > 1.0)
        }
         else if (Attribute == GetCritDamageAttribute())
        {
             NewValue = FMath::Max(NewValue, 1.0f); // Крит урон минимум 1.0 (100%)
        }
        // Мета-атрибуты (Damage, Healing) обычно не требуют зажима здесь
    }

        Super::PostGameplayEffectExecute(Data);

        FGameplayEffectContextHandle Context = Data.EffectSpec.GetContext();
        UAbilitySystemComponent* SourceASC = Context.GetOriginalInstigatorAbilitySystemComponent();
        const FGameplayTagContainer* SourceTags = Data.EffectSpec.CapturedSourceTags.GetAggregatedTags(); // Теги источника эффекта

        }

            const float ArmorValue = GetArmor();
