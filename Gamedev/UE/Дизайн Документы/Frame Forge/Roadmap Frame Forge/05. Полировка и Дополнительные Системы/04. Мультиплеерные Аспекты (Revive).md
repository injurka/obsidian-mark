**DBNO (Down But Not Out) and Revive Mechanics**

**Задача:** Реализовать механику "Тяжело Ранен" (DBNO) и воскрешения. Создать GE, который применяется при `Health <= 0`, дает тег `State.KnockedDown` и запускает таймер "bleedout". Создать `GA_Character_Revive`, которая может быть активирована союзником на персонаже с тегом `State.KnockedDown`.

**Зачем:** Реализация ключевой кооперативной механики, позволяющей игрокам спасать павших товарищей по команде.

**GAS Компоненты и Механизмы UE:** `GameplayTag`, `UGameplayEffect`, `UGameplayAbility` (пассивная и активная), `AbilityTask_WaitGameplayEvent`, `AbilityTask_WaitDelay`/`PlayMontageAndWait`, `FTimerHandle`, `GetWorldTimerManager`, `ApplyGameplayEffectToSelf`, `RemoveActiveGameplayEffectsWithGrantedTags`, `AddLooseGameplayTag`, `RemoveLooseGameplayTag`, `SendGameplayEventToActor`.

---

**Подробная Реализация Шага:**

**Шаг 20.1: Определение Gameplay Tags (в Редакторе)**

Нам нужны теги для представления состояний и событий.

1.  **Откройте Project Settings -> Gameplay Tags**.
2.  **Добавьте следующие теги** (если еще не существуют):
    *   `State.KnockedDown` (Состояние DBNO)
    *   `State.Dead` (Состояние окончательной смерти в раунде)
    *   `State.CannotBeRevived` (Опционально: если нужно временно блокировать повторное воскрешение)
    *   `Event.State.Dead` (Событие, отправляемое, когда Health <= 0) - *Уже должно быть создано в шаге 4/14*
    *   `Event.State.Revived` (Событие, отправляемое при успешном воскрешении)
    *   `GameplayCue.Character.Downed` (Для эффекта перехода в DBNO)
    *   `GameplayCue.Character.Revived` (Для эффекта воскрешения)
    *   `GameplayCue.Character.BleedoutWarning` (Опционально: для эффекта при низком таймере bleedout)
3.  **Сохраните Project Settings.**

**Шаг 20.2: Создание Gameplay Effect для Состояния DBNO (`GE_Status_KnockedDown`)**

Этот эффект будет применяться при переходе в DBNO. Он *не будет* иметь длительности сам по себе, а только предоставит тег. Таймер bleedout будет управляться отдельно.

1.  **Создайте GE:** `Content/GAS/GameplayEffects/Status/Debuffs/` -> ПКМ -> Blueprint Class -> Родитель: `GameplayEffect`. Имя: `GE_Status_KnockedDown`.
2.  **Настройте `GE_Status_KnockedDown`:**
    *   **Duration Policy:** `Infinite` (Эффект активен, пока не будет снят воскрешением или не наступит смерть).
    *   **Modifiers:** Оставьте пустым.
    *   **Granted Tags:** Нажмите `+` -> `Added`. Выберите тег `State.KnockedDown`.
    *   **Gameplay Cues:** Нажмите `+`.
        *   `Gameplay Cue Tag`: `GameplayCue.Character.Downed`.
        *   `Removal Calculation Policy`: `Do Not Remove`.
        *   `Add On Application`: `true`.
    *   **Asset Tags:** `Status.Debuff.KnockedDown`, `State`.
3.  **Сохраните.**

**Шаг 20.3: Создание Gameplay Effect для Состояния Смерти (`GE_Status_Dead`)**

Этот эффект просто применяет тег окончательной смерти.

1.  **Создайте GE:** `Content/GAS/GameplayEffects/Status/Debuffs/` -> Имя: `GE_Status_Dead`.
2.  **Настройте `GE_Status_Dead`:**
    *   **Duration Policy:** `Infinite`.
    *   **Granted Tags:** Нажмите `+` -> `Added`. Выберите тег `State.Dead`.
    *   **Asset Tags:** `Status.Debuff.Dead`, `State`.
3.  **Сохраните.**

**Шаг 20.4: Создание Пассивной Способности для Обработки Смерти и Bleedout (`GA_Passive_HandleDeathState`) (C++)**

Эта способность будет слушать событие `Event.State.Dead` и управлять переходом в DBNO и таймером bleedout.

1.  **Создайте C++ класс способности**:
    *   Родитель: `FrameForgeGameplayAbility`.
    *   Имя: `GA_Passive_HandleDeathState`.
    *   Путь: `.../Public/Abilities/Passive/`.
2.  **`GA_Passive_HandleDeathState.h`**:
    ```cpp
    #pragma once

    #include "CoreMinimal.h"
    #include "Abilities/FrameForgeGameplayAbility.h"
    #include "TimerManager.h" // Для FTimerHandle
    #include "GA_Passive_HandleDeathState.generated.h"

    UCLASS()
    class FRAMEFORGE_API UGA_Passive_HandleDeathState : public UFrameForgeGameplayAbility
    {
        GENERATED_BODY()

    public:
        UGA_Passive_HandleDeathState();

    protected:
        // Вызывается при выдаче способности
        virtual void OnAvatarSet(const FGameplayAbilityActorInfo* ActorInfo, const FGameplayAbilitySpec& Spec) override;

        // Вызывается при активации (которая происходит при выдаче)
        virtual void ActivateAbility(const FGameplayAbilitySpecHandle Handle, const FGameplayAbilityActorInfo* ActorInfo, const FGameplayAbilityActivationInfo ActivationInfo, const FGameplayEventData* TriggerEventData) override;

        // Вызывается при завершении способности (например, при смерти персонажа)
        virtual void EndAbility(const FGameplayAbilitySpecHandle Handle, const FGameplayAbilityActorInfo* ActorInfo, const FGameplayAbilityActivationInfo ActivationInfo, bool bReplicateEndAbility, bool bWasCancelled) override;

        // Обработчик события смерти
        UFUNCTION()
        void HandleDeathEvent(FGameplayEventData Payload);

        // Обработчик события воскрешения (для отмены таймера)
        UFUNCTION()
        void HandleReviveEvent(FGameplayEventData Payload);

        // Вызывается по истечении таймера Bleedout
        UFUNCTION()
        void OnBleedoutTimerExpired();

        // --- Настройки ---
        // Тег события смерти, на которое реагируем
        UPROPERTY(EditDefaultsOnly, Category = "Passive Death Ability")
        FGameplayTag DeathEventTag;

        // Тег события воскрешения
        UPROPERTY(EditDefaultsOnly, Category = "Passive Death Ability")
        FGameplayTag ReviveEventTag;

        // Эффект, применяемый при переходе в DBNO
        UPROPERTY(EditDefaultsOnly, Category = "Passive Death Ability")
        TSubclassOf<class UGameplayEffect> KnockedDownEffectClass;

        // Эффект, применяемый при окончательной смерти (после bleedout)
        UPROPERTY(EditDefaultsOnly, Category = "Passive Death Ability")
        TSubclassOf<class UGameplayEffect> DeathEffectClass;

        // Время истечения крови (Bleedout) в секундах
        UPROPERTY(EditDefaultsOnly, Category = "Passive Death Ability")
        float BleedoutDuration = 30.0f;

        // Тег состояния DBNO
        UPROPERTY(EditDefaultsOnly, Category = "Passive Death Ability")
        FGameplayTag KnockedDownTag;

        // Тег состояния окончательной смерти
        UPROPERTY(EditDefaultsOnly, Category = "Passive Death Ability")
        FGameplayTag DeadTag;

    private:
        // Хэндл для Ability Task ожидания событий
        UPROPERTY()
        TObjectPtr<class UAbilityTask_WaitGameplayEvent> WaitDeathEventTask = nullptr;
        UPROPERTY()
        TObjectPtr<class UAbilityTask_WaitGameplayEvent> WaitReviveEventTask = nullptr;

        // Хэндл для таймера Bleedout
        FTimerHandle BleedoutTimerHandle;

        // Флаг, что мы уже обрабатываем смерть/DBNO
        bool bIsHandlingDeath = false;
    };
    ```
3.  **`GA_Passive_HandleDeathState.cpp`**:
    ```cpp
    #include "Abilities/Passive/GA_Passive_HandleDeathState.h" // Ваш путь
    #include "AbilitySystemComponent.h"
    #include "GameplayEffect.h"
    #include "Abilities/Tasks/AbilityTask_WaitGameplayEvent.h"
    #include "TimerManager.h"
    #include "GameFramework/Actor.h" // Для GetWorldTimerManager

    UGA_Passive_HandleDeathState::UGA_Passive_HandleDeathState()
    {
        // --- Настройки Пассивной Способности ---
        InstancingPolicy = EGameplayAbilityInstancingPolicy::InstancedPerActor;
        // Активируется автоматически при выдаче
        bActivateAbilityOnGranted = true;
        // Не привязана к вводу
        NetExecutionPolicy = EGameplayAbilityNetExecutionPolicy::ServerOnly; // Логика смерти/DBNO авторитативна на сервере

        // --- Установка Тегов по Умолчанию (можно переопределить в BP) ---
        DeathEventTag = FGameplayTag::RequestGameplayTag(FName("Event.State.Dead"));
        ReviveEventTag = FGameplayTag::RequestGameplayTag(FName("Event.State.Revived"));
        KnockedDownTag = FGameplayTag::RequestGameplayTag(FName("State.KnockedDown"));
        DeadTag = FGameplayTag::RequestGameplayTag(FName("State.Dead"));

        // Не имеет смысла для пассивной способности, но хорошая практика
        ActivationBlockedTags.AddTag(DeadTag);
        ActivationBlockedTags.AddTag(KnockedDownTag);
    }

    void UGA_Passive_HandleDeathState::OnAvatarSet(const FGameplayAbilityActorInfo* ActorInfo, const FGameplayAbilitySpec& Spec)
    {
        Super::OnAvatarSet(ActorInfo, Spec);
        // Пытаемся активировать, если еще не активна (на случай, если ActivateAbility не вызовется сразу)
        TryActivateAbility(Spec.Handle, false);
    }

    void UGA_Passive_HandleDeathState::ActivateAbility(const FGameplayAbilitySpecHandle Handle, const FGameplayAbilityActorInfo* ActorInfo, const FGameplayAbilityActivationInfo ActivationInfo, const FGameplayEventData* TriggerEventData)
    {
        Super::ActivateAbility(Handle, ActorInfo, ActivationInfo, TriggerEventData);

        UAbilitySystemComponent* ASC = GetAbilitySystemComponentFromActorInfo();
        if (!ASC)
        {
            EndAbility(Handle, ActorInfo, ActivationInfo, true, true); // Завершаем с отменой, если нет ASC
            return;
        }

        // Отменяем предыдущие таски, если они были
        if(WaitDeathEventTask) WaitDeathEventTask->EndTask();
        if(WaitReviveEventTask) WaitReviveEventTask->EndTask();

        // Создаем и запускаем таск ожидания события смерти
        WaitDeathEventTask = UAbilityTask_WaitGameplayEvent::WaitGameplayEvent(this, DeathEventTag);
        if (WaitDeathEventTask)
        {
            WaitDeathEventTask->EventReceived.AddDynamic(this, &UGA_Passive_HandleDeathState::HandleDeathEvent);
            WaitDeathEventTask->ReadyForActivation();
             UE_LOG(LogTemp, Log, TEXT("GA_Passive_HandleDeathState: Waiting for DeathEventTag %s on %s"), *DeathEventTag.ToString(), *GetNameSafe(ActorInfo->AvatarActor.Get()));
        }
        else
        {
             UE_LOG(LogTemp, Error, TEXT("GA_Passive_HandleDeathState: Could not create WaitDeathEventTask for %s"), *GetNameSafe(ActorInfo->AvatarActor.Get()));
             EndAbility(Handle, ActorInfo, ActivationInfo, true, true);
             return;
        }

        // Создаем и запускаем таск ожидания события воскрешения
        WaitReviveEventTask = UAbilityTask_WaitGameplayEvent::WaitGameplayEvent(this, ReviveEventTag);
         if (WaitReviveEventTask)
        {
            WaitReviveEventTask->EventReceived.AddDynamic(this, &UGA_Passive_HandleDeathState::HandleReviveEvent);
            WaitReviveEventTask->ReadyForActivation();
             UE_LOG(LogTemp, Log, TEXT("GA_Passive_HandleDeathState: Waiting for ReviveEventTag %s on %s"), *ReviveEventTag.ToString(), *GetNameSafe(ActorInfo->AvatarActor.Get()));
        }
         else
         {
              UE_LOG(LogTemp, Error, TEXT("GA_Passive_HandleDeathState: Could not create WaitReviveEventTask for %s"), *GetNameSafe(ActorInfo->AvatarActor.Get()));
              // Не завершаем способность, т.к. ожидание смерти важнее
         }
    }

    void UGA_Passive_HandleDeathState::EndAbility(const FGameplayAbilitySpecHandle Handle, const FGameplayAbilityActorInfo* ActorInfo, const FGameplayAbilityActivationInfo ActivationInfo, bool bReplicateEndAbility, bool bWasCancelled)
    {
        // Очищаем таймер при завершении способности
        if (ActorInfo && ActorInfo->AvatarActor.IsValid())
        {
            ActorInfo->AvatarActor->GetWorldTimerManager().ClearTimer(BleedoutTimerHandle);
        }
        // Отменяем таски ожидания
        if(WaitDeathEventTask) WaitDeathEventTask->EndTask();
        if(WaitReviveEventTask) WaitReviveEventTask->EndTask();

        Super::EndAbility(Handle, ActorInfo, ActivationInfo, bReplicateEndAbility, bWasCancelled);
    }

    void UGA_Passive_HandleDeathState::HandleDeathEvent(FGameplayEventData Payload)
    {
         UE_LOG(LogTemp, Log, TEXT("GA_Passive_HandleDeathState: Received DeathEvent on %s"), *GetNameSafe(GetAvatarActorFromActorInfo()));

        UAbilitySystemComponent* ASC = GetAbilitySystemComponentFromActorInfo();
        if (!ASC || !IsValid(KnockedDownEffectClass) || bIsHandlingDeath)
        {
            return; // Выходим, если нет ASC, эффекта или уже обрабатываем
        }

        // Проверяем, что мы еще не мертвы или в DBNO
        if (ASC->HasMatchingGameplayTag(DeadTag) || ASC->HasMatchingGameplayTag(KnockedDownTag))
        {
             UE_LOG(LogTemp, Log, TEXT("GA_Passive_HandleDeathState: Already Dead or KnockedDown. Ignoring DeathEvent."));
            return;
        }

        bIsHandlingDeath = true; // Устанавливаем флаг

        // --- Применяем Эффект DBNO ---
        FGameplayEffectContextHandle EffectContext = ASC->MakeEffectContext();
        EffectContext.AddSourceObject(GetAvatarActorFromActorInfo());
        FGameplayEffectSpecHandle SpecHandle = ASC->MakeOutgoingSpec(KnockedDownEffectClass, GetAbilityLevel(), EffectContext);

        if (SpecHandle.IsValid())
        {
            FActiveGameplayEffectHandle AppliedHandle = ASC->ApplyGameplayEffectSpecToSelf(*SpecHandle.Data.Get());
            if (AppliedHandle.WasSuccessfullyApplied())
            {
                UE_LOG(LogTemp, Log, TEXT("GA_Passive_HandleDeathState: Applied KnockedDownEffect %s to %s"), *KnockedDownEffectClass->GetName(), *GetNameSafe(GetAvatarActorFromActorInfo()));

                // --- Запускаем Таймер Bleedout ---
                AActor* Avatar = GetAvatarActorFromActorInfo();
                if (Avatar && BleedoutDuration > 0.0f)
                {
                    // Очищаем старый таймер на всякий случай
                    Avatar->GetWorldTimerManager().ClearTimer(BleedoutTimerHandle);
                    // Запускаем новый
                    Avatar->GetWorldTimerManager().SetTimer(BleedoutTimerHandle, this, &UGA_Passive_HandleDeathState::OnBleedoutTimerExpired, BleedoutDuration, false);
                     UE_LOG(LogTemp, Log, TEXT("GA_Passive_HandleDeathState: Started Bleedout timer (%.2f sec) for %s"), BleedoutDuration, *Avatar->GetName());
                }
            }
            else
            {
                 UE_LOG(LogTemp, Error, TEXT("GA_Passive_HandleDeathState: Failed to apply KnockedDownEffect %s"), *KnockedDownEffectClass->GetName());
                 bIsHandlingDeath = false; // Сбрасываем флаг при ошибке
            }
        }
        else
        {
             UE_LOG(LogTemp, Error, TEXT("GA_Passive_HandleDeathState: Failed to make spec for KnockedDownEffect %s"), *KnockedDownEffectClass->GetName());
             bIsHandlingDeath = false; // Сбрасываем флаг при ошибке
        }
        // Не сбрасываем bIsHandlingDeath здесь, если все успешно, сбросим при воскрешении или смерти
    }

     void UGA_Passive_HandleDeathState::HandleReviveEvent(FGameplayEventData Payload)
     {
          UE_LOG(LogTemp, Log, TEXT("GA_Passive_HandleDeathState: Received ReviveEvent on %s"), *GetNameSafe(GetAvatarActorFromActorInfo()));

         // Если мы получили событие воскрешения, значит, другая способность нас воскресила.
         // Нам нужно только отменить таймер Bleedout.
         AActor* Avatar = GetAvatarActorFromActorInfo();
         if (Avatar && BleedoutTimerHandle.IsValid())
         {
             Avatar->GetWorldTimerManager().ClearTimer(BleedoutTimerHandle);
             UE_LOG(LogTemp, Log, TEXT("GA_Passive_HandleDeathState: Cleared Bleedout timer due to ReviveEvent for %s"), *Avatar->GetName());
         }
         bIsHandlingDeath = false; // Сбрасываем флаг
     }


    void UGA_Passive_HandleDeathState::OnBleedoutTimerExpired()
    {
         UE_LOG(LogTemp, Log, TEXT("GA_Passive_HandleDeathState: Bleedout timer expired for %s"), *GetNameSafe(GetAvatarActorFromActorInfo()));

        UAbilitySystemComponent* ASC = GetAbilitySystemComponentFromActorInfo();
        AActor* Avatar = GetAvatarActorFromActorInfo();
        if (!ASC || !Avatar || !IsValid(DeathEffectClass))
        {
            bIsHandlingDeath = false;
            return;
        }

        // Проверяем, что мы все еще в состоянии DBNO (нас не воскресили в последнюю миллисекунду)
        if (ASC->HasMatchingGameplayTag(KnockedDownTag))
        {
            UE_LOG(LogTemp, Log, TEXT("GA_Passive_HandleDeathState: Applying Death state to %s"), *Avatar->GetName());

            // --- Удаляем Эффект/Тег DBNO ---
            // Используем тег, выданный GE_Status_KnockedDown
            FGameplayTagContainer KnockedDownTagContainer;
            KnockedDownTagContainer.AddTag(KnockedDownTag);
            ASC->RemoveActiveGameplayEffectsWithGrantedTags(KnockedDownTagContainer);

            // --- Применяем Эффект Окончательной Смерти ---
            FGameplayEffectContextHandle EffectContext = ASC->MakeEffectContext();
            EffectContext.AddSourceObject(Avatar);
            FGameplayEffectSpecHandle SpecHandle = ASC->MakeOutgoingSpec(DeathEffectClass, GetAbilityLevel(), EffectContext);

            if (SpecHandle.IsValid())
            {
                ASC->ApplyGameplayEffectSpecToSelf(*SpecHandle.Data.Get());
                // Тег State.Dead теперь должен быть применен

                 // TODO: Добавить логику окончательной смерти
                 // Например, скрыть меш, отключить коллизию, уведомить GameMode для респавна в след. раунде
                 // AFrameForgeCharacter* Char = Cast<AFrameForgeCharacter>(Avatar);
                 // if(Char) Char->HandlePermanentDeath();
            }
            else
            {
                 UE_LOG(LogTemp, Error, TEXT("GA_Passive_HandleDeathState: Failed to make spec for DeathEffect %s"), *DeathEffectClass->GetName());
            }
        }
         else
         {
              UE_LOG(LogTemp, Log, TEXT("GA_Passive_HandleDeathState: Target was already revived or dead. Ignoring bleedout expiration."));
         }

         bIsHandlingDeath = false; // Сбрасываем флаг
         BleedoutTimerHandle.Invalidate(); // Очищаем хэндл
    }
    ```

**Шаг 20.5: Создание Gameplay Effect для Лечения при Воскрешении (`GE_Revive_Heal`)**

1.  **Создайте GE:** `Content/GAS/GameplayEffects/Revive/` -> Имя: `GE_Revive_Heal`.
2.  **Настройте `GE_Revive_Heal`:**
    *   **Duration Policy:** `Instant`.
    *   **Modifiers:** Нажмите `+`.

        *   **Modifier Op:** `Add`.
        *   **Magnitude Calculation Type:** `Scalable Float` (простой вариант) или `Attribute Based` (для % от MaxHealth).
        *   **Magnitude (Scalable Float):** `Value` = Количество здоровья при воскрешении (например, `50.0`).

        *   **Magnitude Calculation Type:** `Attribute Based`.
        *   **Attribute:** `BaseAttributeSet.MaxHealth`.
        *   **Coefficient:** `0.3` (для 30% от MaxHealth).
    *   **Gameplay Cues:** Нажмите `+`.
        *   `Gameplay Cue Tag`: `GameplayCue.Character.Revived`.
    *   **Asset Tags:** `Ability.Revive.Heal`.
3.  **Сохраните.**

**Шаг 20.6: Создание Активной Способности Воскрешения (`GA_Character_Revive`) (Blueprint)**

1.  **Создайте BP способности:** `Content/GAS/Abilities/Interaction/` -> Родитель: `FrameForgeGameplayAbility`. Имя: `GA_Character_Revive`.
2.  **Настройте Class Defaults:**
    *   `Ability Tags`: `Ability.Action.Revive`.
    *   `Activation Owned Tags`: `State.Interacting.Reviving`.
    *   `Activation Blocked Tags`: `State.Dead`, `State.Stunned`, `State.KnockedDown`, `State.Interacting` (нельзя воскрешать во время другого взаимодействия).
    *   `Cooldown Gameplay Effect Class`: (Опционально, если у воскрешения есть кулдаун).
    *   `Cost Gameplay Effect Class`: (Опционально, если воскрешение требует энергии/ресурса).
3.  **Переменные (Blueprint):**
    *   `ReviveDuration` (float, default: 5.0).
    *   `InteractionDistance` (float, default: 250.0).
    *   `ReviveHealEffectClass` (TSubclassOf Gameplay Effect, default: `GE_Revive_Heal`).
    *   `KnockedDownTag` (Gameplay Tag, default: `State.KnockedDown`).
    *   `RevivedEventTag` (Gameplay Tag, default: `Event.State.Revived`).
    *   `ReviveMontage` (Animation Montage, опционально).
4.  **Переопределите `CanActivateAbility`:**
    *   Вызовите `Super::CanActivateAbility`. Если false, вернуть false.
    *   Выполните трассировку/оверлап вперед (как в `GA_Character_Interact`).
    *   Проверьте, что `Hit Actor` валиден.
    *   Получите ASC у `Hit Actor` (`UAbilitySystemBlueprintLibrary::GetAbilitySystemComponent`).
    *   Проверьте, что `Target ASC` валиден и имеет тег `KnockedDownTag`.
    *   Верните `true`, если все проверки прошли, иначе `false`.
5.  **Event Graph (`Event ActivateAbility`):**
    *   `Commit Ability` -> `Branch` (True):
        *   **(Получение Цели):** Выполните ту же трассировку/оверлап, что и в `CanActivateAbility`, чтобы снова получить `Hit Actor` (Цель). Сохраните `Target Actor` в локальную переменную.
        *   **(Задача Ожидания/Анимации):**
            *   *Вариант А (Просто Задержка):* `AbilityTask_WaitDelay`: `Time` = `ReviveDuration`.
            *   *Вариант Б (С Анимацией):* `AbilityTask_PlayMontageAndWait`: `Montage to Play` = `ReviveMontage`. `Rate` = (`Montage Play Rate` * `ReviveDuration` / `Montage Get Play Length`).
        *   От выхода `On Finish` / `On Completed`:
            *   **(Проверка Цели):** Получите `Target Actor` из переменной. Проверьте `IsValid`. Получите `Target ASC`. Проверьте `IsValid` и `Has Matching Gameplay Tag` (`KnockedDownTag`). *Важно: цель могла умереть или быть воскрешена кем-то еще за время каста.*
            *   **Если Цель все еще валидна и в DBNO:**
                *   **(Удаление Состояния DBNO):**
                    *   `Target ASC` -> `Remove Active Gameplay Effects with Granted Tags`: `Tags` = Make Container (`KnockedDownTag`).
                *   **(Применение Лечения):**
                    *   `Get Ability System Component from Actor Info` (Это ASC *воскрешающего*) -> `Make Outgoing Gameplay Effect Spec`: Class = `ReviveHealEffectClass`.
                    *   `Apply Gameplay Effect Spec to Target`: Spec = (из Make Spec), Target = `Target ASC`.
                *   **(Отправка События Воскрешения):**

**Итог Шага:**

Вы реализовали полноценную механику DBNO и воскрешения с использованием GAS. При получении смертельного урона персонаж переходит в состояние `State.KnockedDown` благодаря пассивной способности, слушающей событие смерти. Запускается таймер Bleedout. Если таймер истекает до воскрешения, пассивная способность применяет тег `State.Dead`, переводя персонажа в состояние окончательной смерти для текущего этапа игры.
