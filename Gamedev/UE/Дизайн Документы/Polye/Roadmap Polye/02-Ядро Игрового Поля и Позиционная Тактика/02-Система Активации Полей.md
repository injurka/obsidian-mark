**Цель:** Реализовать игровую фазу в начале матча, во время которой каждый игрок может выбрать и активировать от 2 до 5 своих полей. Эта система должна обрабатывать ввод игрока, валидировать его на сервере, обновлять состояние игры (`AGameStateBase`) и синхронизировать визуальное представление (`AFieldTile`), а также позволять игрокам сигнализировать о готовности к переходу в следующую фазу матча.

**Предпосылки (Уже Реализованы):**

1.  **Сетевая Архитектура:** `APolyeGameModeBase`, `APolyeGameStateBase`, `APolyePlayerController`, `APolyePlayerStateBase` с базовой репликацией.
2.  **Система Данных:** Структуры (`FPolyeFieldState` в `PolyeTypes.h`) и Data Assets.
3.  **Система Сущностей:** `APolyeBoardEntityBase` и его наследники.
4.  **Структура Игрового Поля:**
    *   Логическое состояние в `APolyeGameStateBase::BoardState`.
    *   Идентификация полей через `UPolyeBoardStatics`.
    *   Визуальное представление `AGameBoard` и `AFieldTile`.
    *   Связь логики и визуала через `OnRep_BoardState` и `AGameBoard::UpdateBoardVisuals`.
5.  **Обработка Ввода:** Настроен Enhanced Input в `APolyePlayerController`, функция клика по полю (`OnClickGameBoard`) использует `UPolyeBoardStatics::GetFieldIndexAtLocation`.

**Ключевые Компоненты и Их Роли в Системе Активации:**

*   **`APolyeGameModeBase` (Сервер):**
    *   Управляет текущей фазой матча (`EPolyeMatchPhase`).
    *   Инициирует фазу активации, устанавливает лимиты (Min/Max полей).
    *   Получает и валидирует запросы на активацию полей и завершение фазы от `APolyePlayerController`.
    *   Обновляет `APolyeGameStateBase` (активирует поля).
    *   Отслеживает прогресс каждого игрока в этой фазе (сколько полей активировано, кто готов).
    *   Управляет переходом к следующей фазе матча.
*   **`APolyeGameStateBase` (Сервер -> Клиенты):**
    *   Хранит и реплицирует `BoardState` (массив `FPolyeFieldState`). Поле `FPolyeFieldState::bIsActive` будет изменено сервером.
    *   Реплицирует список игроков `ConnectedPlayers` и, возможно, `CurrentMatchPhase` (если решите реплицировать фазу напрямую).
*   **`APolyePlayerController` (Клиент & Сервер):**
    *   **Клиент:**
        *   Обрабатывает клик по полю (`OnClickGameBoard`), отправляет `Server_RequestFieldActivation(FieldIndex)`.
        *   Обрабатывает нажатие кнопки "Готов", отправляет `Server_RequestFinishActivation()`.
        *   Получает Client RPC от GameMode (`Client_StartFieldActivationPhase`, `Client_NotifyFieldActivated`, `Client_NotifyActivationError`, `Client_EndFieldActivationPhase`) для обновления UI и локального состояния.
    *   **Сервер:** Выполняет Server RPC, делегируя логику в `APolyeGameModeBase`.
*   **`APolyePlayerStateBase` (Сервер -> Клиенты):**
    *   Хранит `PlayerIndex` (0 или 1), используемый для определения "своих" полей.
    *   Может хранить флаг `bHasFinishedActivation` (реплицируемый), если GameMode не отслеживает это сам.
*   **`AFieldTile` (Клиент):**
    *   В `UpdateFromState(const FPolyeFieldState& StateData)` (вызываемой через GameBoard из GameState) реагирует на изменение `StateData.bIsActive`, вызывая `BlueprintImplementableEvent` `OnStateUpdated` (или `ShowActiveState`) для изменения своего визуала.
*   **UI (`WBP_FieldActivationOverlay`) (Клиент):**
    *   Отображает информацию о фазе (лимиты, текущее количество активированных полей).
    *   Содержит кнопку "Готов".
    *   Управляется `APolyePlayerController`.

void APolyeGameModeBase::StartFieldActivationPhase()
{
    CurrentMatchPhase = EPolyeMatchPhase::FieldActivation;
    PlayersFinishedActivationPhase.Empty();

    APolyeGameStateBase* GS = GetGameState<APolyeGameStateBase>();
    if (GS) GS->InitializeBoard(); // Инициализация логической доски (владельцы полей)

    for (APolyePlayerStateBase* PS : GS->ConnectedPlayers)
    {
        if (APolyePlayerController* PC = Cast<APolyePlayerController>(PS->GetOwner())) // Получаем PC через PS
        {
            PC->Client_StartFieldActivationPhase(MinFieldsToActivate, MaxFieldsToActivate);
        }
    }
    UE_LOG(LogTemp, Log, TEXT("GameMode: Field Activation Phase Started."));
}

void APolyeGameModeBase::HandlePlayerFieldActivationRequest(APolyePlayerController* RequestingPC, int32 FieldIndex)
{
    if (CurrentMatchPhase != EPolyeMatchPhase::FieldActivation) return;

    APolyePlayerStateBase* RequestingPS = nullptr;
    int32 RequestingPlayerIndex = INDEX_NONE;
    if (!GetPlayerInfo(RequestingPC, RequestingPS, RequestingPlayerIndex))
    {
        RequestingPC->Client_NotifyActivationError(TEXT("Internal player data error."));
        return;
    }

    APolyeGameStateBase* GS = GetGameState<APolyeGameStateBase>();
    if (!GS || !GS->BoardState.IsValidIndex(FieldIndex))
    {
        RequestingPC->Client_NotifyActivationError(TEXT("Invalid field selection."));
        return;
    }

    FPolyeFieldState& TargetFieldState = GS->BoardState[FieldIndex];

    // Валидация:
    // 1. Поле принадлежит игроку?
    if (TargetFieldState.InitialOwnerPlayerIndex != RequestingPlayerIndex)
    {
        RequestingPC->Client_NotifyActivationError(TEXT("You can only activate your starting fields."));
        return;
    }
    // 2. Поле еще не активно?
    if (TargetFieldState.bIsActive)
    {
        RequestingPC->Client_NotifyActivationError(TEXT("This field is already active."));
        return;
    }
    // 3. Не превышен лимит?
    int32* CurrentCountPtr = PlayerActivatedFieldCounts.Find(RequestingPS);
    if (!CurrentCountPtr || *CurrentCountPtr >= MaxFieldsToActivate)
    {
        RequestingPC->Client_NotifyActivationError(FText::Format(NSLOCTEXT("Polye", "MaxFieldsError", "Maximum {0} fields can be activated."), MaxFieldsToActivate).ToString());
        return;
    }

    // Активация:
    GS->SetFieldActive(FieldIndex, true); // Обновляет GameState, вызывает OnRep на клиентах
    (*CurrentCountPtr)++;

    RequestingPC->Client_NotifyFieldActivated(FieldIndex, *CurrentCountPtr); // Уведомляем клиента об успехе
    UE_LOG(LogTemp, Log, TEXT("GameMode: Player %d activated field %d. Count: %d"), RequestingPlayerIndex, FieldIndex, *CurrentCountPtr);
}

void APolyeGameModeBase::HandlePlayerFinishedActivation(APolyePlayerController* RequestingPC)
{
    if (CurrentMatchPhase != EPolyeMatchPhase::FieldActivation) return;

    APolyePlayerStateBase* RequestingPS = nullptr;
    int32 RequestingPlayerIndex = INDEX_NONE; // Не используется здесь, но хорошо бы иметь
    if (!GetPlayerInfo(RequestingPC, RequestingPS, RequestingPlayerIndex))
    {
        RequestingPC->Client_NotifyActivationError(TEXT("Internal player data error."));
        return;
    }

    if (PlayersFinishedActivationPhase.Contains(RequestingPS))
    {
        UE_LOG(LogTemp, Warning, TEXT("GameMode: Player %s already finished activation."), *RequestingPS->GetPlayerName());
        return; // Уже готов
    }

    int32 CurrentCount = PlayerActivatedFieldCounts.FindRef(RequestingPS);
    if (CurrentCount < MinFieldsToActivate)
    {
        RequestingPC->Client_NotifyActivationError(FText::Format(NSLOCTEXT("Polye", "MinFieldsError", "Minimum {0} fields must be activated."), MinFieldsToActivate).ToString());
        return;
    }

    PlayersFinishedActivationPhase.Add(RequestingPS);
    RequestingPC->Client_NotifyPlayerFinishedActivationPhase(); // Уведомляем этого клиента
    UE_LOG(LogTemp, Log, TEXT("GameMode: Player %s finished activation phase."), *RequestingPS->GetPlayerName());

    TryToEndFieldActivationPhase();
}

void APolyeGameModeBase::TryToEndFieldActivationPhase()
{
    APolyeGameStateBase* GS = GetGameState<APolyeGameStateBase>();
    if (GS && PlayersFinishedActivationPhase.Num() >= GS->ConnectedPlayers.Num() && GS->ConnectedPlayers.Num() >= RequiredPlayers)
    {
        TransitionToGameplayPhase();
    }
}

void APolyeGameModeBase::TransitionToGameplayPhase()
{
    CurrentMatchPhase = EPolyeMatchPhase::Gameplay;
    UE_LOG(LogTemp, Log, TEXT("GameMode: All players ready. Transitioning to Gameplay Phase."));

    for (TObjectPtr<APolyePlayerStateBase> PS : GetGameState<APolyeGameStateBase>()->ConnectedPlayers)
    {
        if (APolyePlayerController* PC = Cast<APolyePlayerController>(PS->GetOwner()))
        {
            PC->Client_EndFieldActivationPhaseForAll(); // Новый RPC для всех
        }
    }
    
    // HandleMatchHasStarted(); // UE функция, можно вызвать ее, если ее логика подходит
    // Или ваша логика начала основного цикла игры
    APolyeGameStateBase* GS = GetGameState<APolyeGameStateBase>();
    if (GS && GS->ConnectedPlayers.IsValidIndex(0)) // Начинает игрок с индексом 0
    {
        GS->SetCurrentActivePlayer_Server(GS->ConnectedPlayers[0]);
        GS->AdvanceTurn_Server(); // Устанавливаем ход 1
        // Дополнительная логика начала первого хода (раздача карт, эфир)
    }
}

    3.  Клики по чужим/нейтральным/уже активным полям или при превышении лимита `MaxFieldsToActivate` приводят к сообщению об ошибке от сервера.

**Ключевые Моменты:**

*   **Четкое Разделение:** Сервер (GameMode) валидирует и изменяет состояние (GameState). Клиент (PlayerController) запрашивает и обновляет UI.
*   **Отзывчивость UI:** Клиент может обновлять свой локальный счетчик (`ActivatedFieldsCount_Client`) немедленно после отправки запроса для лучшей отзывчивости, но истинное состояние всегда определяется сервером и приходит с `Client_NotifyFieldActivated`.
*   **Ошибки и Уведомления:** Сервер должен всегда уведомлять клиента о результате его запроса (успех или ошибка).
