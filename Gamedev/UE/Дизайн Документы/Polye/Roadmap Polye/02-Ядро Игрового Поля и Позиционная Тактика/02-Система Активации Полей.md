**Цель:** Реализовать игровую фазу в начале матча, во время которой каждый игрок может выбрать и активировать от 2 до 5 своих полей. Эта система должна обрабатывать ввод игрока, валидировать его на сервере, обновлять состояние игры и синхронизировать визуальное представление.

**Предпосылки:**

*   Реализована базовая сетевая архитектура (`AGameModeBase`, `AGameStateBase`, `APlayerController`, `APlayerState`).
*   Реализована базовая структура игрового поля (`FPolyeFieldState` в `AGameStateBase`) с `FieldIndex` и `InitialOwnerPlayerIndex`.
*   Реализовано визуальное представление поля (`AGameBoard`, `AFieldTile`) с функцией `UpdateVisualsFromGameState` в `AGameBoard` и `UpdateVisuals`/`SetActiveStateVisuals` в `AFieldTile`.
*   Настроена обработка ввода с помощью Enhanced Input в `APolyePlayerController`, позволяющая определять клики по игровому полю (например, через трассировку луча, возвращающую `FieldIndex` кликнутой плитки).

**Ключевые Компоненты:**

*   **Игровая Фаза:** Механизм в `AGameModeBase` для определения и управления "Фазой Активации Полей".
*   **Счетчик Активированных Полей:** Переменная в `AGameModeBase` или `APolyePlayerStateBase` для отслеживания количества полей, активированных каждым игроком.
*   **Логика Валидации:** Серверная логика в `AGameModeBase` или `APolyePlayerController` для проверки допустимости активации выбранного поля.
*   **RPC:** Для передачи запроса активации от клиента к серверу и уведомления клиента о начале/конце фазы или ошибках.
*   **UI:** Для визуального информирования игрока о фазе и количестве активированных полей, а также кнопки "Готов".

        // SERVER ONLY - Обработка запроса игрока на активацию поля
        void APolyeGameModeBase::HandlePlayerFieldActivationRequest(APolyePlayerController* RequestingPlayer, int32 FieldIndex)
        {
             // **ВАЛИДАЦИЯ НА СЕРВЕРЕ!!!**
             if (!RequestingPlayer || CurrentMatchPhase != EPolyeMatchPhase::FieldActivation)
             {
                  // TODO: Отправить ошибку клиенту
                  return;
             }

             APolyeGameStateBase* GS = GetGameState<APolyeGameStateBase>();
             if (!GS || !GS->BoardState.IsValidIndex(FieldIndex))
             {
                  // TODO: Отправить ошибку клиенту
                  return;
             }

             FPolyeFieldState& FieldState = GS->BoardState[FieldIndex]; // Получаем ссылку на состояние поля в GameState

             // 1. Поле принадлежит игроку, запросившему активацию?
             // Нужно знать индекс игрока. Предполагаем, что PlayerIndex хранится в PlayerState
             APolyePlayerStateBase* PS = Cast<APolyePlayerStateBase>(RequestingPlayer->PlayerState);
             if (!PS || FieldState.InitialOwnerPlayerIndex != PS->PlayerIndex)
             {
                  UE_LOG(LogTemp, Warning, TEXT("Player %s tried to activate field %d which is not theirs."), *RequestingPlayer->GetName(), FieldIndex);
                  RequestingPlayer->Client_NotifyActivationError(TEXT("You can only activate your own fields."));
                  return;
             }

             // 2. Поле еще не активно?
             if (FieldState.bIsActive)
             {
                  UE_LOG(LogTemp, Warning, TEXT("Player %s tried to activate already active field %d."), *RequestingPlayer->GetName(), FieldIndex);
                  RequestingPlayer->Client_NotifyActivationError(TEXT("This field is already active."));
                  return;
             }

             // 3. Игрок не превысил максимальное количество полей?
             FieldsActivatedCount.FindOrAdd(PS->PlayerIndex)++; // Увеличиваем счетчик
             if (FieldsActivatedCount[PS->PlayerIndex] > MaxFieldsToActivate)
             {
                  FieldsActivatedCount.FindOrAdd(PS->PlayerIndex)--; // Откатываем счетчик
                  UE_LOG(LogTemp, Warning, TEXT("Player %s tried to activate field %d but exceeded max limit."), *RequestingPlayer->GetName(), FieldIndex);
                  RequestingPlayer->Client_NotifyActivationError(FText::Format(NSLOCTEXT("Polye", "ActivationLimit", "You can activate maximum of {0} fields."), FText::AsNumber(MaxFieldsToActivate)).ToString());
                  return;
             }

             // --- ВАЛИДАЦИЯ ПРОШЛА! Активируем поле на сервере ---
             UE_LOG(LogTemp, Warning, TEXT("Player %s activated field %d."), *RequestingPlayer->GetName(), FieldIndex);

             FieldState.bIsActive = true; // Устанавливаем флаг активности (реплицируется через BoardState)

             // TODO: Обновить GameState: GS->UpdateFieldState(FieldIndex, FieldState);
             // Если BoardState в GS реплицируется через OnRep_BoardState, то прямое изменение FieldState в массиве BoardState
             // вызовет репликацию всего массива, и OnRep сработает. UE может оптимизировать.

             // Уведомляем клиента об успешной активации и текущем количестве
             RequestingPlayer->Client_NotifyFieldActivated(FieldIndex, FieldsActivatedCount[PS->PlayerIndex]);

             // TODO: Проверить, завершили ли все игроки активацию
             // EndFieldActivationPhase(); // Вызвать, когда все готовы
        }

        void APolyeGameModeBase::HandlePlayerFinishedActivation(APolyePlayerController* RequestingPlayer)
        {
             // **ВАЛИДАЦИЯ НА СЕРВЕРЕ!!!**
             if (!RequestingPlayer || CurrentMatchPhase != EPolyeMatchPhase::FieldActivation) return;

             APolyePlayerStateBase* PS = Cast<APolyePlayerStateBase>(RequestingPlayer->PlayerState);
             if (!PS) return;

             // 1. Игрок уже завершил активацию?

             // 2. Игрок активировал минимальное количество полей?
             if (FieldsActivatedCount.FindOrAdd(PS->PlayerIndex) < MinFieldsToActivate)
             {
                  UE_LOG(LogTemp, Warning, TEXT("Player %s tried to finish activation but hasn't activated enough fields (%d/%d)."), *RequestingPlayer->GetName(), FieldsActivatedCount[PS->PlayerIndex], MinFieldsToActivate);
                  RequestingPlayer->Client_NotifyActivationError(FText::Format(NSLOCTEXT("Polye", "NotEnoughFields", "You must activate at least {0} fields."), FText::AsNumber(MinFieldsToActivate)).ToString());
                  return;
             }

             // --- ВАЛИДАЦИЯ ПРОШЛА! Игрок завершил активацию ---
             UE_LOG(LogTemp, Warning, TEXT("Player %s finished field activation."), *RequestingPlayer->GetName());

             // TODO: Отметить игрока как завершившего активацию: PlayerFinishedMap.Add(PS->PlayerIndex, true);
             PlayersFinishedActivation++; // Увеличиваем глобальный счетчик

             RequestingPlayer->Client_NotifyFinishedActivationPhase(); // Уведомить клиента

             // Проверяем, завершили ли все игроки
             if (PlayersFinishedActivation >= GetNumPlayers()) // Для 2 игроков достаточно проверить >= 2

                  EndFieldActivationPhase();
             }

             // Проверяем, что сейчас фаза активации полей и что клик был сделан

                  // TODO: Если не фаза активации, возможно, обрабатывать другие клики (выбор карты, выбор цели)

             FVector WorldLocation, WorldDirection;
             if (DeprojectMousePositionToWorld(WorldLocation, WorldDirection))

                  FHitResult HitResult;
                  // TODO: Использовать собственный Trace Channel для плиток поля
                  FCollisionQueryParams Params;
                  Params.AddIgnoredActor(this); // Игнорировать самого себя
                  // Debug Draw Trace: DrawDebugLine(GetWorld(), WorldLocation, WorldLocation + WorldDirection * 10000.f, FColor::Red, false, 2.f, 0, 1.f);

                  if (GetWorld()->LineTraceSingleByChannel(HitResult, WorldLocation, WorldLocation + WorldDirection * 10000.f, ECC_Visibility, Params)) // ECC_Visibility или ваш канал
                  {
                       if (AFieldTile* ClickedTile = Cast<AFieldTile>(HitResult.GetActor()))
                       {
                            int32 ClickedFieldIndex = ClickedTile->FieldIndex;

                       }
                  }
             }
        }
