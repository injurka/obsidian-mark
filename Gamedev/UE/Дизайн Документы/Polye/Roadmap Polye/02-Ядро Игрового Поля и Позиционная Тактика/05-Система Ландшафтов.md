**Цель:** Реализовать механику привязки Ландшафта к активному полю с фракцией, хранение данных о выбранном Ландшафте в состоянии поля, применение уникального "Ульта" эффекта этого Ландшафта к сущностям на поле и визуальное представление Ландшафта.

**Предпосылки:**

*   Реализована Фаза 1: Фундамент и Базовые Системы (архитектура, репликация, управление данными, базовые сущности).
    *   Определены структуры данных для Фракций, Ландшафтов, Полей, Эффектов (`EPolyeFaction`, `FPolyeFieldState`, `FFieldUltConfig`, `FPolyeEffectConfig`, `EPolyeEffectType`) в `PolyeDataTypes.h`.
    *   Созданы Data Assets для Фракций (`UPolyeFactionData`) и Ландшафтов (`UPolyeLandscapeData`). `UPolyeFactionData` содержит список доступных `UPolyeLandscapeData`. `UPolyeLandscapeData` содержит `FFieldUltConfig`. `FFieldUltConfig` содержит `TSubclassOf<UPolyeGameplayEffectBase>` и `FPolyeEffectConfig`.
    *   Создан Менеджер Фракций (`UPolyeFactionManager`), способный предоставлять данные о фракциях и их доступных ландшафтах.
    *   Созданы C++ классы `ABoardEntityBase` с компонентом `UPolyeEffectManagerComponent`, `UPolyeGameplayEffectBase` (базовый класс эффекта). Система эффектов может применять/удалять экземпляры `UPolyeGameplayEffectBase` и модифицировать атрибуты сущностей.
*   Реализован Пункт 2.1: Структура Игрового Поля (логическое состояние `FPolyeFieldState` в `AGameStateBase`, визуальное представление `AGameBoard`/`AFieldTile`, система индексов, `UPolyeBoardStatics`).
*   Реализован Пункт 2.2: Система Активации Полей (фаза активации в GameMode, `bIsActive` в `FPolyeFieldState` обновляется).
*   Реализован Пункт 2.3: Размещение Фракций (`CurrentFaction` в `FPolyeFieldState` обновляется). RPC для активации поля принимает тип Фракции. Валидация правила соседства реализована.
*   Реализован Пункт 2.4: Затухающее Влияние. Система расчета Влияния и применения эффектов Ауры реализована (хотя Ульты полей - отдельный механизм, не распространяющийся как Аура). `AGameStateBase::CalculateAndApplyInfluence()` существует.

**Ключевые Компоненты:**

*   **Хранение Ландшафта в `FPolyeFieldState`:** `TSoftObjectPtr<UPolyeLandscapeData>` для ссылки на выбранный Ландшафт.
*   **Обновление RPC Активации Поля:** Включение выбора Ландшафта в запрос клиента.
*   **Серверная Валидация Выбора Ландшафта:** Проверка, что выбранный Ландшафт доступен для выбранной Фракции.
*   **Логика Применения/Удаления Ульты Ландшафта:** Функции (вероятно, в `AGameStateBase` или менеджере) для применения эффекта Ульты Ландшафта к сущностям на поле при его активации/изменении и удаления эффекта при деактивации/изменении.
*   **Визуализация Ландшафта:** `AFieldTile` должен визуально отображать выбранный Ландшафт и эффект его Ульты.
*   **UI Выбора Ландшафта:** Интерфейс для игрока во время фазы активации полей, позволяющий выбрать Ландшафт.

        ```cpp
        #include "Data/PolyeFactionManager.h" // Для доступа к менеджеру фракций и их данным

        // SERVER ONLY - Обработка запроса игрока на активацию поля с фракцией И ландшафтом
        void APolyeGameModeBase::HandlePlayerFieldActivationFactionAndLandscapeRequest(APolyePlayerController* RequestingPlayer, int32 FieldIndex, EPolyeFaction FactionType, FName LandscapeID)
        {
             // **ВАЛИДАЦИЯ НА СЕРВЕРЕ!!!**
             if (!RequestingPlayer || CurrentMatchPhase != EPolyeMatchPhase::FieldActivation)
             {
                  RequestingPlayer->Client_NotifyActivationError(TEXT("Неправильная фаза для активации полей."));
                  return;
             }

             APolyeGameStateBase* GS = GetGameState<APolyeGameStateBase>();
             if (!GS || !GS->BoardState.IsValidIndex(FieldIndex))
             {
                  RequestingPlayer->Client_NotifyActivationError(TEXT("Выбрано неверное поле."));
                  return;
             }

             APolyePlayerStateBase* PS = Cast<APolyePlayerStateBase>(RequestingPlayer->PlayerState);
             if (!PS)
             {
                 RequestingPlayer->Client_NotifyActivationError(TEXT("Неверное состояние игрока."));
                 return;
             }

             FPolyeFieldState& FieldState = GS->BoardState[FieldIndex]; // Получаем ссылку на состояние поля в GameState

             // 1. Поле принадлежит игроку? (Логика из Пункта 2.3)
             if (FieldState.InitialOwnerPlayerIndex != PS->PlayerIndex)
             {
                  RequestingPlayer->Client_NotifyActivationError(TEXT("Вы можете активировать только свои поля."));
                  return;
             }

             // 2. Поле еще не активно? (Логика из Пункта 2.3)
             if (FieldState.bIsActive)
             {
                  RequestingPlayer->Client_NotifyActivationError(TEXT("Это поле уже активно."));
                  return;
             }

             // 3. Игрок не превысил максимальное количество полей? (Логика из Пункта 2.3)
             if (FieldsActivatedCount.FindOrAdd(PS->PlayerIndex) >= MaxFieldsToActivate)
             {
                 RequestingPlayer->Client_NotifyActivationError(FText::Format(NSLOCTEXT("Polye", "ActivationLimit", "Вы можете активировать максимум {0} полей."), FText::AsNumber(MaxFieldsToActivate)).ToString());
                 return;
             }

             // 4. Правило размещения фракций (Логика из Пункта 2.3)
             if (FactionType == EPolyeFaction::EF_Neutral) // Нельзя активировать с нейтральной фракцией
             {
                  RequestingPlayer->Client_NotifyActivationError(TEXT("Нельзя активировать поле с нейтральной фракцией."));
                  return;
             }

             // Проверка правила соседства (Логика из Пункта 2.3)
             TArray<int32> AdjacentFields = UPolyeBoardStatics::GetAdjacentFields(FieldIndex, false);
             for (int32 AdjacentIndex : AdjacentFields)
             {
                  if (GS->BoardState.IsValidIndex(AdjacentIndex))
                  {
                       const FPolyeFieldState& AdjacentFieldState = GS->BoardState[AdjacentIndex];
                       if (AdjacentFieldState.bIsActive && AdjacentFieldState.CurrentFaction != EPolyeFaction::EF_Neutral && AdjacentFieldState.CurrentFaction != FactionType)
                       {
                            RequestingPlayer->Client_NotifyActivationError(TEXT("Нельзя размещать разные фракции рядом (нужно нейтральное/неактивное поле между)."));
                            return;
                       }
                  }
             }

             // 5. **ВАЛИДАЦИЯ ВЫБОРА ЛАНДШАФТА**
             UPolyeFactionManager* FactionManager = GetGameInstance() ? Cast<UPolyeFactionManager>(GetGameInstance()->GetFactionManager()) : nullptr;
             if (!FactionManager)
             {
                  UE_LOG(LogTemp, Error, TEXT("Менеджер Фракций не найден! Невозможно валидировать Ландшафт."));
                  RequestingPlayer->Client_NotifyActivationError(TEXT("Произошла внутренняя ошибка (менеджер фракций отсутствует).")); // Или более общее сообщение
                  return;
             }

             const UPolyeFactionData* FactionData = FactionManager->GetFactionData(FactionType);
             if (!FactionData)
             {
                 UE_LOG(LogTemp, Error, TEXT("Данные фракции %s не найдены!"), *UEnum::GetValueAsString(FactionType));
                 RequestingPlayer->Client_NotifyActivationError(TEXT("Произошла внутренняя ошибка (данные фракции отсутствуют)."));
                 return;
             }

             // Ищем UPolyeLandscapeData Asset по ID
             TSoftObjectPtr<const UPolyeLandscapeData> SelectedLandscapePtr;
             for (const TSoftObjectPtr<const UPolyeLandscapeData>& AvailableLandscapePtr : FactionData->AvailableLandscapes)
             {
                  if (AvailableLandscapePtr.IsValid() && AvailableLandscapePtr.GetAssetName() == LandscapeID.ToString()) // Сравнение по Asset Name
                  {
                       SelectedLandscapePtr = AvailableLandscapePtr;
                       break;
                  }
             }

             // Валидация: Выбранный Ландшафт должен быть в списке доступных для этой Фракции И ссылка должна быть валидна.
             if (!SelectedLandscapePtr.IsValid())
             {
                  UE_LOG(LogTemp, Warning, TEXT("Player %s tried to activate field %d with invalid Landscape ID %s for Faction %s."),
                       *RequestingPlayer->GetName(), FieldIndex, *LandscapeID.ToString(), *UEnum::GetValueAsString(FactionType));
                   RequestingPlayer->Client_NotifyActivationError(TEXT("Выбран неверный Ландшафт для этой Фракции."));
                   return;
             }


             // --- ВСЕ ВАЛИДАЦИИ ПРОШЛИ УСПЕШНО! Активируем поле с фракцией И ландшафтом на сервере ---
             UE_LOG(LogTemp, Warning, TEXT("Player %s activated field %d with faction %s and landscape %s."),
                  *RequestingPlayer->GetName(), FieldIndex, *UEnum::GetValueAsString(FactionType), *LandscapeID.ToString());

             // Сохраняем старое состояние поля, чтобы знать, был ли раньше Ландшафт
             FPolyeFieldState OldFieldState = FieldState;

             // Устанавливаем новые реплицируемые свойства на сервере
             FieldState.bIsActive = true; // Активируем поле
             FieldState.CurrentFaction = FactionType; // Устанавливаем фракцию
             FieldState.CurrentLandscapeDataAsset = SelectedLandscapePtr; // Устанавливаем Ландшафт (это TSoftObjectPtr, реплицируется)

             FieldsActivatedCount.FindOrAdd(PS->PlayerIndex)++; // Увеличиваем счетчик активированных полей

             // TODO: Обновить GameState: GS->UpdateFieldState(FieldIndex, FieldState); // Если FieldState[FieldIndex] = FieldState не вызовет репликацию

             // **ПРИМЕНЯЕМ ЭФФЕКТ УЛЬТЫ ЛАНДШАФТА**
             // Если поле уже было активно и имел другой Ландшафт, удаляем старый эффект
             if (OldFieldState.bIsActive && OldFieldState.CurrentLandscapeDataAsset.IsValid() && OldFieldState.CurrentLandscapeDataAsset != FieldState.CurrentLandscapeDataAsset)
             {
                 // Загружаем старый DA Ландшафта, чтобы получить его конфиг Ульты для удаления эффекта
                 if (const UPolyeLandscapeData* OldLandscapeData = OldFieldState.CurrentLandscapeDataAsset.LoadSynchronous()) // TODO: Возможно, асинхронная загрузка лучше, но для удаления эффекта нужен немедленно
                 {
                      RemoveLandscapeUltEffectFromField(FieldIndex, OldLandscapeData); // Вызываем функцию удаления
                 }
             }

             // Применяем эффект Ульты НОВОГО Ландшафта
             ApplyLandscapeUltEffectToField(FieldIndex); // Вызываем функцию применения

             // **ПЕРЕРАСЧЕТ ВЛИЯНИЯ**
             // Активация поля с фракцией меняет карту влияния. Перерасчитываем Ауры.
             // ВАЖНО: Это должно происходить ПОСЛЕ установки фракции и ландшафта в BoardState.
             CalculateAndApplyInfluence(); // Функция из Пункта 2.4


             // Уведомляем клиента об успешной активации, фракции, ландшафте и текущем количестве
             // TODO: Добавить Client RPC: Client_NotifyFieldActivatedWithFactionAndLandscape
             // RequestingPlayer->Client_NotifyFieldActivatedWithFactionAndLandscape(FieldIndex, FactionType, LandscapeID, FieldsActivatedCount[PS->PlayerIndex]);

             // TODO: Проверить, завершили ли все игроки активацию (логика из Пункта 2.2)
             // EndFieldActivationPhase(); // Вызвать, когда все готовы
        }

        ```

        // SERVER ONLY - Применяет эффект Ульты Ландшафта к сущностям на поле
        void APolyeGameStateBase::ApplyLandscapeUltEffectToField(int32 FieldIndex)
        {
             if (!HasAuthority() || !BoardState.IsValidIndex(FieldIndex)) return;

             const FPolyeFieldState& FieldState = BoardState[FieldIndex];
             // Ульта применяется только к активным полям с ландшафтом
             if (!FieldState.bIsActive || !FieldState.CurrentLandscapeDataAsset.IsValid()) return;

             // Загружаем Data Asset Ландшафта, чтобы получить конфиг Ульты
             const UPolyeLandscapeData* LandscapeData = FieldState.CurrentLandscapeDataAsset.LoadSynchronous(); // TODO: Асинхронная загрузка, если это не критично по времени

                  return; // Нечего применять

             const FFieldUltConfig& UltConfig = LandscapeData->LandscapeUlt;

             UE_LOG(LogTemp, Log, TEXT("Применяем Ульту Ландшафта %s к сущностям на поле %d."), *LandscapeData->GetName(), FieldIndex);

             // Применяем эффект Ульты к каждой сущности на этом поле

                        Entity->GetEffectManagerComponent()->ApplyEffect(UltConfig.EffectClass, UltConfig.EffectParameters); // MVP: пока без SourceField в конфиге
                  }
             }

             // TODO: Возможно, запустить визуальный эффект Ульты на самом поле (не на сущностях)
             // Это может быть Multicast RPC или вызов функции на AFieldTile через AGameBoard

        }

        // SERVER ONLY - Удаляет эффект Ульты Ландшафта с сущностей на поле
        void APolyeGameStateBase::RemoveLandscapeUltEffectFromField(int32 FieldIndex, const UPolyeLandscapeData* OldLandscapeData)
        {
             if (!HasAuthority() || !BoardState.IsValidIndex(FieldIndex) || !OldLandscapeData || !OldLandscapeData->LandscapeUlt.EffectClass) return;

             const FFieldUltConfig& OldUltConfig = OldLandscapeData->LandscapeUlt;

             UE_LOG(LogTemp, Log, TEXT("Удаляем Ульту Ландшафта %s с сущностей на поле %d."), *OldLandscapeData->GetName(), FieldIndex);

             // Удаляем эффект Ульты с каждой сущности, которая НАХОДИТСЯ на поле СЕЙЧАС
             // Важно: итерируем по текущему списку сущностей, а не по старому
             const FPolyeFieldState& FieldState = BoardState[FieldIndex]; // Берем актуальное состояние

             for (ABoardEntityBase* Entity : FieldState.EntitiesOnField)
             {
                  if (Entity && !Entity->IsPendingKill() && Entity->GetEffectManagerComponent())

**Тестирование и Дальнейшие Шаги:**

*   **Валидация Ландшафта:** Тщательно протестировать серверную валидацию: попытка выбрать ландшафт, недоступный для выбранной фракции, попытка активировать без выбора ландшафта (если это обязательно).

Проверить, что эффекты Ульты *не* распространяются на соседние поля (в отличие от Аур).
*   **Синхронизация Визуала:** Проверить, что изменение Ландшафта на сервере корректно отображается на всех клиентах (визуал плитки и эффекты Ульты).

Когда сущность покидает поле или уничтожается, эффекты Ульты, примененные этим полем, должны быть сняты с этой конкретной сущности. `UPolyeEffectManagerComponent::RemoveEffectsBySourceField` становится важным здесь.
