**Цель:** Реализовать ключевую игровую механику "Затухающего Влияния", при которой активные поля с фракциями проецируют Ауры на другие активные поля. Эти Ауры воздействуют на сущности, находящиеся на затронутых полях, с силой, зависящей от расстояния от источника (100% на поле источника (если аура действует на себя), 50% на соседних ортогонально, 25% через одно ортогонально). Система должна:
    1.  Рассчитывать суммарное влияние (набор активных аур и их силу) на каждом активном поле.
    2.  Применять/удалять соответствующие экземпляры эффектов на сущностях на этих полях.
    3.  Корректно реплицировать состояние влияния и эффектов.
    4.  Предоставлять основу для визуализации аур на полях и эффектов на сущностях.

**Предпосылки (Уже Реализованы):**

1.  **Сетевая Архитектура:** `APolyeGameModeBase`, `APolyeGameStateBase`, `APolyePlayerController`, `APolyePlayerStateBase`.
2.  **Система Данных:**
    *   `PolyeTypes.h`: `EPolyeFaction`, `FPolyeFieldState`, `EPolyeEffectType`, `EPolyeAttributeType`.
    *   Добавлены (из предыдущего ответа) `FDecayingAuraDefinition` (содержит `EffectAt100`, `EffectAt50`, `EffectAt25` типа `FEffectDefinition`), `FEffectDefinition` (описывает параметры эффекта).
    *   Data Assets: `UPolyeFactionData` (содержит `TArray<FDecayingAuraDefinition> DecayingAuras`), `UPolyeCardData`.
    *   Менеджер Данных (`UPolyeDataManager` или аналогичный) для доступа к `UPolyeFactionData`.
3.  **Система Сущностей:** `APolyeBoardEntityBase` с базовыми атрибутами. **(Критически важно: этот шаг потребует доработки `APolyeBoardEntityBase` для интеграции с системой эффектов).**
4.  **Игровое Поле:** Логическое состояние в `APolyeGameStateBase::BoardState` (`FPolyeFieldState` содержит `bIsActive`, `CurrentFaction`). Идентификация полей через `UPolyeBoardStatics` (`GetAdjacentFieldIndices`, `GetFieldsTwoStepsAway`).
5.  **Фаза Активации Полей:** `APolyeGameModeBase` управляет активацией полей и применением фракций.

**Ключевые Компоненты и Их Роли (Детализация):**

1.  **`UPolyeGameplayEffect` (Новый или доработанный `UPolyeGameplayEffectBase`):**
    *   **Роль:** Представляет активный экземпляр эффекта на сущности. Создается на сервере, реплицируется.
    *   **Данные:** `FEffectDefinition EffectData` (копия из `FDecayingAuraDefinition` для конкретной силы), `float SourceFieldStrength` (0.25/0.5/1.0), `int32 SourceFieldOriginIndex` (откуда пришла аура), `EPolyeFaction SourceFactionType`. Эти данные помогут идентифицировать и управлять эффектом.
    *   **Функции:** `Initialize(const FEffectDefinition& Data, float Strength, int32 OriginIdx, EPolyeFaction OriginFaction)`, `ApplyToEntity_Server(APolyeBoardEntityBase* Target)`, `RemoveFromEntity_Server(APolyeBoardEntityBase* Target)`, `ModifyAttribute_Pure(EPolyeAttributeType Attr, float BaseValue) const`.
2.  **`UPolyeEntityEffectComponent` (Новый или доработанный `UPolyeEffectManagerComponent`):**
    *   **Роль:** Компонент на `APolyeBoardEntityBase`. Управляет массивом `TArray<TObjectPtr<UPolyeGameplayEffect>> ActiveAppliedEffects` (реплицируемый).
    *   **Функции:**
        *   `ApplyGameplayEffect_Server(TSubclassOf<UPolyeGameplayEffect> EffectClass, const FEffectDefinition& EffectData, float Strength, int32 OriginIdx, EPolyeFaction OriginFaction)`: Создает `UPolyeGameplayEffect`, инициализирует, вызывает `ApplyToEntity_Server`, добавляет в массив.
        *   `RemoveGameplayEffectBySourceAndType_Server(int32 OriginIdx, EPolyeFaction OriginFaction, EPolyeEffectType AuraEffectType)`: Находит и удаляет эффект.
        *   `RemoveAllAuraEffectsFromSource_Server(int32 OriginIdx, EPolyeFaction OriginFaction)`: Удаляет все эффекты от конкретного источника.
        *   `GetEffectiveAttributeValue(EPolyeAttributeType Attr, float BaseValue) const`: Итерирует по `ActiveAppliedEffects`, вызывает `ModifyAttribute_Pure`.
        *   `HasEffectFromSource(int32 OriginIdx, EPolyeFaction OriginFaction, EPolyeEffectType AuraEffectType) const`.
    *   `OnRep_ActiveAppliedEffects()`: Для клиентских обновлений UI/визуала эффектов на сущности.
3.  **`UPolyeInfluenceCalculator` (Новый `UObject` или статический класс/`UGameStateComponent`):**
    *   **Роль (Сервер):** Центральный вычислитель. Не хранит состояние, а только выполняет расчеты.
    *   **Функция:** `CalculateFieldInfluenceMap(const TArray<FPolyeFieldState>& CurrentBoardState, UPolyeDataManager* DataManager, TMap<int32, FActiveFieldInfluence>& OutInfluenceMap)`.
        *   Итерирует по всем `Active=true` полям с `Faction != Neutral` (`SourceFields`).
        *   Для каждого `SourceField`:
            *   Получает `UPolyeFactionData` через `DataManager`.
            *   Для каждой `FDecayingAuraDefinition` в `FactionData->DecayingAuras`:
                *   Определяет целевые поля (`TargetFields`) на расстоянии 0 (100%), 1 (50%), 2 (25%) шагов (используя `UPolyeBoardStatics`).
                *   Для каждого `TargetField` (если он `Active=true`):
                    *   Создает `FAppliedAuraData {AuraEffectType, SourceFieldOriginIndex, SourceFactionType, Strength, FEffectDefinition}` (FEffectDefinition берется из `AuraDefinition` для соответствующей силы).
                    *   Добавляет эту `FAppliedAuraData` в `OutInfluenceMap[TargetFieldIndex].AppliedAuras`.
        *   **Правило сложения:** При добавлении `FAppliedAuraData` в `OutInfluenceMap`, если для `TargetFieldIndex` уже есть аура того же `AuraEffectType` от *другого* `SourceFieldOriginIndex`, они обе остаются (складываются). Если от *того же* `SourceFieldOriginIndex` (что невозможно, т.к. каждая аура фракции уникальна), то применяется сильнейшая (это правило для одинаковых аур от разных полей одной фракции уже учтено на этапе расчета силы для `TargetField`).
            *   **Коррекция правила из вашего документа:** "Если активное поле находится под влиянием нескольких полей ОДНОЙ И ТОЙ ЖЕ ФРАКЦИИ ... применяется только САМЫЙ СИЛЬНЫЙ эффект от этой конкретной Ауры." Это нужно реализовать при построении `OutInfluenceMap`. Когда итерируем по `SourceFields`, и для `TargetField` уже есть аура типа X от той же фракции, но с другого источника, нужно сравнить силы и оставить/заменить на сильнейшую.
            *   "Если ... от РАЗНЫХ фракций ... эффекты этих разных Аур СКЛАДЫВАЮТСЯ." Это означает, что в `OutInfluenceMap[TargetFieldIndex].AppliedAuras` могут быть ауры разных типов от разных фракций.
4.  **`APolyeGameStateBase` (Сервер & Клиенты):**
    *   **Данные:** `UPROPERTY(ReplicatedUsing=OnRep_FieldInfluences) TMap<int32, FActiveFieldInfluence> ActiveFieldInfluences;`.
        *   `FActiveFieldInfluence` (новая структура в `PolyeTypes.h`): `TArray<FAppliedAuraData> AppliedAuras;`.
        *   `FAppliedAuraData` (новая структура в `PolyeTypes.h`): `EPolyeEffectType AuraEffectType; int32 SourceFieldOriginIndex; EPolyeFaction SourceFactionType; float Strength; FEffectDefinition EffectiveConfig;` (конфиг с параметрами для данной силы).
    *   **Логика (Сервер):**
        *   Функция `UpdateFieldInfluencesAndApplyEffects_Server()`. Вызывается при изменении `BoardState` (активация/деактивация поля, смена фракции) или перемещении/смерти сущностей.
        *   Внутри вызывает `UPolyeInfluenceCalculator::CalculateFieldInfluenceMap()`, получает `NewInfluenceMap`.
        *   Сравнивает `NewInfluenceMap` с текущим `ActiveFieldInfluences`.
        *   Для каждого поля:
            *   **Удаляет старые эффекты:** Если аура была в `ActiveFieldInfluences` но нет в `NewInfluenceMap`, или изменилась сила/конфиг, вызывает `Entity->EffectComponent->RemoveGameplayEffectBySourceAndType_Server()`.
            *   **Применяет новые/обновленные эффекты:** Если аура есть в `NewInfluenceMap` и ее не было / она изменилась, вызывает `Entity->EffectComponent->ApplyGameplayEffect_Server()`.
        *   Обновляет `this->ActiveFieldInfluences = NewInfluenceMap;` (репликация и `OnRep_FieldInfluences` на клиентах).
    *   **Клиент:** `OnRep_FieldInfluences()` уведомляет `AGameBoard` для обновления визуала аур на плитках.
5.  **`AGameBoard` & `AFieldTile` (Клиент):**
    *   `AFieldTile::UpdateFromState()` или новое `UpdateInfluenceVisuals(const FActiveFieldInfluence& InfluenceData)` (вызывается из `AGameBoard`, который получает данные из `APolyeGameStateBase::OnRep_FieldInfluences`).
    *   `BP_FieldTile` реализует отображение иконок/эффектов аур на плитке на основе `InfluenceData.AppliedAuras`.

```cpp
void UPolyeEntityEffectComponent::ApplyAuraEffect_Server(const FAppliedAuraData& AuraToApply)
{
    if (!GetOwner()->HasAuthority() || !OwningEntity) return;

    // Проверяем, нет ли уже точно такого же эффекта (от того же источника, тот же тип, та же сила)
    for (const auto& ExistingEffect : ActiveAppliedEffects)
    {
        if (ExistingEffect &&
            ExistingEffect->GetEffectType() == AuraToApply.AuraEffectType &&
            ExistingEffect->SourceFieldOriginIndex_Rep == AuraToApply.SourceFieldOriginIndex &&
            ExistingEffect->SourceFactionType_Rep == AuraToApply.SourceFactionType &&
            FMath::IsNearlyEqual(ExistingEffect->SourceStrength_Rep, AuraToApply.Strength))
        {
            // UE_LOG(LogTemp, Log, TEXT("Aura effect %s from %d (%s) strength %.2f already applied to %s."),
            //     *UEnum::GetValueAsString(AuraToApply.AuraEffectType), AuraToApply.SourceFieldOriginIndex, *UEnum::GetValueAsString(AuraToApply.SourceFactionType), AuraToApply.Strength, *OwningEntity->GetName());
            return; // Эффект уже есть, ничего не делаем (или обновляем длительность/стеки, если есть такая логика)
        }
    }

    UPolyeDataManager* DataManager = GetWorld()->GetGameInstance()->GetSubsystem<UPolyeDataManager>();
    if (!DataManager) return;

    // Получаем класс эффекта для создания экземпляра. Эта функция должна быть в DataManager или FactionData.
    // Предположим, DataManager может дать класс по EPolyeEffectType (это может быть TMap в DataManager).
    TSubclassOf<UPolyeGameplayEffect> EffectClass = DataManager->GetGameplayEffectClass(AuraToApply.AuraEffectType);

    if (!EffectClass)
    {
        UE_LOG(LogTemp, Error, TEXT("No GameplayEffect class found for AuraEffectType: %s"), *UEnum::GetValueAsString(AuraToApply.AuraEffectType));
        return;
    }

    UPolyeGameplayEffect* NewEffect = NewObject<UPolyeGameplayEffect>(OwningEntity, EffectClass); // Владелец - OwningEntity для корректной репликации
    if (NewEffect)
    {
        NewEffect->InitializeFromAppliedAura(AuraToApply); // Передаем данные ауры для инициализации
        ActiveAppliedEffects.Add(NewEffect);
        NewEffect->OnAppliedToEntity(OwningEntity); // Серверный коллбэк
        // Массив изменился, OnRep_ActiveEffects вызовется на клиентах
        UE_LOG(LogTemp, Log, TEXT("Applied Aura effect %s from %s to %s. Total: %d"),
               *UEnum::GetValueAsString(AuraToApply.AuraEffectType), *UEnum::GetValueAsString(AuraToApply.SourceFactionType), *OwningEntity->GetName(), ActiveAppliedEffects.Num());
    }
}

void UPolyeEntityEffectComponent::RemoveAllAuraEffectsFromSource_Server(int32 SourceFieldOriginIndex, EPolyeFaction SourceFaction)
{
    if (!GetOwner()->HasAuthority() || !OwningEntity) return;

    for (int32 i = ActiveAppliedEffects.Num() - 1; i >= 0; --i)
    {
        UPolyeGameplayEffect* Effect = ActiveAppliedEffects[i];
```

**2. Реализация `UPolyeInfluenceCalculator`**

*   **Действие:** Создать `UCLASS() class UPolyeInfluenceCalculator : public UObject` (или статический класс `FPolyeInfluenceCalculatorUtils`, если не нужен стейт). Реализовать `CalculateFieldInfluenceMap()`.
    *   **Правило сложения:**
        *   **Ауры от РАЗНЫХ фракций:** Всегда складываются (т.е. все добавляются в `AppliedAuras` для поля).
        *   **Ауры ОДНОГО ТИПА от полей ОДНОЙ И ТОЙ ЖЕ фракции:** Применяется только самый сильный эффект. Это значит, что при добавлении ауры в `AppliedAuras` для `TargetField`, если там уже есть аура такого же `AuraEffectType` от той же `SourceFactionType`, но с другого `SourceFieldOriginIndex`, нужно оставить только ту, у которой `Strength` выше.
*   **Outcome:** Готов алгоритм расчета влияния.

**Пример `PolyeInfluenceCalculator.h`:**

**`PolyeInfluenceCalculator.cpp` (ключевая логика):**
```cpp
// Polye/Source/Polye/GameplaySystems/Influence/PolyeInfluenceCalculator.cpp
#include "GameplaySystems/Influence/PolyeInfluenceCalculator.h"
#include "Polye/Data/PolyeDataManager.h"
#include "Polye/Data/PolyeFactionData.h"
#include "Polye/Utilities/PolyeBoardStatics.h"

void UPolyeInfluenceCalculator::CalculateFieldInfluenceMap(
    const TArray<FPolyeFieldState>& CurrentBoardState,
    UPolyeDataManager* DataManager,
    int32 NumRows, int32 NumColumns,
    TMap<int32, FActiveFieldInfluence>& OutInfluenceMap)
{
    OutInfluenceMap.Empty();
    if (!DataManager) return;

    // 1. Собрать все активные поля-источники фракций
    TArray<int32> SourceFieldIndices;
    for (const auto& Field : CurrentBoardState)
    {
        if (Field.bIsActive && Field.CurrentFaction != EPolyeFaction::Neutral)
        {
            SourceFieldIndices.Add(Field.FieldIndex);
        }
    }

    // Вспомогательная структура для применения правила "сильнейшая аура от одной фракции"
    // TargetFieldIndex -> FactionType -> AuraEffectType -> StrongestAppliedAuraData
    TMap<int32, TMap<EPolyeFaction, TMap<EPolyeEffectType, FAppliedAuraData>>> TempInfluenceBuilder;

    // 2. Для каждого источника, рассчитать его влияние на целевые поля
    for (int32 SourceIdx : SourceFieldIndices)
    {
        const FPolyeFieldState& SourceField = CurrentBoardState[SourceIdx];
        const UPolyeFactionData* FactionData = DataManager->GetFactionData(SourceField.CurrentFaction);
        if (!FactionData) continue;

        for (const FDecayingAuraDefinition& AuraDef : FactionData->DecayingAuras)
        {
            // Поле источника (100%, если аура действует на себя)
            // Соседи (50%)
            // Через одного (25%)
            TArray<TTuple<int32, float>> PotentialTargets; // FieldIndex, Strength
            
            // Само поле (сила 1.0, если аура фракции может действовать на свое поле, иначе пропускаем)
            // По дизайну, "Баффы" действуют на 100% и не распространяются. Ауры - на соседей.
            // Если FDecayingAuraDefinition предназначена только для соседей, то SourceIdx здесь не нужен.
            // Если какая-то аура из FDecayingAuraDefinition может действовать и на 100%, то добавляем:
            // if (AuraDef.bAffectsSourceField) PotentialTargets.Add({SourceIdx, 1.0f});


            TArray<int32> Neighbors = UPolyeBoardStatics::GetAdjacentFieldIndices(SourceIdx, NumRows, NumColumns, false);
            for (int32 NeighborIdx : Neighbors)
            {
                PotentialTargets.Add({NeighborIdx, 0.5f});
            }

            TArray<int32> SecondNeighbors = UPolyeBoardStatics::GetFieldsTwoStepsAway(SourceIdx, NumRows, NumColumns); // Ваша функция
            for (int32 SecondNeighborIdx : SecondNeighbors)
            {
                PotentialTargets.Add({SecondNeighborIdx, 0.25f});
            }

            for (const auto& TargetTuple : PotentialTargets)
            {
                int32 TargetIdx = TargetTuple.Get<0>();
                float Strength = TargetTuple.Get<1>();

                if (!CurrentBoardState.IsValidIndex(TargetIdx) || !CurrentBoardState[TargetIdx].bIsActive) continue;

                // Собираем данные для ауры
                FAppliedAuraData AppliedAura;
                AppliedAura.AuraEffectType = AuraDef.AuraEffectType_DEPRECATED; // TODO: Заменить на FName или GameplayTag
                AppliedAura.SourceFieldOriginIndex = SourceIdx;
                AppliedAura.SourceFactionType = SourceField.CurrentFaction;
                AppliedAura.Strength = Strength;

                // Получаем FEffectDefinition для этой силы
                const FEffectDefinition* ConfigForStrength = AuraDef.GetConfigForStrength(Strength); // Ваша функция
                if (ConfigForStrength)
                {
                    AppliedAura.EffectiveConfig = *ConfigForStrength;
                } else {
                    UE_LOG(LogTemp, Warning, TEXT("No config for strength %.2f for aura %s"), Strength, *UEnum::GetValueAsString(AppliedAura.AuraEffectType));
                    continue; // Не можем применить ауру без конфига
                }
                
                // Применяем правило "сильнейшая аура одного типа от одной фракции"
                FAppliedAuraData* ExistingStrongestAura = TempInfluenceBuilder.FindOrAdd(TargetIdx)
                                                                            .FindOrAdd(AppliedAura.SourceFactionType)
                                                                            .Find(AppliedAura.AuraEffectType);
                if (!ExistingStrongestAura || AppliedAura.Strength > ExistingStrongestAura->Strength)
                {
                    TempInfluenceBuilder.FindOrAdd(TargetIdx)
                                        .FindOrAdd(AppliedAura.SourceFactionType)
                                        .Add(AppliedAura.AuraEffectType, AppliedAura);
                }
            }
        }
    }

    // 3. Собираем итоговую карту влияния. Ауры от разных фракций просто складываются.
    for (const auto& TargetFieldEntry : TempInfluenceBuilder) // TargetFieldIndex -> FactionMap
    {
        int32 TargetFieldIndex = TargetFieldEntry.Key;
        FActiveFieldInfluence FieldInfluence;
        for (const auto& FactionEntry : TargetFieldEntry.Value) // FactionType -> AuraMap
        {
            for (const auto& AuraEntry : FactionEntry.Value) // AuraEffectType -> AppliedAuraData
            {
                FieldInfluence.AppliedAuras.Add(AuraEntry.Value);
            }
        }
        if (FieldInfluence.AppliedAuras.Num() > 0)
        {
            OutInfluenceMap.Add(TargetFieldIndex, FieldInfluence);
        }
    }
    // UE_LOG(LogTemp, Log, TEXT("Influence map calculated. %d fields affected."), OutInfluenceMap.Num());
}
```

```cpp
void APolyeGameStateBase::RecalculateInfluenceAndApplyEffects_Server()
{
    if (!HasAuthority()) return;

    // Сохраняем старое состояние влияния для сравнения
    TMap<int32, FActiveFieldInfluence> OldInfluences = ActiveFieldInfluences;
    TMap<int32, FActiveFieldInfluence> NewInfluences;

    // 1. Рассчитать новую карту влияния
    if (!InfluenceCalculator) InfluenceCalculator = NewObject<UPolyeInfluenceCalculator>(this); // Создаем, если нет
    
    UPolyeDataManager* DataManager = GetWorld()->GetGameInstance()->GetSubsystem<UPolyeDataManager>(); // Получаем DataManager
    // Нужны размеры доски из GameState или статические
    int32 NumRows = 3; // TODO: Получить из конфига/BoardStatics
    int32 NumCols = 5; // TODO: Получить из конфига/BoardStatics
    
    UPolyeInfluenceCalculator::CalculateFieldInfluenceMap(BoardState, DataManager, NumRows, NumCols, NewInfluences);

    // 2. Применить изменения к сущностям
    // Собираем все затронутые поля (старые и новые)
    TSet<int32> AllAffectedFieldIndices;
    for (const auto& Elem : OldInfluences) AllAffectedFieldIndices.Add(Elem.Key);
    for (const auto& Elem : NewInfluences) AllAffectedFieldIndices.Add(Elem.Key);

    for (int32 FieldIdx : AllAffectedFieldIndices)
    {
        if (!BoardState.IsValidIndex(FieldIdx)) continue;

        const FActiveFieldInfluence* OldFieldInfluencePtr = OldInfluences.Find(FieldIdx);
        const FActiveFieldInfluence* NewFieldInfluencePtr = NewInfluences.Find(FieldIdx);

        TArray<FAppliedAuraData> AurasToRemove;
        TArray<FAppliedAuraData> AurasToAdd;

        // Определяем, какие ауры удалить
        if (OldFieldInfluencePtr)
        {
            for (const FAppliedAuraData& OldAura : OldFieldInfluencePtr->AppliedAuras)
            {
                bool bFoundInNew = false;
                if (NewFieldInfluencePtr)
                {
                    for (const FAppliedAuraData& NewAura : NewFieldInfluencePtr->AppliedAuras)
                    {
                        if (OldAura == NewAura) // Используем operator==
                        {
                            bFoundInNew = true;
                            break;
                        }
                    }
                }
                if (!bFoundInNew)
                {
                    AurasToRemove.Add(OldAura);
                }
            }
        }

        // Определяем, какие ауры добавить
        if (NewFieldInfluencePtr)
        {
            for (const FAppliedAuraData& NewAura : NewFieldInfluencePtr->AppliedAuras)
            {
                bool bFoundInOld = false;
                if (OldFieldInfluencePtr)
                {
                    for (const FAppliedAuraData& OldAura : OldFieldInfluencePtr->AppliedAuras)
                    {
                        if (NewAura == OldAura)
                        {
                            bFoundInOld = true;
                            break;
                        }
                    }
                }
                if (!bFoundInOld)
                {
                    AurasToAdd.Add(NewAura);
                }
            }
        }

        // Применяем изменения к сущностям на поле FieldIdx
        for (APolyeBoardEntityBase* Entity : BoardState[FieldIdx].EntitiesOnField)
        {
            if (Entity && Entity->GetEntityEffectComponent()) // Используем GetEntityEffectComponent()
            {
                UPolyeEntityEffectComponent* EffectComp = Entity->GetEntityEffectComponent();
                for (const FAppliedAuraData& Aura : AurasToRemove)
                {
                    EffectComp->RemoveAuraEffectByTypeAndSource_Server(Aura.AuraEffectType, Aura.SourceFieldOriginIndex, Aura.SourceFactionType);
                }
                for (const FAppliedAuraData& Aura : AurasToAdd)
                {
                    EffectComp->ApplyAuraEffect_Server(Aura);
                }
            }
        }
    }

    // 3. Обновить реплицируемое состояние
    ActiveFieldInfluences = NewInfluences;
    // OnRep_ActiveFieldInfluences вызовется на клиентах (и на сервере, если NetMode != NM_Client)
    if(GetNetMode() != NM_Client) OnRep_ActiveFieldInfluences(); 
    UE_LOG(LogTemp, Log, TEXT("GameState: Influence recalculated and effects updated."));
}
```
