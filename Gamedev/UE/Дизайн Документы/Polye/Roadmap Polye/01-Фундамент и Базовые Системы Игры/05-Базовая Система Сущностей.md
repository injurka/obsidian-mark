**Цель:** Создать визуальное и логическое представление игрового поля 3x5, определить систему идентификации полей, настроить их сетевую синхронизацию и реализовать базовую визуализацию их состояния (активное/неактивное).

**Ключевые Компоненты:**

*   **Логическое Состояние:** `APolyeGameStateBase` будет хранить центральное, реплицируемое состояние всего поля.
*   **Структура Данных Поля:** `USTRUCT` для описания состояния одного поля.
*   **Визуальное Представление:** `AActor` для представления всей игровой доски (`AGameBoard`) и отдельные `AActor` (или компоненты) для каждой плитки поля (`AFieldTile`).
*   **Система Идентификации:** Простая числовая индексация полей.

        {
            GENERATED_BODY()

            // Или использовать ReplicatedUsing на свойствах *внутри* AGameStateBase.

            // UFUNCTION()

            // void OnRep_Faction();
            // UFUNCTION()

            bool operator==(const FPolyeFieldState& Other) const

                 return FieldIndex == Other.FieldIndex
                     && bIsActive == Other.bIsActive
                     && CurrentFaction == Other.CurrentFaction

        };

    *   **Обоснование:** Эта структура определяет, какие данные будут храниться для каждого поля и реплицироваться между сервером и клиентами. Она является "схемой" для состояния каждого поля.             }

        void APolyeGameStateBase::AddEntityToField(int32 FieldIndex, ABoardEntityBase* Entity)
        {
             if (!HasAuthority() || !Entity || !BoardState.IsValidIndex(FieldIndex)) return;

             // Убедиться, что сущность еще не добавлена
             if (!BoardState[FieldIndex].EntitiesOnField.Contains(Entity))
             {
                 BoardState[FieldIndex].EntitiesOnField.Add(Entity);
                 // Изменение массива внутри структуры в массиве - может потребовать принудительной репликации или использования OnRep_BoardState

                 // MarkNetDirty(); // Может помочь принудительно реплицировать
             }
        }

         void APolyeGameStateBase::RemoveEntityFromField(int32 FieldIndex, ABoardEntityBase* Entity)
        {
            if (!HasAuthority() || !Entity || !BoardState.IsValidIndex(FieldIndex)) return;

            BoardState[FieldIndex].EntitiesOnField.Remove(Entity);
            // MarkNetDirty(); // Может помочь принудительно реплицировать
        }

            void AGameBoard::SpawnFieldTiles()
            {
                 if (!FieldTileClass)
                 {
                     UE_LOG(LogTemp, Error, TEXT("FieldTileClass is not set on AGameBoard!"));
                     return;
                 }

                 UWorld* World = GetWorld();
                 if (!World) return;

                 FieldTiles.SetNum(UPolyeBoardStatics::TotalFields); // Инициализируем массив

                 for (int32 i = 0; i < UPolyeBoardStatics::TotalFields; ++i)
                 {
                      FVector SpawnLocation = UPolyeBoardStatics::GetWorldLocationForField(i);
                      // TODO: Возможно, добавить повороты для плиток игроков

                      FActorSpawnParameters SpawnParams;
                      SpawnParams.Owner = this; // Владелец - сам AGameBoard
                      SpawnParams.Instigator = GetInstigator();

                      // Спавним Актер плитки поля
                      AFieldTile* NewTile = World->SpawnActor<AFieldTile>(FieldTileClass, SpawnLocation, FRotator::ZeroRotator, SpawnParams);
                      if (NewTile)
                      {
                           FieldTiles[i] = NewTile;
                           NewTile->SetFieldIndex(i); // Устанавливаем индекс поля для плитки
                           // TODO: Установить другие начальные параметры плитки (напр., начальное владение)
                      }
                 }
                 UE_LOG(LogTemp, Warning, TEXT("Spawned %d Field Tiles."), FieldTiles.Num());
            }

            void AGameBoard::UpdateVisualsFromGameState(const TArray<FPolyeFieldState>& CurrentBoardState)
            {
                 // Эта функция вызывается на клиенте из APolyeGameStateBase::OnRep_BoardState

                 if (FieldTiles.Num() != CurrentBoardState.Num())
                 {
                     UE_LOG(LogTemp, Error, TEXT("Mismatch between number of visual tiles and board state data!"));
                     return;
                 }

                 for (int32 i = 0; i < CurrentBoardState.Num(); ++i)
                 {
                     if (FieldTiles[i].IsValid())
                     {
                          // Передаем актуальное состояние поля визуальной плитке для отображения
                          FieldTiles[i]->UpdateVisuals(CurrentBoardState[i]);
                     }
                 }
            }

**Интеграция и Следующие Шаги:**

*   **Размещение `AGameBoard`:** На вашей карте уровня (`Map_GameplayBoard.umap`) необходимо разместить один Актер `AGameBoard` (или его Blueprint наследника) и, в его свойствах, указать `FieldTileClass` на ваш Blueprint плитки поля (`BP_FieldTile`).
*   **Инициализация Владения:** В `APolyeGameModeBase::HandleMatchHasStarted` или похожей функции (на сервере), после подключения игроков, вызвать `GameState->InitializeBoardState()` для установки начального владения полями (Player 0, Player 1, Neutral) и их индексов.
*   **Механика Активации:** В Фазе 2 (пункт 2) будет реализована логика выбора начальных активных полей в `APolyeGameModeBase` (сервер) и отправка Server RPC из `APolyePlayerController`, который будет вызывать `GameState->UpdateFieldState()` для установки `bIsActive = true`. Это вызовет `OnRep_BoardState` на клиентах и обновит визуал через `AGameBoard::UpdateVisualsFromGameState`.
*   **Клик по Полю:** В `APolyePlayerController`, реализовать обработку клика мыши по игровому полю. Использовать трассировку луча (Line Trace) от курсора мыши в мир, чтобы определить, по какой плитке (`AFieldTile`) был клик. Получить из `AFieldTile` его `FieldIndex`. Этот `FieldIndex` будет использоваться в Server RPC для указания цели действия (например, `Server_TryPlayCard(CardData, ClickedFieldIndex)`).
