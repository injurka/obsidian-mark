**Цель:** Создать логическую структуру для игрового поля (3x5 ячеек), определить систему идентификации и владения полями, обеспечить сетевую синхронизацию состояния полей и подготовить основу для их визуального представления.

**Ключевые Компоненты:**

*   **Логическое Состояние Полей:** `APolyeGameStateBase` будет центральным хранилищем реплицируемого состояния всех 15 игровых полей.
*   **Перечисление Фракций:** `EPolyeFaction` (в `PolyeTypes.h`) определит доступные фракции.
*   **Структура Данных для Одного Поля:** `FPolyeFieldData` (в `PolyeTypes.h`) будет описывать состояние одного поля, включая его фракцию.
*   **Визуальное Представление Доски:** `APolyeGameBoard` (ранее `AGameBoard`) будет `AActor`, размещенный на сцене, отвечающий за общее управление визуальным представлением доски.
*   **Визуальное Представление Ячейки Поля:** `APolyeFieldTile` (ранее `AFieldTile`) будет `AActor`, представляющий одну визуальную ячейку на доске. Эти акторы будут создаваться локально на клиентах.
*   **Система Идентификации:** Числовая индексация (0-14) для полей.

    ```cpp
    // Polye/Source/Polye/Utilities/PolyeBoardStatics.cpp
    #include "PolyeBoardStatics.h"

    bool UPolyeBoardStatics::IsValidFieldID(int32 FieldID)
    {
        return FieldID >= 0 && FieldID < TOTAL_FIELDS;
    }

    void UPolyeBoardStatics::GetRowAndColumn(int32 FieldID, int32& OutRow, int32& OutCol)
    {
        if (!IsValidFieldID(FieldID)) { OutRow = -1; OutCol = -1; return; }
        OutRow = FieldID / NUM_COLS;
        OutCol = FieldID % NUM_COLS;
    }

    int32 UPolyeBoardStatics::GetFieldID(int32 Row, int32 Col)
    {
        if (Row < 0 || Row >= NUM_ROWS || Col < 0 || Col >= NUM_COLS) return INDEX_NONE;
        return Row * NUM_COLS + Col;
    }
    
    FVector UPolyeBoardStatics::GetWorldLocationForFieldID(const UObject* WorldContextObject, int32 FieldID, float TileSize, FVector BoardOrigin, int32 PlayerViewDirection)
    {
        int32 Row, Col;
        GetRowAndColumn(FieldID, Row, Col);
        if (Row == -1) return BoardOrigin; // Возвращаем Origin, если ID невалидный

        // Координаты относительно центра доски (0,0) при PlayerViewDirection = 1
        // X соответствует колонкам, Y - строкам
        // PlayerViewDirection инвертирует направление доски (для вида 2-го игрока, если доска не вращается)
        float RelativeX = (Col - (NUM_COLS - 1) / 2.0f) * TileSize * PlayerViewDirection;
        float RelativeY = (Row - (NUM_ROWS - 1) / 2.0f) * TileSize * PlayerViewDirection;
        // Пример: для PlayerViewDirection = 1 и игры "снизу-вверх"
        // Row 0 - "ближний" ряд. Можно инвертировать Y, если нужно:
        // float RelativeY = ((NUM_ROWS - 1) - Row - (NUM_ROWS - 1) / 2.0f) * TileSize; 

        return BoardOrigin + FVector(RelativeX, RelativeY, 0.f); 
    }

    int32 UPolyeBoardStatics::GetFieldIDFromWorldLocation(const UObject* WorldContextObject, const FVector& WorldLocation, float TileSize, FVector BoardOrigin, int32 PlayerViewDirection)
    {
        FVector RelativeLocation = WorldLocation - BoardOrigin;

        float ColFloat = (RelativeLocation.X / (TileSize * PlayerViewDirection)) + (NUM_COLS - 1) / 2.0f;
        float RowFloat = (RelativeLocation.Y / (TileSize * PlayerViewDirection)) + (NUM_ROWS - 1) / 2.0f;
        // Для инвертированного Y (если Row 0 - "ближний")
        // float RowFloat = ((NUM_ROWS - 1) / 2.0f) - (RelativeLocation.Y / (TileSize * PlayerViewDirection));
        // RowFloat = (NUM_ROWS - 1) - RowFloat; // Приводим к 0-индексации "снизу"

        int32 Col = FMath::RoundToInt(ColFloat);
        int32 Row = FMath::RoundToInt(RowFloat);

        // Простая проверка нахождения внутри тайла (можно улучшить до AABB)
        if (FMath::Abs(ColFloat - Col) > 0.5f || FMath::Abs(RowFloat - Row) > 0.5f)
        {
             return INDEX_NONE;
        }
        return GetFieldID(Row, Col);
    }

    TArray<int32> UPolyeBoardStatics::GetAdjacentFieldIDs(int32 FieldID, bool bIncludeDiagonals)
    {
        TArray<int32> AdjacentFields;
        if (!IsValidFieldID(FieldID)) return AdjacentFields;
        int32 Row, Col;
        GetRowAndColumn(FieldID, Row, Col);

        // Ортогональные соседи: {смещение_строки, смещение_колонки}
        const int32 Dirs[][2] = {{0, 1}, {0, -1}, {1, 0}, {-1, 0}};
        for (const auto& Dir : Dirs)
        {
            int32 AdjID = GetFieldID(Row + Dir[0], Col + Dir[1]);
            if (IsValidFieldID(AdjID)) AdjacentFields.Add(AdjID);
        }

        if (bIncludeDiagonals)
        {
            const int32 DiagonalDirs[][2] = {{1,1}, {1,-1}, {-1,1}, {-1,-1}};
            for (const auto& Dir : DiagonalDirs)
            {
                int32 AdjID = GetFieldID(Row + Dir[0], Col + Dir[1]);
                if (IsValidFieldID(AdjID)) AdjacentFields.Add(AdjID);
            }
        }
        return AdjacentFields;
    }

    TArray<int32> UPolyeBoardStatics::GetFieldIDsAtRange(int32 StartFieldID, int32 Range, bool bIncludeDiagonals)
    {
        TArray<int32> ResultFields;
        if (!IsValidFieldID(StartFieldID) || Range < 0) return ResultFields;

        if (Range == 0) { ResultFields.Add(StartFieldID); return ResultFields; }
        
        TSet<int32> Visited;
        TArray<TTuple<int32, int32>> Queue; // FieldID, CurrentDistance

        Queue.Add(MakeTuple(StartFieldID, 0));
        Visited.Add(StartFieldID);
        ResultFields.Add(StartFieldID); // Включаем стартовое поле, если Range >= 0

        int32 Head = 0;
        while(Head < Queue.Num())
        {
            TTuple<int32, int32> Current = Queue[Head++];
            int32 CurrentID = Current.Get<0>();
            int32 CurrentDist = Current.Get<1>();

            if (CurrentDist < Range)
            {
                TArray<int32> Neighbors = GetAdjacentFieldIDs(CurrentID, bIncludeDiagonals);
                for (int32 NeighborID : Neighbors)
                {
                    if (!Visited.Contains(NeighborID))
                    {
                        Visited.Add(NeighborID);
                        ResultFields.Add(NeighborID); // Добавляем всех соседей в пределах Range
                        Queue.Add(MakeTuple(NeighborID, CurrentDist + 1));
                    }
                }
            }
        }
        // Если нужно вернуть ТОЛЬКО поля на расстоянии ТОЧНО Range,
        // тогда ResultFields.Add() вызывается только когда CurrentDist == Range.
        return ResultFields;
    }
    ```
*   **Обоснование:** Статический класс-библиотека для утилит доски инкапсулирует геометрию доски, делая код в других местах чище.
*   **Outcome:** Система идентификации полей готова, есть вспомогательные функции.

    ```cpp
    void APolyeGameBoard::CreateFieldTileVisuals()
    {
        if (!FieldTileClass)
        {
            UE_LOG(LogTemp, Error, TEXT("APolyeGameBoard: FieldTileClass is not set! Assign it in BP_GameBoard."));
            return;
        }
        UWorld* World = GetWorld();
        if (!World) return;

        FieldTileVisuals.Empty(UPolyeBoardStatics::TOTAL_FIELDS); // Очищаем и резервируем
        FieldTileVisuals.SetNum(UPolyeBoardStatics::TOTAL_FIELDS);

        FVector BoardOrigin = GetActorLocation(); // Используем положение APolyeGameBoard как точку отсчета
        int32 PlayerViewDirection = 1; // TODO: Можно будет настроить в зависимости от PlayerController

        for (int32 i = 0; i < UPolyeBoardStatics::TOTAL_FIELDS; ++i)
        {
            FVector SpawnLocation = UPolyeBoardStatics::GetWorldLocationForFieldID(this, i, TileSpacing, BoardOrigin, PlayerViewDirection);
            FRotator SpawnRotation = FRotator::ZeroRotator; // Или GetActorRotation(), если тайлы должны быть сориентированы как доска

            APolyeFieldTile* NewTile = World->SpawnActor<APolyeFieldTile>(FieldTileClass, SpawnLocation, SpawnRotation);
            if (NewTile)
            {
                NewTile->InitializeTile(i, this); // Передаем ID ячейки и ссылку на родительскую доску
                FieldTileVisuals[i] = NewTile;
            }
            else
            {
                 UE_LOG(LogTemp, Error, TEXT("Failed to spawn FieldTile for ID %d"), i);
            }
        }
    }

    void APolyeGameBoard::UpdateBoardVisuals(const TArray<FPolyeFieldData>& InBoardData)
    {
        if (FieldTileVisuals.Num() != UPolyeBoardStatics::TOTAL_FIELDS || InBoardData.Num() != UPolyeBoardStatics::TOTAL_FIELDS)
        {
            UE_LOG(LogTemp, Warning, TEXT("APolyeGameBoard: Mismatch in visual tiles count (%d) or board data count (%d). Expected: %d."), FieldTileVisuals.Num(), InBoardData.Num(), UPolyeBoardStatics::TOTAL_FIELDS);
            // Можно добавить логику пересоздания, если это возможно.
            return;
        }

        for (int32 i = 0; i < InBoardData.Num(); ++i)
        {
            if (FieldTileVisuals.IsValidIndex(i) && FieldTileVisuals[i]) // Проверяем валидность указателя
            {
                FieldTileVisuals[i]->UpdateFromFieldData(InBoardData[i]);
            }
            else
            {
                UE_LOG(LogTemp, Warning, TEXT("APolyeGameBoard: Invalid visual tile at index %d during update."), i);
            }
        }
    }
    ```

**5. Базовая Визуализация Статуса Поля (через Blueprint)**

*   **Действие:** Создать `BP_GameBoard` (наследник `APolyeGameBoard`) и `BP_FieldTile` (наследник `APolyeFieldTile`).
    *   В `BP_GameBoard` в Class Defaults указать `FieldTileClass` (ссылку на `BP_FieldTile`) и `TileSpacing`.
    *   В `BP_FieldTile` в Event Graph реализовать логику для `OnActivationChanged`, `OnFactionChanged` и т.д., чтобы менять материал, цвет `TileMeshComponent` или спавнить/скрывать дополнительные визуальные эффекты.
*   **Пример реализации (в `BP_FieldTile` Event Graph):**
    *   Переопределить `Event OnActivationChanged`. Взять `bIsNowActivated`. Если `true`, установить один материал (например, "M_Field_Active") на `TileMeshComponent`, иначе другой ("M_Field_Inactive").
    *   Аналогично для `Event OnFactionChanged`: в зависимости от `NewFaction` выбрать цвет/материал (например, красный для Children of Coal, синий для Guardians of Ether, серый для Neutral).
    *   `Event OnOwnerChanged`: подсветить границу поля цветом игрока.
*   **Обоснование:** Позволяет дизайнерам легко настраивать внешний вид полей и их реакцию на изменение состояния без изменения C++.
*   **Outcome:** Ячейки поля визуально отображают свой активный статус, фракцию и принадлежность.

**Интеграция и Следующие Шаги:**

*   **Размещение `BP_GameBoard`:** На игровой карте (например, `Map_GameplayBoard`) разместить экземпляр `BP_GameBoard`. Убедиться, что `FieldTileClass` и `TileSpacing` настроены.
*   **Инициализация в `GameMode`:** В `APolyeGameplayGameMode::StartPlay()` (или более подходящей функции, например, после того как все игроки подключились и готовы - `HandleMatchHasStarted` если используется `AGameMode`), получить `APolyeGameStateBase` и вызвать `Server_InitializeBoard()`.
*   **Тестирование Репликации:** Запустить игру в режиме `Play As Client` с двумя игроками. Убедиться, что:
    1.  `APolyeGameBoard` (точнее, его `BP_GameBoard` наследник) создает `BP_FieldTile` для каждого поля на обоих клиентах.
    2.  Визуальное состояние ячеек (`BP_FieldTile`) соответствует данным из `BoardData` в `APolyeGameStateBase` (начальное распределение, статус активации, фракция).
*   **Реализация Активации Полей:** На следующих этапах:
    *   PlayerController будет обрабатывать клики по `APolyeFieldTile`.
    *   Информация о кликнутом `FieldID` будет отправлена через RPC на сервер.
    *   GameMode проверит валидность действия и вызовет `APolyeGameStateBase::Server_ActivateField()`.
    *   Изменение `BoardData` отреплицируется, `OnRep_BoardData` вызовет `APolyeGameBoard::UpdateBoardVisuals`, что приведет к вызову `APolyeFieldTile::UpdateFromFieldData` и соответствующего `BlueprintImplementableEvent` в `BP_FieldTile` для обновления визуала.
