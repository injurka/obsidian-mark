**Цель:** Реализовать компоненты и логику, ответственные за:
    1.  Загрузку статических данных карт из системы данных.
    2.  Представление и управление колодой игрока на сервере во время матча (инициализация, перемешивание, добор).
    3.  Управление рукой игрока (добавление карт, применение лимита, удаление при розыгрыше/сбросе).
    4.  Сетевую репликацию состояния руки (только владельцу) и счетчиков карт (всем).
    5.  Предоставление основы для UI отображения руки и счетчиков.

**Зачем Нужна Эта Система:**

*   **Основа Геймплея:** Карты – ключевой инструмент взаимодействия игрока с игрой.
*   **Доступ к Данным Карт:** Централизованное получение информации о картах из Data Assets/Tables.
*   **Состояние Игрока:** Управление тем, какие карты доступны игроку для розыгрыша.
*   **Сетевая Синхронизация и Безопасность:** Корректная и безопасная передача информации о картах между сервером и клиентами.

**Предпосылки (Уже Реализованы):**

1.  **Сетевая Архитектура:** `APolyeGameModeBase`, `APolyeGameStateBase`, `APolyePlayerController`, `APolyePlayerStateBase`. `PlayerState` реплицируется и `bAlwaysRelevant=true`.
2.  **Система Данных:**
    *   `PolyeTypes.h`: `FCardCatalogEntry` (наследует `FTableRowBase`, содержит `TSoftObjectPtr<UPolyeCardData> CardDataAsset`).
    *   `UPolyeCardData` и его наследники (`UPolyeUnitCardData` и т.д.) для детальных данных карт.
    *   `UPolyeDataManager` (или общий менеджер, доступный через `GameInstance`): Загружает `DT_CardCatalog` (с `FCardCatalogEntry`) и предоставляет функции для доступа к `FCardCatalogEntry` и загруженным `UPolyeCardData` по `FName CardID`.
3.  **Остальные Системы:** Игровое поле, система сущностей и эффектов.

**Ключевые Компоненты и Их Роли:**

1.  **`UPolyeDataManager` (Менеджер Данных):**
    *   Предоставляет `FCardCatalogEntry` по `FName CardID`.
    *   Предоставляет (и кэширует) загруженный `UPolyeCardData` по `FName CardID`.
    *   Предоставляет список всех `FName CardID`, доступных в игре (из `DT_CardCatalog`).
2.  **`APolyePlayerStateBase` (Сервер & Клиенты):**
    *   **Владеет `UPolyeCardComponent`** (новый компонент, ранее `UPolyeCardGameManagerComponent`).
    *   **Реплицируемые Данные:**
        *   `UPROPERTY(ReplicatedUsing = OnRep_HandCards, BlueprintReadOnly)` `TArray<FPolyeCardInHand> HandCards;` (с `COND_OwnerOnly`). `FPolyeCardInHand` (новая структура) будет хранить не только `FName CardID`, но и уникальный `int32 InstanceUID` для каждой карты в руке. Это важно для таргетинга карт в руке.
        *   `UPROPERTY(Replicated, BlueprintReadOnly)` `int32 DeckCount;`.
        *   `UPROPERTY(Replicated, BlueprintReadOnly)` `int32 DiscardPileCount;`.
3.  **`UPolyeCardComponent` (Новый Компонент на `APolyePlayerStateBase`):**
    *   **Роль (Сервер):** Авторитетно управляет колодой (`DeckInstanceUIDs`), сбросом (`DiscardInstanceUIDs`) и логикой добора/сброса для своего владельца-`PlayerState`.
    *   **Данные (Сервер, не реплицируются напрямую):**
        *   `TArray<int32> DeckInstanceUIDs;`
        *   `TArray<int32> DiscardInstanceUIDs;`
        *   `TMap<int32, FName> CardInstanceToCardIDMap;` (сопоставление `InstanceUID` с `CardID`).
        *   `int32 NextCardInstanceUID = 0;` (серверный счетчик для уникальности).
    *   **Функции (Сервер):** `InitializeDeck(const TArray<FName>& CardIDList)`, `ShuffleDeck()`, `DrawCards(int32 NumToDraw)`, `PlayCardFromHand(int32 CardInstanceUID)`, `DiscardCardFromHand(int32 CardInstanceUID)`, `MoveAllHandToDiscard()`, `ShuffleDiscardIntoDeck()`.
4.  **`AGameModeBase` (Сервер):**
    *   В начале матча инициирует `PlayerState->CardComponent->InitializeDeck()`.
    *   В начале хода игрока вызывает `PlayerState->CardComponent->DrawCards()`.
    *   Обрабатывает запросы на розыгрыш карт, и в случае успеха, вызывает `PlayerState->CardComponent->PlayCardFromHand()`.
5.  **UI (`WBP_HandDisplay`, `WBP_CardWidget`) (Клиент):**
    *   Отображает руку на основе `APolyePlayerStateBase::HandCards`.
    *   Каждый `WBP_CardWidget` отображает данные карты (`FCardCatalogEntry` и `UPolyeCardData` из `UPolyeDataManager` по `CardID`) и знает свой `InstanceUID`.
    *   При клике на карту в UI, передает `InstanceUID` в `APolyePlayerController` для Server RPC.

**3. Реализация `UPolyeCardComponent` (Серверная Логика)**

*   **Действие:** Создать C++ класс `UPolyeCardComponent` (`Source/Polye/Core/` или `GameplaySystems/Cards/`).
    *   **Данные:**
        *   `TArray<int32> DeckInstanceUIDs;`
        *   `TArray<int32> DiscardInstanceUIDs;`
        *   `TMap<int32, FName> CardInstanceUIDToCardIDMap;` // Сопоставление UID экземпляра с типом карты CardID
        *   `int32 NextAvailableInstanceUID = 0;`
        *   `UPROPERTY(EditDefaultsOnly) int32 MaxHandSize = 7;` (из дизайн-дока или настроить).
        *   `UPROPERTY(EditDefaultsOnly) int32 StartingHandSize = 3;`
    *   **Функции (все выполняются только если `GetOwner()->HasAuthority()`):**
        *   `InitializeDeck(const TArray<FName>& InDeckCardIDs)`:
            1.  Очищает `DeckInstanceUIDs`, `DiscardInstanceUIDs`, `CardInstanceUIDToCardIDMap`.
            2.  Для каждого `CardID` в `InDeckCardIDs`:
                *   Генерирует новый уникальный `InstanceUID` (инкрементируя `NextAvailableInstanceUID`).
                *   Добавляет `InstanceUID` в `DeckInstanceUIDs`.
                *   Добавляет пару (`InstanceUID`, `CardID`) в `CardInstanceUIDToCardIDMap`.
            3.  Обновляет `PlayerState->DeckCount`.
            4.  Вызывает `ShuffleDeck()`.
        *   `ShuffleDeck()`: Перемешивает `DeckInstanceUIDs`.
        *   `DrawCards(int32 NumToDraw)`:
            1.  Получает `APolyePlayerStateBase* OwningPS = GetOwner<APolyePlayerStateBase>();`.
            2.  Цикл `NumToDraw` раз:
                *   Если `OwningPS->HandCards.Num() >= MaxHandSize`, то "сжигает" карту (берет из `DeckInstanceUIDs`, добавляет в `DiscardInstanceUIDs`, обновляет счетчики).
                *   Если `DeckInstanceUIDs` пуст, вызывает `ShuffleDiscardIntoDeck()`. Если после этого все еще пуст, выход.
                *   Берет `InstanceUID` из `DeckInstanceUIDs.Pop()`.
                *   Находит `CardID` по `InstanceUID` из `CardInstanceUIDToCardIDMap`.
                *   Создает `FPolyeCardInHand NewCardInHand = {InstanceUID, CardID};`.
                *   Добавляет `NewCardInHand` в `OwningPS->HandCards`. (Это изменение реплицируется -> `OnRep_HandCards`).
            3.  Обновляет `OwningPS->DeckCount`.
        *   `PlayCardFromHand(int32 CardInstanceUID)`:
            1.  Находит `FPolyeCardInHand` в `OwningPS->HandCards` по `CardInstanceUID`.
            2.  Если найдена, удаляет ее из `OwningPS->HandCards`.
            3.  Добавляет `CardInstanceUID` в `DiscardInstanceUIDs`.
            4.  Обновляет `OwningPS->DiscardPileCount`.
            5.  Возвращает `CardID` сыгранной карты (для GameMode).
        *   `DiscardCardFromHand(int32 CardInstanceUID)`: Аналогично `PlayCardFromHand`, но без возврата `CardID`.
        *   `MoveAllHandToDiscard()`: Перемещает все `InstanceUID` из `OwningPS->HandCards` в `DiscardInstanceUIDs`, очищает `OwningPS->HandCards`, обновляет счетчики.
        *   `ShuffleDiscardIntoDeck()`: Перемещает все `InstanceUID` из `DiscardInstanceUIDs` в `DeckInstanceUIDs`, очищает `DiscardInstanceUIDs`, вызывает `ShuffleDeck()`, обновляет счетчики.
*   **Outcome:** Компонент управляет логикой колоды и руки на сервере.

```cpp
void UPolyeCardComponent::InitializePlayerDeck(const TArray<FName>& InitialDeckCardIDs)
{
    if (!GetOwner() || !GetOwner()->HasAuthority()) return;

    ServerDeck_InstanceUIDs.Empty();
    ServerDiscardPile_InstanceUIDs.Empty();
    ServerCardInstanceUIDToCardIDMap.Empty();
    NextCardInstanceUIDCounter = 0; // Сброс счетчика UID

    for (const FName& CardID : InitialDeckCardIDs)
    {
        int32 NewInstanceUID = ++NextCardInstanceUIDCounter;
        ServerDeck_InstanceUIDs.Add(NewInstanceUID);
        ServerCardInstanceUIDToCardIDMap.Add(NewInstanceUID, CardID);
    }
    ShuffleArray(ServerDeck_InstanceUIDs);
    UpdatePlayerStateCounts();

    APolyePlayerStateBase* OwningPS = GetOwningPlayerState();
    if (OwningPS) OwningPS->HandCards.Empty(); // Очищаем руку при инициализации колоды

    UE_LOG(LogTemp, Log, TEXT("CardComponent for %s: Deck Initialized with %d cards."), *GetOwningPlayerState()->GetPlayerName(), ServerDeck_InstanceUIDs.Num());
}

void UPolyeCardComponent::ShuffleArray(TArray<int32>& ArrayToShuffle)
{
    if (ArrayToShuffle.Num() > 1)
    {
        for (int32 i = ArrayToShuffle.Num() - 1; i > 0; --i)
        {
            int32 j = FMath::RandRange(0, i);
            ArrayToShuffle.Swap(i, j);
        }
    }
}

void UPolyeCardComponent::UpdatePlayerStateCounts()
{
    if (!GetOwner() || !GetOwner()->HasAuthority()) return;
    APolyePlayerStateBase* OwningPS = GetOwningPlayerState();
    if (OwningPS)
    {
        OwningPS->DeckCount = ServerDeck_InstanceUIDs.Num();
        OwningPS->DiscardPileCount = ServerDiscardPile_InstanceUIDs.Num();
        // OwningPS->HandCards.Num() обновляется напрямую при добавлении/удалении
    }
}

void UPolyeCardComponent::DrawNewCards(int32 NumCardsToDraw)
{
    if (!GetOwner() || !GetOwner()->HasAuthority() || NumCardsToDraw <= 0) return;

    APolyePlayerStateBase* OwningPS = GetOwningPlayerState();
    if (!OwningPS) return;

    for (int32 i = 0; i < NumCardsToDraw; ++i)
    {
        if (OwningPS->HandCards.Num() >= MaxHandSize)
        {
            // Рука полна, сжигаем карту
            if (ServerDeck_InstanceUIDs.Num() == 0)
            {
                if (ServerDiscardPile_InstanceUIDs.Num() > 0)
                {
                    ServerDeck_InstanceUIDs = ServerDiscardPile_InstanceUIDs;
                    ServerDiscardPile_InstanceUIDs.Empty();
                    ShuffleArray(ServerDeck_InstanceUIDs);
                } else break; // Нечего сжигать
            }
            if(ServerDeck_InstanceUIDs.Num() > 0)
            {
                 int32 BurnedInstanceUID = ServerDeck_InstanceUIDs.Pop();
                 ServerDiscardPile_InstanceUIDs.Add(BurnedInstanceUID);
                 UE_LOG(LogTemp, Warning, TEXT("CardComponent for %s: Hand full, card UID %d burned."), *OwningPS->GetPlayerName(), BurnedInstanceUID);
            }
            UpdatePlayerStateCounts();
            continue; // Или break, если правила не позволяют продолжать добор
        }

        if (ServerDeck_InstanceUIDs.Num() == 0)
        {
            if (ServerDiscardPile_InstanceUIDs.Num() > 0)
            {
                ServerDeck_InstanceUIDs = ServerDiscardPile_InstanceUIDs;
                ServerDiscardPile_InstanceUIDs.Empty();
                ShuffleArray(ServerDeck_InstanceUIDs);
                UE_LOG(LogTemp, Log, TEXT("CardComponent for %s: Shuffled discard into deck."), *OwningPS->GetPlayerName());
            }
            else
            {
                UE_LOG(LogTemp, Warning, TEXT("CardComponent for %s: Deck and Discard empty, cannot draw."), *OwningPS->GetPlayerName());
                break; // Нечего добирать
            }
        }

        if (ServerDeck_InstanceUIDs.Num() > 0)
        {
            int32 DrawnInstanceUID = ServerDeck_InstanceUIDs.Pop();
            FName DrawnCardID = ServerCardInstanceUIDToCardIDMap.FindRef(DrawnInstanceUID);
            if (!DrawnCardID.IsNone())
            {
                FPolyeCardInHand NewCard = {DrawnInstanceUID, DrawnCardID};
                OwningPS->HandCards.Add(NewCard); // Это изменение реплицируется -> OnRep_HandCards
                UE_LOG(LogTemp, Log, TEXT("CardComponent for %s: Drew card UID %d (ID: %s). Hand size: %d"),
                       *OwningPS->GetPlayerName(), DrawnInstanceUID, *DrawnCardID.ToString(), OwningPS->HandCards.Num());
            }
        }
    }
    UpdatePlayerStateCounts(); // Обновить счетчики после всех доборов
}

FName UPolyeCardComponent::CardPlayedFromHand(int32 CardInstanceUID)
{
    if (!GetOwner() || !GetOwner()->HasAuthority()) return NAME_None;
    APolyePlayerStateBase* OwningPS = GetOwningPlayerState();
    if (!OwningPS) return NAME_None;

    int32 FoundIndex = OwningPS->HandCards.IndexOfByPredicate(
        [&](const FPolyeCardInHand& Card){ return Card.InstanceUID == CardInstanceUID; });

    if (FoundIndex != INDEX_NONE)
    {
        FPolyeCardInHand PlayedCard = OwningPS->HandCards[FoundIndex];
        OwningPS->HandCards.RemoveAt(FoundIndex); // Реплицируется
        ServerDiscardPile_InstanceUIDs.Add(PlayedCard.InstanceUID);
        UpdatePlayerStateCounts();
        UE_LOG(LogTemp, Log, TEXT("CardComponent for %s: Played card UID %d (ID: %s) from hand."), *OwningPS->GetPlayerName(), PlayedCard.InstanceUID, *PlayedCard.CardID.ToString());
        return PlayedCard.CardID;
    }
    UE_LOG(LogTemp, Warning, TEXT("CardComponent for %s: Failed to play card UID %d, not found in hand."), *OwningPS->GetPlayerName(), CardInstanceUID);
    return NAME_None;
}

// Аналогично реализуются DiscardRandomCardFromHand, DiscardSpecificCardFromHand, MoveHandToDiscard
// ...
```

**4. Инициализация и Логика Игры в `APolyeGameModeBase`**

*   **Действие:**
    *   В `APolyeGameModeBase::StartGameSetup()` (или где инициализируется матч):
        1.  Получить `UPolyeDataManager*`.
        2.  Для каждого `APolyePlayerStateBase* PS`:
            *   Получить `UPolyeCardComponent* CardComp = PS->GetCardComponent();`.
            *   Сформировать `TArray<FName> DeckList` для этого игрока (из `DataManager->GetAllAvailableCardIDs()` для MVP, или из системы профиля игрока).
            *   `CardComp->InitializePlayerDeck(DeckList);`.
            *   `CardComp->DrawNewCards(CardComp->StartingHandDrawCount);` // Используем свойство компонента.
    *   В логике начала хода (когда `APolyeGameModeBase` определяет, чей сейчас ход):
        1.  Получить `CurrentPlayerState` и его `CardComp`.
        2.  `CardComp->DrawNewCards(1);` (или другое количество).
*   **Outcome:** Колоды игроков инициализируются, стартовые руки раздаются, карты добираются в начале хода.

**5. Клиентское Отображение Руки и Счетчиков (`WBP_HandDisplay` и т.д.)**

*   **Действие:**
    *   Создать UMG `WBP_HandCard` (отображает одну карту: арт, стоимость). Имеет функцию `SetCardData(const FPolyeCardInHand& CardData, UPolyeDataManager* DataManager)` для обновления визуала.
    *   Создать UMG `WBP_HandDisplay` (содержит `UHorizontalBox` или `UWrapBox`). Имеет функцию `UpdateHand(const TArray<FPolyeCardInHand>& NewHand, UPolyeDataManager* DataManager)`, которая очищает и пересоздает `WBP_HandCard` виджеты.
    *   В `APolyePlayerController::OnRep_HandCards()` (в `PolyePlayerStateBase`):
        *   Вызывать `HandDisplayWidget->UpdateHand(PS->GetHand(), DataManagerRef)`.
    *   Аналогично для счетчиков `DeckCount` и `DiscardPileCount` обновлять текстовые поля в UI.
*   **Outcome:** UI корректно отображает карты в руке и счетчики.

**Интеграция и Следующие Шаги:**

*   **Система Создания Колоды (Мета-игра):** Позже потребуется система, где игрок сам составляет колоду, и `InitializePlayerDeck` будет получать `DeckList` из этой системы.
*   **Розыгрыш Карт (След. Пункт):** Эта система подготовила руку. Следующий шаг – реализация выбора карты из руки и ее розыгрыша. `CardPlayedFromHand(InstanceUID)` будет вызываться сервером после успешного розыгрыша.
*   **Эффекты Карт:** Данные для эффектов карт (из `UPolyeCardData`) будут использоваться при розыгрыше.
*   **Лимит Руки в Конце Хода:** В `APolyeGameModeBase`, в логике завершения хода, если `PlayerState->HandCards.Num() > PlayerState->CardComponent->MaxHandSize`, инициировать UI для игрока, чтобы он выбрал и сбросил лишние карты (вызывая `PlayerState->CardComponent->DiscardSpecificCardFromHand(InstanceUID)` через RPC).

**Важные Моменты:**

*   **`InstanceUID`:** Использование уникальных `InstanceUID` для каждой карты в игре (даже если это копии одного `CardID`) критически важно для того, чтобы сервер и клиент могли однозначно идентифицировать, какая именно карта была сыграна/сброшена/стала целью.
*   **Серверный Авторитет:** `UPolyeCardComponent` содержит всю авторитетную логику и полные списки. `APolyePlayerStateBase` реплицирует только необходимый минимум для клиента.
*   **UI и Данные:** UI всегда читает данные из `APolyePlayerStateBase` и использует `UPolyeDataManager` для получения статических данных карт для отображения.
