**Цель:** Реализовать компоненты, ответственные за загрузку данных карт, представление колоды игрока во время матча и управление рукой игрока (получение стартовой руки, добор карт, лимит руки) с учетом сетевой репликации и безопасности.

**Зачем Нужна Эта Система:**

*   **Основа Геймплея:** Карты являются центральным элементом игры Polye. Эта система предоставляет базовые инструменты для работы с ними.
*   **Доступ к Данным:** Позволяет игре получать актуальные характеристики и свойства карт, определенные гейм-дизайнерами в Data Assets и Data Tables.
*   **Управление Состоянием Игрока:** Определяет, какие карты доступны игроку в данный момент матча (в руке, в колоде).
*   **Сетевая Синхронизация:** Обеспечивает, чтобы состояние руки игрока (секретная информация) было корректно реплицировано только ему, а состояние колоды (сколько карт осталось) – всем (или только ему, если это скрыто).

**Предпосылки:**

*   **Базовая Сетевая Архитектура (Фаза 1):** Реализованы ключевые C++ классы (`AGameModeBase`, `AGameStateBase`, `APolyePlayerController`, `APolyePlayerStateBase`) с базовой сетевой настройкой (репликация). У игроков корректно создаются и связываются `PlayerController` и `PlayerState` при присоединении к матчу. `APolyePlayerStateBase` настроен на репликацию и `bAlwaysRelevant`.
*   **Система Данных (Фаза 1):** Определены структуры данных (`FCardDataBase`, `FPolyeEffectConfig`, и т.д.) и `UDataAsset`ы карт (`UPolyeCardData`). Создан Менеджер Данных (`UPolyeCardManager`), доступный, например, через `UGameInstance`, который может загружать данные карт из Data Tables и Data Assets по ID.
*   **Игровое Поле (Фаза 2):** Реализовано логическое состояние поля и система идентификации полей (`FieldIndex`).
*   **Система Сущностей и Эффектов (Фаза 1, 2):** Определены базовые сущности (`ABoardEntityBase`) и система эффектов (`UPolyeEffectManagerComponent`, `UPolyeGameplayEffectBase`).

**Ключевые Компоненты и Их Роли в Этом Пункте:**

*   **`UPolyeCardManager` (Менеджер Данных, Фаза 1):** Центральный узел для получения данных о картах. Он загружает `DT_CardCatalog` и `DA_CardData` и предоставляет функции для доступа к `FCardDataBase` и `UPolyeCardData` по `FName CardID`.
*   **`APolyePlayerStateBase` (Сервер и Клиенты):** Хранит реплицируемое состояние игрока. Будет содержать реплицируемый список карт в руке (`HandCardIDs`) и, возможно, количество карт в колоде (`CardsInDeckCount`).
*   **`UPolyeCardGameManagerComponent` (Новый C++ Компонент):** `UActorComponent`, добавляемый к `APolyePlayerStateBase`. Является **серверно-авторитетным** менеджером колоды и руки *для конкретного игрока* в текущем матче. Хранит серверный список карт в колоде (`DeckCardIDs`), сбросе (`DiscardPileCardIDs`). Обрабатывает логику инициализации колоды, перемешивания, добора карт в руку, применения лимита руки, сброса карт.
*   **`AGameModeBase` (Сервер):** Управляет ходом матча. В начале хода игрока вызывает функцию на `UPolyeCardGameManagerComponent` этого игрока для добора карт.
*   **UI (Клиенты - Визуал):** Виджеты UMG, управляемые `APolyePlayerController`, отображают руку игрока, количество карт в колоде и предоставляют интерактивность (клик по карте в руке). Обновляются в ответ на репликацию состояния руки в `PlayerState`.

    // ТОЛЬКО СЕРВЕР: Инициализирует колоду игрока для матча
    void UPolyeCardGameManagerComponent::Server_InitializeMatchDeck(const TArray<FName>& InitialDeckList)
    {
        // **ВАЖНО: Выполняется ТОЛЬКО на СЕРВЕРЕ.**
        if (!GetOwner()->HasAuthority()) return;

        DeckCardIDs = InitialDeckList; // Копируем список ID карт
        DiscardPileCardIDs.Empty(); // Сбрасываем сброс
        // Рука очищается отдельно GameMode'ом или в начале хода.

        // TODO: Обновить реплицируемые счетчики в PlayerState
        if (APolyePlayerStateBase* PS = GetOwnerPlayerState())
        {
            PS->CardsInDeckCount = DeckCardIDs.Num();
            PS->CardsInDiscardCount = 0;
            PS->HandCardIDs.Empty(); // Убедимся, что рука пуста при инициализации колоды
        }

        Server_ShuffleDeck(); // Перемешиваем колоду сразу после инициализации
        UE_LOG(LogTemp, Log, TEXT("Server: Deck initialized for player %s with %d cards."), GetOwner() ? *GetOwner()->GetName() : TEXT("NULL"), DeckCardIDs.Num());
    }

    // ТОЛЬКО СЕРВЕР: Перемешивает колоду
    void UPolyeCardGameManagerComponent::Server_ShuffleDeck()
    {
        // **ВАЖНО: Выполняется ТОЛЬКО на СЕРВЕРЕ.**
        if (!GetOwner()->HasAuthority()) return;

        // Простая реализация перемешивания (Fisher-Yates shuffle)
        int32 LastIndex = DeckCardIDs.Num() - 1;
        for (int32 i = 0; i <= LastIndex; ++i)
        {
            int32 RandomIndex = FMath::RandRange(i, LastIndex);
            if (i != RandomIndex)
            {
                DeckCardIDs.Swap(i, RandomIndex);
            }
        }
        UE_LOG(LogTemp, Log, TEXT("Server: Deck shuffled for player %s."), GetOwner() ? *GetOwner()->GetName() : TEXT("NULL"));
        // Колода DeckCardIDs не реплицируется, поэтому клиентам не нужно знать порядок.
    }

    // ТОЛЬКО СЕРВЕР: Добирает N карт из колоды в руку
    int32 UPolyeCardGameManagerComponent::Server_DrawCards(int32 NumberOfCards)
    {
        // **ВАЖНО: Выполняется ТОЛЬКО на СЕРВЕРЕ.**
        if (!GetOwner()->HasAuthority() || NumberOfCards <= 0) return 0;

        APolyePlayerStateBase* PS = GetOwnerPlayerState();
        if (!PS) return 0;

        int32 CardsDrawn = 0;
        for (int32 i = 0; i < NumberOfCards; ++i)
        {
            // Проверяем лимит руки
            if (PS->HandCardIDs.Num() >= MaxHandSize)
            {
                 UE_LOG(LogTemp, Warning, TEXT("Server: Player %s hand is full (%d cards). Cannot draw more."), GetOwner() ? *GetOwner()->GetName() : TEXT("NULL"), PS->HandCardIDs.Num());
                 // TODO: Реализовать механику "сгорания" карт при доборе с полной рукой (если есть)
                 //       Например, взять карту из колоды и сразу переместить ее в сброс, не добавляя в руку.
                 if (DeckCardIDs.Num() > 0)
                 {
                     // Берем карту из колоды
                     FName CardID = DeckCardIDs.Pop();
                     // Перемещаем ее в сброс (сгорание)
                     DiscardPileCardIDs.Add(CardID);
                     // Обновляем реплицируемые счетчики
                     PS->CardsInDeckCount = DeckCardIDs.Num();
                     PS->CardsInDiscardCount = DiscardPileCardIDs.Num();
                     UE_LOG(LogTemp, Warning, TEXT("Server: Player %s hand is full, card burned."), GetOwner() ? *GetOwner()->GetName() : TEXT("NULL"));
                 }
                 break; // Прекращаем добор, если рука полна
            }

            // Если колода пуста, перемешиваем сброс в колоду
            if (DeckCardIDs.Num() == 0)
            {
                 if (DiscardPileCardIDs.Num() > 0)
                 {
                     UE_LOG(LogTemp, Log, TEXT("Server: Player %s deck empty. Shuffling discard (%d cards) into deck."), GetOwner() ? *GetOwner()->GetName() : TEXT("NULL"), DiscardPileCardIDs.Num());
                     Server_ShuffleDiscardIntoDeck(); // Перемешиваем сброс в колоду
                     if (DeckCardIDs.Num() == 0) // Если сброс тоже был пуст
                     {
                         UE_LOG(LogTemp, Warning, TEXT("Server: Player %s deck and discard are empty. Cannot draw card."), GetOwner() ? *GetOwner()->GetName() : TEXT("NULL"));
                          break; // Нечего добирать
                     }
                 }
                 else
                 {
                      UE_LOG(LogTemp, Warning, TEXT("Server: Player %s deck and discard are empty. Cannot draw card."), GetOwner() ? *GetOwner()->GetName() : TEXT("NULL"));
                      break; // Нечего добирать
                 }
            }

            // Берем верхнюю карту из колоды (удаляем последний элемент)
            FName DrawnCardID = DeckCardIDs.Pop();
            // Добавляем карту в руку игрока (реплицируемый массив в PlayerState)
            PS->HandCardIDs.Add(DrawnCardID);

            CardsDrawn++;

            // Обновляем реплицируемые счетчики в PlayerState
            PS->CardsInDeckCount = DeckCardIDs.Num();
            PS->CardsInDiscardCount = DiscardPileCardIDs.Num();

            UE_LOG(LogTemp, Log, TEXT("Server: Player %s drew card %s. Hand size: %d, Deck size: %d"),
                GetOwner() ? *GetOwner()->GetName() : TEXT("NULL"), *DrawnCardID.ToString(), PS->HandCardIDs.Num(), DeckCardIDs.Num());

            // Репликация HandCardIDs вызовет OnRep_HandCardIDs на клиенте-владельце.
            // Репликация CardsInDeckCount/CardsInDiscardCount обновит UI у всех.
        }

        // TODO: Возможно, воспроизвести звуковой/визуальный эффект добора карты (Multicast RPC)
        //       Например, вызвать Multicast RPC на PlayerController игрока.

        return CardsDrawn; // Возвращаем количество добранных карт
    }

    // ТОЛЬКО СЕРВЕР: Сбрасывает карту из руки
    bool UPolyeCardGameManagerComponent::Server_DiscardCard(FName CardID)
    {
         // **ВАЖНО: Выполняется ТОЛЬКО на СЕРВЕРЕ.**
         if (!GetOwner()->HasAuthority()) return false;

         APolyePlayerStateBase* PS = GetOwnerPlayerState();
         if (!PS) return false;

         // Ищем карту в руке (реплицируемый массив в PlayerState)
         int32 IndexToRemove = PS->HandCardIDs.Find(CardID);
         if (IndexToRemove != INDEX_NONE)
         {
              // Удаляем карту из руки
              FName DiscardedCardID = PS->HandCardIDs.RemoveAt(IndexToRemove); // RemoveAt возвращает удаленный элемент
              // Добавляем карту в сброс (серверный массив в компоненте)
              DiscardPileCardIDs.Add(DiscardedCardID);

              // Обновляем реплицируемые счетчики в PlayerState
              PS->CardsInDiscardCount = DiscardPileCardIDs.Num();
              // HandCardIDs уже изменился (реплицируется), CardsInDeckCount не менялся.

              UE_LOG(LogTemp, Log, TEXT("Server: Player %s discarded card %s. Hand size: %d, Discard size: %d"),
                   GetOwner() ? *GetOwner()->GetName() : TEXT("NULL"), *DiscardedCardID.ToString(), PS->HandCardIDs.Num(), DiscardPileCardIDs.Num());

              // Репликация HandCardIDs вызовет OnRep_HandCardIDs на клиенте-владельце (UI руки обновится).

              return true;
         }

         UE_LOG(LogTemp, Warning, TEXT("Server: Player %s tried to discard card %s but it was not found in hand."), GetOwner() ? *GetOwner()->GetName() : TEXT("NULL"), *CardID.ToString());
         return false; // Карта не найдена в руке
    }

    // ТОЛЬКО СЕРВЕР: Сбрасывает всю руку в сброс
    void UPolyeCardGameManagerComponent::Server_DiscardHand()
    {
        // **ВАЖНО: Выполняется ТОЛЬКО на СЕРВЕРЕ.**
        if (!GetOwner()->HasAuthority()) return;

        APolyePlayerStateBase* PS = GetOwnerPlayerState();
        if (!PS) return;

        UE_LOG(LogTemp, Log, TEXT("Server: Player %s discarding hand (%d cards)."), GetOwner() ? *GetOwner()->GetName() : TEXT("NULL"), PS->HandCardIDs.Num());

        // Перемещаем все карты из руки в сброс
        for (const FName& CardID : PS->HandCardIDs)
        {
            DiscardPileCardIDs.Add(CardID); // Добавляем в сброс (серверный массив)
        }
        PS->HandCardIDs.Empty(); // Очищаем руку (реплицируемый массив в PlayerState)

        // Обновляем реплицируемые счетчики в PlayerState
        PS->CardsInDiscardCount = DiscardPileCardIDs.Num();
        // CardsInDeckCount не менялся. HandCardIDs изменился (реплицируется).

        // Репликация HandCardIDs вызовет OnRep_HandCardIDs на клиенте-владельце (UI руки очистится).
    }

    // ТОЛЬКО СЕРВЕР: Перемешивает сброс обратно в колоду
    void UPolyeCardGameManagerComponent::Server_ShuffleDiscardIntoDeck()
    {
        // **ВАЖНО: Выполняется ТОЛЬКО на СЕРВЕРЕ.**
        if (!GetOwner()->HasAuthority()) return;

        // Перемещаем все карты из сброса в колоду
        DeckCardIDs.Append(DiscardPileCardIDs); // Добавляем все карты сброса в конец колоды
        DiscardPileCardIDs.Empty(); // Очищаем сброс

        // Обновляем реплицируемые счетчики в PlayerState
        if (APolyePlayerStateBase* PS = GetOwnerPlayerState())
        {
             PS->CardsInDeckCount = DeckCardIDs.Num();
             PS->CardsInDiscardCount = 0;
        }

        Server_ShuffleDeck(); // Перемешиваем колоду после добавления карт

        UE_LOG(LogTemp, Log, TEXT("Server: Player %s shuffled discard into deck. New deck size: %d"), GetOwner() ? *GetOwner()->GetName() : TEXT("NULL"), DeckCardIDs.Num());
    }

**Интеграция и Следующие Шаги:**

*   **Инициализация Колоды:** Убедиться, что `APolyeGameModeBase::StartGameSetup` корректно получает список `FName CardID` (из Data Manager, системы создания колод или хардкодом) и передает его в `PolyePS->GetCardGameManagerComponent()->Server_InitializeMatchDeck()`.
*   **Добор Стартовой Руки:** После инициализации колоды, GameMode должен вызвать `PolyePS->GetCardGameManagerComponent()->Server_DrawCards(NumberOfStartingCards)` для каждого игрока.
*   **Добор в Начале Хода:** В логике перехода хода в GameMode (Фаза 3, Пункт 2) вызывать `PolyePS->GetCardGameManagerComponent()->Server_DrawCards(CardsPerTurn)` для текущего игрока.
*   **Лимит Руки:** Логика лимита руки уже в `Server_DrawCards`. Также нужно решить, что происходит, когда игрок *заканчивает ход* с рукой, превышающей лимит (обычно сбрасывает лишние карты). Это будет часть логики конца хода в GameMode, которая вызовет `Server_DiscardCard` или `Server_DiscardHand` на компоненте.
*   **Розыгрыш Карт (Фаза 3, Пункт 3):** Система розыгрыша карт будет использовать `HandCardIDs` из `PlayerState` (на клиенте для отображения, на сервере для валидации). При успешном розыгрыше, сервер вызовет `Server_DiscardCard(PlayedCardID)` на компоненте управления картами, чтобы удалить карту из руки и переместить в сброс.

**Важные Примечания:**

*   **Сетевая Безопасность:** Полный список `DeckCardIDs` и `DiscardPileCardIDs` никогда не реплицируется клиентам. Только их количество (`CardsInDeckCount`, `CardsInDiscardCount`) и содержимое руки владельца (`HandCardIDs` с `COND_OwnerOnly`).
*   **Серверный Авторитет:** Вся логика, которая *меняет* состояние колоды или руки (инициализация, перемешивание, добор, сброс) выполняется ТОЛЬКО на сервере в `UPolyeCardGameManagerComponent`. Клиенты только видят результат через репликацию.
*   **UI и Репликация:** UI клиента должен читать состояние руки и счетчиков из реплицируемых свойств `APolyePlayerStateBase`. `OnRep_HandCardIDs` является основным триггером для обновления UI руки.
*   **Data-Driven:** Данные карт (стоимость, эффекты и т.д.) берутся из `UPolyeCardManager` по `FName CardID`, а не хранятся в экземплярах карт в руке/колоде.
