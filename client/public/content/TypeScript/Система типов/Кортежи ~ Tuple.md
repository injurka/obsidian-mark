## Что это?

Кортеж — это тип, представляющий собой массив с *фиксированным числом элементов*, где *тип каждого элемента на определенной позиции известен* и зафиксирован.

## Зачем нужно?

Для представления структур данных с фиксированной длиной и определенными типами на каждой позиции, таких как пары ключ-значение, координаты, возврат нескольких значений из функции.

## Как работает?

*   Определяется с помощью квадратных скобок `[]` с перечислением типов через запятую: `[Type1, Type2, ...]`.
*   Порядок типов и количество элементов строго проверяются.
*   Можно использовать `?` для обозначения необязательных элементов в конце кортежа.
*   Можно использовать `...ArrayType` (rest элемент) в конце для обозначения массива элементов определенного типа после фиксированных позиций.
*   Являются подтипом `Array` и поддерживают его методы, но с более строгой проверкой типов при доступе по известному индексу.

## Примеры:

```typescript
// Кортеж: имя пользователя и его возраст
let userTuple: [string, number];
userTuple = ["Alice", 30]; // OK
// userTuple = [30, "Alice"]; // Ошибка: неверный порядок типов
// userTuple = ["Bob", 40, true]; // Ошибка: слишком много элементов

// Доступ к элементам по индексу
let userName: string = userTuple[0];
let userAge: number = userTuple[1];

// Деструктуризация
let [name, age] = userTuple;

// Кортеж с необязательным элементом
let response: [number, string?];
response = [200, "OK"]; // OK
response = [404];      // OK

// Кортеж с rest элементом
let tupleWithRest: [string, boolean, ...number[]];
tupleWithRest = ["Data", true, 1, 2, 3]; // OK
```
