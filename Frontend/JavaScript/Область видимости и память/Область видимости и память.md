### Предлагаемая структура материала

**Часть 1: Основы — Что такое Область видимости (Scope)?**

*   **1.1. Концепция области видимости:** Простое определение — правила, по которым движок JavaScript ищет переменные. Ответ на вопрос: "Где доступна эта переменная?".
*   **1.2. Виды областей видимости в JavaScript:**
    *   **Глобальная область видимости (Global Scope):** Доступна везде.
    *   **Функциональная область видимости (Function Scope):** Создается функциями, ключевое слово `var`.
    *   **Блочная область видимости (Block Scope):** Нововведение ES6. Создается `{}` блоками (циклы `for`, `if` и т.д.), ключевые слова `let` и `const`.
*   **1.3. Сравнение `var`, `let` и `const`:** Как каждое ключевое слово связано с функциональной или блочной областью видимости. Кратко упомянуть "поднятие" (hoisting) в этом контексте.

**Часть 2: Механизм — Как работает Область видимости?**

*   **2.1. Лексическое окружение (Lexical Environment):**
    *   **Определение:** Внутренняя структура движка, которая "знает" о переменных и функциях в текущей области видимости. Это техническая реализация концепции "scope".
    *   **Два ключевых компонента:**
        1.  **Запись окружения (Environment Record):** Место, где хранятся объявления переменных и функций.
        2.  **Ссылка на внешнее окружение (Outer Environment):** Ссылка на лексическое окружение родительской области видимости.
*   **2.2. Цепочка областей видимости (Scope Chain):**
    *   **Объяснение:** Когда переменная не найдена в текущем лексическом окружении, движок переходит по ссылке на внешнее окружение. Этот последовательный поиск по цепочке и есть "Scope Chain".
    *   **Наглядный пример:** Вложенные функции, показывающие, как внутренняя функция имеет доступ к переменным внешней и глобальной области видимости.

**Часть 3: Среда выполнения — Где исполняется код?**

*   **3.1. Контекст выполнения (Execution Context):**
    *   **Определение:** Абстрактное "окружение", которое JavaScript создает для выполнения кода. Это более широкое понятие, чем лексическое окружение.
    *   **Ключевые компоненты контекста:**
        1.  **Лексическое окружение (Lexical Environment):** Управляет областями видимости и переменными.
        2.  **Значение `this` (This Binding):** Как определяется `this` в данном контексте.
*   **3.2. Виды контекстов выполнения:**
    *   **Глобальный контекст выполнения (Global Execution Context):** Создается один раз при запуске скрипта.
    *   **Функциональный контекст выполнения (Function Execution Context):** Создается при каждом вызове функции.
*   **3.3. Стек вызовов (Call Stack):**
    *   **Как он работает:** Структура данных LIFO (Last-In, First-Out) для управления контекстами выполнения.
    *   **Жизненный цикл:** При вызове функции ее контекст помещается в стек. По завершении — удаляется из стека. Глобальный контекст всегда в основании.
