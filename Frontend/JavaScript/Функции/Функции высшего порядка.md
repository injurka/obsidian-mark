# Функции высшего порядка (Higher-Order Functions) в JavaScript

**Функция высшего порядка (Higher-Order Function, HOF)** — это функция, которая принимает другую функцию в качестве аргумента, возвращает функцию в качестве результата или выполняет оба этих действия одновременно. 

Использование функций высшего порядка является основой функционального программирования в JavaScript. Оно позволяет писать более выразительный, гибкий и лаконичный код.

---

## Функции как объекты первого класса (First-Class Citizens)

В JavaScript функции называют **"объектами первого класса" (First-Class Citizens / First-Class Objects)**. Это означает, что функции обладают теми же возможностями, что и любые другие типы данных (числа, строки, объекты):

1. **Их можно присваивать переменным** или свойствам объектов (создавая функциональные выражения или методы):
   ```javascript
   const greet = function(name) {
     return `Привет, ${name}!`;
   };
   ```
2. **Их можно передавать в качестве аргументов** в другие функции.
3. **Их можно возвращать** из других функций.

Именно благодаря свойству "первого класса" в JavaScript становится возможным существование функций высшего порядка.

---

## Передача функций в качестве аргументов (Callback-функции)

Функция, которая передается в другую функцию в качестве аргумента и вызывается внутри нее, называется **callback-функцией (коллбэком)**.

Передача коллбэков позволяет делегировать выполнение конкретной логики вызывающему коду. Это делает код гибким и легко настраиваемым.

### Пример: кастомная фильтрация массива
Создадим функцию `filterArray`, которая обходит массив и фильтрует его на основе переданного правила (коллбэка):

```javascript
// Функция высшего порядка, принимающая функцию-коллбэк predicate
function filterArray(arr, predicate) {
  const result = [];
  for (let i = 0; i < arr.length; i++) {
    if (predicate(arr[i])) {
      result.push(arr[i]);
    }
  }
  return result;
}

const numbers = [1, 2, 3, 4, 5, 6];

// Передаем разные коллбэки для фильтрации
const evenNumbers = filterArray(numbers, num => num % 2 === 0);
const greaterThanFour = filterArray(numbers, num => num > 4);

console.log(evenNumbers); // [2, 4, 6]
console.log(greaterThanFour); // [5, 6]
```

## Возврат функций из других функций

Функции высшего порядка также могут возвращать новые функции. Это открывает путь к мощным техникам программирования, таким как **замыкания** и **каррирование**.

### 1. Замыкания (Closures)
Когда функция возвращает другую функцию, возвращаемая функция сохраняет доступ к области видимости родительской функции (лексическому окружению), даже после того, как родительская функция завершила свое выполнение.

#### Пример: фабрика умножителей
```javascript
// Функция высшего порядка возвращает новую функцию
function createMultiplier(factor) {
  // Возвращаемая функция «замыкает» в себе переменную factor
  return function(number) {
    return number * factor;
  };
}

const double = createMultiplier(2);
const triple = createMultiplier(3);

console.log(double(5)); // 10 (5 * 2)
console.log(triple(5)); // 15 (5 * 3)
```

### 2. Каррирование (Currying)
**Каррирование** — это трансформация функции с несколькими аргументами в цепочку функций, каждая из которых принимает ровно один аргумент.

#### Пример: логирование с разным уровнем важности
```javascript
// Каррированная версия
const log = level => message => `[${level}] ${message}`;

// Создаем специализированные функции на основе каррированной
const infoLog = log("INFO");
const errorLog = log("ERROR");

console.log(infoLog("Приложение запущено")); // "[INFO] Приложение запущено"
console.log(errorLog("Ошибка подключения к БД")); // "[ERROR] Ошибка подключения к БД"
```

## Встроенные функции высшего порядка в JavaScript

В прототипе стандартного объекта `Array.prototype` есть встроенные методы высшего порядка для удобной работы с коллекциями данных. Рассмотрим основные из них: `map`, `filter` и `reduce`.

### 1. `map`
Метод `map` создает новый массив, элементами которого являются результаты применения переданной коллбэк-функции к каждому элемента исходного массива.

```javascript
const numbers = [1, 2, 3, 4];
const squared = numbers.map(num => num * num);

console.log(squared); // [1, 4, 9, 16]
```

### 2. `filter`
Метод `filter` создает новый массив, содержащий только те элементы исходного массива, для которых переданная коллбэк-функция (предикат) возвращает `true`.

```javascript
const numbers = [1, 2, 3, 4, 5];
const evens = numbers.filter(num => num % 2 === 0);

console.log(evens); // [2, 4]
```

### 3. `reduce`
Метод `reduce` последовательно применяет коллбэк-функцию к аккумулятору и каждому элементу массива, сворачивая его в одно результирующее значение (число, строку, объект или другой массив).

```javascript
const numbers = [1, 2, 3, 4];
const sum = numbers.reduce((acc, num) => acc + num, 0);

console.log(sum); // 10
```

## Преимущества использования функций высшего порядка

1. **Декларативный стиль**: Код описывает *что* мы хотим сделать (например, отфильтровать элементы), а не *как* это сделать с точки зрения циклов и индексов. Это делает код более читаемым.
2. **Абстракция**: HOF скрывают детали реализации обхода коллекций, управления состоянием счетчиков или хранения промежуточных переменных.
3. **Повторное использование кода (DRY)**: Логику можно разбивать на независимые, легко тестируемые функции-коллбэки и комбинировать их в зависимости от потребностей.
4. **Простота тестирования и поддержки**: Небольшие чистые функции, передаваемые как аргументы, легче тестировать изолированно, не создавая сложного контекста.
