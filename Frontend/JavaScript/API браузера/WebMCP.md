# WebMCP (Model Context Protocol в вебе)

**WebMCP** — это интеграция мощного стандарта **Model Context Protocol (MCP)**, изначально разработанного Anthropic (создателями Claude), в браузерную и веб-экосистему.

## Проблема, которую решает MCP
Представьте, что у вас есть AI-ассистент, и вы хотите, чтобы он помог вам найти баг в вашем проекте. AI нужно дать доступ к:
1. Локальным файлам кода.
2. Логам из консоли браузера.
3. Состоянию базы данных.
До MCP для каждого источника данных нужно было писать уникальную интеграцию, плагины или загружать файлы вручную. MCP стандартизирует это: он выступает как универсальный "USB-C кабель" между любыми AI-моделями и любыми источниками данных.

## Архитектура
*   **MCP Hosts (Хосты):** Программы, где "живет" AI-ассистент (например, Cursor, Claude Desktop, или встроенный ассистент в Chrome DevTools).
*   **MCP Clients (Клиенты):** Часть хоста, которая отправляет запросы к серверам.
*   **MCP Servers (Серверы):** Легковесные программы, которые предоставляют контекст. Сервер может читать файлы (`fs-server`), делать запросы к БД (`postgres-server`), или читать логи браузера.

## WebMCP во вкладке Application (DevTools)
Исторически вкладка Application — это набор изолированных таблиц и логов. С внедрением WebMCP, браузер становится **MCP Server'ом**.
Это означает, что вы можете подключить локальную или удаленную LLM (языковую модель) прямо к вашему браузеру.

**Интересные сценарии (почему это меняет правила игры):**
*   **Умная отладка IndexedDB:** Вместо того чтобы вручную писать JS-код для извлечения 1000 записей из IndexedDB и поиска аномалий, вы просите AI: "Проанализируй базу *OrdersDB* и найди заказы, у которых сумма не сходится с массивом товаров". WebMCP-сервер DevTools сам выполнит запрос к БД, отдаст данные модели, и она вернет результат.
*   **Анализ Service Workers:** Вы спрашиваете: "Почему мой PWA не работает оффлайн?". Модель через MCP запрашивает у браузера статус кэша (Cache Storage API) и логи Service Worker, видит, что регулярное выражение в `fetch` перехватчике написано с ошибкой, и выдает вам готовый фикс.
*   **Приватность (Локальное выполнение):** Благодаря WebMCP, можно использовать локальные модели (например, Llama 3 через Ollama), которые будут иметь доступ к логам браузера без отправки конфиденциальных данных (куки с токенами, персональные данные из LocalStorage) на сервера OpenAI или Google.

WebMCP превращает DevTools из пассивного инструмента просмотра в проактивного агента, который "видит" то же, что и разработчик.
