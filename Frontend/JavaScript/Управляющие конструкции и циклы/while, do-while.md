# Циклы с условием: while и do-while в JavaScript

## 1. Введение в циклы с условием
Циклы позволяют выполнять блок кода многократно, пока определенное условие истинно. В отличие от цикла `for`, который чаще используется при известном количестве итераций, циклы `while` и `do-while` применяются тогда, когда число повторений заранее неизвестно и зависит от динамически меняющихся условий.

---

## 2. Цикл `while` (цикл с предусловием)
Цикл `while` сначала проверяет условие, и если оно истинно (truthy), выполняет тело цикла. Если условие изначально ложно (falsy), тело цикла не выполнится ни разу.

### Синтаксис
```javascript
while (условие) {
  // тело цикла (выполняется, пока условие истинно)
}
```

### Пример 1: Базовый счетчик
```javascript
let counter = 0;

while (counter < 5) {
  console.log(`Итерация: ${counter}`);
  counter++; // Обязательный шаг изменения переменной условия
}
// Вывод: 0, 1, 2, 3, 4
```

### Пример 2: Деструктивное обхождение массива
Цикл `while` отлично подходит для опустошения стека или очереди:
```javascript
const tasks = ["Написать план", "Проверить ссылки", "Отправить отчет"];

while (tasks.length > 0) {
  const currentTask = tasks.shift(); // Извлекает первый элемент
  console.log(`Выполняется задача: ${currentTask}`);
}
console.log(`Все задачи выполнены. Длина массива: ${tasks.length}`);
```

## 3. Цикл `do-while` (цикл с постусловием)
Цикл `do-while` сначала выполняет тело цикла один раз, а затем проверяет условие. Если условие истинно, цикл повторяется. Это гарантирует, что тело цикла выполнится **минимум один раз**, независимо от истинности условия на старте.

### Синтаксис
```javascript
do {
  // тело цикла (выполнится хотя бы один раз)
} while (условие);
```

### Пример: Запрос ввода у пользователя
Типичный сценарий — получение данных от пользователя, когда первая попытка ввода обязательна.
```javascript
// Пример для браузерной среды (работает с prompt)
let number;

do {
  const input = prompt("Пожалуйста, введите число больше 100:", "");
  // Если пользователь нажал Отмена, input будет null, прерываем цикл
  if (input === null) {
    console.log("Ввод отменен пользователем");
    break;
  }
  number = Number(input);
} while (isNaN(number) || number <= 100);

if (number !== undefined) {
  console.log(`Вы ввели валидное число: ${number}`);
}
```

## 4. Управление циклами: `break`, `continue` и метки

### Прерывание цикла: `break`
Инструкция `break` немедленно завершает выполнение цикла и передает управление следующей за циклом строке кода.
```javascript
let sum = 0;
while (true) {
  const value = Math.floor(Math.random() * 10);
  if (value === 5) {
    console.log("Выпало число 5, прекращаем суммирование.");
    break;
  }
  sum += value;
}
console.log(`Итоговая сумма: ${sum}`);
```

### Пропуск текущей итерации: `continue`
Инструкция `continue` останавливает текущую итерацию цикла и переходит к следующей проверке условия.
```javascript
let i = 0;
while (i < 10) {
  i++;
  if (i % 2 === 0) {
    continue; // Пропускаем четные числа
  }
  console.log(`Нечетное число: ${i}`);
}
```

### Метки для `break` и `continue`
Метки позволяют управлять внешними циклами из внутренних вложенных конструкций.
```javascript
outerLoop: while (true) {
  console.log("Внешний цикл запущен");
  
  let innerCounter = 0;
  while (innerCounter < 3) {
    innerCounter++;
    console.log(`--- Внутренний цикл: ${innerCounter}`);
    if (innerCounter === 2) {
      console.log("Выходим из обоих циклов с помощью метки");
      break outerLoop; // Завершает внешний цикл
    }
  }
}
console.log("Оба цикла завершены.");
```

## 5. Пограничные случаи и частые ошибки

### 1. Бесконечный цикл (Infinite Loop)
Если условие цикла никогда не станет ложным, программа зависнет.
```javascript
// ОШИБКА: Забыли инкрементировать счетчик
let count = 0;
while (count < 5) {
  console.log(count);
  // count никогда не меняется -> бесконечный цикл!
}
```

### 2. Ошибка точности вычислений с плавающей точкой
Проверка на строгое равенство чисел с плавающей точкой в условии цикла может привести к зависанию.
```javascript
// ОШИБКА: Из-за погрешности IEEE 754 x может никогда не стать ровно 1.0
let x = 0;
while (x !== 1.0) {
  console.log(x);
  x += 0.1; // x будет принимать значения 0.1, 0.2, 0.30000000000000004 и промахнется мимо 1.0
  if (x > 1.5) break; // Защитный break
}
```
*Решение:* Использовать неравенства (`x < 1.0`) вместо строгих проверок на равенство.

### 3. Точка с запятой после условия `while`
Случайная точка с запятой сразу после `while(условие)` превращает тело цикла в пустую инструкцию, приводя к бесконечному циклу без выполнения блока в фигурных скобках.
```javascript
let y = 0;
// ОШИБКА: Точка с запятой создает пустой цикл, который крутится бесконечно
while (y < 5); 
{
  console.log(y);
  y++;
}
```
