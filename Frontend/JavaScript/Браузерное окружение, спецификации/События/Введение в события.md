## Описание

**Событие** — это сигнал от браузера о том, что что-то произошло (например, клик мышью, нажатие клавиши, загрузка страницы). JavaScript позволяет "слушать" эти события и выполнять код в ответ на них.

---

## Назначение обработчиков событий

Существует несколько способов назначить функцию-обработчик, которая сработает при возникновении события.

### 1. Атрибут HTML (Не рекомендуется)

Обработчик можно задать прямо в HTML-разметке с помощью атрибутов `on<событие>`.

```html
<button onclick="alert('Клик!')">Нажми меня</button>
```
*Минусы:* Смешивание HTML и JavaScript, сложность поддержки, можно назначить только один обработчик.

### 2. Свойство DOM-объекта (Устаревший способ)

Можно назначить функцию свойству `on<событие>` элемента в JavaScript.

```javascript
const btn = document.querySelector('button');
btn.onclick = function() {
  alert('Клик!');
};
```
*Минусы:* Нельзя назначить несколько обработчиков на одно событие (новое значение перезапишет старое).

### 3. `addEventListener` (Современный и рекомендуемый)

Метод `addEventListener` позволяет добавлять неограниченное количество обработчиков на одно событие и управлять фазами их выполнения.

```javascript
const btn = document.querySelector('button');

// Функция-обработчик
function handleClick() {
  alert('Клик!');
}

// Подписка на событие
btn.addEventListener('click', handleClick);

// Отписка от события
btn.removeEventListener('click', handleClick);
```
> **Важно:** Для `removeEventListener` нужно передавать ту же самую функцию (по ссылке), которая была передана в `addEventListener`. Анонимные функции удалить нельзя!

#### Опции `addEventListener`
Третьим аргументом может быть объект с настройками:
- `once: true` — обработчик сработает один раз и автоматически удалится.
- `capture: true` — обработчик сработает на фазе погружения (перехвата), а не всплытия.
- `passive: true` — указывает, что обработчик не будет вызывать `preventDefault()`. Полезно для оптимизации событий скролла (`scroll`, `touchstart`).

## Объект события (Event Object)

При срабатывании события браузер автоматически передает в обработчик **объект события** (обычно называют `e` или `event`). Он содержит всю информацию о произошедшем.

```javascript
btn.addEventListener('click', function(event) {
  console.log(event.type); // "click" - тип события
  console.log(event.target); // элемент, на котором произошло событие
  console.log(event.clientX, event.clientY); // координаты курсора
});
```

Ключевые свойства объекта события:
- `event.type` — тип события (строка, например "click").
- `event.target` — элемент, который инициировал событие (исходный элемент).
- `event.currentTarget` — элемент, на котором в данный момент выполняется обработчик (равен `this`).
- `event.isTrusted` — `true`, если событие сгенерировано действиями пользователя, и `false`, если скриптом (через `dispatchEvent`).

## Фазы событий (Всплытие и Погружение)

Когда происходит событие на вложенном элементе, оно проходит 3 фазы:

1. **Фаза погружения (Capturing phase):** Событие идет сверху вниз от `window` $\rightarrow$ `document` $\rightarrow$ `<html>` $\rightarrow$ ... $\rightarrow$ целевой элемент.
2. **Фаза цели (Target phase):** Событие достигло целевого элемента.
3. **Фаза всплытия (Bubbling phase):** Событие поднимается от целевого элемента обратно вверх к `window`.

По умолчанию `addEventListener` ловит события на **фазе всплытия** (3).

### Остановка всплытия
Вызов метода `event.stopPropagation()` внутри обработчика предотвратит дальнейшее всплытие события к родительским элементам.

```javascript
button.addEventListener('click', (e) => {
  e.stopPropagation(); // Событие не пойдет выше button
});
```
> **Внимание:** Не используйте `stopPropagation` без явной необходимости. Это может сломать логику других скриптов на странице (например, аналитику), которые слушают события на документе.

## Делегирование событий

**Делегирование** — это мощный паттерн, основанный на механизме всплытия. Вместо того чтобы вешать обработчики на множество дочерних элементов (например, на каждый `<li>` в списке), мы вешаем **один** обработчик на их общего родителя (на `<ul>`).

```javascript
// HTML: <ul id="list"> <li>1</li> <li>2</li> ... </ul>

const list = document.getElementById('list');

list.addEventListener('click', function(event) {
  // Проверяем, что клик был по li
  if (event.target.tagName === 'LI') {
    console.log('Кликнули по:', event.target.textContent);
  }
});
```
*Преимущества:*
- Экономия памяти (одна функция вместо сотен).
- При динамическом добавлении новых элементов не нужно назначать им обработчики.

## Отмена действий по умолчанию

Многие события влекут за собой встроенные действия браузера (клик по ссылке `<a href="...">` перенаправляет на другой URL, сабмит формы `<form>` перезагружает страницу).

Чтобы отменить это поведение, используется метод `event.preventDefault()`.

```javascript
const link = document.querySelector('a');

link.addEventListener('click', function(event) {
  event.preventDefault(); // Отменяет переход по ссылке
  console.log('Переход отменен!');
});
```

## Пользовательские события (Custom Events)

Вы можете создавать собственные события и запускать их программно.

```javascript
const elem = document.querySelector('.my-element');

// Создаем событие
const myEvent = new CustomEvent('hello', {
  detail: { name: 'Иван' }, // передаем любые данные
  bubbles: true // разрешаем всплытие
});

// Слушаем событие
elem.addEventListener('hello', (e) => {
  console.log(`Привет, ${e.detail.name}!`);
});

// Генерируем (запускаем) событие
elem.dispatchEvent(myEvent);
```
