# Figma для разработчика (Design Handoff)

Figma — это основной инструмент для UI/UX дизайна, но фронтендеру не нужно уметь рисовать в ней. Главная задача разработчика — правильно "читать" макет и экспортировать ресурсы (Design Handoff).

## Dev Mode (Режим разработчика)
В Figma есть специальный переключатель (зеленая иконка `</>`), который превращает интерфейс из дизайнерского в инструмент для верстальщика.

### 1. Измерение расстояний
*   При наведении на элементы Figma автоматически показывает расстояния в пикселях (margins, paddings) до соседних блоков.
*   Важно понимать концепцию **Auto Layout** (аналог Flexbox в CSS). Если блок сделан через Auto Layout, отступы будут идеально ровными. Если нет — расстояния могут быть дробными (`14.34px`), и разработчику придется их округлять.

### 2. Экспорт CSS (Осторожно!)
*   Dev Mode умеет генерировать CSS/Tailwind код для выделенного элемента.
*   **Правило:** Никогда не копируйте этот код слепо! Figma генерирует абсолютные значения и не знает контекста вашего приложения. Используйте эту панель только для того, чтобы подсмотреть `border-radius`, `box-shadow`, линейные градиенты или `font-weight`. Макетную сетку (Flex/Grid) вы должны писать сами.

### 3. Design Tokens (Переменные)
*   В современных проектах цвета, шрифты и отступы задаются не хардкодом (`#ff0000`), а через переменные (Токены), например `--color-primary`.
*   В Dev Mode справа отображаются используемые переменные. Ваша задача — использовать эти переменные в своем CSS/SCSS/Tailwind коде, а не копировать HEX-значения напрямую.

### 4. Экспорт иконок (SVG)
*   Иконки всегда нужно экспортировать в формате **SVG** (вектор).
*   **Частая ошибка:** Перед экспортом иконки убедитесь, что вы выделили *фрейм* иконки или саму *векторную кривую*, а не прозрачный контейнер вокруг нее размером на пол-экрана.
*   В коде SVG полезно удалять атрибуты `fill` (если цвет должен наследоваться через CSS `currentColor`) и лишние теги `<def>`.

### 5. Экспорт растра (PNG, WebP)
*   Фотографии и сложные иллюстрации (где много теней и градиентов) экспортируются в растре.
*   Выбирайте формат **WebP** для лучшего сжатия или экспортируйте PNG/JPG в размере `@2x` (для Retina-экранов), чтобы картинка не мылилась на современных мониторах.
