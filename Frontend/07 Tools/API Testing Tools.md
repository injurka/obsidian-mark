# Инструменты для тестирования API (Postman / Insomnia)

При разработке фронтенда часто возникает необходимость проверять запросы к серверу до того, как они будут реализованы в коде, или дебажить уже существующие API. Для этого используются специальные инструменты.

## Основные инструменты

### 1. Postman
Самый популярный инструмент для работы с API.
*   **Коллекции (Collections):** Позволяют группировать запросы по логическим блокам (например, "Авторизация", "Пользователи") и делиться ими с командой.
*   **Окружения (Environments):** Можно создавать переменные для разных сред (Local, Dev, Prod). Например, `{{base_url}}/api/users`.
*   **Скрипты (Pre-request Scripts & Tests):** Возможность писать JS-код, который выполнится до или после запроса (например, для автоматического сохранения токена из ответа в переменную окружения).
*   **Генерация кода:** Postman умеет генерировать код запроса для разных языков и библиотек (fetch, axios и т.д.).

### 2. Insomnia
Мощная альтернатива Postman. Многие разработчики предпочитают ее за более чистый интерфейс и высокую скорость работы.
*   Менее перегруженный интерфейс.
*   Отличная поддержка GraphQL.
*   Удобная работа с переменными окружения.

## Зачем они фронтендеру:
1.  **Проверка контрактов:** Убедиться, что бэкенд возвращает данные в ожидаемом формате.
2.  **Mock-серверы:** Если бэкенд еще не готов, в Postman можно создать мок-сервер, который будет возвращать заранее заданные фейковые данные, чтобы не блокировать работу фронтенда.
3.  **Дебаг авторизации:** Удобно проверять, как работают токены (Bearer, JWT), куки и заголовки без необходимости писать UI для логина.
