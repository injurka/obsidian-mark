# Менеджеры версий Node.js (NVM / Volta)

При работе над несколькими проектами одновременно часто возникает ситуация, когда один старый проект требует `Node.js v14`, а новый — `Node.js v20`. Глобальная установка одной версии 노ды в систему больше не работает. Для решения этой проблемы используются менеджеры версий.

## 1. NVM (Node Version Manager)
Самый старый и популярный инструмент для управления версиями Node.js.

*   **Как работает:** Позволяет скачивать несколько версий Node.js на один компьютер и переключаться между ними в терминале.
*   **Основные команды:**
    *   `nvm install 20` — скачать и установить 20-ю версию.
    *   `nvm use 16` — переключить текущую сессию терминала на 16-ю версию.
    *   `nvm ls` — показать все установленные версии.
*   **Файл `.nvmrc`:** В корень проекта обычно кладут файл `.nvmrc` с указанием версии (например, `v18.17.0`). Разработчику достаточно зайти в папку и написать `nvm use`, чтобы менеджер сам прочитал файл и включил нужную версию.

## 2. Volta
Современная и очень быстрая альтернатива NVM, написанная на Rust.

*   **В чем отличие:** Volta работает автоматически. Вы не пишете `volta use 18`. Volta перехватывает команды (node, npm, yarn) и автоматически подставляет нужную версию в зависимости от того, в какой папке вы находитесь.
*   **Интеграция с package.json:** Вместо отдельного файла `.nvmrc`, Volta записывает требования прямо в `package.json`:
    ```json
    "volta": {
      "node": "20.9.0",
      "yarn": "1.22.19"
    }
    ```
*   **Глобальные пакеты:** Volta решает проблему глобальных пакетов (например, `create-react-app`). Она привязывает глобальный пакет к той версии Node.js, при которой он был установлен, что исключает ошибки совместимости.

## 3. Другие альтернативы
*   **n (tj/n):** Очень простой менеджер для macOS и Linux.
*   **fnm (Fast Node Manager):** Еще одна быстрая альтернатива на Rust, похожая на NVM, но работающая быстрее.
