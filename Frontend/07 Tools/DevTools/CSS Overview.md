# Вкладка CSS Overview (Chrome DevTools)

**CSS Overview** (Обзор CSS) — это экспериментальная (в прошлом), а теперь стандартная вкладка, которая собирает статистику по всем стилям, используемым на странице.

*Как открыть: Нажать `Ctrl+Shift+P` (Cmd+Shift+P на Mac) -> ввести `Show CSS Overview` -> нажать кнопку "Capture overview".*

## Какую информацию она собирает:

### 1. Сводка (Overview summary)
*   Общее количество элементов на странице.
*   Количество внешних таблиц стилей и инлайн-стилей.
*   Количество используемых CSS-правил и селекторов.

### 2. Цвета (Colors)
*   Собирает **все** цвета, используемые на странице для фона, текста, границ и SVG-заливок.
*   **Зачем нужно:** Это идеальный инструмент при рефакторинге легаси-проекта или переносе дизайна в переменные (CSS Custom Properties). Позволяет увидеть, что вместо одного нужного серого цвета в проекте используется 15 разных оттенков серого (`#ccc`, `#c0c0c0`, `#c2c2c2` и т.д.).
*   Также показывает **проблемы с контрастом** (по стандартам доступности WCAG) между цветом текста и фоном.

### 3. Шрифты (Font info)
*   Список всех используемых `font-family`.
*   Все размеры шрифтов (`font-size`), вес (`font-weight`) и высота строки (`line-height`), которые применяются на странице.
*   **Зачем нужно:** Помогает привести типографику к единому стандарту и избавиться от случайных размеров шрифта вроде `13.5px` или неиспользуемых семейств шрифтов.

### 4. Неиспользуемые объявления (Unused declarations)
*   Показывает CSS-правила, которые не имеют смысла в данном контексте и игнорируются браузером.
*   **Пример:** Применение `vertical-align` к блочному элементу, или использование `top`/`left` на элементе с `position: static`.

### 5. Медиазапросы (Media queries)
*   Список всех точек останова (breakpoints) медиазапросов, найденных в CSS.
*   Помогает убедиться, что проект использует консистентные брейкпоинты для адаптивного дизайна, а не хаотичный набор случайных значений.
