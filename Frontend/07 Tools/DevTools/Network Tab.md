# Вкладка Network (Chrome DevTools)

Вкладка **Network** позволяет отслеживать все сетевые запросы, которые делает страница, и анализировать их производительность.

## Основные возможности:

### 1. Запись запросов
*   По умолчанию DevTools записывает все запросы (кнопка записи в левом верхнем углу).
*   **Preserve log:** Сохранение истории запросов при перезагрузке страницы или переходе на другую.
*   **Disable cache:** Отключение кэша браузера (работает только при открытых DevTools).

### 2. Фильтрация
*   По типу ресурса (Fetch/XHR, JS, CSS, Img, Media, Font, Doc, WS, Wasm).
*   По тексту (поиск по имени файла, домену и т.д.).
*   Инвертирование фильтра (чекбокс Invert).

### 3. Анализ отдельного запроса
При клике на запрос открывается панель с детальной информацией:
*   **Headers:** URL, метод (GET, POST и т.д.), статус-код, заголовки запроса и ответа.
*   **Payload (или Params):** Данные, отправленные на сервер (query string или body).
*   **Preview / Response:** Предпросмотр ответа сервера (удобно для JSON или изображений) и сырой ответ.
*   **Initiator:** Цепочка вызовов (call stack), которая привела к выполнению запроса.
*   **Timing:** Подробная разбивка времени выполнения запроса (DNS, TCP, Request sent, Waiting (TTFB), Content Download).

### 4. Троттлинг (Throttling)
*   Имитация медленного интернет-соединения (Fast 3G, Slow 3G, Offline) для тестирования производительности в плохих условиях.

### 5. Общая статистика
*   Внизу экрана отображается количество запросов, объем переданных данных (Transferred), реальный размер ресурсов (Resources) и время загрузки (Finish, DOMContentLoaded, Load).
