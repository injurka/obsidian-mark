# Вкладка Application (Chrome DevTools)

Вкладка **Application** — это центр управления ресурсами, которые браузер сохраняет на устройстве пользователя. 

## Основные разделы:

### 1. Application (Приложение)
Позволяет управлять жизненным циклом PWA и фоновых скриптов.
*   **Manifest:** Позволяет просмотреть `manifest.json`, проверить иконки и симулировать события установки PWA.
*   **Service Workers:** Место для регистрации, отмены (unregister) Service Workers, симуляции оффлайн режима и отправки тестовых Push-уведомлений.

### 2. Storage (Хранилище)
Все локальные данные сайта.
*   **Local / Session Storage & Cookies:** Просмотр, редактирование и удаление пар ключ-значение и кук.
*   **IndexedDB:** Интерфейс для просмотра баз данных, Object Stores и выполнения простых запросов.
*   **Cache Storage:** Просмотр кэшированных ответов сети.
*   **Кнопка "Clear site data":** Удобный инструмент для полной очистки всех хранилищ и кэшей сайта одним кликом.

### 3. Background Services (Фоновые службы)
Отладка API, работающих в фоне.
*   **Background Fetch / Sync:** Логи фоновых скачиваний и синхронизаций.
*   **Notifications / Push Messaging:** Логирование системных уведомлений.
*   **Back/forward cache:** Инструмент для проверки того, подходит ли ваша страница для мгновенной навигации bfcache, и указание причин, если она не подходит.

### 4. Frames (Фреймы)
Инструмент для анализа структуры документа.
*   Отображает иерархию всех фреймов на странице (включая основной документ и `<iframe>`).
*   Для каждого фрейма показывает изолированный список загруженных скриптов, стилей и медиа-ресурсов. Полезно для отладки сложного контента, встроенного со сторонних доменов.
