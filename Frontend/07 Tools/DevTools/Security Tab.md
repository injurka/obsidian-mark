# Вкладка Security (Chrome DevTools)

Вкладка **Security** (Безопасность) предназначена для анализа проблем с HTTPS-соединением и сертификатами сайта.

## Основные возможности:

### 1. Общий статус безопасности
*   **Secure (Зеленый статус):** Страница загружена по защищенному протоколу HTTPS, сертификат валиден.
*   **Not Secure (Красный статус):** Страница загружена по HTTP или есть серьезные проблемы с сертификатом.

### 2. Проверка сертификата (View certificate)
*   Позволяет посмотреть подробную информацию об SSL-сертификате: кем выдан (Issuer), для каких доменов действует (Subject Alternative Name), срок действия (Valid from/to).
*   Полезно, когда сайт внезапно перестал открываться у пользователей с ошибкой конфиденциальности — здесь можно проверить, не истек ли сертификат.

### 3. Mixed Content (Смешанный контент)
*   **Проблема:** Возникает, когда сама HTML-страница загружается безопасно по HTTPS, но некоторые ресурсы на ней (картинки, скрипты, стили) грузятся по небезопасному HTTP.
*   Браузеры блокируют небезопасные скрипты и стили (Active Mixed Content), что ломает работу сайта. Картинки (Passive Mixed Content) обычно загружаются, но браузер помечает сайт как небезопасный.
*   На вкладке Security четко указано, какие именно ресурсы вызвали предупреждение Mixed Content, что позволяет быстро найти их и исправить пути с `http://` на `https://`.

### 4. Connection Details
*   Показывает протокол (например, TLS 1.3), алгоритм обмена ключами и шифр, используемые для текущего соединения.
