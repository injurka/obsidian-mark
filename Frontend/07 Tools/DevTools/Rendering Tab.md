# Вкладка Rendering (Chrome DevTools)

Вкладка **Rendering** (Рендеринг) — это скрытая по умолчанию панель, которая содержит инструменты для визуальной отладки того, как браузер отрисовывает страницу. 

*Как открыть: Нажать `Ctrl+Shift+P` (Cmd+Shift+P на Mac) -> ввести `Show Rendering`.*

## Самые полезные инструменты:

### 1. Paint Flashing (Подсветка перерисовки)
*   **Что делает:** Подсвечивает зеленым прямоугольником области экрана, которые браузер перерисовывает в данный момент.
*   **Зачем нужно:** Это критически важный инструмент для оптимизации React/Vue/Angular приложений. Если при скролле, ховере или вводе текста в инпут мигает половина экрана (или вся страница), значит, у вас проблемы с лишними рендерами, и браузер тратит ресурсы впустую.

### 2. Layout Shift Regions (Области смещения макета)
*   **Что делает:** Подсвечивает синим цветом элементы, которые неожиданно сдвигаются (вызывают Reflow/Layout).
*   **Зачем нужно:** Помогает найти виновников плохой метрики **CLS (Cumulative Layout Shift)**. Например, картинки без заданных размеров или шрифты, которые поздно загрузились и сдвинули текст.

### 3. Layer Borders (Границы слоев)
*   **Что делает:** Показывает сетку, разделяющую страницу на композитные слои (Compositor Layers).
*   **Зачем нужно:** Полезно для отладки сложных анимаций. Элементы, которые анимируются через `transform` или `opacity` (и имеют `will-change`), выносятся на отдельный слой, который обрабатывается GPU. Это позволяет избежать перерисовки (Paint) всей страницы.

### 4. Emulate CSS media features (Эмуляция медиа-функций)
*   **Что делает:** Позволяет протестировать, как сайт выглядит при разных системных настройках пользователя, не меняя настройки самой ОС.
*   **Примеры:** 
    *   `prefers-color-scheme: dark/light` (тестирование темной темы).
    *   `prefers-reduced-motion: reduce` (тестирование отключения анимаций для людей с вестибулярными расстройствами).

### 5. Emulate vision deficiencies (Эмуляция нарушений зрения)
*   **Что делает:** Накладывает фильтры на страницу, чтобы показать, как её видят люди с различными формами дальтонизма (например, протанопия, дейтеранопия) или с размытым зрением.
*   **Зачем нужно:** Важный инструмент для проверки доступности (Accessibility) дизайна.
