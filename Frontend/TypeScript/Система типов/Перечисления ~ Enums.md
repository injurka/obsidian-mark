## Что это?

Enums позволяют определить набор именованных констант, представляющих дискретные значения.

## Зачем нужно?

Для представления фиксированного набора вариантов (состояния, статусы, роли, типы событий и т.д.), делая код более читаемым и менее подверженным ошибкам по сравнению с использованием "магических" строк или чисел.

## Как работает?

*   **Числовые (Numeric):** По умолчанию значения начинаются с 0 и автоинкрементируются. Значения можно задавать вручную. Поддерживают обратное отображение (получение имени по значению).
*   **Строковые (String):** Значения задаются явно строковыми литералами. Обратного отображения нет. Более понятны при отладке.
*   **Константные (Const Enums):** Объявляются с `const`. Не генерируют JavaScript-объект, значения встраиваются в код при компиляции для производительности.

## Примеры:

```typescript
// Числовой enum (автоматические значения)
enum Direction {
  Up,    // 0
  Down,  // 1
  Left,  // 2
  Right  // 3
}
let dir: Direction = Direction.Left; // dir === 2
console.log(Direction[2]); // Выведет: "Left" (обратное отображение)

// Строковый enum
enum LogLevel {
  Error = "ERROR",
  Warn = "WARN",
  Info = "INFO"
}
let level: LogLevel = LogLevel.Warn; // level === "WARN"

// Const Enum
const enum Color { Red, Green, Blue }
let c: Color = Color.Red;
// В скомпилированном JS будет: let c = 0;
```
