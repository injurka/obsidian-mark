# Lighthouse

**Lighthouse** — это автоматизированный инструмент с открытым исходным кодом от Google для улучшения качества веб-страниц. Его можно запускать как встроенную утилиту в Chrome DevTools (вкладка Lighthouse), как расширение для браузера, или из командной строки (Node.js).

## Основные метрики (Аудиты)

Lighthouse оценивает страницу по нескольким ключевым направлениям и выдает оценку от 0 до 100 для каждого из них:

### 1. Performance (Производительность)
Оценивает, насколько быстро страница загружается и становится интерактивной для пользователя. Включает метрики **Core Web Vitals**:
*   **FCP (First Contentful Paint):** Время до появления первого текста или изображения.
*   **LCP (Largest Contentful Paint):** Время рендеринга самого крупного видимого элемента в области просмотра.
*   **TBT (Total Blocking Time):** Время, в течение которого главный поток был заблокирован достаточно долго, чтобы предотвратить реакцию на ввод.
*   **CLS (Cumulative Layout Shift):** Оценка неожиданных смещений макета страницы во время загрузки.

### 2. Accessibility (Доступность - a11y)
Проверяет, насколько страница удобна для людей с ограниченными возможностями (использование экранных дикторов, навигация с клавиатуры).
*   Наличие `alt` у изображений.
*   Правильный контраст цветов.
*   Корректное использование ARIA-атрибутов.
*   Структура заголовков.

### 3. Best Practices (Лучшие практики)
Проверка на соответствие современным стандартам веб-разработки:
*   Использование HTTPS.
*   Отсутствие уязвимостей в используемых библиотеках.
*   Корректное использование API браузера (отказ от устаревших методов).

### 4. SEO (Поисковая оптимизация)
Проверка базовых требований для индексации поисковыми роботами:
*   Наличие тегов `<title>` и `<meta name="description">`.
*   Правильные HTTP-статусы.
*   Корректные атрибуты `hreflang` и `rel="canonical"`.

### 5. PWA (Progressive Web App)
Дополнительный аудит (сейчас часто выделен отдельно), проверяющий, соответствует ли сайт критериям PWA (наличие Service Worker, манифеста, работа в оффлайне).
