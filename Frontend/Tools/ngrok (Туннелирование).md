# Туннелирование локального сервера (ngrok)

При разработке часто возникает ситуация, когда проект работает только на `localhost` (например, `http://localhost:3000`), но к нему нужно дать доступ извне.

## Зачем это нужно:
1.  **Показать работу заказчику/менеджеру:** Вместо того чтобы разворачивать приложение на тестовом стенде, можно просто дать временную ссылку на ваш компьютер.
2.  **Тестирование на мобильных устройствах:** Проверить, как сайт выглядит на реальном iPhone или Android по сотовой сети, если они не подключены к вашему домашнему Wi-Fi.
3.  **Тестирование вебхуков (Webhooks):** Если вы интегрируете платежную систему (Stripe, ЮKassa) или Telegram-бота, их серверы должны отправлять запросы на ваш бэкенд. Они не могут отправлять запросы на `localhost`, им нужен публичный URL (HTTPS).

## Популярные инструменты

### 1. ngrok
Самый популярный и стабильный инструмент для туннелирования.
*   **Как работает:** Устанавливается как небольшая утилита в консоль. Запускается командой:
    ```bash
    ngrok http 3000
    ```
*   **Результат:** В консоли появляется публичная ссылка вида `https://1234-abcd.ngrok-free.app`. Любой человек, перейдя по ней, попадет на ваш `localhost:3000`.
*   *Минусы:* Бесплатная версия стала ограничивать функционал и иногда требует от посетителей кликнуть на кнопку "Продолжить" (предупреждение о фишинге), что может ломать автоматические вебхуки.

### 2. localtunnel
Отличная бесплатная альтернатива на Node.js.
*   **Как использовать:** Не требует регистрации, запускается через `npx`:
    ```bash
    npx localtunnel --port 3000
    ```
*   Можно даже задать свой красивый поддомен:
    ```bash
    npx localtunnel --port 3000 --subdomain my-awesome-app
    ```
    (ссылка будет `https://my-awesome-app.loca.lt`).

### 3. Cloudflare Tunnels (cloudflared)
Профессиональное и мощное решение от Cloudflare (бесплатно).
*   Требует чуть больше времени на настройку, но работает невероятно стабильно, не требует "прокликивания" предупреждений и позволяет привязывать постоянные домены. Идеально для длительной разработки с вебхуками.
