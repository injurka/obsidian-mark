# Вкладка Console (Chrome DevTools)

Вкладка **Console** (Консоль) используется для вывода логов сообщений, ошибок и предупреждений, а также для выполнения JavaScript-кода в контексте текущей страницы.

## Основные возможности:

### 1. Вывод сообщений (Логирование)
*   **`console.log()`:** Стандартный вывод.
*   **`console.error()`:** Вывод ошибок (с красным фоном и стеком вызовов).
*   **`console.warn()`:** Вывод предупреждений (с желтым фоном).
*   **`console.table()`:** Удобный вывод массивов или объектов в виде таблицы.
*   **`console.time()` / `console.timeEnd()`:** Замер времени выполнения блоков кода.

### 2. Фильтрация
*   По уровню (Verbose, Info, Warnings, Errors).
*   По тексту или регулярному выражению.
*   Скрытие сетевых ошибок (`Hide network`).

### 3. REPL (Read-Eval-Print Loop)
*   Ввод и немедленное выполнение любого JS-кода.
*   Доступ к переменным и функциям глобальной области видимости (например, `window`).
*   Автодополнение (autocomplete) при вводе.

### 4. Полезные утилиты (Console Utilities API)
*   `$_`: Возвращает результат последнего вычисленного выражения.
*   `$0`, `$1`...: Ссылки на элементы, недавно выбранные на вкладке Elements ( `$0` — последний выбранный).
*   `$(selector)`: Псевдоним для `document.querySelector()`.
*   `$$(selector)`: Псевдоним для `document.querySelectorAll()`.

### 5. Контекст выполнения
*   По умолчанию консоль выполняется в контексте `top` (основной документ). Можно переключиться на контекст любого `iframe` на странице, чтобы взаимодействовать с его переменными.
