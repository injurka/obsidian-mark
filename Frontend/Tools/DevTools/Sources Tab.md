# Вкладка Sources (Chrome DevTools)

Вкладка **Sources** — это мощная среда для дебаггинга (отладки) JavaScript, просмотра исходников и редактирования файлов прямо в браузере.

## Основные возможности:

### 1. Дебаггинг с помощью Breakpoints (Точек останова)
Это гораздо эффективнее, чем использовать `console.log`.
*   **Line-of-code breakpoints:** Остановка выполнения на конкретной строке кода.
*   **Conditional breakpoints:** Остановка только при выполнении определенного условия (ПКМ по номеру строки -> Add conditional breakpoint).
*   **DOM breakpoints:** Остановка, когда скрипт изменяет DOM (удаляет узел, меняет атрибуты). Настраивается на вкладке Elements (ПКМ по элементу -> Break on).
*   **XHR/fetch breakpoints:** Остановка при отправке сетевого запроса, если URL содержит определенную строку.
*   **Event listener breakpoints:** Остановка при срабатывании определенных событий (например, клик мышью, таймер, загрузка страницы).

### 2. Навигация при дебаггинге
Когда код остановлен, доступны элементы управления (в верхней правой панели):
*   **Resume (F8):** Продолжить выполнение до следующего брейкпоинта.
*   **Step over (F10):** Выполнить текущую строку и перейти к следующей (не заходя внутрь функций).
*   **Step into (F11):** Зайти внутрь функции, которая вызывается на текущей строке.
*   **Step out (Shift+F11):** Выйти из текущей функции и вернуться в место её вызова.

### 3. Инспекция состояния (Scope & Watch)
*   **Scope:** Просмотр значений переменных в локальной, модульной и глобальной областях видимости во время паузы.
*   **Watch:** Добавление собственных выражений, за значениями которых нужно следить (они будут пересчитываться при каждом шаге дебаггера).

### 4. Рабочие области (Workspaces)
Позволяют связать папку на вашем компьютере с DevTools. Изменения, внесенные в код на вкладке Sources или Elements, будут сохраняться прямо в ваши локальные файлы.

### 5. Сниппеты (Snippets)
*   Небольшие JS-скрипты, которые можно сохранить в DevTools и запускать на любой странице. Полезно для часто используемых утилит или проверок.

### 6. Local Overrides
*   Позволяет подменять файлы, загружаемые с сервера, на локальные версии. Отличный способ тестировать исправления на "живом" сайте без доступа к бэкенду.
