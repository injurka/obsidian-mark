# Вкладка Elements (Chrome DevTools)

Вкладка **Elements** позволяет просматривать и редактировать DOM-дерево и CSS-стили страницы в реальном времени.

## Основные возможности:

### 1. DOM-дерево
*   **Просмотр структуры:** Навигация по HTML-разметке страницы.
*   **Редактирование:** Изменение тегов, атрибутов и текстового содержимого (двойной клик или ПКМ -> Edit as HTML).
*   **Drag & Drop:** Перемещение узлов дерева.
*   **Брейкпоинты:** Установка точек останова на изменение атрибутов, удаление узла или изменение его дочерних элементов (ПКМ -> Break on).

### 2. Стили (Styles)
*   **Просмотр CSS:** Отображение всех стилей, примененных к выбранному элементу (включая унаследованные).
*   **Редактирование:** Добавление, изменение или отключение CSS-свойств на лету.
*   **Состояния элементов:** Эмуляция состояний `:hover`, `:active`, `:focus`, `:visited` (кнопка `:hov`).
*   **Классы:** Быстрое добавление и переключение CSS-классов (кнопка `.cls`).

### 3. Computed (Вычисленные стили)
*   **Блочная модель:** Визуализация box-model (margins, borders, padding, размеры контента).
*   **Финальные значения:** Отображение итоговых значений всех CSS-свойств, примененных к элементу, после разрешения всех конфликтов и каскада.

### 4. Layout
*   Настройки отображения CSS Grid и Flexbox (подсветка линий, промежутков, имен областей).

### 5. Event Listeners
*   Просмотр обработчиков событий, привязанных к элементу (и его предкам).
