
# Структура HTML документа

Любая веб-страница в интернете — это обычный текстовый файл с расширением `.html`. Чтобы браузер (Chrome, Safari, Firefox) мог правильно прочитать этот файл и отрисовать его в виде красивого интерфейса, документ должен иметь строго определенную **базовую структуру (каркас)**.

Браузер читает HTML-код линейно: сверху вниз, строка за строкой. На основе этого кода он строит в оперативной памяти древовидную структуру — **DOM (Document Object Model)**.

---

## 1. Базовый каркас (Boilerplate)

Это минимальный, обязательный набор тегов для любой современной HTML-страницы. В редакторах кода (например, VS Code) этот каркас можно сгенерировать за секунду, набрав символ `!` и нажав `Tab` (благодаря встроенному плагину Emmet).

```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Заголовок страницы</title>
</head>
<body>
  
  <!-- Здесь размещается видимый контент страницы -->
  
</body>
</html>
```

---

## 2. Построчный разбор каркаса

### `<!DOCTYPE html>` (Объявление типа документа)
Строго говоря, это не HTML-тег, а **инструкция** для браузера. Она говорит: *"Этот документ написан по современному стандарту HTML5"*. 
* **Зачем это нужно?** На заре интернета существовало множество несовместимых версий HTML. Если не указать `<!DOCTYPE html>`, браузер перейдет в так называемый **Quirks Mode (режим совместимости)** — он начнет эмулировать поведение старых браузеров из 90-х годов, и ваша современная CSS-верстка сломается.

### `<html>` (Корневой элемент)
Это контейнер, внутри которого находится абсолютно весь код страницы. Его часто называют **корневым тегом** (root element).
* Атрибут `lang="ru"` крайне важен. Он указывает основной язык страницы. Это критично для программ экранного доступа (скринридеров) и встроенных переводчиков в браузерах.

---

## 3. Раздел `<head>` (Голова документа)

Контейнер `<head>` содержит служебную информацию (метаданные). **Всё, что находится внутри `<head>`, не отображается визуально** на самой странице (за исключением тега `<title>`, который виден на вкладке браузера).

**Что обычно находится в `<head>`:**
1. **Метатеги (`<meta>`):** Настройки кодировки (`charset="UTF-8"`), адаптивности (`viewport`), SEO-описания и микроразметка для соцсетей *(подробнее см. в файле "Метатеги и SEO")*.
2. **Заголовок страницы (`<title>`):** Имя вкладки и главный заголовок для поисковой выдачи.
3. **Подключение стилей (`<link>`):** Ссылки на внешние CSS-файлы, шрифты или иконку сайта (favicon).
   ```html
   <link rel="stylesheet" href="styles.css">
   <link rel="icon" href="favicon.ico">
   ```
4. **Подключение скриптов (`<script>`):** Ссылки на JavaScript-файлы. 
   *(Современный стандарт — подключать скрипты в `<head>` с атрибутом `defer`, чтобы они не блокировали загрузку визуальной части страницы).*
   ```html
   <script src="app.js" defer></script>
   ```

---

## 4. Раздел `<body>` (Тело документа)

Контейнер `<body>` — это область визуального представления. **Здесь находится всё, что увидит пользователь:** текст, изображения, видео, кнопки, формы и структура навигации.

В одном HTML-документе может быть **строго один** тег `<body>`. 
Внутри него располагается иерархическая структура из семантических и структурных тегов (`<header>`, `<main>`, `<footer>`, `<div>`, `<p>` и т.д.).

---

## 5. Иерархия (Вложенность и DOM-дерево)

HTML использует принцип вложенности. Теги могут (и должны) находиться внутри других тегов. Это формирует родственные связи, которые являются основой для написания CSS-селекторов и манипуляций через JavaScript.

* **Родитель (Parent):** Элемент, внутри которого находится другой элемент.
* **Потомок / Дочерний элемент (Child):** Элемент, находящийся непосредственно внутри родителя.
* **Соседи / Сестринские элементы (Siblings):** Элементы, находящиеся на одном уровне вложенности (имеющие одного родителя).

**Пример:**
```html
<section>
  <h1>Заголовок</h1>
  <p>Текст абзаца</p>
</section>
```
*В данном случае `<section>` — родитель для `<h1>` и `<p>`. А `<h1>` и `<p>` — это соседи по отношению друг к другу.*

### Главное правило вложенности (Пересечение тегов запрещено)
Теги должны закрываться в порядке, обратном их открытию. Они не должны «перехлестываться».

✅ **Правильно:** (Сначала закрыли `<strong>`, потом `<a>`)
```html
<a href="#">Нажми <strong>сюда</strong></a>
```

❌ **Неправильно:** (Пересечение — браузеру придется исправлять ошибку)
```html
<a href="#">Нажми <strong>сюда</a></strong>
```

## 6. Комментарии в коде

В любой части документа (как в `<head>`, так и в `<body>`) можно оставлять комментарии. Они полностью игнорируются браузером, не видны на странице, но доступны, если открыть исходный код страницы (`Ctrl+U` / `Cmd+Option+U`).

```html
<!-- Это HTML-комментарий. Он нужен для пояснений разработчикам -->
<!-- 
  Комментарии могут быть 
  многострочными
-->
```

> [!WARNING] Важно (Безопасность)
> Никогда не оставляйте в HTML-комментариях пароли, API-ключи, ссылки на закрытые админ-панели или черновики с конфиденциальными данными клиента. Исходный код доступен абсолютно любому пользователю интернета.

---

## 7. Правила хорошего тона (Best Practices)

1. **Отступы (Индентация):** Каждому новому уровню вложенности добавляется отступ (обычно 2 или 4 пробела). Это не влияет на работу кода, но делает его читаемым. *Писать весь код в одну линию — плохая практика.*
2. **Только строчные буквы:** Имена тегов и атрибутов по стандарту можно писать капсом (`<DIV ID="MAIN">`), но в современном сообществе принято использовать **только строчные буквы** (`<div id="main">`).
3. **Двойные кавычки:** Всегда оборачивайте значения атрибутов в двойные кавычки (`class="btn"`). Одинарные кавычки используются редко, а отсутствие кавычек может привести к багам, если в значении есть пробел.
