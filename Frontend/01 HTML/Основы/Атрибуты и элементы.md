# Атрибуты и элементы в HTML

**HTML-элементы** и **атрибуты** — это фундаментальные строительные блоки любой веб-страницы. Элементы определяют структуру и смысл контента, а атрибуты задают их дополнительные свойства, поведение и настройки.

---

## 1. HTML-Элементы (Elements)

HTML-элемент — это отдельный компонент документа, который говорит браузеру, как именно нужно интерпретировать заключенный в него контент.

### Анатомия элемента
Обычно элемент состоит из трех частей:
1. **Открывающий тег** (например, `<p>`), который указывает начало элемента.
2. **Содержимое** (текст, другие элементы).
3. **Закрывающий тег** (например, `</p>`), который указывает конец элемента.

```html
<p>Это текстовое содержимое абзаца.</p>
```

### Пустые элементы (Void elements)
Некоторые элементы не могут содержать внутри себя текст или другие элементы. У них нет закрывающего тега.
*Примеры:* `<img>`, `<br>`, `<hr>`, `<input>`, `<meta>`.
```html
<img src="logo.png" alt="Логотип компании">
<input type="text" name="username">
```

### Классификация элементов
В HTML5 элементы классифицируются по их семантике и поведению:
* **Блочные элементы (Block-level):** Занимают всю доступную ширину родителя и начинаются с новой строки. Формируют структуру (каркас) страницы. (*Примеры: `<div>`, `<p>`, `<h1>`–`<h6>`, `<section>`, `<article>`*).
* **Строчные элементы (Inline):** Занимают ровно столько места, сколько необходимо их содержимому, и не переносят текст на новую строку. (*Примеры: `<span>`, `<a>`, `<strong>`, `<em>`*).
* **Семантические элементы:** Четко описывают свой смысл как для разработчика, так и для браузера (скринридера, поискового робота). (*Примеры: `<header>`, `<nav>`, `<footer>`*).
* **Несемантические элементы:** Не несут информации о содержимом, используются как контейнеры для стилизации или скриптов. (*Примеры: `<div>`, `<span>`*).

## 2. Атрибуты (Attributes)

**Атрибуты** предоставляют дополнительную информацию об элементах или изменяют их поведение. 

### Правила написания атрибутов
1. Атрибуты всегда указываются **только в открывающем теге**.
2. Обычно они состоят из имени и значения: `имя="значение"`.
3. Значения атрибутов принято заключать в двойные кавычки (хотя одинарные кавычки или отсутствие кавычек в простых случаях спецификацией допускаются, двойные — стандарт де-факто).

### Логические (Boolean) атрибуты
Некоторые атрибуты не требуют указания значения. Само их присутствие в теге означает `true`, а отсутствие — `false`.
*Примеры:* `disabled`, `readonly`, `checked`, `required`, `autofocus`, `defer`.
```html
<!-- Поле ввода отключено -->
<input type="text" disabled>

<!-- Чекбокс заранее выбран -->
<input type="checkbox" checked>
```

### Специфичные (Локальные) атрибуты
Это атрибуты, которые применимы только к определенным тегам и не имеют смысла для других.
* `src` и `alt` — только для `<img>`, `<script>`, `<audio>`, `<video>`, `<iframe>`.
* `href` — только для `<a>`, `<link>`.
* `type`, `value`, `placeholder` — для `<input>`, `<button>`.

---

## 3. Глобальные атрибуты (Global Attributes)

Глобальные атрибуты могут быть применены абсолютно к **любому** HTML-элементу (хотя для некоторых элементов они могут не иметь видимого эффекта).

| Атрибут | Описание |
| :--- | :--- |
| `class` | Список CSS-классов (через пробел) для связывания элемента со стилями или JS. |
| `id` | Уникальный идентификатор элемента на странице. Должен встречаться ровно 1 раз на документ. |
| `style` | Содержит inline CSS-стили (например, `style="color: red;"`). Имеет высший приоритет в CSS-каскаде. |
| `hidden` | Логический атрибут. Если он есть, браузер не отображает элемент (аналог `display: none`). |
| `tabindex` | Управляет порядком получения фокуса при навигации с помощью клавиши `Tab`. `tabindex="0"` делает элемент фокусируемым, `-1` убирает из навигации (но оставляет доступным для JS `focus()`). |
| `title` | Содержит текст всплывающей подсказки (тултипа), которая появляется при наведении курсора. |
| `dir` | Направление текста (от англ. *direction*). Значения: `ltr` (слева направо), `rtl` (справа налево), `auto`. |
| `lang` | Указывает базовый язык содержимого элемента (например, `lang="ru"`). Важно для SEO и скринридеров. |

### Пользовательские data-атрибуты (`data-*`)
Особый класс глобальных атрибутов, позволяющий безопасно хранить произвольные данные (строки) прямо в HTML-разметке для их дальнейшего использования в JavaScript или CSS.
```html
<button id="buy-btn" data-product-id="12345" data-category="books">Купить</button>
```
В JavaScript эти атрибуты очень удобно читать и изменять через свойство `dataset`:
```javascript
const btn = document.getElementById('buy-btn');
console.log(btn.dataset.productId); // "12345"
console.log(btn.dataset.category); // "books"
```

## 4. Атрибуты событий (Event Attributes)

Это специальные атрибуты, которые позволяют запускать код на JavaScript при взаимодействии пользователя с элементом. Они начинаются с префикса `on`.

* **События мыши:** `onclick`, `ondblclick`, `onmouseover`, `onmouseout`, `onmousemove`.
* **События клавиатуры:** `onkeydown`, `onkeyup`, `onkeypress`.
* **События форм:** `onsubmit`, `onchange`, `oninput`, `onfocus`, `onblur`.

```html
<button onclick="alert('Привет!')">Кликни меня</button>
```

> [!WARNING] Важно (Архитектура)
> Использование атрибутов событий (так называемый *inline event handling*) сегодня считается **плохой практикой**. Это нарушает принцип разделения ответственности (Separation of Concerns) между разметкой (HTML) и логикой (JS), а также может конфликтовать с политиками безопасности (Content Security Policy — CSP). 
> **Современный подход:** использование метода `addEventListener` в JS-файлах или использование системы событий современных фреймворков (Vue `@click`, React `onClick`).

## 5. Устаревшие атрибуты (Deprecated Attributes)

В ранних версиях HTML (HTML 3.2, HTML 4) атрибуты активно использовались для визуального оформления элементов. С появлением HTML5 и развитием CSS использование оформительских атрибутов стало считаться грубой ошибкой (антипаттерном), и большинство из них признаны устаревшими.

**Примеры устаревших атрибутов, которые нужно заменять на CSS:**
* `align` (выравнивание) $\rightarrow$ использовать CSS `text-align`, `margin: auto`, `justify-content` и т.д.
* `bgcolor` (цвет фона) $\rightarrow$ использовать CSS `background-color`.
* `border` у таблиц и картинок $\rightarrow$ использовать CSS `border`.
* `color` (цвет текста), `size` (размер шрифта) у тега `<font>` $\rightarrow$ тег `<font>` и его атрибуты полностью удалены из стандарта, использовать `color` и `font-size` в CSS.
* `valign` (вертикальное выравнивание) $\rightarrow$ использовать CSS `vertical-align` или Flexbox/Grid.

## 6. Важный вопрос для собеседований: Атрибут vs Свойство (Attribute vs Property)

Очень часто на собеседованиях по фронтенду просят объяснить разницу между атрибутом HTML и свойством DOM-узла:

1. **Атрибуты (Attributes):** Это то, что написано **в HTML-коде**. Они всегда являются строками. Они инициализируют DOM-свойства при создании узла (начальное состояние). Работа с ними в JS: `getAttribute()`, `setAttribute()`.
2. **Свойства (Properties):** Это свойства объекта **в памяти (DOM-дереве)**. Они могут иметь любой тип данных (boolean, число, объект). Это текущее (динамическое) состояние элемента.

**Пример:**
```html
<input id="myInput" type="text" value="Начальное значение">
```
Если пользователь введет в это поле текст *"Новое значение"*:
* `input.getAttribute('value')` вернет `"Начальное значение"` (атрибут в HTML не поменялся).
* `input.value` вернет `"Новое значение"` (свойство DOM изменилось, так как содержит актуальное состояние).
