# Мультимедиа теги (video, audio, iframe, picture)

Интеграция медиа-контента в HTML5 происходит с помощью нативных тегов, которые заменили устаревший и небезопасный Flash.

---

## 1. Тег `<video>`

Позволяет встраивать видеофайлы на страницу без внешних плееров.

```html
<video 
  controls 
  width="640" 
  height="360" 
  poster="preview.jpg" 
  preload="metadata"
>
  <!-- Предлагаем браузеру разные форматы файлов. Он выберет первый поддерживаемый -->
  <source src="video.webm" type="video/webm">
  <source src="video.mp4" type="video/mp4">
  Ваш браузер не поддерживает тег video.
</video>
```

### Разбор критических атрибутов:
*   `controls` — выводит дефолтную панель управления (плей, громкость, полноэкранный режим).
*   `poster` — картинка-превью, отображаемая до запуска видео.
*   `preload` — указывает стратегию предзагрузки (`none`, `metadata` — загрузить только длительность/разрешение, `auto` — скачивать видео сразу).
*   **Автовоспроизведение (Autoplay):**
    Современные браузеры блокируют автозапуск видео со звуком ради тишины пользователя. Чтобы автозапуск сработал гарантированно, видео **обязательно** должно быть без звука:
    ```html
    <video autoplay muted loop playsinline src="background.mp4"></video>
    ```

---

## 2. Тег `<audio>`

Схож с `<video>`, но не имеет визуальной области для вывода кадров.

```html
<audio controls>
  <source src="song.ogg" type="audio/ogg">
  <source src="song.mp3" type="audio/mpeg">
</audio>
```

---

## 3. Встраивание внешних ресурсов: `<iframe>`

Позволяет встраивать сторонние веб-страницы (например, карты Google Maps или видео с YouTube) внутрь вашего документа.

```html
<iframe 
  src="https://www.youtube.com/embed/dQw4w9WgXcQ" 
  width="560" 
  height="315" 
  title="YouTube video player"
  loading="lazy"
  sandbox="allow-scripts allow-same-origin"
  allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture"
  allowfullscreen
></iframe>
```

### Безопасность и производительность iframe (Lead Checklist):
1.  **`sandbox`:** Самый важный атрибут безопасности. Он изолирует код внутри iframe. По умолчанию пустой `sandbox` отключает вложенной странице всё (JS, формы, куки). С помощью параметров мы точечно разрешаем нужное (например, `allow-scripts` разрешает выполнение JS, но запрещает всплывающие окна).
2.  **`allow`:** Управляет доступом к API устройства (камера, микрофон, геолокация).
3.  **`loading="lazy"`:** Откладывает загрузку тяжелого iframe (и файлов внутри него) до тех пор, пока пользователь не проскроллит к нему близко. Это ускоряет первую загрузку сайта.

## 4. Адаптивная и современная графика: `<picture>`

Тег `<picture>` — это обертка, позволяющая отдавать разные изображения в зависимости от условий (разрешение экрана, плотность пикселей, поддержка формата браузером).

```html
<picture>
  <!-- 1. Если браузер поддерживает современный легкий формат AVIF -->
  <source srcset="image.avif" type="image/avif">
  
  <!-- 2. Если экран мобильный (ширина < 600px), отдаем обрезанную мобильную версию -->
  <source srcset="image-mobile.webp" media="(max-width: 600px)" type="image/webp">
  
  <!-- 3. Дефолтный формат-fallback для старых браузеров -->
  <img src="image-fallback.jpg" alt="Красивый пейзаж" loading="lazy">
</picture>
```
