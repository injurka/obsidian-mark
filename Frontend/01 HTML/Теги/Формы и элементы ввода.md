# Формы и элементы ввода

Формы (`<form>`) обеспечивают интерактивное взаимодействие пользователя с сайтом, позволяя отправлять данные на сервер (авторизация, заказы, обратная связь).

---

## 1. Контейнер `<form>` и его атрибуты

```html
<form action="/api/login" method="POST" enctype="multipart/form-data" novalidate>
  <!-- Поля ввода -->
</form>
```

*   `action` — URL-адрес сервера, куда будут отправлены данные формы.
*   `method` — HTTP-метод отправки (`POST` — для отправки скрытых данных, создания/обновления; `GET` — для поисковых запросов, параметры прикрепляются к URL).
*   `enctype` — тип кодирования данных. При отправке файлов (тегов `<input type="file">`) **обязательно** указывать `multipart/form-data`.
*   `novalidate` — отключает встроенную валидацию браузера. Это нужно, если вы реализуете свою сложную валидацию на JS.

---

## 2. Связывание с `<label>`

> [!IMPORTANT]
> Каждый элемент ввода должен иметь связанный с ним тег `<label>`. Это увеличивает область клика (клик по тексту лейбла переводит фокус на сам инпут, что важно для мелких чекбоксов) и сообщает имя поля скринридерам.

### Способ 1: Явное связывание через ID (Рекомендуется)
```html
<label for="username-field">Имя пользователя:</label>
<input type="text" id="username-field" name="username">
```

### Способ 2: Неявное связывание (Вложенность)
```html
<label>
  <span>Имя пользователя:</span>
  <input type="text" name="username">
</label>
```

## 3. Обзор элементов ввода

### 3.1. Разнообразие типов `<input>`
Атрибут `type` определяет поведение инпута:
*   `type="text"` — стандартная строка ввода.
*   `type="password"` — скрывает вводимые символы точками.
*   `type="email"`, `type="tel"`, `type="number"` — на мобильных устройствах сразу открывают специализированную клавиатуру (с символом `@`, цифровую клавиатуру).
*   `type="checkbox"` и `type="radio"` — флажки и переключатели (для радио-кнопок важен одинаковый атрибут `name`, чтобы они работали как группа, выбирая только один элемент).

### 3.2. Многострочный ввод: `<textarea>`
В отличие от инпутов, это парный тег. Стартовое значение пишется между тегами:
```html
<textarea name="comment" rows="4" cols="50">Стартовый текст...</textarea>
```

### 3.3. Выпадающие списки: `<select>`
```html
<select name="country">
  <optgroup label="Европа">
    <option value="ru">Россия</option>
    <option value="de">Германия</option>
  </optgroup>
</select>
```

## 4. Кнопки в форме: Проблема Submit по умолчанию

Внутри тега `<form>` любая кнопка `<button>` по умолчанию имеет тип `submit`:

```html
<form>
  <!-- Клик по этой кнопке перезагрузит страницу и отправит форму! -->
  <button>Проверить баланс</button>
  
  <!-- Правильно для обычных действий на JS: -->
  <button type="button" onclick="checkBalance()">Проверить баланс</button>
</form>
```
Всегда явно указывайте атрибут `type`:
*   `type="submit"` — для кнопок отправки формы.
*   `type="button"` — для обычных кнопок, поведение которых управляется через JS.
*   `type="reset"` — очищает все поля формы к дефолтным значениям.
