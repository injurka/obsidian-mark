# Семантические теги

Семантическая верстка — это использование HTML-тегов в соответствии с их смысловым назначением. В отличие от бессмысленных «контейнеров общего назначения» (`<div>`, `<span>`), семантические теги четко объясняют браузеру, поисковым роботам и скринридерам, какой именно тип контента находится внутри.

---

## 1. Зачем нужна семантика?

1.  **Доступность (Accessibility / a11y):** Скринридеры используют семантическую разметку как карту сайта. Пользователь может нажать кнопку "Перейти к навигации" (если есть `<nav>`) или "Пропустить шапку и перейти к основному контенту" (если есть `<main>`). С `<div>`-версткой это невозможно.
2.  **SEO (Поисковая оптимизация):** Поисковые краулеры (Google, Яндекс) лучше понимают структуру страницы. Текст внутри `<main>` или `<article>` имеет больший вес для индексации, чем рекламный блок в `<aside>`.
3.  **Читаемость кода:** Разработчику проще читать структуру `<header> <main> <footer>`, чем вложенность `<div class="header"> <div class="content">`.

---

## 2. Ключевые структурные семантические теги HTML5

```text
┌────────────────────────────────────────────────────────┐
│                        <header>                        │
├────────────────────────────────────────────────────────┤
│                          <nav>                         │
├──────────────────────────┬─────────────────────────────┤
│                          │           <aside>           │
│          <main>          │   (Боковая панель, виджеты, │
│ (Уникальный контент)     │          реклама)           │
│   ┌──────────────────┐   │                             │
│   │    <article>     │   │                             │
│   │ (Пост, карточка) │   │                             │
│   └──────────────────┘   │                             │
│   ┌──────────────────┐   │                             │
│   │    <section>     │   │                             │
│   │  (Смысловой блок)│   │                             │
│   └──────────────────┘   │                             │
├──────────────────────────┴─────────────────────────────┤
│                        <footer>                        │
└────────────────────────────────────────────────────────┘
```

*   **`<header>`:** Шапка сайта или раздела. Обычно содержит логотип, форму поиска, имя автора.
*   **`<nav>`:** Навигационный блок. Содержит ссылки для перемещения по сайту.
*   **`<main>`:** Основной контент страницы. Должен быть **уникальным** (не повторяться на других страницах) и присутствовать на странице в единственном экземпляре.
*   **`<article>`:** Самодостаточный, независимый раздел контента, который можно вырезать из страницы и опубликовать в другом месте без потери смысла.
    *   *Кейсы:* статья в блоге, новость, карточка товара, комментарий пользователя.
*   **`<section>`:** Смысловой тематический блок документа. Обычно содержит собственный заголовок (`<h2>`–`<h6>`). 
    *   *Правило:* Не используйте `<section>` как обертку для стилизации (для этого есть `<div>`). Используйте его только если у этого блока есть логическая тема и заголовок.
*   **`<aside>`:** Второстепенный контент, косвенно связанный с основным. Сайдбары, блоки рекламы, списки похожих статей.
*   **`<footer>`:** Подвал сайта или раздела. Информация об авторе, копирайт, контакты, ссылки на соцсети.

## 3. Инлайновые семантические теги

*   **`<strong>`** (Важно!) — выделяет текст, имеющий большую важность. Браузеры рендерят его жирным.
    *   *В отличие от `<b>`:* тег `<b>` делает текст жирным чисто визуально, без добавления логической важности.
*   **`<em>`** (Акцент) — логическое ударение в предложении, меняющее смысл при чтении. Отображается курсивом.
    *   *В отличие от `<i>`:* тег `<i>` делает текст курсивным без смыслового акцента (например, технический термин или иностранное слово).
*   **`<time>`** — семантически обозначает дату или время.
    ```html
    <!-- Позволяет поисковым роботам парсить точную дату через атрибут datetime -->
    Опубликовано <time datetime="2026-06-29T15:30">сегодня днем</time>
    ```
*   **`<mark>`** — подсвеченный/выделенный мартером текст (удобно для подсветки поискового запроса в тексте).
