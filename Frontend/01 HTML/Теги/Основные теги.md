# Основные теги HTML

Основные теги формируют скелет документа и базовую разметку текстового содержимого.

---

## 1. Структура HTML-документа

Каждая веб-страница начинается со стандартного каркаса:

```html
<!DOCTYPE html> <!-- Сообщает браузеру, что это современный HTML5 документ -->
<html lang="ru"> <!-- Язык документа (важно для экранных дикторов и переводчиков) -->
<head>
  <meta charset="UTF-8">
  <title>Заголовок вкладки</title>
</head>
<body>
  <!-- Контент страницы находится здесь -->
</body>
</html>
```

---

## 2. Заголовки (headings)

В HTML есть 6 уровней заголовков: от `<h1>` (самый важный) до `<h6>` (наименее важный).

```html
<h1>Главный заголовок страницы</h1>
<h2>Подзаголовок раздела</h2>
<h3>Подзаголовок подраздела</h3>
```

### Правила использования (SEO & Accessibility):
*   На странице должен быть строго **один заголовок `<h1>`**, кратко отражающий суть всей страницы.
*   Соблюдайте иерархию. Нельзя прыгать с `<h1>` сразу на `<h4>`, ломая структуру. Заголовки формируют логический конспект страницы, по которому ориентируются скринридеры.

---

## 3. Текстовые блоки

*   **Параграф (`<p>`):** Оборачивает абзацы текста. Создает вертикальные отступы по умолчанию.
*   **Строчный элемент (`<span>`):** Используется для выделения части текста в стилистических целях. Не имеет встроенной семантики или отступов.
*   **Перенос строки (`<br>`):** Создает принудительный перенос строки внутри абзаца.
    *   *Правило:* Не используйте `<br>` для создания отступов между блоками/абзацами. Для этого существуют CSS свойства `margin` и `padding`.
*   **Горизонтальная линия (`<hr>`):** Семантически означает тематический разрыв (смену темы обсуждения). Визуально отображается серой линией.
*   **Форматированный текст (`<pre>` и `<code>`):**
    Тег `<pre>` сохраняет все пробелы и переносы строки, написанные в коде. Обычно используется в связке с `<code>` для демонстрации листингов кода:
    ```html
    <pre><code>
    function hello() {
      console.log("World");
    }
    </code></pre>
    ```
