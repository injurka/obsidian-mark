
Управление состоянием (State Management) — одна из самых сложных и важных частей архитектуры фронтенд-приложений. 

## Виды состояний:
1. **Локальное состояние (Local State):** Состояние конкретного компонента (например, открыт ли дропдаун, значение инпута).
2. **Глобальное состояние (Global State):** Данные, нужные во многих местах приложения (тема оформления, данные текущего пользователя, права доступа).
3. **Серверное состояние (Server State):** Кэш данных с бэкенда (данные профиля, списки, результаты поиска). *Современный подход — выносить его из глобального состояния в инструменты вроде React Query, SWR, RTK Query или Apollo.*
4. **Состояние URL (URL State):** Данные, которые должны быть синхронизированы с адресной строкой (параметры фильтрации, сортировка, пагинация).

## Основные архитектурные подходы (Паттерны):

### 1. Flux / Redux (Однонаправленный поток данных)
- **Примеры:** Redux, Vuex, Pinia, Zustand.
- **Суть:** Единый глобальный стор (Store), изменения происходят только через отправку действий (Actions) и обработку их редьюсерами (Reducers).
- **Плюсы:** Предсказуемость, отличный дебаг (Time-travel), строгий контракт.
- **Минусы:** Много бойлерплейта, может быть избыточным для простых задач.

### 2. Atomic (Атомарное состояние)
- **Примеры:** Recoil, Jotai, Nanostores.
- **Суть:** Состояние разбивается на множество мелких, независимых кусочков (атомов). Компоненты подписываются только на нужные атомы.
- **Плюсы:** Отличная производительность (нет лишних ререндеров), гибкость, простота.
- **Минусы:** Сложно отслеживать зависимости между множеством атомов в больших проектах.

### 3. Signals (Сигналы / Реактивность на основе графа)
- **Примеры:** Vue Composition API (ref), SolidJS, Preact Signals, Angular Signals, MobX.
- **Суть:** Значения сами знают, кто от них зависит. При изменении сигнала обновляются только те части UI, которые его используют.
- **Плюсы:** Максимальная производительность, автоматический трекинг зависимостей.
- **Минусы:** Магия "под капотом", риск непредсказуемых цепочек обновлений при плохом проектировании.
