#### 2. Серверное состояние (Server State)
Данные, владельцем которых является бэкенд. Фронтенд берет их «в аренду» для отображения.
*   **Инструменты:** `TanStack Query` (React Query), `RTK Query`, `SWR`, `Apollo`.
*   **Ответственность:**
    *   Кэширование и дедупликация (5 компонентов просят профиль юзера — в сеть уйдет 1 запрос).
    *   Управление статусами (`isLoading`, `isError`, `isFetching`).
    *   Фоновое обновление (refetch on window focus / reconnect).
    *   **Мутации:** отправка POST/PUT/DELETE запросов с последующей инвалидацией кэша.
    *   **Optimistic Updates:** мгновенное обновление UI до получения ответа от сервера (для быстрых лайков/переключателей).
