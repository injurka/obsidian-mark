# Styled Components

## Суть концепции
Styled Components — это популярная библиотека для экосистемы React (подход CSS-in-JS). Она позволяет создавать компоненты, которые уже содержат внутри себя свои стили, используя фичу JavaScript под названием Tagged Template Literals (шаблонные строки с тегами).

Библиотека берет CSS, написанный внутри бектиков (`` ` ``), генерирует для него уникальный хэш-класс, вставляет его в тег `<style>` и возвращает готовый к использованию React-компонент.

## Какую боль мы решаем
1. **Отвязка от имен классов:** Разработчику больше не нужно придумывать имена классов (BEM) и следить за их уникальностью.
2. **Динамика пропсов:** Стилизация сильно зависит от состояния компонента (props). В классическом подходе нужно было вычислять класс (`className={isActive ? 'active' : ''}`). В Styled Components логика инкапсулируется прямо в CSS.
3. **Удаление мертвого кода:** Компонент удален из JSX? Его CSS больше никогда не попадет в бандл.

## Как это работает

```mermaid
graph LR
    A[const Btn = styled.button] -->|CSS template string + props| B(Styled Components Engine)
    B -->|Generate Hash| C[.sc-dkzDqf { ... }]
    B -->|Create Component| D[<button class='sc-dkzDqf'>]
    
    C --> E[Injected into DOM <style>]
    D --> F[Rendered in Virtual DOM]
```

## Примеры кода

**❌ Антипаттерн: Объявление стилизованного компонента внутри рендера**
```jsx
const Card = () => {
  // ОШИБКА: При каждом рендере Card, StyledComponents будет заново создавать
  // класс Title, генерировать новый хэш и перерисовывать DOM. Это убьет FPS.
  const Title = styled.h1`color: red;`; 
  
  return <Title>Hello</Title>;
};
```

**✅ Правильное решение: Статичное объявление + пропсы**
```jsx
// Выносим наружу. Движок отработает один раз при загрузке модуля.
const Title = styled.h1`
  font-size: 24px;
  /* Читаем React-пропсы прямо внутри CSS! */
  color: ${props => props.isError ? 'red' : 'black'};
  
  /* Поддерживает вложенность и псевдоклассы */
  &:hover { text-decoration: underline; }
`;

const Card = ({ error }) => {
  return <Title isError={error}>Hello</Title>; // Рендерит черным или красным
};
```

## Неочевидные нюансы и границы применимости
- **Runtime Overhead:** Так же как и Emotion, Styled Components парсит стили в рантайме (в браузере пользователя). Для сложных интерфейсов с тысячами узлов это может стать "бутылочным горлышком" производительности.
- **Server Components:** Библиотека опирается на React Context, что делает её несовместимой (по умолчанию) с React Server Components (RSC) в Next.js 13+. Приходится помечать всё как `"use client"`, теряя преимущества серверного рендеринга.
- **Theming:** Встроена мощная система темизации (`<ThemeProvider>`), позволяющая передавать дизайн-токены в любой стилизованный компонент через пропс `props.theme`.
