# Глобальные стили

## Суть концепции
Глобальные стили — это CSS-правила, которые применяются ко всему HTML-документу и не изолированы внутри конкретных компонентов. В современной архитектуре (где всё стремится к изоляции) глобальные стили сводятся к необходимому минимуму:
1. **Сброс / Нормализация** (Reset.css / Normalize.css).
2. **Дизайн-токены** (CSS Custom Properties в `:root`).
3. **Базовая типографика** (Шрифты на `body`, `h1-h6`).
4. **Утилитарные классы** (если не используется Tailwind).

## Какую боль мы решаем
Если отказаться от глобальных стилей полностью, придется в каждом компоненте заново импортировать шрифты, устанавливать `box-sizing: border-box`, сбрасывать отступы браузера и хардкодить цвета. Глобальные стили обеспечивают DRY (Don't Repeat Yourself) на макро-уровне.

## Как это работает

```mermaid
graph TD
    A[Global Styles] --> B(Reset.css: box-sizing, margins)
    A --> C(Variables.css: :root { --primary })
    A --> D(Typography.css: body { font-family })
    
    B --> E[All UI Components]
    C --> E
    D --> E
    
    F[Isolated Component Styles] -.->|Overrides globals if needed| E
```

## Примеры кода

**❌ Антипаттерн: Раздувание глобальных стилей компонентами**
```css
/* global.css */
* { box-sizing: border-box; }
body { font-family: 'Inter', sans-serif; }

/* ОШИБКА: Этому здесь не место! Это стили конкретного компонента.
   Если удалить этот компонент из HTML, мертвый CSS останется здесь навсегда. */
.product-card-special-banner {
  background: red;
  border-radius: 8px;
}
```

**✅ Правильное решение: Строгий фундамент**
```css
/* global.css */
@import './reset.css';
@import './fonts.css';

:root {
  --color-primary: #007bff;
  --color-bg: #ffffff;
  --font-base: 'Inter', system-ui, sans-serif;
}

body {
  margin: 0;
  background-color: var(--color-bg);
  color: #333;
  font-family: var(--font-base);
  -webkit-font-smoothing: antialiased;
}

/* Всё остальное пишется в CSS Modules / Styled Components / Tailwind */
```

## Неочевидные нюансы и границы применимости
- **Micro-frontends / Web Components:** В архитектуре микрофронтендов несколько разных приложений могут жить на одной странице. Глобальный стиль `body { font-size: 16px; }` от Приложения А может сломать Приложение Б. В таких случаях глобальные стили запрещены, а изоляция достигается через Shadow DOM (там даже `box-sizing` нужно сбрасывать внутри каждой тени).
- **Слои (Cascade Layers):** Очень хорошей практикой является упаковка всех глобальных стилей в слой: `@layer reset, global, utilities;`. Это гарантирует, что любой стиль внутри компонента (даже самый слабый класс) гарантированно переопределит глобальное правило.
