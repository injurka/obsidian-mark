# Управление фокусом и навигация с клавиатуры (Focus trap)

## 1. Основы клавиатурной доступности
Навигация с клавиатуры — это фундамент веб-доступности (a11y). Ею пользуются люди с нарушениями зрения (скринридеры управляются клавиатурными командами), люди с моторными нарушениями (им сложно или невозможно управлять мышью), а также продвинутые пользователи (power users), предпочитающие хоткеи.

Основной инструмент перемещения по элементам страницы — клавиша **Tab** (движение вперед) и комбинация **Shift + Tab** (движение назад). 

**Главное правило:** Всё, на что можно нажать, заполнить или перетащить с помощью мыши, должно быть полностью доступно для фокуса и взаимодействия с клавиатуры.

---

## 2. Атрибут `tabindex` под лупой

Атрибут `tabindex` управляет тем, как элемент участвует в клавиатурной навигации:

| Значение `tabindex` | Поведение элемента | Кейсы использования |
| :--- | :--- | :--- |
| **`tabindex="0"`** | Элемент становится фокусируемым и участвует в естественном порядке табуляции (по DOM-дереву). | Кастомные кнопки, чекбоксы, интерактивные элементы. |
| **`tabindex="-1"`** | Элемент удаляется из естественного порядка табуляции, но его **можно** сфокусировать программно через JS (`element.focus()`). | Модальные окна (контейнеры), скрытые вкладки, выпадающие списки. |
| **`tabindex="1"` и выше** | **Антипаттерн!** Принудительно задает порядок фокуса. | **Никогда не используйте.** Ломает навигацию при изменении DOM. |

> [!WARNING]
> Если вы даете элементу `tabindex="0"` или `-1`, вы обязаны обработать нажатия клавиш **Enter** и **Space (Пробел)** для выполнения действия, так как браузер автоматически делает это только для нативных интерактивных тегов (`<button>`, `<a>`, `<input>`).

## 3. Стилизация фокуса: `:focus`, `:focus-visible` и `:focus-within`

Стиль фокуса (outline) — это визуальный курсор для клавиатурного пользователя. Без него человек не понимает, где находится на странице.

*   **`:focus`** — применяется при любом фокусе на элементе (и от клавиатуры, и при клике мышкой).
*   **`:focus-visible`** — умный селектор. Применяется **только** тогда, когда фокус был вызван клавиатурным вводом (или когда браузер считает это необходимым). Позволяет скрыть навязчивую рамку при клике мышью, но оставить её для пользователей клавиатуры.
*   **`:focus-within`** — срабатывает на родителе, если фокус находится на любом из его дочерних элементов (удобно для подсветки всей формы или карточки товара).

```css
/* Современный стандарт стилизации */
.button:focus {
  outline: none; /* Убираем дефолтный outline для мыши */
}

.button:focus-visible {
  outline: 3px solid #3b82f6; /* Красивый кастомный outline только для клавиатуры */
  outline-offset: 2px;
}
```

## 4. Что такое Focus Trap (Ловушка фокуса) и зачем она нужна?

**Focus Trap (Ловушка фокуса)** — это паттерн проектирования, при котором фокус клавиатуры принудительно удерживается внутри определенной области страницы (например, модального окна) и не может выйти за ее пределы по нажатию `Tab` или `Shift+Tab`.

### Почему это критично?
Без ловушки фокуса пользователь, открыв модальное окно и нажимая `Tab`, пройдет сквозь него и начнет переходить по ссылкам на основном (заднем) плане страницы. При этом модальное окно заблокирует визуальный обзор, и пользователь скринридера окажется полностью дезориентирован.

```text
БЕЗ FOCUS TRAP:
[Ссылка на фоне] -> [Модалка: Ок] -> [Ссылка на фоне 2] (Пользователь потерялся)

С FOCUS TRAP:
[Модалка: Ввод имени] -> [Модалка: Отправить] -> [Модалка: Закрыть] -> [Модалка: Ввод имени] (Цикл)
```

## 5. Реализация Focus Trap на чистом JavaScript

Чтобы создать ловушку фокуса, нам нужно:
1. Найти первый и последний интерактивные (фокусируемые) элементы внутри модального окна.
2. Перехватить событие нажатия клавиши `Tab`.
3. Если фокус на последнем элементе и нажат `Tab` — перекинуть фокус на первый элемент.
4. Если фокус на первом элементе и нажат `Shift + Tab` — перекинуть фокус на последний.

### Код реализации:

```javascript
const focusableSelectors = [
  'a[href]',
  'area[href]',
  'input:not([disabled])',
  'select:not([disabled])',
  'textarea:not([disabled])',
  'button:not([disabled])',
  'iframe',
  'object',
  'embed',
  '[contenteditable]',
  '[tabindex]:not([tabindex^="-"])'
].join(',');

function initFocusTrap(modalElement) {
  const focusableElements = modalElement.querySelectorAll(focusableSelectors);
  const firstFocusable = focusableElements[0];
  const lastFocusable = focusableElements[focusableElements.length - 1];

  // Фокусируем первый элемент при открытии
  if (firstFocusable) {
    firstFocusable.focus();
  }

  modalElement.addEventListener('keydown', function(e) {
    if (e.key !== 'Tab') return;

    if (e.shiftKey) { // Shift + Tab (назад)
      if (document.activeElement === firstFocusable) {
        lastFocusable.focus();
        e.preventDefault();
      }
    } else { // Tab (вперед)
      if (document.activeElement === lastFocusable) {
        firstFocusable.focus();
        e.preventDefault();
      }
    }
  });
}
```

## 6. Важные детали, о которых все забывают

### 6.1. Возврат фокуса (Focus Restoration)
Когда пользователь закрывает модальное окно (или выпадающее меню), фокус **обязательно** должен вернуться на тот элемент (кнопку/триггер), который это окно открыл.

```javascript
let lastFocusedElement = null;

function openModal(modal) {
  lastFocusedElement = document.activeElement; // Запоминаем триггер
  modal.classList.add('open');
  initFocusTrap(modal);
}

function closeModal(modal) {
  modal.classList.remove('open');
  if (lastFocusedElement) {
    lastFocusedElement.focus(); // Возвращаем фокус
  }
}
```

### 6.2. Атрибут `inert` (Современный API)
Атрибут `inert` — это революция в a11y. Будучи добавленным на DOM-узел, он делает весь этот узел и его детей невидимыми для скринридеров и недоступными для фокуса, избавляя от необходимости писать сложные ловушки вручную.

При открытии модалки мы можем временно сделать основной контент `inert`:

```html
<body>
  <div id="main-content" inert>
    <!-- Весь сайт заблокирован для фокуса -->
  </div>
  
  <div id="modal" role="dialog" aria-modal="true">
    <!-- Фокус доступен только здесь -->
  </div>
</body>
```
