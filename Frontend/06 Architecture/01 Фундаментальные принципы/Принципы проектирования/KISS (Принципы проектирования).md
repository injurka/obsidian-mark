## 2. KISS — Keep It Simple, Stupid (Делай проще)

Простота — это высшая степень искусства проектирования. Пишите код так, чтобы его мог понять джуниор-разработчик без чтения документации.

### Признаки нарушения KISS на фронтенде:
1.  **Сверхсложный State-менеджмент:** Использование Redux/Saga там, где достаточно обычного локального `useState` или реактивного `Zustand`.
2.  **Заумные JS-трюки:** Использование вложенных тернарных операторов, сложных побитовых сдвигов или перегруженных регулярных выражений вместо простых условий `if/else`.
3.  **Перегруженность библиотеками:** Подключение тяжелых npm-пакетов для элементарных задач (например, `lodash` ради одной функции `debounce` или `moment.js` для форматирования дат в современных браузерах).

### Пример (KISS):
*   *Плохо (Умный, но нечитаемый код):*
    ```javascript
    const getStatusColor = (s) => s === 'active' ? 'green' : s === 'pending' ? 'yellow' : s === 'failed' ? 'red' : 'gray';
    ```
*   *Хорошо (Просто и наглядно):*
    ```javascript
    const STATUS_COLORS = {
      active: 'green',
      pending: 'yellow',
      failed: 'red',
    };
    const getStatusColor = (status) => STATUS_COLORS[status] || 'gray';
    ```
