Value Object (объект-значение) — это объект, который описывает какую-то характеристику, измерение или концепцию, но при этом принципиально не имеет уникального идентификатора. Две стодолларовые купюры для нас абсолютно идентичны — нам не важно, какая именно из них лежит в кошельке. Если все свойства двух Value Object равны, то и сами объекты считаются абсолютно равными.

**Какую боль фронтенда мы решаем?**
Мы боремся с "Primitive Obsession" — маниакальной привычкой использовать встроенные примитивы для всего подряд. Мы используем `number` для хранения денег, `string` для email, телефона или координат. В результате логика валидации email или сложения валют расползается дублями по десяткам компонентов.

**Пример типичной боли:**
```typescript
let balance = 100; // Это доллары? Рубли? Центры?
function addFunds(amount: number) {
  // А что если amount отрицательный? А если пришел NaN?
  balance += amount; 
}
```

**Решение через Value Object:**
```typescript
class Money {
  constructor(
    public readonly amount: number, 
    public readonly currency: string
  ) {
    if (amount < 0) throw new Error("Money cannot be negative");
  }

  add(other: Money): Money {
    if (this.currency !== other.currency) {
      throw new Error("Cannot add different currencies");
    }
    // VO всегда иммутабельны. Мы не меняем текущий, мы рождаем новый.
    return new Money(this.amount + other.amount, this.currency);
  }

  equals(other: Money): boolean {
    return this.amount === other.amount && this.currency === other.currency;
  }
}
```

**Скрытые трейдоффы:**
Value Objects **обязаны** быть иммутабельными. Их неизменяемость отлично ложится на концепции React или Redux, где мутации под запретом. 

Однако создавать класс для абсолютно каждого примитива в проекте — это изнурительный оверхед. Оборачивайте примитивные типы в Value Object только тогда, когда за ними скрывается значимая бизнес-логика (конвертация, строгая валидация, форматирование) или специфичное поведение. Если поле `firstName` просто выводится на экран и ни на что не влияет, оставьте его обычной строкой.
