# Термины и сокращения (Architectural Glossary & Abbreviations)

Справочник общепринятых сокращений и аббревиатур, используемых в сфере разработки программного обеспечения и фронтенд-архитектуры.

---

* **a11y (Accessibility):** Доступность веб-интерфейсов для людей с ограниченными возможностями здоровья (название образовано от первой буквы «A», последней «y» и 11 букв между ними).
* **ACL (Anti-Corruption Layer):** Предохранительный (антикоррупционный) слой. Переводит данные из внешнего формата во внутренний, предотвращая засорение домена деталями внешних систем.
* **ADR (Architecture Decision Record):** Документ, фиксирующий важное архитектурное решение, его контекст, альтернативы и последствия.
* **BFF (Backend for Frontend):** Промежуточный бэкенд-сервер, спроектированный под нужды конкретного клиентского приложения (например, отдельный BFF для мобильного приложения и для веб-версии).
* **CLS (Cumulative Layout Shift):** Метрика Core Web Vitals, оценивающая визуальную стабильность страницы (сдвиги контента во время загрузки).
* **CQRS (Command Query Responsibility Segregation):** Патерн, разделяющий операции чтения (Queries) и операции записи/изменения данных (Commands).
* **CSR (Client-Side Rendering):** Клиентский рендеринг. Браузер загружает минимальный HTML и JS-бандл, который строит DOM динамически на стороне клиента.
* **DDD (Domain-Driven Design):** Предметно-ориентированное проектирование. Подход к разработке ПО, фокусирующийся на бизнес-модели предметной области.
* **DIP (Dependency Inversion Principle):** Принцип инверсии зависимостей (буква D в SOLID).
* **DOM (Document Object Model):** Объектная модель документа. Структурированное представление HTML-документа в виде дерева объектов в браузере.
* **DTO (Data Transfer Object):** Объект переноса данных. Простой объект без бизнес-логики, служащий для передачи данных по сети.
* **FCP (First Contentful Paint):** Метрика производительности, измеряющая время от начала загрузки страницы до момента, когда на экране отрисовывается первый элемент контента.
* **FSD (Feature-Sliced Design):** Методология организации фронтенд-кода, основанная на разделении проекта по слоям, слайсам и сегментам.
* **HOC (Higher-Order Component):** Компонент высшего порядка. Функция, принимающая компонент и возвращающая новый, расширенный компонент.
* **INP (Interaction to Next Paint):** Метрика Core Web Vitals, оценивающая отзывчивость интерфейса на действия пользователя.
* **ISR (Incremental Static Regeneration):** Инкрементальная статическая регенерация. Подход к рендерингу, позволяющий обновлять статические страницы в фоновом режиме по истечении заданного времени без полной пересборки сайта.
* **LCP (Largest Contentful Paint):** Метрика Core Web Vitals, измеряющая время, необходимое для загрузки и отрисовки самого крупного видимого элемента контента на экране.
* **MFE (Microfrontends):** Микрофронтенды. Архитектура разделения фронтенд-монолита на изолированные приложения.
* **PWA (Progressive Web Application):** Прогрессивное веб-приложение. Веб-приложение, использующее современные возможности браузера (Service Workers, манифест), чтобы работать как нативное приложение на мобильном устройстве (включая оффлайн-режим).
* **RFC (Request for Comments):** Запрос предложений. Документ-предложение с описанием планируемого крупного технического изменения, выносимый на обсуждение команды.
* **RUM (Real User Monitoring):** Мониторинг производительности на основе реальных данных, собираемых у пользователей приложения в рантайме.
* **SPA (Single Page Application):** Одностраничное веб-приложение, загружающееся один раз и динамически обновляющее контент при навигации без полной перезагрузки страницы.
* **SSG (Static Site Generation):** Статическая генерация сайта. Контент собирается в готовые HTML-файлы на этапе сборки (build time).
* **SSR (Server-Side Rendering):** Серверный рендеринг. Сервер генерирует полную HTML-страницу по запросу пользователя и отправляет её в браузер.
* **TTL (Time to Live):** Время жизни кэша или токена.
* **VDOM (Virtual DOM):** Виртуальный DOM. Легковесное представление реального DOM-дерева в оперативной памяти (используется в React, Vue для оптимизации обновлений).
* **XSS (Cross-Site Scripting):** Межсайтовый скриптинг. Уязвимость, позволяющая злоумышленнику внедрить вредоносный JS-код в веб-страницу, просматриваемую другими пользователями.
