# Карта знаний (Frontend Architecture Mind Map)

Эта карта знаний визуализирует взаимосвязи между различными областями проектирования фронтенд-приложений. Каждая область раскрывается в соответствующих главах нашей базы знаний.

```mermaid
mindmap
  root((Frontend Architecture))
    Фундамент
      SOLID
      GRASP
      DRY / KISS / YAGNI
      Cohesion & Coupling
    Стили и Методологии
      Clean Architecture
      DDD во Frontend
      Feature-Sliced Design
      Atomic Design
    Компоненты и UI
      Паттерны композиции
      Design System & Tokens
      Темизация и бренды
      UI Lifecycle
    Данные и Состояние
      Модель состояния
      Flux / Redux / Signals
      Таблицы и Формы
      Офлайн и Кэширование
    Сеть и API
      API Clients / Axios / Fetch
      REST / GraphQL / gRPC
      BFF & Gateway
      Валидация контрактов
    Сборка и Доставка
      Vite / Webpack / Rspack
      Monorepos
      CI/CD Pipelines
      CDN & Edge Delivery
    Нефункциональные
      Core Web Vitals
      Веб-безопасность
      Стратегии рендеринга
      Тестирование
```
