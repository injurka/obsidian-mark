# Path Aliases (Алиасы путей)

Path Aliases — это механизм в TypeScript и современных сборщиках (Vite, Webpack), позволяющий заменить длинные, запутанные относительные пути к файлам на короткие, абсолютные префиксы.

## Какую боль решаем?

Без алиасов импорты в глубоко вложенных компонентах выглядят так:
`import { Button } from '../../../../../shared/ui/Button'`.

Боль:
1. **Хрупкость при рефакторинге.** Если вы переместите файл с таким импортом на один уровень выше или ниже, все относительные пути сломаются.
2. **Когнитивная нагрузка.** Приходится визуально "парсить" количество точек и слэшей, чтобы понять, из какой папки мы берем код.
3. **Уродливый код.** Блок импортов занимает половину экрана.

С алиасами тот же импорт выглядит так:
`import { Button } from '@/shared/ui/Button'`.
Он всегда одинаковый, независимо от того, где физически находится файл, который его вызывает.

## Как это работает на практике

Для настройки алиасов нужно "подружить" две системы: TypeChecker (TypeScript) и Сборщик (Vite/Webpack), иначе либо IDE будет ругаться, либо сборка упадет.

**1. Настройка TypeScript (`tsconfig.json`):**
```json
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["src/*"] // Всё, что начинается с @, искать в папке src
    }
  }
}
```

**2. Настройка Vite (`vite.config.ts`):**
```typescript
import path from 'path';

export default defineConfig({
  resolve: {
    alias: {
      '@': path.resolve(__dirname, './src'),
    },
  },
});
```

## Неочевидные нюансы и трейдоффы

1. **Зоопарк алиасов.** Некоторые команды создают алиасы для каждой папки: `@ui`, `@utils`, `@api`, `@features`. Это антипаттерн. Когда новый разработчик видит `import x from '@magic/something'`, он не понимает, где физически на диске лежит эта папка (в `src`? в `libs`? в `node_modules`?). Идеально иметь один корневой алиас (например, `@/` или `~/`, указывающий на `src/`).
2. **Рассинхронизация инструментов.** Помимо TypeScript и сборщика, вам придется настраивать алиасы в Jest (`moduleNameMapper`), в Storybook, в линтерах (`eslint-plugin-import`). Если забыть хотя бы одно место — тулинг сломается.
3. **Поддержка IDE.** Раньше (в эпоху JavaScript) алиасы ломали автокомплит и "Go to Definition" в редакторах. Сегодня TypeScript Language Server решает эту проблему безупречно.
