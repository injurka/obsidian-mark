# RTL (Right-to-Left) Поддержка

## Суть концепции
RTL (Right-to-Left) — это адаптация пользовательского интерфейса для языков, которые читаются справа налево, таких как арабский, иврит или персидский. При смене направления языка интерфейс должен зеркально отразиться: боковые панели, отступы, иконки-стрелки и порядок колонок меняют свое положение.

## Какую боль мы решаем
Если бизнес решает выйти на рынки Ближнего Востока, неадаптированный интерфейс будет полностью сломан. Исторически разработчикам приходилось писать сотни строк переопределяющего CSS (`.rtl .sidebar { float: right; margin-left: 0; margin-right: 20px; }`). Это удваивало стоимость поддержки и приводило к постоянным регрессиям (когда в LTR поправили, а в RTL забыли).

## Как это работает

```mermaid
graph LR
    A[dir="ltr"] --> B[Text reads left to right]
    A --> C[Margin-left pushes from left]
    
    D[dir="rtl"] --> E[Text reads right to left]
    D --> F[Margin-inline-start pushes from RIGHT]
```
Браузер делает большую часть работы сам, если на теге `<html>` установлен атрибут `dir="rtl"`. Он автоматически инвертирует поведение блоков с текстом и Flex/Grid контейнеров.

## Примеры кода

**❌ Антипаттерн: Ручное переопределение**
```css
.alert-icon {
  margin-right: 12px; /* LTR */
}

html[dir="rtl"] .alert-icon {
  margin-right: 0;
  margin-left: 12px; /* RTL override */
}
```

**✅ Правильное решение: Атрибут HTML и логические свойства**
```html
<!-- Браузер сам перевернет flexbox и выравнивание текста -->
<html lang="ar" dir="rtl">
```
```css
/* CSS адаптируется автоматически */
.alert-icon {
  margin-inline-end: 12px; 
}
```

## Неочевидные нюансы и границы применимости
- **Иконки:** Логические свойства не разворачивают иконки. Иконка "Стрелка вправо" (➡️) в RTL-интерфейсе должна указывать влево. Это решается трансформацией:
  ```css
  html[dir="rtl"] .icon-back { transform: scaleX(-1); }
  ```
- **Смешанный контент:** Иногда внутри арабского текста встречаются английские слова или номера телефонов. Они должны читаться слева направо (bidi - bidirectional text). Для этого используется атрибут `dir="auto"` или тег `<bdi>`.
- **Шрифты:** Арабская вязь часто требует большего размера шрифта и межстрочного интервала для читаемости по сравнению с латиницей. Вам понадобятся разные дизайн-токены типографики для разных языков.
