#### 3. Состояние URL (URL / Router State)
Самый надежный источник истины для глобальных параметров представления. Если состоянием можно поделиться ссылкой — оно должно быть в URL.
*   **Что храним:** `?category=books&sort=price_desc&page=2&modal=auth` (фильтры, сортировки, пагинация, открытые сущности).
*   **Плюсы:** Работает навигация "Вперед/Назад" в браузере, можно скинуть ссылку коллеге, сохраняется при обновлении страницы (F5). Данные из URL часто выступают ключами (`queryKey`) для Server State.
