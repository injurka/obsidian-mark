# Техники оптимизации: Code Splitting

**Code Splitting (Разделение кода)** — это мощная техника оптимизации производительности веб-приложений. Вместо того чтобы отдавать пользователю один огромный JavaScript-файл (`bundle.js`) со всем кодом приложения, код разбивается на несколько более мелких частей (чанков, chunks).

## Зачем это нужно?
1. **Ускорение начальной загрузки:** Пользователь загружает только тот код, который необходим для отображения текущей страницы.
2. **Улучшение метрик (FCP, LCP):** Браузеру нужно распарсить и выполнить меньше JS кода перед первым рендерингом.
3. **Эффективное кэширование:** Если вы обновили логику на одной странице, инвалидируется кэш только для чанка этой страницы, а не для всего приложения.

## Как реализуется Code Splitting?

### 1. На уровне роутинга (Route-based splitting)
Самый частый подход. Код загружается только при переходе на соответствующий маршрут (URL).

*Пример (Vue Router):*
```javascript
const routes = [
  // Компонент Home загрузится сразу (в основном бандле)
  { path: '/', component: Home },
  // About будет выделен в отдельный файл и загрузится только при переходе на /about
  { path: '/about', component: () => import('./views/About.vue') }
]
```

### 2. На уровне компонентов (Component-based splitting)
Загрузка тяжелых компонентов (например, графики, 3D модели, сложный текстовый редактор) только тогда, когда они появляются на экране или по взаимодействию пользователя (например, при открытии модального окна).

*Пример (Vue 3 `defineAsyncComponent`):*
```javascript
import { defineAsyncComponent } from 'vue'

// Этот компонент не попадет в начальную загрузку
const HeavyChart = defineAsyncComponent(() => import('./HeavyChart.vue'))
```

### 3. Разделение вендоров (Vendor splitting)
Библиотеки из `node_modules` (Vue, Lodash, Axios и т.д.) меняются редко по сравнению с кодом вашего приложения. Сборщики (Webpack, Vite/Rollup) могут автоматически выделять их в отдельный файл (часто называемый `vendor.js`), чтобы браузер мог агрессивно его кэшировать.

## Роль сборщиков
Современные сборщики, такие как Vite, Webpack, и Rollup, поддерживают Code Splitting из коробки на основе динамических импортов (`import()`). Когда сборщик видит `import()`, он автоматически создает отдельный бандл для этого модуля.
