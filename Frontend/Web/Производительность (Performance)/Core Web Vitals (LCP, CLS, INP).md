# Core Web Vitals

**Core Web Vitals** — это набор специфических метрик производительности, введенных Google, которые оценивают общий пользовательский опыт (UX) на веб-странице. Они влияют на ранжирование сайта в поисковой выдаче (SEO). 

Три основные метрики оценивают загрузку, интерактивность и визуальную стабильность.

---

## 1. LCP (Largest Contentful Paint)
**Метрика загрузки.** Измеряет время, необходимое для рендеринга самого большого видимого элемента контента (текстового блока, изображения или видео) в области просмотра пользователя с момента начала загрузки страницы.

- **Хорошо:** < 2.5 секунд
- **Нужно улучшить:** до 4.0 секунд
- **Плохо:** > 4.0 секунд

**Как улучшить:** 
Оптимизировать время ответа сервера, использовать CDN, оптимизировать изображения (WebP/AVIF, сжатие), предварительно загружать важные ресурсы (`<link rel="preload">`), удалять блокирующие рендеринг CSS/JS.

---

## 2. INP (Interaction to Next Paint)
**Метрика интерактивности.** (Заменила FID в марте 2024). Измеряет общую отзывчивость страницы к взаимодействию пользователя. INP оценивает задержку всех кликов, тапов и взаимодействий с клавиатурой в течение всего жизненного цикла страницы, и сообщает о худшем значении. Он показывает время между взаимодействием и следующим кадром, который рисует браузер.

- **Хорошо:** < 200 миллисекунд
- **Нужно улучшить:** до 500 миллисекунд
- **Плохо:** > 500 миллисекунд

**Как улучшить:** 
Уменьшить размер основного бандла JavaScript, использовать Web Workers для тяжелых вычислений, разбивать длинные задачи (Long Tasks) на более мелкие, чтобы не блокировать главный поток (Main Thread).

---

## 3. CLS (Cumulative Layout Shift)
**Метрика визуальной стабильности.** Измеряет сумму всех неожиданных сдвигов макета, происходящих на странице. Это случается, когда видимые элементы меняют свою позицию во время загрузки (например, загрузилась картинка без указанных размеров и сдвинула текст вниз).

- **Хорошо:** < 0.1
- **Нужно улучшить:** до 0.25
- **Плохо:** > 0.25

**Как улучшить:** 
Всегда указывать атрибуты `width` и `height` для изображений и видео (`<img width="500" height="300" />`). Резервировать место под рекламу, iframe и динамический контент (например, skeleton loaders). Использовать CSS `aspect-ratio`. Избегать вставки контента поверх существующего.
