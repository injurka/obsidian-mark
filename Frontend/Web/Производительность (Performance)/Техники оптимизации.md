# Техники оптимизации
## Современные API оптимизации (Bfcache & Speculative loads)

### Back/forward cache (bfcache)
**Bfcache** — это встроенная в браузер оптимизация, обеспечивающая мгновенную загрузку страниц при навигации кнопками «Назад» и «Вперед».
*   Браузер сохраняет полный снимок (snapshot) страницы в памяти, включая состояние JavaScript и DOM.
*   При переходе назад страница не загружается заново из сети и даже не рендерится из обычного кэша — она просто восстанавливается из памяти в том виде, в котором пользователь ее оставил.
*   *Важно:* Использование некоторых устаревших API (например, `unload` событий) может отключить bfcache для вашей страницы.

### Speculation Rules API (Speculative loads)
Позволяет разработчикам передать браузеру строгие правила о том, какие страницы пользователь, скорее всего, посетит следующими.
*   **Prefetch (Предзагрузка):** Скачивание ресурсов следующей страницы заранее.
*   **Prerender (Предрендеринг):** Страница не только скачивается, но и полностью отрисовывается в невидимой фоновой вкладке. При клике переход происходит абсолютно мгновенно.
*   Использует JSON-подобный синтаксис внутри тега `<script type="speculationrules">`.
