# Privacy Sandbox
**Privacy Sandbox** — это масштабная инициатива (в основном продвигаемая Google), направленная на создание веб-стандартов, которые позволят отказаться от third-party cookies и других механизмов скрытого отслеживания пользователей, сохранив при этом функциональность веба (реклама, антифрод).

## Ключевые технологии:

### 1. Private State Tokens (Токены состояния)
Механизм для борьбы с мошенничеством и ботами без использования межсайтового трекинга.
*   Сайт, которому вы доверяете (например, банк), выдает браузеру криптографический токен, подтверждающий, что вы реальный человек.
*   На другом сайте браузер может предъявить этот токен, чтобы доказать вашу подлинность, не раскрывая вашу личность или историю браузинга.

### 2. Protected Audience API (ранее FLEDGE / Interest Groups)
Новый способ показа таргетированной рекламы.
*   Вместо того чтобы рекламные сети следили за вами по всему интернету, браузер сам локально определяет ваши интересы (например, "интересуется кроссовками").
*   Аукцион рекламных объявлений происходит прямо на устройстве пользователя, что гарантирует, что данные о ваших интересах не утекают на сервера рекламодателей.

### 3. Shared Storage API
API, решающее проблему того, что иногда сайтам действительно нужно обмениваться данными, но так, чтобы не создать лазейку для трекинга.
*   Данные хранятся в общем хранилище, в которое разные сайты могут писать.
*   Однако *читать* из этого хранилища можно только в специальной изолированной среде (worklet), которая может отдавать наружу только агрегированные или "зашумленные" результаты, не позволяющие идентифицировать конкретного пользователя.
