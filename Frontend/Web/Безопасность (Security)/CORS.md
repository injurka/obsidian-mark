# CORS (Cross-Origin Resource Sharing)

**CORS** (Совместное использование ресурсов между разными источниками) — это механизм безопасности в браузере, который позволяет или запрещает веб-приложению запрашивать ресурсы с другого домена (origin), отличного от того, с которого был загружен сам сайт.

**Origin (Источник)** состоит из трех частей: `Протокол` + `Домен` + `Порт`. 
Например: `https://example.com:443`. Если любой из этих трех параметров отличается при запросе (например, запрос с `http://localhost:3000` к `http://api.mysite.com`), браузер применяет политику Same-Origin Policy (SOP).

## Как работает CORS?

Если клиент делает "сложный" кросс-доменный запрос (например, с методами `PUT`, `DELETE` или кастомными заголовками вроде `Authorization`), браузер сначала отправляет **Preflight-запрос** (предварительный запрос) методом `OPTIONS`.

1. **Браузер отправляет `OPTIONS`** с заголовками:
   - `Origin: https://my-frontend.com`
   - `Access-Control-Request-Method: POST`
2. **Сервер отвечает** (разрешает или нет):
   - `Access-Control-Allow-Origin: https://my-frontend.com` (или `*` для всех)
   - `Access-Control-Allow-Methods: GET, POST, OPTIONS`
   - `Access-Control-Allow-Headers: Content-Type, Authorization`
3. Если сервер разрешил, **Браузер отправляет реальный запрос** (POST). Если сервер запретил, браузер блокирует запрос и выдает ошибку CORS в консоль.

## Важные заголовки:
* `Access-Control-Allow-Origin`: Указывает, каким доменам разрешен доступ. Значение `*` разрешает всем, но это небезопасно для приватных API.
* `Access-Control-Allow-Credentials`: Если `true`, разрешает передачу куки (cookies) и HTTP аутентификации в кросс-доменных запросах (в этом случае `Origin` не может быть `*`).

## Зачем нужен CORS?
Для защиты пользователя. Без CORS вредоносный сайт мог бы отправить AJAX-запрос на сайт вашего банка (где вы авторизованы через куки), выполнить перевод денег, и прочитать ответ сервера. CORS заставляет браузер блокировать такие ответы, если банк явно не разрешил этому вредоносному сайту читать данные.
