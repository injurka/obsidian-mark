# Modern Web Security (Современная веб-безопасность)

Помимо классических XSS и CSRF, браузеры внедряют новые механизмы защиты от более изощренных угроз и нарушения приватности.

### Bounce Tracking Mitigations
С попытками браузеров заблокировать third-party cookies рекламные сети начали использовать "bounce tracking" (трекинг через редиректы).
*   **Как это работает:** При клике на ссылку пользователь на долю секунды перенаправляется на сайт-трекер, который записывает first-party cookie, и только потом на целевой сайт.
*   **Защита:** Браузеры (особенно Safari и Chrome) внедряют механизмы обнаружения таких транзитных сайтов и автоматически удаляют установленные ими куки и данные хранилища.

### Device Bound Session Credentials (DBSC)
Кража сессионных кук с помощью вредоносного ПО (стилеров) на ПК пользователя стала огромной проблемой, обходящей даже 2FA.
*   **Решение (DBSC):** Инициатива по привязке сессии к устройству.
*   Браузер генерирует криптографический ключ, который аппаратно защищен модулем TPM на компьютере.
*   Сервер привязывает сессию к этому аппаратному ключу. Если хакер украдет куки и попытается использовать их на другом ПК, сессия будет недействительна, так как у него нет физического чипа TPM для подписи запросов.
