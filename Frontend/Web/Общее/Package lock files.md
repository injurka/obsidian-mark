# Lock файлы

Lock файлы (файлы блокировки) — это механизм, используемый в системах управления зависимостями для жесткой фиксации дерева зависимостей проекта, включая точные версии всех пакетов и их подзависимостей. 

## Зачем они нужны?

1. **Гарантия воспроизводимости (Reproducibility):** В файле `package.json` версии часто указываются с использованием символов `^` (совместимая минорная версия) или `~` (совместимая патч-версия). Без lock файла два разработчика, выполнившие `npm install` в разное время, могут получить разные версии подзависимостей. Lock файл фиксирует точную установленную версию, устраняя проблему "на моей машине все работает".
2. **Фиксация транзитивных зависимостей:** Вы можете контролировать версии пакетов, которые устанавливаете вы, но не версии пакетов, от которых зависят ваши зависимости. Lock файл сохраняет плоский список абсолютно всех зависимостей в дереве с их версиями и хэшами целостности.
3. **Ускорение установки:** Пакетному менеджеру не нужно делать запросы в реестр (например, npm registry) для резолва версий каждой зависимости. Он читает lock файл и сразу скачивает/распаковывает нужные версии.
4. **Безопасность (Integrity Checks):** Lock файлы содержат хэши (integrity) скачанных архивов. При установке менеджер проверяет, совпадает ли хэш скачанного пакета с хэшем в lock файле, предотвращая атаки с подменой пакетов.

## Популярные Lock файлы в экосистеме JS/TS

* **`package-lock.json`** — генерируется и используется по умолчанию в **npm**.
* **`yarn.lock`** — используется пакетным менеджером **Yarn**.
* **`pnpm-lock.yaml`** — используется менеджером **pnpm** (хранит данные в формате YAML для лучшей читаемости и меньшего количества конфликтов слияния).

## Правила работы с Lock файлами

* **Всегда коммитьте lock файл в систему контроля версий (Git):** Это гарантирует, что CI/CD серверы и другие разработчики получат идентичную среду.
* **Не редактируйте вручную:** Эти файлы генерируются автоматически пакетным менеджером.
* **Используйте правильные команды в CI:** Для непрерывной интеграции (CI) следует использовать команды, которые строго опираются на lock файл и не обновляют его:
  * В npm: `npm ci` (вместо `npm install`).
  * В Yarn: `yarn install --frozen-lockfile`.
  * В pnpm: `pnpm install --frozen-lockfile`.
