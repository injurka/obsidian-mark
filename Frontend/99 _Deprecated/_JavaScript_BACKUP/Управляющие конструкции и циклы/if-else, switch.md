# Условное ветвление: if-else и switch в JavaScript

## 1. Введение в условное ветвление
Условное ветвление (conditional branching) — это базовый механизм управления ходом выполнения программы, позволяющий выполнять различные блоки кода в зависимости от истинности или ложности заданных условий. В JavaScript для ветвления используются инструкции `if`, `else if`, `else`, а также конструкция `switch` и тернарный оператор `?`.

---

## 2. Конструкция `if`, `else if`, `else`
Синтаксис `if` позволяет проверить условие (выражение, которое приводится к логическому типу) и выполнить блок кода, если это условие истинно.

### Синтаксис и структура
```javascript
if (условие1) {
  // Выполняется, если условие1 истинно (truthy)
} else if (условие2) {
  // Выполняется, если условие1 ложно, а условие2 истинно
} else {
  // Выполняется, если все предыдущие условия ложны
}
```

### Особенности работы:
- **Круглые скобки `()`**: Условие внутри `if (...)` обязательно оборачивается в круглые скобки.
- **Фигурные скобки `{}`**: Если блок кода состоит из одной инструкции, фигурные скобки можно опустить, однако для улучшения читаемости и предотвращения ошибок настоятельно рекомендуется всегда использовать `{}`.
- **Преобразование типов**: Выражение в скобках `if (...)` неявно приводится к логическому типу (Boolean).

---

## 3. Концепция Truthy и Falsy в JavaScript
В JavaScript любое значение имеет встроенную логическую окраску: при приведении к логическому типу (например, в условии `if`) оно становится либо `true` (истинное значение / truthy), либо `false` (ложное значение / falsy).

### Falsy-значения (приводятся к `false`)
В JavaScript существует ровно 8 значений, которые приравниваются к `false`:
1. `false` — логическое ложное значение.
2. `0` — число ноль.
3. `-0` — отрицательный ноль.
4. `0n` — тип BigInt ноль.
5. `""` (или `''`, `\Template literal\`) — пустая строка.
6. `null` — отсутствие значения.
7. `undefined` — неопределенное значение.
8. `NaN` — Not-a-Number (не-число).

*(Примечание: в браузерной среде также существует историческое falsy-значение `document.all`).*

### Truthy-значения (приводятся к `true`)
Все остальные значения, не входящие в список выше, являются истинными (truthy).
Примеры часто путающих разработчиков truthy-значений:
- Любые объекты и массивы, даже пустые: `[]`, `{}`.
- Строка из пробелов или строка `"0"`: `" "`, `"0"`, `"false"`.
- Функции.

## 4. Конструкция `switch`: структура, использование и строгое сравнение
Конструкция `switch` заменяет собой несколько ветвлений `if`. Она представляет собой более наглядный способ сравнить выражение сразу с несколькими вариантами.

### Синтаксис
```javascript
switch (выражение) {
  case значение1:
    // Код выполняется, если выражение === значение1
    [break;]
  case значение2:
    // Код выполняется, если выражение === значение2
    [break;]
  default:
    // Выполняется, если совпадений не найдено
    [break;]
}
```

### Важные правила работы с `switch`:
1. **Строгое сравнение (===)**: Сравнение значения выражения с вариантами `case` всегда происходит строго (без приведения типов, как оператор `===`). Например, строка `"3"` не совпадет с числом `3`.
2. **Директива `break`**:
   - `break` прерывает выполнение конструкции `switch`.
   - Если опустить `break`, выполнение продолжится дальше по следующим `case` (так называемый «провал» / fall-through), игнорируя их условия, пока не встретится первый `break` или не закончится весь `switch`.
3. **Группировка case**:
   - Несколько `case` можно группировать вместе, если для них требуется выполнить один и тот же блок кода.
4. **Секция `default`**:
   - Выполняется, если ни одно из условий `case` не совпало. Наличие `default` необязательно, но рекомендуется.

## 5. Иллюстрирующие примеры кода

### Пример 1: Использование `if`, `else if`, `else` и проверка Truthy/Falsy
```javascript
const username = "Иван"; // Truthy-значение

if (username) {
  console.log(`Привет, ${username}!`);
} else {
  console.log("Привет, Гость!"); // Выполнится, если username пустая строка, null или undefined
}

const score = 0; // Falsy-значение

if (score === 0) {
  console.log("Очков нет, но условие сработало благодаря строгому сравнению.");
}

if (score) {
  console.log("Этот блок не выполнится, так как 0 — falsy-значение.");
}
```

### Пример 2: Конструкция `switch` и строгое сравнение
```javascript
const value = "2"; // Строка

switch (value) {
  case 2:
    console.log("Это число 2"); // Не выполнится из-за строгого сравнения ("2" !== 2)
    break;
  case "2":
    console.log("Это строка '2'"); // Выполнится!
    break;
  default:
    console.log("Совпадений нет");
}
```

### Пример 3: Группировка `case` в `switch` без `break`
```javascript
const day = "Суббота";

switch (day) {
  case "Понедельник":
  case "Вторник":
  case "Среда":
  case "Четверг":
  case "Пятница":
    console.log("Это будний день.");
    break;
  case "Суббота":
  case "Воскресенье":
    console.log("Это выходной!");
    break;
  default:
    console.log("Неверный день недели.");
}
```
