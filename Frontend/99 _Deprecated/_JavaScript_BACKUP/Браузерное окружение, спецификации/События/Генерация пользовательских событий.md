# Генерация пользовательских событий

В JavaScript мы можем не только обрабатывать стандартные браузерные события (клик, нажатие клавиши, фокус), но и создавать собственные, а затем генерировать их программно на элементах интерфейса. Это позволяет создавать слабосвязанную архитектуру компонентов и передавать данные между независимыми частями приложения.

Для понимания жизненного цикла событий рекомендуется ознакомиться с разделами [[Введение в события]] и [[Всплытие и погружение]].

---

## Конструктор `Event` против `CustomEvent`

Для создания события используются конструкторы `Event` и `CustomEvent`. Основная разница между ними заключается в возможности передачи пользовательских данных.

### 1. Конструктор `Event`

Используется для простых событий или имитации стандартных браузерных действий.

```javascript
const type = 'ping';
const options = { bubbles: true, cancelable: false };
const event = new Event(type, options);
```

- **`type`** — название события (например, `"hello"` или `"click"`).
- **`options`** — объект со следующими свойствами:
  - `bubbles` (`boolean`, по умолчанию `false`): если `true`, событие всплывает по иерархии DOM.
  - `cancelable` (`boolean`, по умолчанию `false`): если `true`, событие можно отменить с помощью `event.preventDefault()`.

### 2. Конструктор `CustomEvent`

Используется, когда вместе с событием необходимо передать дополнительные данные.

```javascript
const type = 'userLogin';
const options = {
  bubbles: true,
  cancelable: true,
  detail: { name: 'Алексей', role: 'Администратор' }
};
const customEvent = new CustomEvent(type, options);
```

Помимо опций `bubbles` и `cancelable`, его объект настроек поддерживает свойство:
- **`detail`** — любые данные (объект, массив, число и т.д.), которые прикрепляются к событию. Получатели события смогут извлечь их через свойство `event.detail`.

## Метод `dispatchEvent`

Чтобы сгенерировать событие на конкретном DOM-элементе, используется метод `element.dispatchEvent(event)`.

```javascript
const element = document.createElement('div');
const event = new Event('build');
const isNotCancelled = element.dispatchEvent(event);
```

- Вызов метода немедленно запускает обработчики события на целевом элементе, а при наличии `bubbles: true` — и на его предках.
- Метод возвращает `false`, если событие отменяемое (`cancelable: true`) и хотя бы один обработчик вызвал `event.preventDefault()`. В остальных случаях возвращается `true`.

---

## Всплытие (`bubbles`) и отмена (`cancelable`)

- **Всплытие (`bubbles: true`)** делает кастомное событие видимым для родительских элементов. Без этого флага событие сработает только на самом элементе.
- **Отмена (`cancelable: true` и `event.preventDefault()`)** позволяет обработчикам заявить о несогласии с действием по умолчанию. Если обработчик вызывает `event.preventDefault()`, то `dispatchEvent` вернет `false`, что служит сигналом для отмены последующего встроенного или кастомного действия.

## Практические примеры

### Пример 1. Базовое событие с использованием `Event`

Простейшая отправка сигнала от элемента к его родителю.

```javascript
const parentDiv = document.createElement('div');
const childButton = document.createElement('button');
parentDiv.appendChild(childButton);

// Слушаем всплывающее событие на родителе
parentDiv.addEventListener('ping', () => {
  console.log('Событие ping дошло до родителя!');
});

// Создаем и генерируем событие
const pingEvent = new Event('ping', { bubbles: true });
childButton.dispatchEvent(pingEvent);
```

### Пример 2. Передача данных через `CustomEvent` (`detail`)

Передача объекта с информацией о пользователе.

```javascript
const form = document.createElement('form');
const dashboard = document.createElement('div');
dashboard.appendChild(form);

// Слушаем событие на предке
dashboard.addEventListener('userLogin', (event) => {
  const user = event.detail;
  console.log(`Пользователь ${user.name} вошел под ролью: ${user.role}`);
});

// Генерируем событие на форме с передачей данных
const loginEvent = new CustomEvent('userLogin', {
  bubbles: true,
  detail: { name: 'Алексей', role: 'Администратор' }
});

form.dispatchEvent(loginEvent);
```

### Пример 3. Отменяемое событие и обработка `event.preventDefault()`

Предотвращение удаления элемента пользователем.

```javascript
const item = document.createElement('div');

// Обработчик события, который может отменить действие
item.addEventListener('beforeDelete', (event) => {
  // Имитируем подтверждение удаления
  const confirmDelete = true; 
  if (!confirmDelete) {
    event.preventDefault(); // Отменяем действие
  }
});

// Инициатор удаления
function deleteItem(targetElement) {
  const deleteEvent = new CustomEvent('beforeDelete', {
    bubbles: false,
    cancelable: true // Обязательно разрешаем отмену
  });

  const shouldProceed = targetElement.dispatchEvent(deleteEvent);

  if (shouldProceed) {
    console.log('Действие разрешено. Удаляем элемент из DOM...');
    targetElement.remove();
  } else {
    console.log('Действие отменено.');
  }
}

// Запускаем функцию удаления
deleteItem(item);
```
