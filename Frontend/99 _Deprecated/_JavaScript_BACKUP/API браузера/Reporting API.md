# Reporting API
**Reporting API** предоставляет браузеру стандартный механизм для автоматического сбора отчетов об ошибках и отправки их на указанный вами сервер (endpoint).

### Что можно мониторить:
*   **Нарушения CSP (Content Security Policy):** Попытки загрузить ресурсы из неразрешенных источников.
*   **Deprecations (Устаревшие API):** Использование функций браузера, которые скоро будут удалены.
*   **Crashes:** Сбои браузера (например, вкладка упала из-за нехватки памяти — OOM).
*   **Сетевые ошибки (Network Error Logging):** Проблемы с DNS, TLS или таймауты подключения к вашему серверу.

### Как работает:
Сервер отправляет специальный HTTP-заголовок `Report-To` (или более новый `Reporting-Endpoints`), указывая URL, куда браузер должен фоново отправлять JSON-отчеты. Это позволяет собирать статистику о проблемах реальных пользователей без написания сложного клиентского кода на JS.
