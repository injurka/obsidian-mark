
Писать мобильные приложения на "голом" React Native CLI (через Xcode и Android Studio) к 2026 году — это удел специфических энтерпрайз-проектов с глубокой интеграцией нативного кода. Стандарт разработки — **Expo**.

## 1. Что такое Expo?
Это мета-фреймворк (как Next.js, только для React Native). Он предоставляет набор инструментов, библиотек и сервисов для создания iOS, Android и Web приложений из одной кодовой базы.

## 2. Главная революция: Continuous Native Generation (CNG)
Раньше, если вам нужно было добавить модуль камеры или Bluetooth, вам приходилось "eject-ать" (извлекать) проект из Expo и лезть в файлы `build.gradle` (Java) и `Podfile` (Objective-C/Swift). Это ломало обновления и вызывало боли у фронтендеров.

С внедрением **Prebuilds (CNG)** вы больше не коммитите папки `ios` и `android` в Git!
Вместо этого вы используете плагины конфигурации (Config Plugins) в файле `app.json`.
При запуске сборки Expo **генерирует** нативные папки с нуля, применяя нужные настройки (разрешения на камеру, иконки). Это позволяет оставаться в "Managed" (управляемом) рабочем процессе бесконечно.

## 3. Expo Router
Аналог Next.js App Router для мобилок. 
Маршрутизация (навигация между экранами) теперь основана на файловой системе.

```text
app/
  _layout.tsx (Обертка, например, нижняя панель вкладок - TabBar)
  index.tsx (Главный экран - путь "/")
  profile/
    [id].tsx (Динамический экран - путь "/profile/123")
```
Expo Router автоматически конвертирует эти файлы в сложную нативную навигацию (React Navigation) под капотом, управляя стеками, модалками и глубокими ссылками (Deep Linking) "из коробки".

## 4. Облачные сервисы (EAS)
EAS (Expo Application Services) решает главную боль мобильной разработки — сборку и релизы.
1. **EAS Build:** Вы можете собрать iOS-приложение (файл `.ipa`), **даже не имея MacBook**! Код отправляется в облако Expo, там собирается на Mac-серверах и возвращается вам готовый билд.
2. **EAS Update (OTA - Over The Air):** 
   **Edge Case / Суперсила:** Вы нашли опечатку в тексте или баг в логике. Вы можете выпустить обновление, и оно загрузится у пользователей прямо при открытии приложения! Вам **не нужно** проходить модерацию в App Store и Google Play (главное — не менять нативный код, только JS/Ассеты). Это экономит недели времени на релизах.
