
Переход с Nuxt 2 на Nuxt 3 — это не просто обновление версии, это **полное переосмысление архитектуры**. Nuxt 3 был написан с нуля, чтобы стать быстрее, легче и удобнее для разработчика.

## 🏗 Главные Архитектурные Изменения

### 1. Ядро: Vue 2 ➡️ Vue 3
* **Composition API**: Вместо громоздкого `Options API` (data, methods, computed) теперь используется `<script setup>` и `Composition API`. Код стал логичнее и легче переиспользуется.
* **Фрагменты (Fragments)**: Компоненты больше не требуют одного корневого элемента (одного `div` обертки).

### 2. Сборщик: Webpack ➡️ Vite
* **Моментальный старт**: В Nuxt 2 Webpack мог собирать проект десятки секунд. В Nuxt 3 благодаря Vite (и esbuild) HMR (Hot Module Replacement) и холодный старт происходят почти мгновенно.

### 3. Серверный движок: Connect ➡️ Nitro
* В Nuxt 2 серверная часть была тяжеловесной и привязанной к Node.js.
* **Nitro** — это новый, невероятно быстрый серверный движок. Он позволяет разворачивать Nuxt-приложения **где угодно**: на Vercel, Netlify, Cloudflare Workers, Deno, Bun.
* Появились **API Routes** (папка `server/api/`), что позволяет писать полноценный бэкенд прямо в Nuxt-проекте (Full-stack фреймворк).

---

## 🛠 Изменения в Экосистеме и Разработке

### 4. Автоимпорты (Auto-imports)
В Nuxt 3 магия достигла апогея. Вам больше не нужно импортировать компоненты, хуки Vue (например, `ref`, `computed`) или собственные composables. Nuxt делает это сам!

### 5. Стейт-менеджер: Vuex ➡️ Pinia
* **Vuex мёртв**. Да здравствует **Pinia**! 🍍
* Больше никаких громоздких мутаций (mutations). 
* Идеальная поддержка TypeScript из коробки.

### 6. Получение данных (Data Fetching)
* **Nuxt 2**: Использовались хуки `asyncData` и `fetch` в `Options API`.
* **Nuxt 3**: Появились мощные изоморфные composables: `useFetch` и `useAsyncData`. Они автоматически предотвращают двойной запрос данных (на сервере и на клиенте) во время SSR.

```vue
<!-- Пример получения данных в Nuxt 3 -->
<script setup>
const { data, pending, error } = await useFetch('/api/users')
</script>
```

### 7. TypeScript
В Nuxt 2 поддержку TS приходилось прикручивать модулями с большими страданиями. Nuxt 3 **написан на TypeScript** и предоставляет идеальную типизацию из коробки (автогенерируемые типы в папке `.nuxt`).
