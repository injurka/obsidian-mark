
Nuxt 4 — это не радикальная революция (как было с переходом от v2 к v3), а скорее **эволюционное развитие**. Основной фокус был сделан на улучшение структуры проектов, производительность и подготовку к будущим стандартам веба.

## 📁 Главное изменение: Новая Структура Директорий

Самое заметное изменение (breaking change) — это переход к новой файловой структуре. Nuxt 4 стремится отделить конфигурацию и серверный код от самого клиентского приложения.

* В **Nuxt 3** всё лежало в корне: `pages/`, `components/`, `server/`, `nuxt.config.ts`.
* В **Nuxt 4** по умолчанию вводится папка `app/` для фронтенда.

**Сравнение структур:**

| Сущность | Nuxt 3 (Старая) | Nuxt 4 (Новая) |
| :--- | :--- | :--- |
| **Компоненты** | `/components` | `/app/components` |
| **Страницы** | `/pages` | `/app/pages` |
| **Плагины** | `/plugins` | `/app/plugins` |
| **Composables** | `/composables` | `/app/composables` |
| **Сервер (API)**| `/server` | `/server` (Остается в корне!) |
| **Конфиг** | `/nuxt.config.ts`| `/nuxt.config.ts` (Остается в корне!) |
| **Public** | `/public` | `/public` (Остается в корне!) |

*💡 Это решает давнюю проблему "каши" в корне проекта, четко разделяя frontend-код (`app/`) и backend/настройки.*

## ⚡ Оптимизация и Под Капотом

### 1. Переход на Vue 3.4+ и новые фичи Vue
Nuxt 4 опирается на свежие версии Vue, что по умолчанию включает улучшенный реактивный движок и новые фичи (например, `defineModel`).

### 2. Обновление Nitro
Серверный движок Nitro получил мажорные обновления производительности. Улучшена поддержка Edge-вычислений и новых рантаймов (включая нативную работу с Bun и Deno).

### 3. Изменения в `nuxt.config`
Некоторые устаревшие (deprecated) опции конфигурации из Nuxt 3 были полностью удалены в Nuxt 4.

## 🔄 Плавный переход (Compatibility Flag)

Команда Nuxt сделала переход максимально безболезненным. В Nuxt 3.12+ был добавлен флаг совместимости. 

Включив его в `nuxt.config.ts`, вы можете поэтапно адаптировать свой проект (например, перенести файлы фронтенда в папку `app/`) до фактического перехода на 4-ю версию!

```ts
export default defineNuxtConfig({
  future: {
    compatibilityVersion: 4,
  },
})
```
