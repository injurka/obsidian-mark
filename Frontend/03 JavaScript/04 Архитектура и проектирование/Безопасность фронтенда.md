# Безопасность веб-приложений

Угрозы и методы защиты на стороне клиента.

## Ключевые риски
- **XSS (Cross-Site Scripting):** Внедрение вредоносных скриптов.
- **CSRF (Cross-Site Request Forgery):** Межсайтовая подделка запроса.
- **CSP (Content Security Policy):** Политика защиты контента.
- **CORS (Cross-Origin Resource Sharing):** Настройка совместного использования ресурсов.
