# Производительность фронтенда (Web Performance)

Оптимизация скорости загрузки и отзывчивости интерфейсов.

## Метрики Core Web Vitals
- **LCP (Largest Contentful Paint):** Скорость загрузки основного контента.
- **INP (Interaction to Next Paint):** Отзывчивость на действия пользователя.
- **CLS (Cumulative Layout Shift):** Визуальная стабильность.
