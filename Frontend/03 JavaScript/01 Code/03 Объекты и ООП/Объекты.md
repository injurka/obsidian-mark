# Объекты

Объект в JavaScript — это структура данных, которая позволяет хранить коллекции различных значений (свойств) и более сложных сущностей (методов). Объекты являются ссылочным типом данных.

## Создание объекта

Существует несколько способов создания объекта, но самый популярный — **литерал объекта**:

```javascript
const user = {
  name: "Ivan",        // Свойство (ключ: значение)
  age: 30,
  "likes birds": true  // Ключ из нескольких слов должен быть в кавычках
};

// Создание через конструктор
const emptyObj = new Object();
```

## Обращение к свойствам

```javascript
// Через точку (Dot notation)
console.log(user.name); // "Ivan"

// Через квадратные скобки (Bracket notation)
// Обязательно, если ключ содержит пробелы или если ключ хранится в переменной
console.log(user["likes birds"]); // true

let key = "age";
console.log(user[key]); // 30
```

## Добавление, изменение и удаление

```javascript
// Добавление / Изменение
user.isAdmin = true;
user["name"] = "Petr";

// Удаление
delete user.age;
```

## Ссылочная природа объектов

Важнейшее отличие объектов от примитивов (строк, чисел, булевых значений) заключается в том, что объекты хранятся и копируются "по ссылке".

```javascript
let a = { name: "John" };
let b = a; // Копируется ссылка, а не сам объект

b.name = "Pete"; // Изменили по ссылке из b
console.log(a.name); // "Pete" (изменилось и в a)
```

## Ключевое слово this

Объекты могут содержать функции, которые называются **методами**. Для доступа к свойствам текущего объекта внутри метода используется ключевое слово `this`.

```javascript
const calculator = {
  a: 10,
  b: 20,
  sum() {
    return this.a + this.b;
  }
};

console.log(calculator.sum()); // 30
```

> [!WARNING]
> Значение `this` в JavaScript вычисляется во время выполнения и зависит от **контекста вызова** (то есть от того, *как* была вызвана функция), а не от места ее объявления. Стрелочные функции не имеют собственного `this` — они берут его из внешнего окружения.
