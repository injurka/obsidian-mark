## Визуализация: Что такое прототип?

В JavaScript объекты могут наследоваться друг от друга. Если мы читаем свойство из объекта, а оно отсутствует, JavaScript автоматически берет его из **прототипа**.

```mermaid
graph BT
    subgraph "Объект (дочерний)"
        obj[Rabbit]
        obj_jumps[jumps: true]
    end

    subgraph "Прототип (родительский объект)"
        proto[Animal]
        proto_eats[eats: true]
        proto_walk[walk()]
    end

    obj -->|__proto__| proto

    %% Примечание для понимания
    note[Rabbit.walk() вызывает Animal.walk] -.-> proto_walk
```

> [!TIP]
> Цепочка прототипов может быть длинной, но в самом верху всегда находится `Object.prototype`, чей прототип равен `null`.
