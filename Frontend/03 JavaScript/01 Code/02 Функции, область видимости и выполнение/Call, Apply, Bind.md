# Явное указание контекста: Call, Apply, Bind

В JavaScript контекстом функции можно управлять вручную. Для явного указания контекста (`this`) у функций существуют три встроенных метода: `call()`, `apply()` и `bind()`.

---

## 1. Метод `call()`

Метод `call()` вызывает функцию с указанным значением `this` и индивидуально перечисленными аргументами.

### Синтаксис:
```text
func.call(context, arg1, arg2, ...);
```
* `context` — объект, который должен стать значением `this` внутри функции.
* `arg1, arg2, ...` — параметры, передаваемые в функцию.

### Пример:
```javascript
function introduce(language, experience) {
  return `Привет, меня зовут ${this.name}. Я пишу на ${language} уже ${experience} лет.`;
}

const developer = { name: 'Сергей' };

// Непосредственный вызов функции с привязкой контекста
const result = introduce.call(developer, 'JavaScript', 5);
console.log(result); // "Привет, меня зовут Сергей. Я пишу на JavaScript уже 5 лет."
```

---

## 2. Метод `apply()`

Метод `apply()` делает то же самое, что и `call()`, но принимает аргументы в виде единого массива (или массивоподобного объекта).

### Синтаксис:
```text
func.apply(context, [arg1, arg2, ...]);
```

### Пример:
```javascript
const developer = { name: 'Сергей' };

// Передаем аргументы списком в массиве
const result = introduce.apply(developer, ['JavaScript', 5]);
console.log(result); // "Привет, меня зовут Сергей. Я пишу на JavaScript уже 5 лет."
```

### Сравнение `call()` и `apply()`
* Оба метода вызывают функцию **немедленно**.
* Разница заключается исключительно в **формате передачи аргументов**: `call` принимает аргументы списком через запятую, а `apply` — в виде массива.
* Исторически до появления spread-оператора (`...`) метод `apply` часто использовался для передачи массива аргументов в функции, которые ожидали список аргументов (например, `Math.max.apply(null, array)`).

---

## 3. Метод `bind()`

В отличие от `call` и `apply`, метод `bind()` **не вызывает** функцию сразу. Он создает и возвращает **новую функцию**, у которой контекст `this` жестко привязан к указанному объекту.

### Синтаксис:
```text
const boundFunc = func.bind(context, arg1, arg2, ...);
```
* Возвращает новую функцию с зафиксированным контекстом.
* Можно предварительно зафиксировать часть аргументов (частичное применение).

### Пример:
```javascript
const user = {
  name: 'Ирина',
  greet() {
    return `Привет, ${this.name}`;
  }
};

const greetLater = user.greet.bind(user);
// Теперь greetLater можно вызывать без потери контекста
console.log(greetLater()); // "Привет, Ирина"
```

> **Важно:** Связывание через `bind()` является окончательным. Контекст созданной функции невозможно изменить повторным вызовом `bind()`, `call()` или `apply()`.

---

## 4. Практические паттерны применения

### А. Заимствование методов (Method Borrowing)

Мы можем «одолжить» метод у одного объекта для использования с другим объектом, даже если второй объект не имеет этого метода в своем прототипе. Чаще всего это применяется к псевдомассивам (например, объекту `arguments` или NodeList), у которых нет встроенных методов массивов (`map`, `filter`, `reduce`).

```javascript
function sumAll() {
  // arguments не является массивом, но мы заимствуем метод reduce у Array.prototype
  return Array.prototype.reduce.call(arguments, (acc, curr) => acc + curr, 0);
}

console.log(sumAll(1, 2, 3, 4)); // 10
```

Современная альтернатива: В современном коде вместо заимствования методов чаще используют `Array.from(arguments)` или spread-оператор `[...arguments]`.

### Б. Каррирование и частичное применение (Partial Application)

`bind()` позволяет фиксировать не только контекст, но и первые аргументы функции. Это полезно для создания специализированных функций из более общих.

```javascript
function multiply(a, b) {
  return a * b;
}

// Фиксируем первый аргумент (a = 2), context передаем как null (он здесь не важен)
const double = multiply.bind(null, 2);
const triple = multiply.bind(null, 3);

console.log(double(5)); // 10 (2 * 5)
console.log(triple(5)); // 15 (3 * 5)
```

### В. Решение проблемы потери контекста в колбэках

Использование `bind()` гарантирует стабильный контекст при передаче методов в качестве аргументов в асинхронные операции или события.

```javascript
const notifier = {
  message: 'Данные успешно загружены',
  notify() {
    console.log(this.message);
  }
};

// Передаем метод с жестко связанным контекстом
setTimeout(notifier.notify.bind(notifier), 500);
```
