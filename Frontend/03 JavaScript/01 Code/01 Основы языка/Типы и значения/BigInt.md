# BigInt

`BigInt` — это специальный числовой тип в JavaScript, который предоставляет возможность работать с целыми числами произвольной длины. 

Обычные числа в JavaScript (тип `Number`) используют 64-битный формат IEEE-754, что означает, что они могут безопасно представлять целые числа от `-(2^53 - 1)` до `2^53 - 1`. Числа за пределами этого диапазона теряют точность.

Тип `BigInt` был добавлен, чтобы решить эту проблему.

## Создание BigInt

Создать значение типа `BigInt` можно двумя способами:

1. Добавить суффикс `n` к концу целочисленного литерала.
2. Вызвать функцию `BigInt()`, передав ей целое число или строку.

```javascript
const bigIntFromLiteral = 1234567890123456789012345678901234567890n;
const bigIntFromNumber = BigInt(10); // 10n
const bigIntFromString = BigInt("123456789012345678901234567890");

console.log(typeof bigIntFromLiteral); // "bigint"
```

## Математические операции

`BigInt` поддерживает обычные математические операторы, такие как `+`, `-`, `*`, `/`, `**` и `%`. Однако деление `/` всегда возвращает целое число, отбрасывая дробную часть (работает как целочисленное деление).

```javascript
const a = 10n;
const b = 3n;

console.log(a + b); // 13n
console.log(a / b); // 3n (дробная часть отбрасывается)
```

> [!WARNING]
> Вы не можете смешивать `BigInt` и обычные `Number` в математических операциях напрямую. Это вызовет ошибку `TypeError`.

```javascript
const num = 10;
const big = 20n;

// console.log(num + big); // TypeError: Cannot mix BigInt and other types

// Правильный способ — явное преобразование:
console.log(BigInt(num) + big); // 30n
console.log(num + Number(big)); // 30 (если уверены, что значение поместится в Number)
```

## Сравнение

Операторы сравнения (`>`, `<`, `>=`, `<=`, `==`, `===`) работают между `BigInt` и `Number`.

```javascript
console.log(10n === 10); // false (строгое равенство проверяет и тип)
console.log(10n == 10);  // true (нестрогое равенство преобразует типы)
console.log(10n > 5);    // true
```

## Логические операции

При приведении к логическому типу `BigInt` ведет себя так же, как `Number`. Значение `0n` является ложным (falsy), а остальные — истинными (truthy).

```javascript
if (0n) {
  console.log("Не выполнится");
}
if (1n) {
  console.log("Выполнится");
}
```
