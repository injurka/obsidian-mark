# ArrayBuffer и SharedArrayBuffer

`ArrayBuffer` — это базовый объект для представления сырых бинарных данных. Это просто непрерывная область памяти фиксированной длины. 
Вы не можете напрямую читать или писать данные в `ArrayBuffer`. Для этого нужно использовать так называемые «представления» (views) — объекты `TypedArray` или `DataView`, которые интерпретируют сырые байты в нужный формат (например, 8-битные целые числа или 32-битные числа с плавающей точкой).

## Пример применения ArrayBuffer
Создание буфера на 16 байт:
```javascript
let buffer = new ArrayBuffer(16);
console.log(buffer.byteLength); // 16
```

## SharedArrayBuffer
`SharedArrayBuffer` работает аналогично `ArrayBuffer`, но может совместно использоваться между веб-воркерами (Web Workers) и основным потоком. Это позволяет реализовывать многопоточность и обмен данными без накладных расходов на их копирование (как это происходит при передаче обычных данных через `postMessage`).

### Пример применения SharedArrayBuffer
```javascript
// В основном потоке
const sab = new SharedArrayBuffer(1024);
worker.postMessage(sab);

// В воркере память доступна напрямую
```
> Внимание: из-за угроз безопасности (например, атаки Spectre) для использования `SharedArrayBuffer` в браузере часто требуются специальные заголовки изоляции (`Cross-Origin-Isolated`).
