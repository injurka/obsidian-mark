# TypedArray и Uint8Array

Объекты `TypedArray` (типизированные массивы) представляют собой механизмы для работы с `ArrayBuffer`. Сам по себе `TypedArray` — это не класс, который можно создать через `new TypedArray()`, а собирательное название для ряда конкретных классов.

## Uint8Array и другие
Каждый конкретный класс типизированного массива указывает, как интерпретировать байты буфера:
- `Uint8Array`: 8-битные целые числа без знака (1 байт на элемент).
- `Uint16Array`: 16-битные целые числа без знака (2 байта на элемент).
- `Uint32Array`: 32-битные целые числа без знака (4 байта на элемент).
- `Float32Array`: 32-битные числа с плавающей точкой (4 байта на элемент).
- `Float64Array`: 64-битные числа с плавающей точкой (8 байт на элемент).

И так далее.

## Примеры применения
Если вам нужно обрабатывать изображения попиксельно (например, данные из `canvas`), или работать с сетевыми пакетами побайтово, то `Uint8Array` или `Uint8ClampedArray` (который ограничивает значения от 0 до 255) — ваш выбор.

```javascript
// Создаём ArrayBuffer на 16 байт
let buffer = new ArrayBuffer(16);

// Создаём представление Uint32Array на этот буфер (16 байт / 4 байта на элемент = 4 элемента)
let view = new Uint32Array(buffer);

view[0] = 123456;
console.log(view[0]); // 123456
console.log(view.length); // 4
```

Типизированные массивы ведут себя почти так же, как и обычные массивы JavaScript (имеют методы `map`, `filter`, `reduce` и т.д.), но работают значительно быстрее при математических вычислениях и операциях с бинарными данными.
