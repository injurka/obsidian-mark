# DataView

В то время как типизированные массивы (`TypedArray`) работают с буфером как с набором элементов одного типа (например, только 32-битные целые числа), `DataView` обеспечивает низкоуровневый интерфейс для чтения и записи различных типов данных в `ArrayBuffer` в любом смещении.

## Зачем нужен DataView?
В реальных сетевых протоколах или форматах файлов (например, в заголовках изображений) данные часто смешаны: первые 2 байта могут быть 16-битным числом, следующие 4 байта — 32-битным числом, затем строка и т.д.
С помощью `DataView` вы можете вручную управлять тем, откуда и какой тип данных вы читаете, а также указывать порядок следования байтов (endianness: little-endian или big-endian).

## Пример применения
```javascript
// Допустим, мы получили бинарный буфер по сети
let buffer = new ArrayBuffer(16);
let view = new DataView(buffer);

// Записываем 16-битное число со смещением 0
view.setUint16(0, 256); 

// Записываем 32-битное число с плавающей точкой со смещением 2
view.setFloat32(2, 2.5);

// Читаем данные обратно
console.log(view.getUint16(0)); // 256
console.log(view.getFloat32(2)); // 2.5
```

Использование `DataView` необходимо при написании парсеров для бинарных файлов (ZIP, PDF, JPG) или при обмене сложными структурами данных по WebSocket.
