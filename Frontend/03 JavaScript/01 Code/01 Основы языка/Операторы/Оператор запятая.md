# Оператор запятая (,)

Оператор запятая (`,`) вычисляет каждый из своих операндов слева направо и возвращает значение последнего операнда.

```javascript
let x = (1, 2, 3);
console.log(x); // 3
```

## Где это полезно?

Чаще всего оператор запятая используется в циклах `for`, когда нужно изменять сразу несколько переменных при каждой итерации.

```javascript
for (let i = 0, j = 10; i < 10; i++, j--) {
  console.log(`i: ${i}, j: ${j}`);
}
```

В этом примере `i++, j--` — это два выражения, объединенные оператором запятая. Они выполняются последовательно.

## Ловушки и плохие практики

> [!WARNING]
> Использование оператора запятая вне циклов `for` считается плохой практикой, так как оно сильно ухудшает читаемость кода и часто путает разработчиков.

```javascript
// Плохо (запутанно):
let a = 10;
let b = (a++, a + 5); 
console.log(b); // 16

// Хорошо (понятно):
let a = 10;
a++;
let b = a + 5;
console.log(b); // 16
```

Также не путайте оператор запятая с запятыми, используемыми для:
- Разделения элементов в массивах `[1, 2, 3]`
- Разделения свойств в объектах `{a: 1, b: 2}`
- Разделения аргументов функций `fn(a, b, c)`
- Объявления нескольких переменных `let x = 1, y = 2;`
