Операторы сложения (`+`) и вычитания (`-`) выполняют арифметические операции.

```ts
let a = 5;
let b = 3;

console.log(a + b); // 8
console.log(a - b); // 2
```

---

## Из источника: Операторы/Мультипликативные.md

Мультипликативные операторы (`*`, `/`, `%`) используются для умножения, деления и получения остатка от деления.

```ts
let result = 10 * 2; // 20

result = 10 / 2; // 5
result = 10 % 3; // 1
```

## Из источника: Операторы/Возведения в степень.md

Оператор возведения в степень (`**`) возвращает результат возведения первого операнда в степень, указанную вторым операндом.

```ts
let result = 2 ** 3; // 8
```
