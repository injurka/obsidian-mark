# Логические операторы

Логические операторы в JavaScript обычно используются с логическими (булевыми) значениями. Однако в JavaScript они также могут использоваться с небулевыми значениями и возвращать небулевые значения (так называемое "короткое замыкание" или short-circuiting).

## Основные операторы

### 1. И (AND) — `&&`

Оператор `&&` возвращает первое "ложное" (falsy) значение, если оно есть. Если все значения "истинны" (truthy), возвращается последнее значение.

```javascript
let x = true;
let y = false;

console.log(x && y); // false
console.log(1 && 2 && 3); // 3 (все truthy, возвращается последнее)
console.log("hello" && 0 && "world"); // 0 (0 - это falsy)
```

### 2. ИЛИ (OR) — `||`

Оператор `||` возвращает первое "истинное" (truthy) значение. Если все значения "ложны", возвращается последнее значение.

```javascript
console.log(x || y); // true
console.log(0 || null || "Javascript" || false); // "Javascript"
console.log(undefined || 0 || null); // null
```

### 3. НЕ (NOT) — `!`

Унарный оператор `!` преобразует операнд к булевому типу и инвертирует его.

```javascript
console.log(!true); // false
console.log(!"");   // true (пустая строка — falsy)
console.log(!!"test"); // true (двойное отрицание часто используется для явного приведения к Boolean)
```

## Короткое замыкание (Short-circuit evaluation)

JavaScript вычисляет логические выражения слева направо и останавливается, как только результат становится очевиден.

```mermaid
graph TD
    A[Начало &&] --> B{Левый операнд истинный?}
    B -- Нет (falsy) --> C[Вернуть левый операнд]
    B -- Да (truthy) --> D[Вернуть правый операнд]

    E[Начало ||] --> F{Левый операнд истинный?}
    F -- Да (truthy) --> G[Вернуть левый операнд]
    F -- Нет (falsy) --> H[Вернуть правый операнд]
```

Это часто используется для установки значений по умолчанию или условного выполнения кода:

```javascript
// Установка значения по умолчанию
let userName = "";
let displayName = userName || "Аноним"; 
console.log(displayName); // "Аноним"

// Условное выполнение
let isLoggedIn = true;
isLoggedIn && console.log("Пользователь вошел в систему"); 
// Эквивалентно: if (isLoggedIn) { console.log(...) }
```

## Оператор нулевого слияния — `??`

Не путайте `||` с оператором нулевого слияния `??`.
В отличие от `||`, который реагирует на *любое* falsy значение (включая `0`, `""`, `false`), оператор `??` возвращает правый операнд только в том случае, если левый операнд равен `null` или `undefined`.

```javascript
let count = 0;
console.log(count || 10); // 10 (так как 0 это falsy)
console.log(count ?? 10); // 0 (так как 0 это не null и не undefined)
```
