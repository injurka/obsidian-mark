# Глоссарий терминов

- **ECMAScript (ES):** Стандарт языка программирования JavaScript.
- **DOM (Document Object Model):** Программный интерфейс (API) для HTML и XML документов.
- **BOM (Browser Object Model):** Объектная модель браузера (window, location, navigator, history, screen).
- **Event Loop:** Механизм событийного цикла, позволяющий JavaScript выполнять неблокирующие ввод-вывод операции.
- **Closure (Замыкание):** Комбинация функции и лексического окружения, в котором эта функция была объявлена.
- **Prototype (Прототип):** Механизм, с помощью которого объекты JavaScript наследуют свойства друг от друга.
