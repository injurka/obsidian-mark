# Практические задачи по JavaScript

Сборник задач для отработки навыков и подготовки к собеседованиям.

1. Написание собственной реализации `Promise.all` / `Promise.allSettled`.
2. Написание функции `deepClone` (глубокое копирование).
3. Написание `debounce` и `throttle`.
4. Реализация кастомного `Event Emitter`.
