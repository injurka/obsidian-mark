# Payment Handler API (Web Payments)
**Payment Request API** и связанный с ним **Payment Handler API** предоставляют стандартизированный, нативный интерфейс браузера для совершения платежей.

### Проблема, которую он решает
Ранее каждому интернет-магазину приходилось создавать свои собственные формы ввода данных кредитных карт. Это долго, неудобно для пользователя и чревато ошибками.

### Как это работает
1.  Сайт вызывает Payment Request API.
2.  Браузер показывает свой собственный, нативный UI для оплаты.
3.  Пользователь может выбрать сохраненную в браузере карту или использовать сторонний обработчик платежей (Payment Handler), например Google Pay, Apple Pay или даже сторонние банковские приложения, установленные на устройстве.
4.  Браузер безопасно передает платежные данные обратно сайту.

Это кардинально улучшает конверсию при оплате (особенно на мобильных устройствах), так как пользователю достаточно нажать пару кнопок и подтвердить оплату биометрией.
