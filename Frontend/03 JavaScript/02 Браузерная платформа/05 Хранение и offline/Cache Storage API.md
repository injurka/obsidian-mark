# Cache Storage API и Storage Buckets

## Cache Storage (Cache API)
Специализированное хранилище, предназначенное для кэширования пар `Request` (сетевой запрос) и `Response` (ответ сервера). Чаще всего используется вместе с Service Workers для обеспечения оффлайн-работы PWA.

*   **Принцип работы:** Позволяет скриптам явно сохранять ответы сервера (включая HTML, CSS, JS, изображения и другие ресурсы) и выдавать их при повторных запросах без обращения к сети.
*   **Управление:** Разработчик сам должен управлять жизненным циклом кэша (создание, обновление, удаление старых версий).

## Storage Buckets
**Storage Buckets API** — это новый стандарт управления хранилищем данных на клиенте. Исторически браузеры при нехватке памяти удаляли все данные сайта разом (IndexedDB, LocalStorage, Cache).

*   **Идея:** API позволяет разделить данные сайта на логические "корзины" (buckets). Например, корзина "Черновики писем" и корзина "Кэш картинок".
*   **Приоритизация:** Каждой корзине можно задать свою политику (например, сделать корзину с черновиками персистентной, чтобы браузер не удалял ее никогда, а корзину с кэшем картинок удалил первой при нехватке места).
