## Сравнение механизмов хранения

Браузер предоставляет несколько способов хранения данных на клиенте. Выбор зависит от объема данных, требований к безопасности и необходимости отправлять данные на сервер с каждым запросом.

```mermaid
graph TD
    A["Где хранить данные?"] --> B{"Нужно ли отправлять<br/>на сервер автоматически?"}
    
    B -- Да --> C["Cookies<br/>(До 4КБ, авторизация)"]
    B -- Нет --> D{"Какой объем<br/>данных?"}
    
    D -- Маленький (до 5МБ) --> E{"Нужны ли данные<br/>после закрытия вкладки?"}
    E -- Да --> F["localStorage<br/>(Синхронно, Key-Value)"]
    E -- Нет --> G["sessionStorage<br/>(Только для текущей вкладки)"]
    
    D -- Большой / Структурированный --> H["IndexedDB<br/>(Асинхронно, NoSQL база данных)"]
    D -- Бинарные данные / Wasm-БД --> J["OPFS<br/>(Файлы, sync-доступ в Workers)"]
    D -- Файлы / Ответы сети --> I["Cache API<br/>(Для Service Workers и PWA)"]
```
