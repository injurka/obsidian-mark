# Обзор стратегий рендеринга

Стратегия рендеринга определяет, **где** и **когда** генерируется HTML для веб-приложения.

## Базовые стратегии

- [[CSR — Client-Side Rendering]] — рендеринг полностью на клиенте
- [[SSR — Server-Side Rendering]] — генерация HTML на сервере при каждом запросе
- [[SSG — Static Site Generation]] — генерация HTML на этапе сборки
- [[ISR — Incremental Static Regeneration]] — инкрементальное обновление статики
- [[Edge Rendering]] — рендеринг на edge-нодах CDN

## Гидратация и серверные UI-модели

- [[Hydration]] — привязка JS-обработчиков к серверному HTML
- [[Partial Hydration]] — частичная гидратация
- [[Progressive Hydration]] — прогрессивная гидратация
- [[Islands Architecture]] — архитектура островов
- [[Resumability]] — возобновляемость (Qwik)
- [[Streaming SSR]] — потоковый SSR
- [[Server Components]] — серверные компоненты (React RSC & Nuxt Server Components)
- [[Server Actions]] — серверные действия (Next.js Actions & Nuxt Nitro Handlers)

> Все стратегии и модели в данных заметках подкреплены сравнительными примерами и паттернами как для **React / Next.js**, так и для **Vue 3 / Nuxt 3**.
