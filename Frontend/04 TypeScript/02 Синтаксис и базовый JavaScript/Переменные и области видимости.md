# Переменные и области видимости

## Описание

> [!info] 
> **Переменные** — это именованные хранилища для данных. **Область видимости (scope)** определяет, где в коде эта переменная доступна для использования.

В JavaScript существует три ключевых слова для объявления переменных: `var`, `let` и `const`. 
- **`var`** имеет функциональную или глобальную область видимости и подвержен "всплытию" (hoisting), из-за чего его использование в современном коде не рекомендуется.
- **`let`** и **`const`** имеют блочную область видимости (ограничены фигурными скобками `{}`) и не инициализируются до строки их объявления. `const` требует обязательной инициализации при объявлении и не позволяет переназначить значение (но объекты и массивы по ссылке можно изменять).

В TypeScript переменным можно задавать типы, что позволяет отлавливать ошибки несоответствия типов еще на этапе компиляции. Если тип не указан явно, TypeScript пытается вывести его автоматически (type inference).

## Примеры использования

```typescript
// Явное указание типов
let userName: string = "Алиса";
let userAge: number = 28;

// Вывод типов (Type inference)
let isOnline = true; // TypeScript понимает, что это boolean

// Использование const для объектов
const config: { endpoint: string, timeout: number } = {
    endpoint: "https://api.example.com",
    timeout: 5000
};

// Свойства объекта, объявленного через const, можно изменять:
config.timeout = 10000; 

// Блочная область видимости
function calculate(value: number) {
    if (value > 0) {
        let result = value * 2;
        const factor = 1.5;
        console.log(result * factor);
    }
    // Ошибка: Cannot find name 'result'.
    // console.log(result); 
}
```

## Особенности и нюансы

- **Всплытие (Hoisting):** Переменные `var` всплывают со значением `undefined`. Переменные `let` и `const` также всплывают, но попадают в "временную мертвую зону" (Temporal Dead Zone, TDZ), и обращение к ним до инициализации вызовет ошибку ReferenceError.
- **Shadowing (Затенение):** Вложенные области видимости могут объявлять переменные с тем же именем, что и во внешней области, скрывая ("затеняя") внешнюю переменную внутри блока.
- **`const` не делает объект неизменяемым:** Он лишь защищает саму ссылку от переназначения. Чтобы сделать объект полностью неизменяемым, в TypeScript можно использовать утилиту `as const` или тип `Readonly<T>`.
