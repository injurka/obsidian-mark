# Функции

## Описание

> [!info] 
> **Функция** — это переиспользуемый блок кода, предназначенный для выполнения определенной задачи. В JavaScript функции являются объектами первого класса (first-class citizens).

Функции в JavaScript могут быть объявлены несколькими способами: Function Declaration, Function Expression и стрелочные функции (Arrow Functions). 

В TypeScript функции получают строгую типизацию. Вы можете и должны типизировать как принимаемые аргументы, так и возвращаемое значение функции. Это обеспечивает безопасность вызовов и предсказуемость поведения. Если функция ничего не возвращает, используется тип `void`. Также TypeScript поддерживает необязательные параметры, параметры по умолчанию и rest-параметры.

## Примеры использования

```typescript
// Function Declaration с типизацией аргументов и возвращаемого значения
function greet(name: string, greeting: string = "Hello"): string {
    return `${greeting}, ${name}!`;
}

// Стрелочная функция
const multiply = (a: number, b: number): number => a * b;

// Необязательные параметры (помечаются знаком вопроса)
function printUser(name: string, age?: number): void {
    if (age) {
        console.log(`User: ${name}, Age: ${age}`);
    } else {
        console.log(`User: ${name}`);
    }
}

// Rest-параметры
function sumAll(...numbers: number[]): number {
    return numbers.reduce((acc, current) => acc + current, 0);
}

// Типизация самой функции как типа
type MathOperation = (x: number, y: number) => number;

const divide: MathOperation = (x, y) => {
    if (y === 0) throw new Error("Division by zero");
    return x / y;
};
```

## Особенности и нюансы

- **Стрелочные функции и контекст (`this`):** Стрелочные функции не имеют собственного контекста `this`. Они берут его из окружающего лексического окружения, что делает их идеальными для коллбэков, но неподходящими для методов объектов, где важен контекст объекта.
- **Перегрузка функций:** TypeScript поддерживает перегрузку функций (Function Overloading) — возможность определить несколько сигнатур типов для одной функции, чтобы обрабатывать разные типы входных данных.
- **Тип `never`:** Если функция никогда не завершается успешно (например, всегда бросает исключение или содержит бесконечный цикл), ее возвращаемым типом в TypeScript является `never`.
