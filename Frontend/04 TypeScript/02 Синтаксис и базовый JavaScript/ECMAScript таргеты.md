# ECMAScript таргеты

## Описание

> [!info] 
> ECMAScript таргет (настройка `target` в `tsconfig.json`) — это указание компилятору TypeScript на то, в какую именно версию стандарта JavaScript (ES3, ES5, ES6/ES2015, ESNext и т.д.) должен быть скомпилирован исходный код.

TypeScript позволяет использовать самые современные возможности JavaScript и синтаксис (например, классы, стрелочные функции, `async/await`), даже если целевая платформа (старый браузер или старая версия Node.js) их не поддерживает. Компилятор преобразует современный синтаксис в эквивалентный код указанной версии. Однако важно понимать, что TypeScript преобразует только синтаксис, но не добавляет полифиллы для новых API (например, `Promise`, `Map`, `Array.prototype.includes`).

## Примеры использования

Пример конфигурации в `tsconfig.json`:
```json
{
  "compilerOptions": {
    "target": "ES5",
    "module": "CommonJS",
    "strict": true
  }
}
```

Пример трансформации кода (исходный TypeScript код):
```typescript
const greet = (name: string) => `Hello, ${name}`;
```

Скомпилированный JavaScript (target: "ES5"):
```javascript
var greet = function (name) { return "Hello, ".concat(name); };
```

Скомпилированный JavaScript (target: "ES2015" или новее):
```javascript
const greet = (name) => `Hello, ${name}`;
```

## Особенности и нюансы

- **Разница между `target` и `lib`**: `target` определяет синтаксис скомпилированного кода. Настройка `lib` определяет, какие встроенные API (библиотеки типов) доступны в TypeScript во время проверки типов. Если `target` низкий, но используются новые API (например, `Promise`), нужно добавить их в `lib` и самостоятельно подключить полифиллы в проекте.
- **Синтаксические полифиллы**: Для некоторых возможностей (например, итераторы или `async/await` в ES5) TypeScript генерирует много вспомогательного кода. Использование флага `importHelpers` совместно с библиотекой `tslib` позволяет уменьшить размер итогового бандла.
- **Современные стандарты**: В современной разработке чаще всего используются таргеты `ES2015` (ES6) или выше, так как большинство современных браузеров и актуальные версии Node.js полностью их поддерживают.
