# Итераторы и генераторы

## Описание

> [!info] 
> Итераторы — это объекты, реализующие протокол итерации (`next()`), позволяющие последовательно обходить коллекции. Генераторы — это специальные функции (объявляются через `function*`), которые могут приостанавливать свое выполнение (через `yield`) и возвращать генератор-итератор.

В TypeScript генераторы и итераторы строго типизируются, что позволяет явно указывать тип возвращаемых значений, значений, передаваемых обратно в генератор, и типа возвращаемого значения при завершении (`return`).

## Примеры использования

```typescript
// Типизация генератора: Generator<T, TReturn, TNext>
// T - тип отдаваемых (yield) значений
// TReturn - тип возвращаемого (return) значения
// TNext - тип принимаемых через .next(val) значений

function* numberGenerator(): Generator<number, string, boolean> {
  let i = 0;
  while (i < 3) {
    // yield отдает число. В переменную nextPassed попадет boolean из next(true/false)
    const nextPassed = yield i++;
    if (nextPassed) {
      console.log('Skipping!');
      i++;
    }
  }
  return "Done!";
}

const gen = numberGenerator();

console.log(gen.next()); // { value: 0, done: false }
console.log(gen.next(true)); // Skipping! -> { value: 2, done: false }
console.log(gen.next(false)); // { value: "Done!", done: true }

// Создание итерируемого объекта (Iterable)
class CustomCollection implements Iterable<string> {
  private items: string[] = ["A", "B", "C"];

  [Symbol.iterator](): Iterator<string> {
    let index = 0;
    return {
      next: () => {
        if (index < this.items.length) {
          return { value: this.items[index++], done: false };
        } else {
          return { value: undefined, done: true };
        }
      }
    };
  }
}

const collection = new CustomCollection();
for (const item of collection) {
  console.log(item); // A, B, C
}
```

## Особенности и нюансы

- Генераторы удобны для ленивой генерации бесконечных последовательностей или сложной итерационной логики.
- `Symbol.iterator` — это встроенный символ, который указывает функцию, возвращающую итератор для объекта. Именно он позволяет объекту работать в циклах `for...of` и с оператором spread (`...`).
- Асинхронные генераторы (`async function*`) и асинхронные итераторы (`for await...of`) используются для обработки потоков асинхронных данных. В TS они типизируются как `AsyncGenerator<T>`.
