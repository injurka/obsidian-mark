# Rest и Spread

## Описание

> [!info] 
> Операторы `...` (Rest и Spread) в JavaScript позволяют собирать элементы в массив или объект (Rest) и разворачивать массивы или объекты на отдельные элементы (Spread). В TypeScript они полностью типизированы и помогают писать гибкий, безопасный код.

- **Spread (`...` при вызове или создании)** позволяет "распаковать" элементы итерабельного объекта (массива или строки) или свойства объекта в другой массив/объект или аргументы функции. Это удобно для копирования и слияния структур.
- **Rest (`...` в параметрах функции или при деструктуризации)** позволяет "упаковать" оставшиеся элементы в один массив или оставшиеся свойства в один объект.

В TypeScript типы для Rest параметров в функциях всегда должны быть массивами или кортежами, а Spread корректно объединяет интерфейсы.

## Примеры использования

```typescript
// --- Spread оператор ---

// Копирование и слияние массивов
const arr1: number[] = [1, 2];
const arr2: number[] = [3, 4];
const combinedArray: number[] = [...arr1, ...arr2, 5]; // [1, 2, 3, 4, 5]

// Копирование и слияние объектов (поверхностное копирование)
interface Person { name: string; age: number; }
const person: Person = { name: "Bob", age: 25 };
const updatedPerson = { ...person, age: 26, role: "user" }; 
// Тип: { name: string; age: number; role: string; }

// --- Rest параметр ---

// В функциях: сбор неограниченного числа аргументов в массив
function sum(...numbers: number[]): number {
  return numbers.reduce((acc, curr) => acc + curr, 0);
}
console.log(sum(1, 2, 3, 4)); // 10

// В деструктуризации объектов
const config = { host: "localhost", port: 8080, secure: true };
const { host, ...restConfig } = config; 
// restConfig имеет тип { port: number; secure: boolean; }

// Использование Spread при вызове функции с кортежами (Tuples)
function multiply(x: number, y: number, z: number) {
    return x * y * z;
}
const args: [number, number, number] = [2, 3, 4];
console.log(multiply(...args)); // 24
```

## Особенности и нюансы

- Оператор Spread выполняет **поверхностное (shallow) копирование**. Вложенные объекты и массивы копируются по ссылке, а не по значению.
- В TypeScript при использовании Spread для аргументов функции исходный массив должен быть типизирован как кортеж (Tuple), либо объявлен как `as const`, чтобы TypeScript точно знал количество и типы элементов.
- Rest-параметр в функции должен быть последним параметром: `function f(a: string, ...rest: number[])`.
- При слиянии объектов с помощью Spread, если ключи совпадают, последнее указанное значение переопределит предыдущие (справа налево). TypeScript это учтет при выводе типов.
