# Объекты

## Описание

> [!info] 
> **Объект** — это структура данных, позволяющая хранить коллекции пар "ключ-значение". Это основной строительный блок для представления сложных сущностей в коде.

В JavaScript объекты могут содержать свойства (данные) и методы (функции). Ключами объектов обычно выступают строки или символы (Symbol). 

В TypeScript работа с объектами выходит на новый уровень благодаря возможности строго описывать их структуру с помощью интерфейсов (`interface`) и псевдонимов типов (`type`). TypeScript проверяет наличие обязательных полей, их типы, а также запрещает доступ к неописанным свойствам объекта.

## Примеры использования

```typescript
// Описание структуры объекта через type
type Point = {
    x: number;
    y: number;
    z?: number; // Необязательное свойство
};

const p1: Point = { x: 10, y: 20 };

// Описание структуры объекта через interface
interface User {
    readonly id: number; // Свойство только для чтения
    name: string;
    isActive: boolean;
    greet(): void; // Метод объекта
}

const currentUser: User = {
    id: 1,
    name: "Евгений",
    isActive: true,
    greet() {
        console.log(`Привет, я ${this.name}`);
    }
};

// Ошибка: Cannot assign to 'id' because it is a read-only property.
// currentUser.id = 2; 

// Индексные сигнатуры (для объектов с неизвестным заранее набором ключей)
interface Dictionary {
    [key: string]: string;
}

const colors: Dictionary = {
    red: "#FF0000",
    green: "#00FF00"
};
```

## Особенности и нюансы

- **`type` против `interface`:** В TypeScript оба подхода используются для описания объектов. `interface` лучше подходит для публичных API библиотек, так как поддерживает слияние объявлений (Declaration Merging). `type` более гибок и позволяет использовать объединения (unions) и пересечения (intersections).
- **Структурная типизация (Duck Typing):** TypeScript использует структурную типизацию. Если объект имеет все свойства, требуемые интерфейсом, он считается совместимым с этим интерфейсом, даже если явно не был имплементирован.
- **Копирование объектов:** Стандартное присваивание объектов в JavaScript происходит по ссылке. Для поверхностного копирования используются оператор Spread (`...`) или `Object.assign()`. Для глубокого копирования часто применяется `structuredClone()` или сторонние библиотеки.
