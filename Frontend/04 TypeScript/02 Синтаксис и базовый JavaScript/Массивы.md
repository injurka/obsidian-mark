# Массивы

## Описание

> [!info] 
> Массивы — это структуры данных, позволяющие хранить упорядоченные коллекции элементов. В JavaScript массивы могут содержать элементы разных типов, а в TypeScript типизация массивов позволяет строго задать тип элементов, обеспечивая безопасность типов на этапе компиляции.

В JavaScript массивы представляют собой объекты, в которых ключами являются числовые индексы. У массивов есть встроенное свойство `length` и множество методов для перебора, трансформации и модификации элементов (например, `map`, `filter`, `reduce`, `push`, `pop`).
В TypeScript тип массива можно задать двумя способами: `Type[]` или `Array<Type>`. TypeScript строго следит за тем, чтобы в массив добавлялись только элементы указанного типа. Также TypeScript поддерживает `ReadonlyArray` для неизменяемых массивов и кортежи (Tuples) для массивов с фиксированным количеством элементов и известными типами по каждому индексу.

## Примеры использования

```typescript
// Определение массивов в TypeScript
const numbers: number[] = [1, 2, 3, 4, 5];
const strings: Array<string> = ["hello", "world"];

// Массивы с несколькими типами (Union)
const mixed: (number | string)[] = [1, "two", 3, "four"];

// Использование ReadonlyArray (нельзя изменять массив)
const readonlyNumbers: ReadonlyArray<number> = [1, 2, 3];
// readonlyNumbers.push(4); // Ошибка TypeScript

// Кортежи (Tuples) - массивы с фиксированной длиной и типами
const user: [number, string] = [1, "John"];
// user[0] = "error"; // Ошибка TypeScript (ожидается number)

// Многомерные массивы
const matrix: number[][] = [
  [1, 2, 3],
  [4, 5, 6]
];
```

## Особенности и нюансы

- В TypeScript массивы передаются по ссылке, как и в JavaScript. Изменение массива внутри функции отразится на оригинальном массиве.
- Метод `Array.isArray()` возвращает `true` для массивов. В TypeScript он также выступает в качестве type guard.
- Использование `ReadonlyArray<T>` или модификатора `readonly T[]` полезно, когда необходимо гарантировать неизменяемость данных в функции.
- Кортежи (Tuples) позволяют задавать опциональные элементы (например, `[number, string?]`) или rest-элементы (например, `[string, ...number[]]`).
- Стоит избегать использования типа `any[]`, так как это полностью отключает проверку типов.
