# Версии TypeScript и нововведения

## Описание

> [!info] 
> Хронология развития TypeScript, ключевые версии и их главные нововведения.

В этом разделе собрана история изменений языка TypeScript, чтобы понимать, в какой версии появились те или иные возможности.

## Ключевые релизы

### TypeScript 5.0 (Март 2023)
- **Декораторы стандарта ECMAScript:** Поддержка нового стандарта декораторов.
- **Оптимизация производительности:** Уменьшение размера пакета и ускорение сборки.
- **const Type Parameters:** Возможность добавления модификатора `const` к параметрам типа (`<const T>`), что улучшает вывод типов для литералов.

### TypeScript 4.9 (Ноябрь 2022)
- **Оператор `satisfies`:** Позволяет проверить, соответствует ли выражение определенному типу, не изменяя (не расширяя) при этом сам выведенный тип.
- Улучшения в `in` операторе для сужения неявных типов `unknown`.

### TypeScript 4.5 (Ноябрь 2021)
- **Тип `Awaited`:** Встроенный утилитный тип для разворачивания `Promise`.
- **Поддержка `node12` и `nodenext`:** Улучшенная работа с ESM в Node.js.

### TypeScript 4.1 (Ноябрь 2020)
- **Template Literal Types (Шаблонные литеральные типы):** Позволяют создавать новые строковые типы на основе существующих.
- **Key Remapping в Mapped Types:** Возможность переименовывать ключи при создании новых типов через `as`.
