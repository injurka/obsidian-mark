# Полезные ссылки

## Описание

> [!info] 
> Кураторский список полезных ресурсов, статей, курсов и инструментов для изучения и работы с TypeScript.

Этот раздел содержит материалы, которые помогут углубить знания языка и следить за его развитием.

## Официальные ресурсы
- [Официальный сайт TypeScript](https://www.typescriptlang.org/) — главная страница.
- [TypeScript Handbook](https://www.typescriptlang.org/docs/handbook/intro.html) — официальное руководство, лучшее место для старта.
- [TypeScript Playground](https://www.typescriptlang.org/play) — онлайн-песочница для тестирования кода и просмотра сгенерированного JS.
- [Репозиторий TypeScript на GitHub](https://github.com/microsoft/TypeScript) — исходный код, обсуждения и issues.

## Книги и курсы
- **Programming TypeScript** (Boris Cherny) — отличная книга для глубокого понимания системы типов.
- **Effective TypeScript** (Dan Vanderkam) — советы и лучшие практики по написанию качественного кода на TypeScript.
- [Total TypeScript](https://www.totaltypescript.com/) — продвинутые курсы и материалы от Matt Pocock.

## Инструменты и шпаргалки
- [TS AST Viewer](https://ts-ast-viewer.com/) — инструмент для просмотра абстрактного синтаксического дерева (AST) TypeScript.
- [React+TypeScript Cheatsheets](https://react-typescript-cheatsheet.netlify.app/) — исчерпывающая шпаргалка по использования TS в React.
