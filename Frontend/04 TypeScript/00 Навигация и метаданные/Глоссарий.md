# Глоссарий

## Описание

> [!info] 
> Глоссарий терминов и понятий TypeScript — единый справочник для всех основных определений, используемых в языке.

Глоссарий содержит краткие определения и ссылки на более подробные статьи по ключевым терминам TypeScript, таким как типы, интерфейсы, дженерики, сужение типов (narrowing), и т.д.

## Термины

### Типы и структуры
- **Type Alias (Псевдоним типа):** Имя для любого типа. Позволяет создавать сложные типы, объединения и пересечения.
- **Interface (Интерфейс):** Способ описания формы объекта. В отличие от type, может расширяться через слияние деклараций.
- **Generics (Дженерики):** Параметризованные типы, позволяющие писать переиспользуемый код, работающий с различными типами данных.

### Продвинутые концепции
- **Narrowing (Сужение типов):** Процесс уточнения типа переменной в определенном блоке кода (например, с помощью `typeof` или `instanceof`).
- **Widening (Расширение типов):** Процесс, при котором TypeScript выводит более общий тип (например, `string` вместо литерала `"hello"`).
- **Variance (Ковариантность, Контравариантность и Бивариантность):** Правила, определяющие, когда типы могут быть заменены друг на друга при наследовании и передаче параметров.
- **Soundness (Надежность):** Гарантия того, что программа на этапе выполнения не упадет с ошибкой типа, если она успешно прошла проверку типов. TypeScript обладает *частичной* надежностью (unsoundness) ради удобства разработчиков.
