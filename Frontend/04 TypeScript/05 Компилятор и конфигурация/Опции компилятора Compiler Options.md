# Опции компилятора Compiler Options

> [!info]
> **Compiler Options** — это секция `compilerOptions` в файле конфигурации `tsconfig.json`, содержащая список параметров, которые управляют поведением процесса проверки типов и трансляции (генерации) JavaScript.

## Суть концепции

TypeScript чрезвычайно гибок. Опции компилятора позволяют разработчику адаптировать TypeScript под конкретную среду выполнения (браузер, Node.js), выбрать формат модулей и уровень строгости проверок.

### Ключевые опции компилятора

1. **`target`**: Указывает версию ECMAScript, в которую будет скомпилирован код. Например, `ES6`, `ES2022`, `ESNext`. Если среда поддерживает современные функции JS, лучше выбирать более новые стандарты.
2. **`module`**: Задает систему модулей в сгенерированном коде. Например, `CommonJS` (для старых версий Node.js), `ESNext` или `NodeNext`.
3. **`outDir`**: Директория, куда будут помещены все скомпилированные `.js` и `.d.ts` файлы.
4. **`rootDir`**: Базовая директория для вычисления относительных путей. Обычно указывает на папку с исходным кодом (`./src`).
5. **`lib`**: Массив стандартных библиотек типов (например, `["DOM", "ES2022"]`), которые должны быть доступны в глобальном пространстве имен.

### Пример настройки

```json
{
  "compilerOptions": {
    "target": "ES2020",
    "module": "ESNext",
    "outDir": "./build",
    "rootDir": "./src",
    "lib": ["DOM", "ES2020"],
    
    // Важнейшая опция для безопасности кода
    "strict": true,
    
    // Опции для работы с декларациями (.d.ts)
    "declaration": true,
    "declarationMap": true
  }
}
```

### Strict Mode и Ambient Declarations
Среди опций компилятора флаг `"strict": true` является фундаментальным. Он объединяет множество проверок безопасности. Также компилятор позволяет настраивать обработку глобального контекста и ambient-деклараций (`declare module ...`) через опции `typeRoots` и `types`, обеспечивая корректное подключение файлов окружения `.d.ts`.
