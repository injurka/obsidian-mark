# Продвинутые опции компиляции

> [!info]
> Продвинутые опции компиляции TypeScript — это специфические настройки в `tsconfig.json`, предназначенные для оптимизации процесса сборки, интеграции со сложными инструментами и тонкой настройки поведения транслятора.

## Суть концепции

В дополнение к базовым опциям, TypeScript предоставляет ряд параметров для особых случаев использования: работа с декораторами, ускорение сборки монорепозиториев, интеграция с Babel/SWC и специфическая обработка путей.

### Важные продвинутые опции

- **`isolatedModules`**: Гарантирует, что каждый файл может быть безопасно транспилирован без знания контекста других файлов. Это критически важно при использовании внешних инструментов (например, Vite, Babel, esbuild, SWC) для генерации кода вместо `tsc`.
- **`incremental`**: Сохраняет информацию о предыдущих компиляциях в файл `.tsbuildinfo`, чтобы ускорить последующие запуски `tsc`. Очень полезно в крупных проектах.
- **`experimentalDecorators` / `emitDecoratorMetadata`**: Включает поддержку декораторов (legacy-стиль) и генерацию метаданных для типов, что активно используется в таких фреймворках, как NestJS и Angular.
- **`paths` и `baseUrl`**: Позволяют настраивать алиасы (псевдонимы) для импортов, избавляя от "ада относительных путей" (например, `import { util } from "@utils/index"`).
- **`resolveJsonModule`**: Позволяет напрямую импортировать данные из `.json` файлов, предоставляя им строгую типизацию на лету.

### Пример конфигурации

```json
{
  "compilerOptions": {
    "strict": true,
    "isolatedModules": true,
    "incremental": true,
    "experimentalDecorators": true,
    "emitDecoratorMetadata": true,
    "baseUrl": "./src",
    "paths": {
      "@components/*": ["components/*"],
      "@utils/*": ["utils/*"]
    }
  }
}
```

### Связь со Strict Mode и декларациями
При использовании продвинутых алиасов через `paths` или опции `isolatedModules`, компилятор всё равно продолжает подчиняться правилам `Strict Mode`. Для внешних нетипизированных зависимостей, импортируемых через пути, разработчику может потребоваться написание `.d.ts` файлов с `declare module "..."` (ambient context) для корректного разрешения типов.
