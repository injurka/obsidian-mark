# tsc CLI и команды

> [!info]
> `tsc` (TypeScript Compiler) — это консольная утилита и компилятор TypeScript, который транспилирует код `.ts` в обычный `.js`, а также выполняет статическую проверку типов.

## Суть концепции

Интерфейс командной строки `tsc` позволяет компилировать проект, опираясь на параметры из `tsconfig.json`, или через передачу аргументов напрямую. Его основная задача — проанализировать исходный код, проверить его на наличие типовых ошибок и сгенерировать JavaScript (а также `.d.ts` декларации, если это настроено).

### Основные команды и использование

- **Инициализация проекта:**
  ```bash
  tsc --init
  ```
  Создает базовый файл `tsconfig.json` с дефолтными настройками и комментариями ко всем доступным опциям.

- **Компиляция проекта:**
  ```bash
  tsc
  ```
  Запускает компиляцию всего проекта. Компилятор будет искать `tsconfig.json` в текущей и родительских директориях.

- **Режим наблюдения (Watch Mode):**
  ```bash
  tsc --watch
  # или
  tsc -w
  ```
  Компилятор остается запущенным в фоне и пересобирает файлы при их изменении. Это ускоряет процесс разработки.

- **Проверка типов без генерации файлов:**
  ```bash
  tsc --noEmit
  ```
  Часто используется в связке с бандлерами (например, Vite, Webpack). Бандлер собирает код, а `tsc` работает исключительно как тайп-чекер (Type Checker).

### Важность Strict Mode и Деклараций
При вызове `tsc`, компилятор считывает из `tsconfig.json` такие флаги, как `"strict": true`. Также `tsc` автоматически подключает файлы деклараций (`.d.ts`) из директорий `typeRoots`, чтобы понимать типы внешних библиотек и ambient-контексты (описанные через `declare`).
