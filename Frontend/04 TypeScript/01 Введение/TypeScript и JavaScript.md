# TypeScript и JavaScript

## Описание

> [!info] 
> TypeScript — это синтаксическое надмножество JavaScript. Это означает, что любой валидный код на JavaScript (с некоторыми оговорками) является валидным кодом на TypeScript. TS расширяет JS, добавляя строгие типы, интерфейсы, дженерики и другие конструкции статического анализа.

Связь между TypeScript и JavaScript заключается в том, что TS в итоге всегда транспилируется в чистый JS. TypeScript не имеет собственного движка выполнения, он полагается на JavaScript-среды (браузеры, Node.js). Основная задача TypeScript — исчезнуть после проверки типов, оставив за собой оптимизированный и синтаксически корректный JavaScript.

## Примеры использования

```typescript
// Это валидный код как на JS, так и на TS
const jsVariable = 42;
console.log(jsVariable);

// Это чисто TypeScript-конструкции, которые исчезнут после компиляции
type ID = string | number;

function printId(id: ID): void {
    console.log("Your ID is: " + id);
}

printId(101); // Валидно
printId("202"); // Валидно
// printId({ myId: 123 }); // Ошибка TS
```

## Особенности и нюансы

- **Постепенное внедрение (Gradual Typing)**: Вы можете переводить проект с JS на TS постепенно, настраивая строгость с помощью опций `allowJs` и `strict`.
- **Любой JS — это TS**: Вы можете взять `.js` файл, переименовать его в `.ts`, и он будет работать (возможно, с предупреждениями компилятора, которые можно исправить).
- **Подводный камень (Ощущение безопасности)**: TypeScript обеспечивает типобезопасность только на этапе компиляции. Если данные приходят извне (например, по API), и они не валидируются в рантайме (например, через Zod или Joi), TypeScript не спасет от рантайм-ошибки.
