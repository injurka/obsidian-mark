# Зачем нужен TypeScript

## Описание

> [!info] 
> TypeScript — это строго типизированный язык программирования, являющийся надмножеством JavaScript. Он добавляет статическую типизацию, что позволяет отлавливать ошибки на этапе компиляции, улучшать автодополнение и рефакторинг в IDE, а также делать код более предсказуемым и самодокументируемым.

TypeScript был создан Microsoft для решения проблем масштабируемости JavaScript в крупных проектах. JavaScript — язык с динамической типизацией, где ошибки типов часто обнаруживаются только во время выполнения (runtime). TypeScript решает эту проблему за счет статического анализатора (компилятора `tsc`), который проверяет типы до запуска кода. В результате, разработчики получают быстрый фидбэк, а качество кодовой базы существенно возрастает.

## Примеры использования

```typescript
// Без TypeScript (JS) мы могли бы передать что угодно
function greet(user) {
    return "Hello, " + user.name.toUpperCase();
}
// greet(null) упадет в рантайме!

// С TypeScript ошибка отлавливается на этапе написания
interface User {
    name: string;
}

function greetTS(user: User): string {
    return "Hello, " + user.name.toUpperCase();
}

// greetTS(null); // Ошибка компиляции: Argument of type 'null' is not assignable to parameter of type 'User'.
```

## Особенности и нюансы

- **Ошибки на этапе компиляции**: Позволяет найти баги до того, как код попадет к пользователю.
- **Самодокументация**: Типы описывают контракты данных, облегчая онбординг новых разработчиков.
- **Поддержка современных фич**: TypeScript позволяет использовать новейшие фичи ECMAScript, компилируя их в совместимый с более старыми средами JavaScript.
- **Подводный камень (Over-engineering)**: Избыточная типизация может замедлить разработку простых прототипов.
- **Дополнительный этап сборки**: Код на TypeScript нельзя напрямую запустить в браузере (за исключением Deno/Bun), требуется компиляция (или транспиляция) в JavaScript.
