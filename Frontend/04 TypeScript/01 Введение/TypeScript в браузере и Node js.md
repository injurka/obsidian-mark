# TypeScript в браузере и Node.js

## Описание

> [!info] 
> Ни браузеры, ни стандартный Node.js (до экспериментальных версий) не умеют напрямую исполнять файлы `.ts`. TypeScript-код должен быть преобразован (скомпилирован или транспилирован) в JavaScript, прежде чем он сможет быть выполнен в этих средах выполнения.

Процесс разработки с использованием TypeScript требует наличия инструмента для сборки и компиляции. В экосистеме существует несколько подходов:
1. Использование официального компилятора `tsc` для генерации `.js` файлов.
2. Использование сборщиков (Webpack, Rollup, Vite) с плагинами для TS (ts-loader, esbuild).
3. Использование сред, которые на лету транслируют TS (например, `ts-node`, `tsx` для Node.js).
Существуют и современные среды выполнения, такие как Deno и Bun, которые имеют встроенную поддержку выполнения TypeScript-файлов из коробки.

## Примеры использования

```typescript
// Пример кода, который будет по-разному собираться для фронтенда и бэкенда

// Для Node.js (импорты специфичны для среды)
import * as fs from 'fs';

export function readConfig(path: string): string {
    return fs.readFileSync(path, 'utf-8');
}

// Для браузера (взаимодействие с DOM)
export function updateHeader(title: string): void {
    const header = document.querySelector('h1');
    if (header) {
        header.textContent = title;
    }
}
```

## Особенности и нюансы

- **Поддержка DOM API**: TypeScript включает встроенные декларации типов (`lib.dom.d.ts`) для работы с браузерным API из коробки.
- **Node.js типы**: Для работы с Node.js необходимо установить пакет `@types/node`, так как встроенные модули Node (`fs`, `path`, `http`) не типизированы по умолчанию в стандартном TS.
- **Настройка tsconfig.json**: Опции `target` (версия JS) и `module` (система модулей: CommonJS, ESNext) критически важны и настраиваются по-разному в зависимости от того, пишем мы под браузер или под Node.js.
- **Подводный камень**: Использование специфичных для Node.js типов в браузерном коде приведет к ошибкам в рантайме, хотя TS может пропустить код, если не настроено изолированное окружение (tsconfig `lib` опция).
