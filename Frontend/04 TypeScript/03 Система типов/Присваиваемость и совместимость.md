# Присваиваемость и совместимость

## Описание

> [!info] 
> Присваиваемость (Assignability) и совместимость (Compatibility) определяют, можно ли значение одного типа использовать там, где ожидается другой тип.

TypeScript использует структурную типизацию (structural typing), также известную как "утиная типизация" (duck typing). Это означает, что совместимость типов определяется их структурой (членами и их типами), а не явным наследованием.

## Суть концепции

Если тип `A` содержит все свойства типа `B` с совместимыми типами, то `A` совместим с `B`, и значение типа `A` можно присвоить переменной типа `B`.

### Пример совместимости

```typescript
interface Animal {
  name: string;
}

interface Dog {
  name: string;
  breed: string;
}

let animal: Animal;
let dog: Dog = { name: "Buddy", breed: "Golden" };

// Допустимо, так как Dog имеет все необходимые свойства Animal
animal = dog; 

// Ошибка: Animal не имеет свойства breed, требуемого в Dog
// dog = animal; 
```

## Особенности и нюансы

- **Функции:** Совместимость функций зависит от их аргументов (контравариантность) и возвращаемого значения (ковариантность). Функция с меньшим числом параметров может быть присвоена функции с большим числом параметров (если их типы совместимы).
- **Свежие литералы объектов (Fresh Object Literals):** При присваивании свежих объектов TypeScript выполняет строгую проверку избыточных свойств (Excess Property Checking), чтобы предотвратить опечатки.

```typescript
function printAnimal(a: Animal) {
  console.log(a.name);
}

// Ошибка из-за избыточного свойства
// printAnimal({ name: "Lucy", breed: "Poodle" });

// Работает, так как объект уже существует и проверка мягче
const myDog = { name: "Lucy", breed: "Poodle" };
printAnimal(myDog);
```
