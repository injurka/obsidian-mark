# Вывод типов

## Описание

> [!info] 
> Вывод типов (Type Inference) — способность компилятора TypeScript автоматически определять тип переменной, функции или свойства на основе присвоенного значения или контекста.

Благодаря выводу типов можно избежать написания явных аннотаций типов в большинстве случаев. Это делает код чище и лаконичнее, сохраняя при этом все преимущества статической типизации.

## Примеры использования

```typescript
// Тип выводится как `number`
let x = 3;

// Тип выводится как `number[]`
let arr = [0, 1, null]; // Если strictNullChecks включен, выведется `(number | null)[]`

// Возвращаемый тип выводится как `number`
function add(a: number, b: number) {
  return a + b;
}
```

## Особенности и нюансы

- **Лучший общий тип (Best common type):** При выводе типов для массива из разных элементов TypeScript пытается найти базовый тип, совместимый со всеми элементами массива. Если такого общего типа нет (кроме объединения), выводится объединение типов (Union type).
- **Контекстная типизация:** Вывод типов работает в обе стороны: не только от значения к переменной, но и от контекста переменной к ее значению (см. [[Контекстная типизация]]).
- Рекомендуется полагаться на вывод типов и не указывать типы явно, если компилятор справляется сам. Исключения составляют возвращаемые типы публичных функций и сложных объектов, где явное указание типа помогает избежать ошибок в реализации.
