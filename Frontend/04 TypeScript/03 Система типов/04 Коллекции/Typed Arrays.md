# Typed Arrays

## Описание

> [!info]
> Typed Arrays (Типизированные массивы) — это встроенный механизм JavaScript (и TypeScript) для работы с сырыми бинарными данными в памяти с использованием структур, похожих на массивы.

В TypeScript типизированные массивы описываются с помощью глобальных интерфейсов (`Uint8Array`, `Float32Array` и т.д.), которые предоставляют строгую типизацию для операций с бинарными буферами.

## Примеры использования

```typescript
// Создание буфера на 16 байт
const buffer = new ArrayBuffer(16);

// Создание представления (view) в виде массива 32-битных целых чисел
const int32View = new Int32Array(buffer);

// Запись данных (каждое число займет 4 байта)
int32View[0] = 42;
int32View[1] = 100;

console.log(int32View[0]); // 42

// int32View[2] = "string"; // Ошибка TypeScript: Type 'string' is not assignable to type 'number'
```

## Особенности и нюансы

- Типы `Uint8Array`, `Int32Array` и другие являются **интерфейсами стандартной библиотеки (lib.d.ts)**. Они гарантируют, что элементы будут числами (`number`).
- Типизированные массивы имеют фиксированную длину (в отличие от обычных массивов) и не имеют методов вроде `push` или `pop`.
- В TypeScript нет встроенного способа на уровне системы типов ограничить диапазон чисел (например, чтобы `Uint8Array` принимал только числа от 0 до 255 на этапе компиляции), поэтому TypeScript позволяет присвоить любое `number`, а обрезание произойдет в рантайме.
