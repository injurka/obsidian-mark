# readonly кортежи

## Описание

> [!info]
> `readonly` кортежи — это кортежи, элементы которых не могут быть изменены (мутированы) после их создания.

Подобно `ReadonlyArray`, `readonly` кортежи обеспечивают иммутабельность на уровне системы типов TypeScript. Они гарантируют фиксированную длину и неизменяемость значений по каждому индексу.

## Примеры использования

```typescript
// Объявление через модификатор readonly
type Point = readonly [number, number];

const p: Point = [10, 20];
console.log(p[0]); // OK
// p[0] = 15; // Ошибка: Cannot assign to '0' because it is a read-only property
// p.push(30); // Ошибка: Property 'push' does not exist on type 'readonly [number, number]'

// Использование as const для создания readonly кортежа из литерала
const color = [255, 0, 0] as const;
// Тип color выводится как readonly [255, 0, 0]
// color[1] = 128; // Ошибка
```

## Особенности и нюансы

- Самый частый и удобный способ создания `readonly` кортежей "на лету" — использование `as const`.
- В отличие от обычных кортежей, которые по сути являются массивами под капотом (и имеют мутирующие методы, из-за чего их длина может измениться в рантайме вопреки типам!), `readonly` кортежи лишены таких методов, что делает их более безопасными и надежными.
- Мутабельные кортежи могут быть присвоены `readonly` кортежам, но не наоборот.
