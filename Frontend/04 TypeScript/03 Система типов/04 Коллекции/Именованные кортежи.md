# Именованные кортежи

## Описание

> [!info]
> Именованные кортежи (Labeled Tuples) — это фича TypeScript, позволяющая добавлять имена (метки) к элементам кортежа, улучшая читаемость и документирование кода.

Без именованных кортежей типы вида `[number, number]` не дают контекста (это координаты x/y или ширина/высота?). Именованные кортежи решают эту проблему, предоставляя подсказки в IDE.

## Примеры использования

```typescript
// Обычный кортеж
type Point = [number, number];

// Именованный кортеж
type NamedPoint = [x: number, y: number];

function draw(point: NamedPoint) {
  console.log(`Drawing at ${point[0]}, ${point[1]}`);
}

// При использовании функции в IDE мы увидим подсказки: draw(point: [x: number, y: number])
draw([10, 20]);
```

## Особенности и нюансы

- Метки в именованных кортежах нужны **исключительно для документации и подсказок в IDE**. Они не создают свойств в объекте во время выполнения, и вы все равно обращаетесь к элементам по индексу (`point[0]`), а не по имени (`point.x` — вызовет ошибку).
- Если вы добавляете метку одному элементу кортежа, вы должны добавить метки и всем остальным элементам. Нельзя смешивать именованные и неименованные элементы в одном кортеже.
- Очень полезны при типизации аргументов функций через `...args: [name: string, age: number]`.
