# Массивы

## Описание

> [!info]
> Массивы в TypeScript — это типизированные коллекции, элементы которых имеют один или несколько заранее определенных типов, что позволяет гарантировать консистентность данных.

TypeScript поддерживает строгую типизацию массивов, предотвращая случайное добавление элементов неверного типа и предоставляя автодополнение для методов массивов.

## Примеры использования

```typescript
// Два способа объявления:
let arr1: number[] = [1, 2, 3];
let arr2: Array<number> = [1, 2, 3]; // Generic синтаксис

// Массив с элементами разных типов (Union type)
let mixedArr: (number | string)[] = [1, "two", 3];

// Двумерный массив
let matrix: number[][] = [[1, 2], [3, 4]];

arr1.push(4); // OK
// arr1.push("5"); // Ошибка: Argument of type 'string' is not assignable to parameter of type 'number'
```

## Особенности и нюансы

- Синтаксис `type[]` обычно предпочтительнее `Array<type>` из-за его краткости, но они абсолютно взаимозаменяемы.
- Использование объединений типов (`(A | B)[]`) требует обязательных круглых скобок, иначе `A | B[]` будет интерпретировано как "тип A или массив типа B".
- По умолчанию TypeScript может вывести тип пустого массива как `any[]`, поэтому их всегда стоит явно типизировать при создании (`const arr: string[] = []`).
