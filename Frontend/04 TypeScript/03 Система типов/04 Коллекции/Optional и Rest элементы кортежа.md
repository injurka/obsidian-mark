# Optional и Rest элементы кортежа

## Описание

> [!info]
> Кортежи в TypeScript могут содержать необязательные элементы (Optional) с помощью знака `?` и оставшиеся элементы (Rest) с помощью `...`, делая их длину гибкой.

Это позволяет использовать кортежи для описания массивов переменной длины, но со строгой типизацией конкретных позиций, что особенно полезно при типизации параметров функций.

## Примеры использования

```typescript
// Опциональные элементы
type UserTuple = [string, number, boolean?];
const user1: UserTuple = ["Alice", 25]; // OK
const user2: UserTuple = ["Bob", 30, true]; // OK

// Rest элементы
type StringNumberTuple = [string, ...number[]];
const data1: StringNumberTuple = ["Scores", 100, 95, 80]; // OK
const data2: StringNumberTuple = ["Empty"]; // OK
```

## Особенности и нюансы

- **Опциональные элементы** (`?`) могут находиться только в конце кортежа, после всех обязательных элементов.
- Вы не можете получить доступ к опциональному элементу без проверки на `undefined`, так как его тип включает `undefined` (например, `boolean | undefined`).
- **Rest элементы** (`...`) могут находиться в любом месте кортежа (с TypeScript 4.2), например, `[...number[], string]` (сначала любое количество чисел, в конце одна строка).
