# Narrowing

## Описание

> [!info] 
> Narrowing (Сужение типов) — это процесс, при котором TypeScript статически анализирует поток выполнения кода (Control Flow Analysis) и постепенно сужает потенциально широкий тип до более специфичного.

Когда у вас есть переменная типа Union (например, `string | number`), вы не можете сразу вызывать специфичные методы (например, `.toLowerCase()`), так как они могут быть недоступны для всех типов в объединении. Narrowing позволяет "доказать" компилятору через условия в коде, какой именно тип сейчас находится в переменной, чтобы безопасно работать с ним.

## Примеры использования

```typescript
function padLeft(padding: number | string, input: string) {
  // На этом этапе padding имеет тип number | string
  
  if (typeof padding === "number") {
    // TypeScript сузил тип padding до number
    return " ".repeat(padding) + input;
  }
  
  // Здесь TypeScript понимает, что padding может быть только string
  return padding + input;
}
```

## Особенности и нюансы

- **Естественность**: Вам не нужно писать специальный "TypeScript-код" для сужения. Вы используете обычные JavaScript-конструкции (`typeof`, `instanceof`, `===`, `in`), и TypeScript понимает их семантику.
- **Взаимодействие с Control Flow Analysis**: Компилятор анализирует не только `if`/`else`, но и `switch`, `return`, `throw`, логические операторы (`&&`, `||`) для вычисления типа в каждой точке программы.
- **Никакого рантайм оверхеда**: Все проверки типов происходят с помощью стандартного JavaScript, нет никаких дополнительных невидимых преобразований.
