# in operator

## Описание

> [!info] 
> Оператор `in` в качестве Type Guard позволяет сузить тип, проверяя наличие определенного свойства в объекте на этапе выполнения.

JavaScript-оператор `in` возвращает `true`, если свойство присутствует в самом объекте или его цепочке прототипов. TypeScript использует это поведение, чтобы сужать Union-типы, отфильтровывая те типы, в которых данное свойство точно отсутствует.

## Примеры использования

```typescript
type Fish = { swim: () => void };
type Bird = { fly: () => void };

function move(animal: Fish | Bird) {
  if ("swim" in animal) {
    // TypeScript понимает, что это Fish
    animal.swim();
  } else {
    // TypeScript понимает, что это Bird
    animal.fly();
  }
}
```

## Особенности и нюансы

- **Опциональные свойства**: Если свойство в типе является опциональным (например, `a?: string`), проверка `"a" in obj` сузит тип, но если свойство отсутствует, это не значит, что объект принадлежит к другому типу из Union. Нужно быть внимательным.
- **Безопасность**: Это один из самых безопасных способов различать интерфейсы и неклассовые объекты в TypeScript, так как он не требует добавления искусственных полей (хотя Discriminant Property часто удобнее).
- **Различие `undefined` и отсутствия**: Оператор `in` вернет `true`, даже если значение свойства равно `undefined`. Он проверяет именно *наличие ключа*, а не его значение.
