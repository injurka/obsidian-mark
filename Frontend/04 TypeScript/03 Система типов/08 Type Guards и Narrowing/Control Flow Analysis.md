# Control Flow Analysis

## Описание

> [!info] 
> Control Flow Analysis (CFA, анализ потока управления) — это встроенный в TypeScript механизм статического анализа, который позволяет компилятору понимать, как меняется тип переменной по мере выполнения кода в различных ветвях (if, switch, return, throw).

Это "движок", который стоит за Narrowing. TypeScript проходит по графу выполнения вашей программы и на каждой строке вычисляет наиболее точный тип переменной, учитывая все пройденные проверки, возвраты из функции и присваивания.

## Примеры использования

```typescript
function analyze(x: string | number | boolean) {
  if (typeof x === "string") {
    return; // Выход из функции
  }
  
  // Здесь CFA понимает, что x уже не может быть string
  // Тип x сужен до: number | boolean
  
  x = 10;
  // CFA отслеживает переприсваивание. Теперь x точно number
  
  if (x === 10) {
    // Внутри блока тоже number
  }
}
```

## Особенности и нюансы

- **Reachability (Достижимость)**: CFA способен определять недостижимый код. Если после всех проверок тип переменной стал `never` (то есть все возможные варианты исчерпаны), компилятор может подсветить последующий код как мертвый.
- **Ограничения с замыканиями (Closures)**: CFA имеет трудности с функциями обратного вызова (колбэками). Если переменная сужена до определенного типа, а затем используется внутри колбэка, TypeScript может "забыть" сужение, потому что он не знает, когда именно выполнится колбэк (переменная могла быть изменена извне).
- **Проверки на исчерпываемость (Exhaustiveness checking)**: При использовании оператора `switch` по Discriminated Union, CFA помогает убедиться, что вы обработали все возможные случаи, присвоив оставшееся значение переменной типа `never`.
