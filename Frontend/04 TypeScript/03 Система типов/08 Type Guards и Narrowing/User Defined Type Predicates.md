# User Defined Type Predicates

## Описание

> [!info] 
> User Defined Type Predicates (пользовательские предикаты типов) — это функции, возвращающие булево значение, чья сигнатура возврата имеет специальный вид `parameterName is Type`, позволяющий TypeScript сужать типы.

Когда стандартных проверок (`typeof`, `in`) недостаточно, или когда логика проверки вынесена в отдельную функцию, TypeScript по умолчанию возвращает просто `boolean`, теряя контекст сужения. Чтобы научить TS сужать типы при вызове ваших проверочных функций, используется синтаксис предикатов типов.

## Примеры использования

```typescript
interface Fish { swim: () => void; }
interface Bird { fly: () => void; }

// Возвращаемый тип `pet is Fish` — это и есть Type Predicate
function isFish(pet: Fish | Bird): pet is Fish {
  return (pet as Fish).swim !== undefined;
}

function move(pet: Fish | Bird) {
  if (isFish(pet)) {
    // TypeScript знает, что здесь pet - это Fish
    pet.swim();
  } else {
    // А здесь - Bird
    pet.fly();
  }
}
```

## Особенности и нюансы

- **Ответственность на разработчике**: Как и в случае с `as`, TypeScript **доверяет** вашей реализации предиката. Если функция `isFish` написана неверно (например, возвращает `true` для `Bird`), компилятор этого не заметит, что приведет к ошибкам в рантайме.
- **Работа с массивами**: Предикаты часто используются вместе с методом `.filter()`. 
  `const fishes = pets.filter(isFish); // fishes получит тип Fish[]`
- **Проверка параметра**: Имя переменной в предикате (например, `pet is Fish`) должно точно совпадать с именем параметра функции.
