# Equality Narrowing

## Описание

> [!info] 
> Equality Narrowing (Сужение через равенство) — это механизм, при котором TypeScript использует операторы `===`, `!==`, `==` и `!=` для сужения типов.

Когда вы сравниваете две переменные (или переменную и литерал), TypeScript анализирует это сравнение. Если две переменные равны, это означает, что их типы должны пересекаться. TypeScript сузит типы обеих переменных до их общего пересечения в ветке `true`.

## Примеры использования

```typescript
function printValue(x: string | number, y: string | boolean) {
  if (x === y) {
    // x и y могут быть равны только в том случае, если они оба string!
    // TypeScript сужает их типы до string
    x.toUpperCase();
    y.toLowerCase();
  } else {
    console.log(x, y); // Типы остаются прежними
  }
}

function checkLiteral(state: "loading" | "success" | "error") {
  if (state === "success") {
    // Тип state сужен до "success"
  }
}
```

## Особенности и нюансы

- **Сравнение с `null` или `undefined`**: Использование `x != null` (нестрогое неравенство) является идиоматическим способом в TypeScript отсечь одновременно и `null`, и `undefined` (по правилам JS `null == undefined`).
- **Сравнение с литералами**: Очень часто используется в связке с Discriminant Property.
- **Ограничения**: Equality narrowing лучше всего работает с литеральными типами и примитивами. Сравнение объектов по ссылке (`obj1 === obj2`) не сужает структуру их типов, а лишь подтверждает, что это один и тот же инстанс.
