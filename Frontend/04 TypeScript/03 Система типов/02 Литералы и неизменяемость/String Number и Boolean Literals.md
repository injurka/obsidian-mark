# String Number и Boolean Literals

## Описание

> [!info]
> Литеральные типы в TypeScript — это типы, которые представляют собой одно конкретное значение примитива (строки, числа или логического значения), а не все возможные значения этого примитивного типа.

Литеральные типы позволяют разработчикам точно указывать, какое именно значение должна принимать переменная. Если переменная имеет тип `"hello"`, она может содержать только строку `"hello"` и ничего более. Комбинация литеральных типов с Union (объединениями) делает систему типов невероятно мощной.

## Примеры использования

```typescript
// Строковые литералы
let direction: "left" | "right" | "up" | "down";
direction = "up"; // OK
// direction = "diagonal"; // Ошибка: Type '"diagonal"' is not assignable...

// Числовые литералы
function rollDice(): 1 | 2 | 3 | 4 | 5 | 6 {
  return (Math.floor(Math.random() * 6) + 1) as 1 | 2 | 3 | 4 | 5 | 6;
}

// Логические литералы
let isTrue: true;
isTrue = true; // OK
// isTrue = false; // Ошибка
```

## Особенности и нюансы

- Идеально подходят для типизации конфигураций, флагов и стейт-машин.
- Часто используются вместе с объединениями (Unions) для создания конечного списка возможных значений.
- При объявлении переменных с помощью `const` (если это примитив), TypeScript автоматически выводит тип как литерал, а не расширенный примитив (type widening). В случае с `let`, происходит расширение типа.
