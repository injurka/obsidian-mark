# as const

## Описание

> [!info]
> `as const` (const assertion) — это конструкция в TypeScript, которая указывает компилятору вывести максимально строгий, неизменяемый тип (readonly литерал) для переданного значения.

Использование `as const` предотвращает "расширение типа" (type widening), при котором TypeScript обычно выводит, например, тип `string` для строковых литералов в объектах или массивах. Вместо этого выводится конкретный литеральный тип, а все свойства объекта или элементы массива становятся `readonly`.

## Примеры использования

```typescript
// Без as const
const routes = {
  home: "/",
  about: "/about"
};
// routes.home имеет тип string, можно перезаписать
routes.home = "/new-home";

// С as const
const strictRoutes = {
  home: "/",
  about: "/about"
} as const;
// strictRoutes.home имеет тип "/", свойство readonly
// strictRoutes.home = "/new-home"; // Ошибка!
```

## Особенности и нюансы

- Использование `as const` заменяет необходимость писать длинные интерфейсы с `readonly` и строковыми литералами вручную для статических объектов-конфигов.
- Превращает массивы в `readonly` кортежи (`readonly ["a", "b"]`), что позволяет безопасно извлекать типы элементов.
- Ограничение: `as const` работает только с примитивами, массивами и объектами (не работает на сложных выражениях).
- Часто является лучшей альтернативой Enum для создания словарей значений.
