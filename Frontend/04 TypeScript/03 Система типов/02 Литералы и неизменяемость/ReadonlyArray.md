# ReadonlyArray

## Описание

> [!info]
> `ReadonlyArray<T>` — это встроенный тип TypeScript, который описывает массив, элементы которого не могут быть изменены (добавлены, удалены или перезаписаны).

В отличие от обычного `Array<T>`, тип `ReadonlyArray<T>` лишен мутирующих методов, таких как `push`, `pop`, `splice` и других. Это позволяет гарантировать, что функция или класс не изменит переданный ей массив.

## Примеры использования

```typescript
// Два способа объявления:
let arr1: ReadonlyArray<number> = [1, 2, 3];
let arr2: readonly number[] = [1, 2, 3];

// Чтение разрешено
console.log(arr1[0]);

// Мутации запрещены:
// arr1[0] = 5; // Ошибка
// arr1.push(4); // Ошибка: Property 'push' does not exist on type 'readonly number[]'

// Передача в функции для защиты от мутаций
function printElements(items: readonly string[]) {
  items.forEach(i => console.log(i));
  // items.push("new"); // Ошибка компиляции предотвращает баги
}
```

## Особенности и нюансы

- Использование синтаксиса `readonly T[]` предпочтительнее, так как он короче и читабельнее.
- Обычные массивы (`T[]`) могут быть безопасно присвоены переменным типа `readonly T[]`, но обратное невозможно (без приведения типов), так как ожидающий мутаций код сломается.
- `ReadonlyArray` — это shallow-защита. Если элементы массива — объекты, их свойства все еще можно изменять, если они сами не типизированы как `readonly`.
