# readonly

## Описание

> [!info]
> Модификатор `readonly` в TypeScript используется для свойств интерфейсов и типов (а также классов), чтобы указать, что свойство не может быть изменено после его инициализации.

Это важный инструмент для создания неизменяемых (immutable) структур данных на уровне системы типов. Стоит отметить, что `readonly` проверяется только на этапе компиляции TypeScript, и не добавляет никакой защиты во время выполнения (в рантайме).

## Примеры использования

```typescript
interface User {
  readonly id: number;
  name: string;
}

const user: User = { id: 1, name: "Alice" };
user.name = "Bob"; // OK
// user.id = 2; // Ошибка: Cannot assign to 'id' because it is a read-only property

// Использование Readonly<T> Utility Type
interface Point { x: number; y: number; }
const p: Readonly<Point> = { x: 10, y: 20 };
// p.x = 11; // Ошибка
```

## Особенности и нюансы

- Модификатор `readonly` не является глубоким (не рекурсивным). Если свойство само является объектом, его внутренние свойства могут быть изменены, если они не помечены как `readonly`.
- `readonly` не защищает от изменения данных через алиасы. Если на тот же объект ссылается переменная другого типа без `readonly`, данные могут быть изменены.
- В классах `readonly` свойства могут быть инициализированы только в момент объявления или в конструкторе.
- Отличие от `const`: `const` применяется к переменным (ссылкам), а `readonly` — к свойствам.
