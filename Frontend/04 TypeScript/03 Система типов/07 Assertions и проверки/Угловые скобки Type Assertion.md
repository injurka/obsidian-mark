# Угловые скобки Type Assertion

## Описание

> [!info] 
> Синтаксис угловых скобок `<Type>` — это устаревший и альтернативный способ выполнения утверждения типа (Type Assertion) в TypeScript, эквивалентный оператору `as`.

До появления оператора `as` утверждения типов выполнялись исключительно с помощью синтаксиса угловых скобок перед выражением. Компилятору сообщалось: "Относись к этому выражению как к указанному типу". Однако, этот синтаксис стал проблематичным при работе с JSX, так как парсер не мог отличить утверждение типа от тега JSX, что привело к внедрению синтаксиса `as`.

## Примеры использования

```typescript
const someValue: any = "this is a string";

// Использование синтаксиса угловых скобок для утверждения типа
const strLength: number = (<string>someValue).length;

// Пример с DOM
const myInput = <HTMLInputElement>document.getElementById("user-input");
myInput.value = "test";
```

## Особенности и нюансы

- **Конфликты с JSX/TSX**: В файлах `.tsx` синтаксис угловых скобок для утверждения типа не работает, поскольку он парсится как открывающий JSX тег. Именно поэтому `as` является предпочтительным.
- **Идентичность с `as`**: За исключением различий в синтаксисе и совместимости с JSX, угловые скобки полностью идентичны оператору `as` в поведении (работают только на этапе компиляции, не меняют данные в рантайме).
- **Не путать с Generics**: Синтаксис `<Type>` также используется при вызове обобщенных функций (`myFunc<string>()`), что иногда может создавать путаницу в чтении кода, хотя компилятор их различает.
