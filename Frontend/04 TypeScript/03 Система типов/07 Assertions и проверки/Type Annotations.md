# Type Annotations

## Описание

> [!info] 
> Type Annotations (Аннотации типов) — это базовый механизм TypeScript для явного указания типа переменной, параметра функции или возвращаемого значения.

Аннотации типов добавляются с помощью двоеточия (`:`) после идентификатора. Хотя TypeScript обладает мощной системой вывода типов (Type Inference) и часто может догадаться о типе сам, аннотации необходимы для фиксации контрактов, документирования намерений разработчика и разрешения неоднозначностей.

## Примеры использования

```typescript
// Аннотация переменной
const userName: string = "Alice";
let count: number = 42;

// Аннотация параметров и возвращаемого значения функции
function greet(name: string): string {
  return `Hello, ${name}`;
}

// Аннотация объекта
const user: { id: number; name: string } = {
  id: 1,
  name: "Bob"
};
```

## Особенности и нюансы

- **Контракт против вывода**: Когда вы явно аннотируете тип (например, `const obj: MyType = ...`), вы заставляете `obj` строго следовать `MyType`. Если `obj` имеет более узкие свойства, эта конкретика теряется.
- **Отсутствие в JS**: Аннотации типов удаляются при транспиляции в JavaScript. Они существуют исключительно для статической проверки на этапе компиляции.
- **Избыточность**: Хорошей практикой считается не писать аннотации там, где TypeScript очевидно выводит тип (например, `const x: number = 10` избыточно, достаточно `const x = 10`), но всегда указывать их в сигнатурах публичных функций.
