# as синтаксис

## Описание

> [!info] 
> `as` — это синтаксис утверждения типа (Type Assertion) в TypeScript, позволяющий разработчику явно указать компилятору конкретный тип значения, переопределяя автоматический вывод типов.

Утверждения типов (Type Assertions) используются, когда вы знаете о типе значения больше, чем TypeScript. Синтаксис `as Type` позволяет "привести" тип переменной к нужному, при этом он не выполняет никаких проверок и преобразований данных в рантайме (во время выполнения), а существует исключительно на этапе компиляции для статического анализа. 

## Примеры использования

```typescript
// Работа с DOM-элементами (TypeScript изначально знает только, что это HTMLElement)
const myCanvas = document.getElementById("main_canvas") as HTMLCanvasElement;

// Альтернативный пример с неизвестным API
const someValue: unknown = "Hello, TypeScript";
// Мы уверены, что это строка, поэтому используем as
const strLength: number = (someValue as string).length;
```

## Особенности и нюансы

- **Отсутствие влияния на рантайм**: `as` удаляется при компиляции в JavaScript. Если вы приведете объект к неверному типу, приложение может упасть во время выполнения.
- **Ограничения приведения**: TypeScript разрешает приводить типы только в том случае, если они достаточно похожи. Например, нельзя напрямую привести `string` к `number`. Для обхода этого ограничения используется двойное приведение: `expr as unknown as T`.
- **Предпочтительнее угловых скобок**: Синтаксис `as` рекомендуется использовать вместо синтаксиса угловых скобок (`<Type>value`), так как последний конфликтует с JSX в React.
