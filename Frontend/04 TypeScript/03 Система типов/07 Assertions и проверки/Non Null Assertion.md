# Non Null Assertion

## Описание

> [!info] 
> Non-null Assertion Operator (`!`) — это постфиксный оператор в TypeScript, который указывает компилятору, что выражение не является `null` или `undefined`.

Когда TypeScript выполняет строгую проверку на null (флаг `strictNullChecks`), он может предупреждать вас, что значение потенциально отсутствует (`null | undefined`). Если вы, как разработчик, логически уверены, что значение точно существует в данном контексте, вы можете добавить восклицательный знак в конце выражения, чтобы "отключить" эти предупреждения для конкретного случая.

## Примеры использования

```typescript
function liveDangerously(x?: number | null) {
  // TypeScript выдал бы ошибку "Object is possibly 'null' or 'undefined'."
  // Но мы используем '!', утверждая, что x точно имеет значение
  console.log(x!.toFixed());
}

// Поиск элемента, в наличии которого мы уверены
const el = document.getElementById("critical-element")!;
el.style.color = "red"; // Без '!' была бы ошибка
```

## Особенности и нюансы

- **Отсутствие проверок в рантайме**: Как и другие assertions, оператор `!` удаляется после компиляции. Если значение всё-таки окажется `null` или `undefined`, произойдет ошибка времени выполнения (например, `TypeError: Cannot read properties of undefined`).
- **Скрытая угроза**: Использование `!` часто маскирует реальные ошибки проектирования или потенциальные краши. Лучше использовать сужение типов (Narrowing) или опциональную цепочку (`?.`), если вы не на 100% уверены в наличии значения.
- **Альтернативы**: Вместо `foo!.bar` часто безопаснее написать `foo?.bar` (опциональная цепочка) или использовать явный `if (foo)` для сужения типа (Control Flow Analysis).
