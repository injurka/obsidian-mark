# symbol и unique symbol

## Описание

> [!info] 
> `symbol` — это примитивный тип данных, значения которого гарантированно уникальны и неизменяемы. `unique symbol` — подтип `symbol`, жестко привязанный к конкретной переменной, позволяющий использовать символы в качестве ключей интерфейсов и классов.

Символы в основном используются в качестве уникальных ключей для свойств объектов, что предотвращает случайные коллизии имен (например, при добавлении свойств в объекты из сторонних библиотек). TypeScript вводит тип `unique symbol`, который можно использовать только с переменными, объявленными через `const`, и статическими свойствами классов, доступными только для чтения (`static readonly`).

## Примеры использования

```typescript
// Базовый symbol
let sym1 = Symbol();
let sym2 = Symbol("key"); // Опциональное описание для отладки

console.log(sym1 === sym2); // false (символы всегда уникальны)

// Использование в качестве ключа объекта
const mySymbol = Symbol("myProp");
const obj = {
    [mySymbol]: "value"
};
console.log(obj[mySymbol]); // "value"

// unique symbol
const uniqueKey: unique symbol = Symbol("uniqueKey");

// Использование unique symbol в интерфейсах
interface MyInterface {
    [uniqueKey]: string;
}

const impl: MyInterface = {
    [uniqueKey]: "Hello"
};
```

## Особенности и нюансы

- **Скрытие свойств**: Свойства объекта, ключами которых являются символы, не перечисляются в циклах `for...in` и не возвращаются `Object.keys()`. Чтобы их получить, нужно использовать `Object.getOwnPropertySymbols()`.
- **Типизация `unique symbol`**: Две переменные с типом `unique symbol` имеют абсолютно разные и несовместимые типы на уровне системы типов TypeScript.
- **Глобальный реестр символов**: `Symbol.for("key")` создает или возвращает существующий символ из глобального реестра. Такие символы имеют тип `symbol`, но не могут быть типизированы как `unique symbol`.
- Использование `unique symbol` требует обязательного использования `const` для переменных (или `readonly static` для классов), иначе TypeScript выдаст ошибку компиляции.
