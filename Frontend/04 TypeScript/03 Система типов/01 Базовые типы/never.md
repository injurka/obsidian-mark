# never

## Описание

> [!info] 
> `never` — это тип, представляющий значения, которые *никогда* не должны возникнуть. Это "нижний тип" (bottom type) в TypeScript, который означает отсутствие любой возможности.

Тип `never` обычно появляется в качестве возвращаемого значения функций, которые всегда выбрасывают исключения или содержат бесконечный цикл и никогда не завершаются. Также `never` возникает, когда TypeScript с помощью анализа потока управления определяет, что переменная не может иметь никакого возможного типа (например, после исчерпывающих проверок в объединениях).

## Примеры использования

```typescript
// Функция, которая выбрасывает ошибку, никогда не возвращает значение
function throwError(message: string): never {
    throw new Error(message);
}

// Функция с бесконечным циклом
function infiniteLoop(): never {
    while (true) {
        // Делаем что-то вечно
    }
}

// Исчерпывающая проверка типов (Exhaustiveness checking)
type Shape = "circle" | "square";

function getArea(shape: Shape) {
    switch (shape) {
        case "circle":
            return Math.PI * 2;
        case "square":
            return 4;
        default:
            // Если мы добавим "triangle" в Shape, но не обработаем его,
            // TypeScript выдаст ошибку здесь, так как shape будет иметь тип "triangle", 
            // а не never.
            const _exhaustiveCheck: never = shape;
            return _exhaustiveCheck;
    }
}
```

## Особенности и нюансы

- **Присваиваемость**: Значение типа `never` можно присвоить переменной любого другого типа, но переменной типа `never` нельзя присвоить ничего, кроме самого `never` (даже `any` нельзя присвоить `never`).
- **Разница между `void` и `never`**: `void` означает, что функция возвращается, но не возвращает полезного значения (возвращает `undefined`). `never` означает, что функция *вообще никогда не завершает свое выполнение* нормальным образом (либо зависает, либо крашится).
- **Использование в условных типах**: `never` очень полезен при создании сложных условных типов (Conditional Types) для фильтрации или исключения нежелательных типов. Например, `Exclude<T, U>` из стандартной библиотеки использует `never` для удаления свойств.
