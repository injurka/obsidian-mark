# bigint

## Описание

> [!info] 
> `bigint` — это примитивный тип данных, который представляет целые числа произвольной длины (больше, чем $2^{53} - 1$, максимальное безопасное целое число для типа `number`).

Тип `bigint` позволяет безопасно работать с очень большими целыми числами без потери точности, что недоступно при использовании обычного типа `number` (основанного на 64-битных числах с плавающей запятой стандарта IEEE 754). В TypeScript для его использования необходимо, чтобы целевая версия конфигурации (`target` в `tsconfig.json`) была `ES2020` или выше.

## Примеры использования

```typescript
// Создание bigint с помощью суффикса 'n'
const maxSafeInt: bigint = 9007199254740991n;

// Создание с помощью функции BigInt()
const anotherBigInt: bigint = BigInt("9007199254740991");

// Арифметические операции
const a: bigint = 100n;
const b: bigint = 200n;
const sum: bigint = a + b; // 300n
const product: bigint = a * b; // 20000n

// Операторы сравнения работают с number и bigint
if (a < 150) {
    console.log("a is less than 150");
}
```

## Особенности и нюансы

- **Несовместимость с `number`**: Вы не можете напрямую смешивать `bigint` и `number` в математических операциях. Их необходимо явно приводить друг к другу (например, `Number(myBigInt)` или `BigInt(myNumber)`).
- **Отсутствие дробной части**: Деление `bigint` на `bigint` всегда округляется к нулю (отбрасывает дробную часть). Например, `5n / 2n` равно `2n`.
- **Поддержка Math**: Встроенный объект `Math` в JavaScript не поддерживает работу с `bigint`. Вызов `Math.max(1n, 2n)` приведет к ошибке `TypeError`.
- **JSON сериализация**: По умолчанию `JSON.stringify` выбрасывает ошибку при попытке сериализовать значение `bigint`. Для этого нужно реализовывать собственный метод `toJSON` в прототипе `BigInt` или передавать специальный `replacer`.
