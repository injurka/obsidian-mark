# Базовые типы

## Описание

> [!info] 
> Базовые типы — это фундаментальные строительные блоки системы типов TypeScript, расширяющие стандартные примитивы JavaScript и добавляющие новые механизмы для обеспечения типобезопасности.

Базовые типы в TypeScript включают в себя как стандартные примитивы JavaScript (такие как `string`, `number`, `boolean`, `null`, `undefined`, `symbol`, `bigint`), так и специфические для TypeScript типы (`any`, `unknown`, `never`, `void`). Они позволяют описывать форму данных и ожидаемое поведение переменных, параметров функций и возвращаемых значений, помогая отлавливать ошибки на этапе компиляции.

## Примеры использования

```typescript
// Стандартные примитивы
let isDone: boolean = false;
let decimal: number = 6;
let color: string = "blue";
let bigIntId: bigint = 100n;

// Специальные типы TypeScript
let notSure: any = 4;
notSure = "maybe a string instead";

function warnUser(): void {
    console.log("This is my warning message");
}

function error(message: string): never {
    throw new Error(message);
}
```

## Особенности и нюансы

- В TypeScript названия базовых примитивных типов пишутся со строчной буквы (`string`, `number`, `boolean`). Использование типов с заглавной буквы (`String`, `Number`, `Boolean`) крайне не рекомендуется, так как они ссылаются на встроенные объекты-обёртки JavaScript, а не на сами примитивы.
- Строгая типизация (`strictNullChecks: true`) меняет поведение базовых типов, не позволяя присваивать `null` и `undefined` другим типам.
- Использование специфических типов TypeScript (`any`, `never`, `unknown`) должно быть осознанным, так как неправильное их применение может лишить код преимуществ статической типизации.
