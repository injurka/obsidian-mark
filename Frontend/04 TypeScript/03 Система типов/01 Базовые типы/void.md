# void

## Описание

> [!info] 
> `void` — это тип, указывающий на отсутствие возвращаемого значения. Чаще всего используется как тип возвращаемого значения для функций, которые не возвращают никаких данных.

По сути, `void` является противоположностью `any` — полное отсутствие типа. Когда функция не имеет инструкции `return` или возвращает пустой `return;`, ее возвращаемый тип считается `void`.

## Примеры использования

```typescript
// Функция, которая ничего не возвращает (только побочные эффекты)
function logMessage(message: string): void {
    console.log(message);
    // return; - неявно происходит здесь
}

// Использование void в описании типов коллбэков
type Callback = (result: string) => void;

function fetchData(callback: Callback) {
    const data = "Some data";
    callback(data);
}

// Стрелочная функция с типом void
const throwWarning = (): void => {
    console.warn("This is a warning");
};
```

## Особенности и нюансы

- **Отличие от `undefined`**: Функция, возвращающая `void`, фактически во время выполнения вернет `undefined`. Однако в TypeScript `void` и `undefined` — разные вещи. `void` означает, что возвращаемое значение *игнорируется* или *не ожидается*.
- **Совместимость коллбэков**: Интересная особенность TypeScript заключается в том, что тип `() => void` позволяет функции вернуть значение, но вызывающая сторона не должна его использовать.
  ```typescript
  type VoidFunc = () => void;
  const myFunc: VoidFunc = () => true; // Это допустимо!
  const result = myFunc(); // Тип result будет void, его нельзя использовать
  ```
- **Переменные типа `void`**: Использовать `void` в качестве типа для переменных практически бесполезно, так как им можно присвоить только `undefined` (или `null`, если отключен флаг `strictNullChecks`).
