# null и undefined

## Описание

> [!info] 
> `null` и `undefined` — примитивные типы, представляющие отсутствие значения. `undefined` означает, что значение не было инициализировано, а `null` — что значение намеренно отсутствует.

В TypeScript эти типы играют критически важную роль при использовании строгих проверок на null (`strictNullChecks: true`). Без этого флага `null` и `undefined` можно присвоить переменной любого типа (например, `string` или `number`). С включенным флагом они образуют собственные уникальные типы, что помогает избежать печально известной ошибки "Cannot read property of undefined/null" во время выполнения.

## Примеры использования

```typescript
// Базовое использование
let u: undefined = undefined;
let n: null = null;

// Использование в объединениях (Union types)
function printName(name: string | null) {
    if (name === null) {
        console.log("No name provided");
    } else {
        console.log(`Hello, ${name.toUpperCase()}`);
    }
}

// Опциональные параметры и свойства неявно могут быть undefined
interface User {
    id: number;
    email?: string; // Тип: string | undefined
}

const user: User = { id: 1 };
console.log(user.email); // Выведет undefined
```

## Особенности и нюансы

- **Семантика**: `undefined` обычно возвращается самим JavaScript (например, доступ к несуществующему свойству объекта или невозвращенный результат функции). `null` обычно используется программистами для явного указания на "пустоту" (например, когда поиск не дал результатов).
- **`strictNullChecks`**: Всегда рекомендуется включать эту опцию в `tsconfig.json`. Это заставляет вас явно обрабатывать потенциальное отсутствие значения, делая код более надежным.
- **Опциональная цепочка (Optional Chaining)**: Оператор `?.` позволяет безопасно обращаться к свойствам, которые могут быть `null` или `undefined` (например, `user?.address?.city`).
- **Оператор нулевого слияния (Nullish Coalescing)**: Оператор `??` позволяет задать значение по умолчанию только в случае, если левый операнд равен `null` или `undefined` (в отличие от `||`, который срабатывает на любое falsy-значение).
