# object, Object и {} (пустой объект)

## Описание

> [!info] 
> В TypeScript `object` представляет не-примитивный тип (всё, кроме string, number, boolean, symbol, null, undefined). `Object` описывает функциональность всех объектов JavaScript (через `Object.prototype`). Тип `{}` (пустой объект) означает объект без собственных свойств.

Хотя эти три типа кажутся похожими, они имеют принципиально разную семантику в системе типов TypeScript. Неправильное их использование часто приводит к ошибкам и потере строгой типизации. 

## Примеры использования

```typescript
// 1. object (с маленькой буквы)
// Используется, когда нужно гарантировать, что значение не является примитивом.
function create(o: object | null): void {}
create({ prop: 0 }); // OK
create(null); // OK
// create(42); // Ошибка: Argument of type 'number' is not assignable to parameter of type 'object'.

// 2. {} (пустой тип)
// Означает "любое значение, кроме null и undefined".
let emptyObj: {} = {};
emptyObj = { a: 1 }; // OK, но свойства недоступны
emptyObj = 42; // OK (так как у number есть методы от Object)
// console.log(emptyObj.a); // Ошибка: Property 'a' does not exist on type '{}'.

// 3. Object (с большой буквы)
// Описывает интерфейс Object, содержит методы типа toString(), hasOwnProperty().
let objType: Object = {};
objType = 42; // OK (number наследует Object)
// objType = null; // Ошибка
```

## Особенности и нюансы

- **Использование `object`**: Это наиболее строгий и правильный способ обозначить, что аргумент или переменная должна быть ссылочным типом (объектом, массивом, функцией и т.д.).
- **Опасность `{}` и `Object`**: Использование `Object` (с большой буквы) или `{}` крайне не рекомендуется для описания объектов в прикладном коде, так как они разрешают присваивание примитивов (чисел, строк), что почти никогда не является ожидаемым поведением.
- Если вам нужен объект с ключами-строками и значениями любого типа, лучше использовать `Record<string, any>` или `{[key: string]: any}` вместо `{}`.
- Ни один из этих типов не позволяет обращаться к произвольным свойствам объекта (для этого нужен `any` или явное описание свойств).
