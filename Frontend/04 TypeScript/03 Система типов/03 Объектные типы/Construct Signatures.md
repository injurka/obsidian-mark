# Construct Signatures

## Описание

> [!info] 
> **Construct Signatures (Сигнатуры конструктора)** описывают типы функций, которые могут быть вызваны с оператором `new`. Они позволяют типизировать классы и функции-конструкторы в TypeScript.

В JavaScript функции могут быть вызваны с помощью оператора `new`, чтобы создать новый объект (выступая в роли конструктора). TypeScript позволяет описать такие функции с помощью сигнатур конструктора. Синтаксис очень похож на обычные сигнатуры вызова функций (Call Signatures), но перед аргументами добавляется ключевое слово `new`.

Они часто используются при написании фабрик или при типизации классов, когда функция или метод ожидает в качестве аргумента сам класс (а не его экземпляр).

## Примеры использования

```typescript
// Определение интерфейса с сигнатурой конструктора
interface SomeConstructor {
  new (s: string): SomeObject;
}

class SomeObject {
  constructor(public s: string) {}
}

// Функция, принимающая конструктор в качестве аргумента
function createInstance(ctor: SomeConstructor, arg: string) {
  return new ctor(arg);
}

const instance = createInstance(SomeObject, "hello");
console.log(instance.s); // "hello"
```

В типах можно также использовать сокращенный синтаксис:
```typescript
type SomeConstructorType = new (s: string) => SomeObject;
```

## Особенности и нюансы

- **Совмещение Call и Construct Signatures:** Иногда объект может быть вызван и с `new`, и без него (например, стандартный `Date()` в JavaScript). TypeScript позволяет описывать такие объекты, комбинируя сигнатуры вызова и конструктора в одном интерфейсе.
  ```typescript
  interface CallOrConstruct {
    new (s: string): Date;
    (n?: number): string;
  }
  ```
- **Типизация классов:** Класс в TypeScript состоит из двух типов — типа экземпляра (instance type) и типа самой функции-конструктора (constructor function type). Сигнатура конструктора описывает именно тип функции-конструктора.
- **Возвращаемый тип:** Конструктор обычно возвращает экземпляр какого-то класса или объекта. Возвращаемый тип обязательно указывается после двоеточия (или `=>` в синтаксисе `type`).
