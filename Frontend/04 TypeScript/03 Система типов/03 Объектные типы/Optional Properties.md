# Optional Properties

## Описание

> [!info] 
> **Опциональные свойства** (Optional Properties) — это свойства объекта, которые могут присутствовать, а могут и отсутствовать. Они обозначаются знаком вопроса (`?`) после имени свойства.

В реальных приложениях объекты часто не имеют полного набора данных. Например, при заполнении профиля пользователя поле "отчество" может быть необязательным, или настройки конфигурации могут иметь значения по умолчанию, если они не заданы явно. Опциональные свойства позволяют гибко описывать такие структуры данных, не заставляя разработчика передавать `undefined` вручную.

При обращении к опциональному свойству TypeScript автоматически учитывает, что его значением может быть `undefined`, и заставляет разработчика обрабатывать этот случай (например, с помощью optional chaining `?.`).

## Примеры использования

```typescript
interface PaintOptions {
  shape: string;
  xPos?: number;
  yPos?: number;
}

// Опциональные свойства можно не указывать
function paintShape(opts: PaintOptions) {
  // TypeScript понимает, что xPos и yPos могут быть undefined.
  // Мы можем задать значения по умолчанию.
  let x = opts.xPos === undefined ? 0 : opts.xPos;
  let y = opts.yPos === undefined ? 0 : opts.yPos;
  
  console.log(`Рисуем ${opts.shape} на координатах: ${x}, ${y}`);
}

paintShape({ shape: "Круг" });
paintShape({ shape: "Квадрат", xPos: 100 });
paintShape({ shape: "Треугольник", xPos: 10, yPos: 20 });

// Использование Optional Chaining
function logPosition(opts: PaintOptions) {
  // Безопасное обращение к методам (если бы они были)
  console.log(opts.xPos?.toString());
}
```

## Особенности и нюансы

- **Отличие от `T | undefined`**: Свойство, описанное как `key?: string`, отличается от `key: string | undefined`. В первом случае вы можете вообще не указывать ключ `key` при создании объекта. Во втором случае вы **обязаны** указать ключ `key`, даже если его значение будет равно `undefined` явно.
- **Опция `exactOptionalPropertyTypes`**: Если в `tsconfig.json` включена строгая настройка `exactOptionalPropertyTypes`, TypeScript запретит явно присваивать `undefined` опциональным свойствам (если они не типизированы дополнительно как `| undefined`). Это предотвращает путаницу между "свойство отсутствует" и "свойство присутствует, но равно undefined".
- **Чтение опциональных свойств**: При чтении опционального свойства TypeScript всегда будет добавлять `undefined` к его типу, заставляя вас использовать сужение типов (Type Narrowing) или оператор опциональной последовательности (Optional Chaining `?.`), чтобы избежать ошибок времени выполнения (`Cannot read properties of undefined`).
