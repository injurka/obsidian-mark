# Объектные типы

## Описание

> [!info] 
> **Объектные типы** — это способ описания структуры данных в TypeScript, где ключи (свойства) являются строками (или символами), а значения могут иметь любой валидный TypeScript-тип.

В JavaScript объекты играют фундаментальную роль, выступая основным способом группировки связанных данных. TypeScript расширяет этот механизм, добавляя возможность строгой типизации структуры объектов. Это позволяет компилятору ловить ошибки на этапе разработки, если вы пытаетесь обратиться к несуществующему свойству или присвоить значение неправильного типа.

В TypeScript существует несколько способов задать объектный тип:
- Анонимные объектные типы (inline-типизация).
- Алиасы типов (`type`).
- Интерфейсы (`interface`).

## Примеры использования

```typescript
// 1. Анонимный объектный тип
function printCoord(pt: { x: number; y: number }) {
  console.log("Координата x: " + pt.x);
  console.log("Координата y: " + pt.y);
}
printCoord({ x: 3, y: 7 });

// 2. Использование type (алиас типа)
type Point = {
  x: number;
  y: number;
};

function drawPoint(pt: Point) {
  // ...
}

// 3. Использование interface
interface User {
  name: string;
  age: number;
  isAdmin: boolean;
}

const currentUser: User = {
  name: "Алексей",
  age: 30,
  isAdmin: false
};
```

## Особенности и нюансы

- **`type` против `interface`**: Главное различие между `type` и `interface` заключается в том, что интерфейсы всегда можно расширять путём повторного объявления (Declaration Merging), тогда как алиас типа не может быть переопределён. Интерфейсы обычно предпочтительнее для описания публичных API и объектов, в то время как `type` позволяет использовать объединения (unions) и пересечения (intersections).
- **Структурная типизация**: TypeScript использует структурную типизацию (duck typing). Это означает, что если два объекта имеют одинаковую структуру (совпадают ключи и типы значений), они считаются совместимыми, даже если они были описаны через разные `interface` или `type`.
- **Избыточные свойства**: При передаче объектного литерала напрямую в функцию или переменную, TypeScript применяет строгую проверку на избыточные свойства (Excess Property Checks). Если передать объект через промежуточную переменную, эта проверка может быть ослаблена благодаря duck typing.
