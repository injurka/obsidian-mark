# Index Signatures

## Описание

> [!info] 
> **Index Signatures (индексные сигнатуры)** — это способ в TypeScript описать типы свойств объекта, когда их конкретные имена заранее неизвестны, но известна структура ключей и их значений.

Индексные сигнатуры позволяют создавать объекты-словари или мапы, где в качестве ключей могут выступать строки, числа или символы, а значения имеют строго определенный тип. Это гибкий инструмент для работы с динамическими данными, такими как конфигурации, кэш или ответы от API.

## Примеры использования

```typescript
// Словарь, где ключи — строки (имена пользователей), а значения — их возраст
interface UserAges {
  [name: string]: number;
}

const ages: UserAges = {
  Alice: 25,
  Bob: 30,
  Charlie: 35
};

// Индексная сигнатура с числовыми ключами (похоже на массив)
interface StringArray {
  [index: number]: string;
}

const myArray: StringArray = ["hello", "world"];
const firstItem = myArray[0]; // Тип: string
```

## Особенности и нюансы

- **Ограниченные типы ключей**: В индексных сигнатурах типом ключа может быть только `string`, `number`, `symbol` или шаблонные литеральные типы (Template Literal Types).
- **Смешивание строковых и числовых индексов**: Если в интерфейсе есть и строковый, и числовой индексы, тип значений числового индекса должен быть подтипом значений строкового индекса. Это связано с тем, что в JavaScript числовые ключи преобразуются в строки (`obj[100]` это то же самое, что `obj["100"]`).
  ```typescript
  interface Dictionary {
    [key: string]: string | number; // Более широкий тип
    [index: number]: number;        // Подтип
  }
  ```
- **Ограничение явных свойств**: Любые явно объявленные свойства в типе должны соответствовать типу, указанному в индексной сигнатуре.
  ```typescript
  interface Config {
    [key: string]: number;
    // ❌ Ошибка: Property 'timeout' of type 'boolean' is not assignable to 'string' index type 'number'.
    timeout: boolean; 
    retries: number; // ✅ OK
  }
  ```
- **Readonly индексные сигнатуры**: Вы можете сделать индексную сигнатуру доступной только для чтения с помощью модификатора `readonly`, предотвращая добавление новых или изменение существующих свойств.
  ```typescript
  interface ReadonlyDictionary {
    readonly [key: string]: string;
  }
  ```
- **Альтернатива - Record<K, V>**: Во многих случаях вместо написания индексной сигнатуры удобнее использовать встроенный utility-тип `Record<Keys, Type>`.
