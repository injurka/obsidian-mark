# Методы в объектных типах

## Описание

> [!info] 
> **Методы в объектных типах** — это способ описания функций, которые принадлежат объекту. В TypeScript можно определить типы методов объекта с помощью синтаксиса свойств или сокращенного синтаксиса методов.

Объектные типы могут содержать не только свойства-значения (числа, строки, булевы), но и функции, которые называются методами. TypeScript позволяет строго типизировать параметры и возвращаемое значение таких методов.

Существуют два основных способа описания методов в интерфейсах или псевдонимах типов (`type`):
1. **Синтаксис свойства (Property Syntax):** Использование стрелочной функции или сигнатуры вызова.
2. **Синтаксис метода (Method Syntax):** Использование обычного синтаксиса функций внутри объекта.

## Примеры использования

```typescript
// 1. Синтаксис метода (Method Syntax)
interface Animal {
  name: string;
  speak(sound: string): void;
}

// 2. Синтаксис свойства (Property Syntax)
interface Person {
  name: string;
  greet: (greeting: string) => void;
}

// Использование
const dog: Animal = {
  name: "Рекс",
  speak(sound) {
    console.log(`${this.name} говорит ${sound}`);
  }
};

const user: Person = {
  name: "Иван",
  greet: (greeting) => {
    console.log(`${greeting}, я Иван`);
  }
};
```

## Особенности и нюансы

- **`this` и контекст вызова:** При использовании синтаксиса метода `this` обычно привязывается к самому объекту. При использовании синтаксиса свойства со стрелочными функциями `this` берется из лексического окружения. TypeScript позволяет явно типизировать `this` в первом параметре метода.
- **Strict Function Types (Строгие типы функций):** Существует важное различие между синтаксисом методов `method(arg: string): void` и свойств `method: (arg: string) => void`. При включенном флаге `--strictFunctionTypes` (который обычно включен в `--strict`), параметры методов в синтаксисе метода проверяются бивариантно, тогда как параметры в синтаксисе свойств проверяются контравариантно. Это означает, что синтаксис свойства обеспечивает более строгую проверку типов и предотвращает некоторые ошибки во время выполнения.
- **Перегрузка методов:** Синтаксис методов позволяет описывать перегрузки внутри интерфейсов и типов.
  ```typescript
  interface Overloaded {
    func(x: number): number;
    func(x: string): string;
  }
  ```
