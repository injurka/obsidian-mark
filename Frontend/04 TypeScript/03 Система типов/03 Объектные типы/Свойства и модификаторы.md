# Свойства и модификаторы

## Описание

> [!info] 
> **Модификаторы свойств** — это специальные ключевые слова в TypeScript (`readonly`, `?`), которые позволяют управлять доступом и обязательностью полей в объектных типах и интерфейсах.

При описании объектного типа вы можете не только указать тип каждого свойства, но и уточнить его поведение. TypeScript предоставляет мощные инструменты для контроля над свойствами:
1. **Опциональные свойства (`?`)**: Позволяют указать, что свойство может отсутствовать.
2. **Свойства только для чтения (`readonly`)**: Защищают свойство от перезаписи после инициализации объекта.
3. **Индексные сигнатуры**: Позволяют описать объекты, где имена свойств неизвестны заранее, но известен тип их ключей и значений.

## Примеры использования

```typescript
interface Product {
  // Обычное свойство
  name: string;
  // Свойство только для чтения
  readonly id: number;
  // Опциональное свойство
  description?: string;
}

const myProduct: Product = {
  id: 12345,
  name: "Ноутбук"
};

// Ошибка! Свойство id доступно только для чтения.
// myProduct.id = 54321; 

// Допустимо, мы меняем обычное свойство
myProduct.name = "Игровой ноутбук"; 

// Индексная сигнатура
interface StringDictionary {
  [index: string]: string;
}

const colors: StringDictionary = {
  red: "#ff0000",
  green: "#00ff00",
  blue: "#0000ff",
};
```

## Особенности и нюансы

- **Глубокая неизменяемость**: Модификатор `readonly` работает только на верхнем уровне свойства (shallow). Если свойство само является объектом или массивом, его внутренние элементы всё ещё можно изменять. Для глубокой неизменяемости нужно использовать рекурсивные типы или утилиту типа `Readonly<T>`.
- **Удаление модификаторов в Mapped Types**: При создании новых типов на основе существующих с помощью Mapped Types (например, `Partial` или `Required`), вы можете добавлять или удалять модификаторы с помощью префиксов `+` и `-` (например, `-readonly` или `-?`).
- **Индексные сигнатуры и строгие типы**: Если в объекте есть индексная сигнатура, все явно объявленные свойства должны иметь тип, совместимый с типом индексной сигнатуры.
