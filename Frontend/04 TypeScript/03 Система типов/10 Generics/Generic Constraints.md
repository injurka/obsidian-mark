# Generic Constraints

## Описание

> [!info] 
> **Ограничения обобщений (Generic Constraints)** — механизм, позволяющий сузить допустимые типы, которые могут быть переданы в параметр типа, с помощью ключевого слова `extends`. Это гарантирует, что переданный тип обладает определённым набором свойств.

По умолчанию параметр типа `T` может быть чем угодно. Если в функции попытаться обратиться к свойству, которого может не быть у произвольного типа (например, `.length`), компилятор выдаст ошибку. С помощью ограничения `<T extends SomeType>` мы сообщаем компилятору: "тип T может быть любым, **при условии, что он совместим с SomeType**".

## Примеры использования

```typescript
// Определяем интерфейс для ограничения
interface Lengthwise {
    length: number;
}

// Ограничиваем T так, чтобы у него обязательно было свойство length
function logLength<T extends Lengthwise>(arg: T): T {
    console.log(arg.length); // Теперь компилятор знает, что length существует
    return arg;
}

logLength({ length: 10, value: 3 }); // OK, объект имеет length
logLength("Hello"); // OK, у строки есть length
logLength([1, 2, 3]); // OK, у массива есть length
// logLength(42); // Ошибка! У типа number нет свойства length
```

## Особенности и нюансы

- **Сужение типов:** Использование ограничения позволяет TypeScript понимать, какие свойства или методы точно доступны на переменной типа `T`.
- Ограничение не меняет то, что функция возвращает тип `T`. То есть, если вы передаете объект со свойством `length` и кучей других свойств, на выходе вы получите тот же самый объект со всеми его свойствами, а не просто объект типа `Lengthwise`.
- Можно использовать одни параметры типа для ограничения других, например: `<T, K extends keyof T>`.
- Если нужно ограничить тип примитивом или объединением, это тоже возможно: `<T extends string | number>`.
