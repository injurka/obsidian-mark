# Generic Functions

## Описание

> [!info] 
> **Обобщенные функции (Generic Functions)** — это функции, которые принимают один или несколько параметров типа, что позволяет им работать с различными типами данных с сохранением информации о типах аргументов и возвращаемого значения.

Функции-дженерики позволяют абстрагироваться от конкретных типов, с которыми они работают. При объявлении обобщенной функции параметр типа указывается в угловых скобках `<T>` перед списком обычных параметров. В теле функции и сигнатуре возвращаемого значения `T` используется как обычный тип.

## Примеры использования

```typescript
// Обобщенная функция, возвращающая массив из элементов определенного типа
function createArray<T>(length: number, value: T): T[] {
    return Array.from({ length }, () => value);
}

const stringArray = createArray<string>(3, "hello"); // string[]
const numberArray = createArray(3, 42); // number[], тип T выведен автоматически

// Функция с несколькими параметрами типа
function mapPair<T, U, V>(pair: [T, U], fn: (t: T, u: U) => V): V {
    return fn(pair[0], pair[1]);
}

const result = mapPair([10, "20"], (num, str) => num + Number(str)); // number
```

## Особенности и нюансы

- Обобщения можно применять как к обычным функциям (`function foo<T>()`), так и к стрелочным функциям (`const foo = <T>(arg: T) => {}`).
- При использовании стрелочных функций в React (TSX файлах), компилятор может перепутать синтаксис `<T>` с JSX-тегом. В таких случаях используют конструкцию `<T,>` или `extends unknown`, например: `const foo = <T,>(arg: T) => arg;`.
- Благодаря выводу типов (Type Inference), компилятору в большинстве случаев удается определить тип самостоятельно, избавляя от необходимости писать `<T>` явно.
