# Что такое Generics

## Описание

> [!info]
> **Обобщения (Generics)** — это механизм в TypeScript, позволяющий создавать компоненты (функции, классы, интерфейсы, типы), способные работать с различными типами данных, не теряя при этом строгой типизации.

Generics позволяют писать переиспользуемый, гибкий и типобезопасный код. Вместо того чтобы привязываться к конкретному типу (например, `string` или `number`) или использовать небезопасный `any`, мы используем **параметры типа** (type parameters), которые подставляются в момент вызова или использования компонента.

Параметр типа обычно обозначается заглавной буквой, чаще всего `T` (от Type), но можно использовать и более осмысленные имена (`TItem`, `TResponse` и т.д.).

## Примеры использования

```typescript
// Без дженериков (использование any - потеря типизации)
function identityAny(arg: any): any {
    return arg;
}

let resultAny = identityAny(42); // тип any 😢

// С использованием дженериков
function identity<T>(arg: T): T {
    return arg;
}

let resultNum = identity<number>(42); // тип number
let resultStr = identity("Hello");    // тип "Hello" (благодаря выводу типов)
```

## Особенности и нюансы

- **Стирание типов (Type Erasure):** Дженерики существуют только на этапе компиляции TypeScript. При компиляции в JavaScript вся информация о параметрах типа удаляется, поэтому во время выполнения программы (runtime) типы дженериков недоступны (нельзя использовать `typeof T`).
- **Автоматический вывод типов (Type Inference):** Часто TypeScript способен сам вывести значение `T` из переданных аргументов, поэтому явно указывать тип (как в `identity<number>(42)`) не всегда обязательно.
- **Множественные параметры:** Можно объявлять несколько параметров типа: `<T, U>`.
