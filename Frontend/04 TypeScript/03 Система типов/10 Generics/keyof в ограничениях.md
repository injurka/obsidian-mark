# keyof в ограничениях

## Описание

> [!info] 
> Сочетание оператора **`keyof` и ограничений (`extends`)** в дженериках — это мощный паттерн, который позволяет ограничить один параметр типа ключами другого параметра типа.

Этот механизм крайне полезен при создании функций, которые работают со свойствами объектов. Конструкция вида `<T, K extends keyof T>` говорит компилятору: "параметр `K` может принимать только те значения, которые являются именами свойств (ключами) типа `T`". Это гарантирует безопасность типов при доступе к свойствам объекта по динамическому ключу.

## Примеры использования

```typescript
// Функция безопасного получения свойства из объекта
function getProperty<T, K extends keyof T>(obj: T, key: K): T[K] {
    return obj[key];
}

const user = {
    id: 1,
    name: "Alice",
    isActive: true
};

const userName = getProperty(user, "name"); // тип: string
const userId = getProperty(user, "id");     // тип: number

// const invalid = getProperty(user, "age"); // Ошибка! "age" не является ключом user
```

## Особенности и нюансы

- **Автоматический вывод:** Компилятор TypeScript невероятно хорошо выводит типы `T` и `K` на основе переданных аргументов. В примере выше `T` выводится как тип объекта `user`, а `K` — как литеральный тип `"name"`. В результате тип возвращаемого значения `T[K]` корректно определяется как `string`.
- Оператор `keyof` извлекает все публичные ключи объекта в виде объединения (union type) строковых или числовых литералов.
- Это фундаментальный паттерн для написания типобезопасных утилит типа `Pick` и `Omit`.
