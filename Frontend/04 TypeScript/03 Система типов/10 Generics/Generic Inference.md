# Generic Inference

## Описание

> [!info] 
> **Вывод типов обобщений (Generic Inference)** — это процесс, при котором компилятор TypeScript автоматически определяет (выводит) значения параметров типа на основе аргументов, переданных в функцию или класс, без необходимости явного указания `<T>`.

Это одна из самых мощных возможностей TypeScript, которая делает код чище и избавляет от избыточности. Компилятор анализирует типы фактических аргументов при вызове и пытается найти наиболее подходящий тип для `T`. 

## Примеры использования

```typescript
function wrapInArray<T>(value: T): T[] {
    return [value];
}

// Явное указание типа (многословно)
const a = wrapInArray<string>("hello");

// Вывод типа (лаконично)
const b = wrapInArray(42);       // T выведено как number, результат number[]
const c = wrapInArray(true);     // T выведено как boolean, результат boolean[]
const d = wrapInArray({ id: 1}); // T выведено как { id: number }

// Вывод из нескольких аргументов (берется объединение типов)
function choose<T>(a: T, b: T): T {
    return Math.random() > 0.5 ? a : b;
}

const e = choose(1, 2);       // T = number
const f = choose(1, "hello"); // T = number | string
```

## Особенности и нюансы

- TypeScript использует все доступные аргументы, в которых участвует параметр типа, для выведения наилучшего общего типа. 
- Иногда вывод может быть шире, чем хотелось бы. Например, пустой массив `[]` может вывести `T` как `any`.
- Начиная с TypeScript 4.7, появился модификатор `in` (NoInfer) или использование утилиты `NoInfer<T>`, чтобы запретить компилятору выводить тип по определённому аргументу. Это полезно, когда один аргумент должен определять тип `T`, а другой — строго следовать ему.
  ```typescript
  // Встроенный тип NoInfer появился в TS 5.4+
  function updateState<T>(initial: T, newState: NoInfer<T>) {}
  updateState("red", "blue"); // OK
  // updateState("red", "green"); // Ошибка, если тип initial был литералом
  ```
