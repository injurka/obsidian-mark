# Паттерны обобщений

## Описание

> [!info] 
> **Паттерны обобщений (Generic Patterns)** — это устоявшиеся подходы, идиомы и архитектурные решения в TypeScript, которые используют дженерики для решения типичных задач типизации сложных потоков данных, проектирования API и создания переиспользуемых утилит.

TypeScript обладает очень мощной системой типов на основе дженериков. За годы использования сформировались определенные паттерны, которые помогают писать код, способный безошибочно выводить типы без лишних приведений (`as`).

## Примеры использования

### 1. Builder Pattern с постепенным накоплением типов
Позволяет шаг за шагом собирать объект, обогащая его тип.
```typescript
class QueryBuilder<T = {}> {
    select<K extends string, V>(key: K, value: V): QueryBuilder<T & Record<K, V>> {
        // ...
        return this as any;
    }

    execute(): T {
        return null as any;
    }
}

const query = new QueryBuilder()
    .select("id", 1)
    .select("name", "Alice")
    .execute(); 
// Тип query: { id: number; name: string; }
```

### 2. Паттерн "Обновление" (Partial Updates)
Использование `Partial<T>` в функциях, обновляющих сущности.
```typescript
function updateEntity<T>(original: T, update: Partial<T>): T {
    return { ...original, ...update };
}
```

### 3. Фабрика с привязкой к типу (Type Registry)
Связывание строковых ключей с конкретными типами для создания фабрик событий или компонентов.
```typescript
interface EventMap {
    click: MouseEvent;
    keypress: KeyboardEvent;
}

function on<K extends keyof EventMap>(event: K, handler: (e: EventMap[K]) => void) {
    // Регистрация слушателя
}

on("click", (e) => e.clientX); // e автоматически типизирован как MouseEvent
```

## Особенности и нюансы

- Паттерны обобщений часто комбинируют дженерики, условные типы (Conditional Types), маппинг типов (Mapped Types) и ограничения (Constraints).
- Использование сложных паттернов может привести к появлению огромных, нечитаемых ошибок компиляции и "магии" в коде, поэтому их следует применять только там, где они действительно приносят пользу для Developer Experience.
- Для глубокого понимания полезно изучать исходные коды популярных библиотек (Redux, React, Zod, tRPC), где дженерики используются на максимум.
