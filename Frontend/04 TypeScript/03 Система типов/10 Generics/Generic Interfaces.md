# Generic Interfaces

## Описание

> [!info] 
> **Обобщенные интерфейсы (Generic Interfaces)** — это интерфейсы, принимающие параметры типа, позволяющие описать гибкие структуры данных, формы объектов или сигнатуры функций, зависящие от внешних типов.

Обобщенные интерфейсы крайне полезны для описания контейнеров данных, структур ответа от API (где обертка одинаковая, а сами данные отличаются), компонентов и других сущностей, структура которых зависит от какого-то типа.

Параметры типа описываются сразу после имени интерфейса в угловых скобках: `interface Name<T, U>`.

## Примеры использования

```typescript
// Интерфейс для стандартного ответа от сервера
interface ApiResponse<T> {
    data: T;
    status: number;
    message: string;
}

interface User {
    id: number;
    name: string;
}

// Конкретизируем интерфейс для User
const response: ApiResponse<User> = {
    data: { id: 1, name: "Alice" },
    status: 200,
    message: "Success"
};

// Обобщенный интерфейс для функции
interface Transformer<T, U> {
    (input: T): U;
}

const numToStr: Transformer<number, string> = (n) => n.toString();
```

## Особенности и нюансы

- В отличие от обобщенных функций, где тип часто выводится из аргументов, при использовании обобщенного интерфейса вы **обязаны** указывать параметр типа явно (если для него не задано значение по умолчанию).
- Можно использовать ограничения `extends` на параметры типа в интерфейсах: `interface Store<T extends object>`.
- Обобщенные интерфейсы часто комбинируются с обобщенными классами или функциями для создания мощных абстракций.
