# Контекстная типизация

## Описание

> [!info] 
> Контекстная типизация (Contextual Typing) — это механизм TypeScript, при котором тип выражения определяется его местоположением (контекстом).

В отличие от вывода типов (Type Inference), когда тип определяется на основе значения, при контекстной типизации тип "спускается" от ожидаемого типа к значению.

## Примеры использования

Самый распространенный случай — это коллбэки:

```typescript
// TypeScript знает, что `e` — это MouseEvent благодаря контексту `window.onmousedown`
window.onmousedown = function (e) {
  console.log(e.button); 
  // console.log(e.kangaroo); // Ошибка: Property 'kangaroo' does not exist on type 'MouseEvent'.
};
```

Другой пример с функциями:

```typescript
type Greeter = (name: string) => string;

// Контекстная типизация выводит, что `n` имеет тип string, а результат должен быть string
const sayHello: Greeter = (n) => {
  return `Hello, ${n.toUpperCase()}`;
};
```

## Особенности и нюансы

- Контекстная типизация работает для аргументов функций, возвращаемых значений, литералов объектов и массивов.
- Если контекстная типизация конфликтует с явно указанным типом, предпочтение отдается явному типу.
- Она особенно полезна при работе с библиотеками (например, React-компонентами), когда тип пропсов или событий выводится автоматически из декларации интерфейса.
