# Required

## Описание

> [!info] Required<Type>
> Утилитарный тип `Required<Type>` является противоположностью `Partial`. Он создает новый тип, в котором все опциональные свойства исходного типа `Type` становятся обязательными.

Этот тип используется в ситуациях, когда у вас есть тип с необязательными полями (возможно, из сторонней библиотеки или базовых настроек), но в определенном контексте вашей программы вы точно знаете или требуете, чтобы все эти поля были заполнены и присутствовали.

## Примеры использования

```typescript
interface Props {
  a?: number;
  b?: string;
  c?: boolean;
}

const obj1: Props = { a: 5 }; // Все хорошо, поля опциональные

const obj2: Required<Props> = { a: 5 };
// Ошибка: Свойство 'b' отсутствует в типе '{ a: number; }',
// но обязательно в типе 'Required<Props>'.
// Ошибка: Свойство 'c' отсутствует...

const obj3: Required<Props> = { a: 5, b: "hello", c: true }; // Ок
```

## Особенности и нюансы

- **Снятие модификатора**: Как и `Partial`, `Required` работает поверхностно (на первом уровне вложенности).
- **Под капотом**: Реализация `Required` основана на Mapped Types (сопоставленных типах) и использует оператор `-?` (минус вопрос), который буквально означает "убрать опциональность":
  ```typescript
  type Required<T> = {
      [P in keyof T]-?: T[P];
  };
  ```
  Здесь `-?` удаляет модификатор `?` со всех свойств `T`.
- **Практика**: Очень часто используется при слиянии дефолтных настроек с пользовательскими, когда на выходе функции гарантируется объект со всеми определенными полями.
