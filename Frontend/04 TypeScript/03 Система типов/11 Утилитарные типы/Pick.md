# Pick

## Описание

> [!info] Pick<Type, Keys>
> Утилитарный тип `Pick<Type, Keys>` создает новый тип путем выборки определенного набора свойств `Keys` (обычно строковых литералов или их объединения) из существующего типа `Type`.

Тип `Pick` решает проблему переиспользования интерфейсов, когда вам нужен не весь объект целиком, а только его конкретная часть. Вместо дублирования нужных полей в новый интерфейс, вы "выбираете" их из базового типа.

## Примеры использования

```typescript
interface User {
  id: number;
  username: string;
  email: string;
  passwordHash: string;
  avatarUrl: string;
}

// Нам нужен тип только для отображения базовой информации в UI
type UserPreview = Pick<User, "id" | "username" | "avatarUrl">;

const userPreview: UserPreview = {
  id: 1,
  username: "johndoe",
  avatarUrl: "https://example.com/avatar.jpg"
  // passwordHash и email здесь недоступны и их добавление вызовет ошибку
};
```

## Особенности и нюансы

- **Проверка ключей**: Параметр `Keys` должен существовать в базовом типе `Type`. Если вы попробуете выбрать свойство, которого нет в исходном типе, компилятор выдаст ошибку.
- **Сохранение модификаторов**: `Pick` сохраняет опциональность (`?`) и доступность только для чтения (`readonly`) выбранных свойств из исходного типа.
- **Под капотом**: Как и многие другие утилитарные типы, `Pick` основан на Mapped Types (сопоставленных типах):
  ```typescript
  type Pick<T, K extends keyof T> = {
      [P in K]: T[P];
  };
  ```
  `K extends keyof T` гарантирует, что мы можем выбрать только существующие ключи из `T`.
