# Partial

## Описание

> [!info] Partial<Type>
> Утилитарный тип `Partial<Type>` создает новый тип, в котором все свойства исходного типа `Type` становятся необязательными (опциональными).

Этот тип решает проблему частичного обновления объектов. Часто в функциях вроде `updateUser` мы хотим передать не всего пользователя целиком (со всеми обязательными полями), а только те поля, которые требуется изменить. Вместо того чтобы вручную дублировать интерфейс и ставить каждому полю `?`, можно использовать `Partial`.

## Примеры использования

```typescript
interface Todo {
  title: string;
  description: string;
  completed: boolean;
}

// Создаем функцию, которая обновляет только часть полей Todo
function updateTodo(todo: Todo, fieldsToUpdate: Partial<Todo>): Todo {
  return { ...todo, ...fieldsToUpdate };
}

const todo1: Todo = {
  title: "Убраться",
  description: "Помыть полы и протереть пыль",
  completed: false
};

// Передаем только поле `completed`
const todo2 = updateTodo(todo1, {
  completed: true
});
```

## Особенности и нюансы

- **Неглубокий (Shallow)**: По умолчанию `Partial` делает свойства опциональными только на верхнем уровне (shallow). Вложенные объекты не становятся опциональными рекурсивно.
- **Под капотом**: Реализован через Mapped Types с использованием модификатора `?`:
  ```typescript
  type Partial<T> = {
      [P in keyof T]?: T[P];
  };
  ```
  Здесь `keyof T` получает ключи (union свойств), а `in` перебирает их, добавляя к каждому оператор `?`.
- **Глубокий вариант (DeepPartial)**: Если требуется сделать все поля рекурсивно опциональными, TypeScript из коробки такого типа не предоставляет, но его легко написать самостоятельно с использованием условных типов:
  ```typescript
  type DeepPartial<T> = T extends object ? {
      [P in keyof T]?: DeepPartial<T[P]>;
  } : T;
  ```
