# String Enums

## Описание

> [!info]
> String Enums (Строковые перечисления) — это перечисления, где каждое значение явно инициализируется строковым литералом.

В отличие от числовых перечислений, строковые перечисления не поддерживают автоматическую инкрементацию, поэтому каждый член должен быть инициализирован явно. Они более читабельны при сериализации/десериализации данных (например, при передаче JSON).

## Примеры использования

```typescript
enum Direction {
  Up = "UP",
  Down = "DOWN",
  Left = "LEFT",
  Right = "RIGHT",
}

// В рантайме это превратится в обычный объект:
// { "Up": "UP", "Down": "DOWN", "Left": "LEFT", "Right": "RIGHT" }

function move(dir: Direction) {
  console.log(`Moving ${dir}`);
}

move(Direction.Up); // OK
// move("UP"); // Ошибка! Строковые Enum-ы не принимают обычные строки
```

## Особенности и нюансы

- Строковые Enum-ы имеют так называемую номинативную типизацию. Даже если обычная строка совпадает со значением Enum-а (`"UP"`), вы не можете передать её в функцию, ожидающую тип `Direction`. Вы обязаны использовать `Direction.Up`. Это делает их более строгими, но иногда менее удобными, чем Union Types.
- В отличие от числовых Enum-ов, строковые **не** создают обратного отображения (Reverse Mapping) в скомпилированном JS.
- Отличный выбор для отладки, так как в консоли или логах вы увидите осмысленное строковое значение, а не непонятную цифру.
