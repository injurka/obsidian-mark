# Const Enums

## Описание

> [!info]
> `const enum` — это специальная разновидность перечислений, которая полностью удаляется на этапе компиляции TypeScript, а в местах её использования значения подставляются напрямую (инлайнятся).

Это используется для экономии размера бандла и оптимизации производительности, так как `const enum` не генерирует JavaScript-объект в итоговом коде.

## Примеры использования

```typescript
// Объявление с использованием const
const enum Directions {
  Up,
  Down,
  Left,
  Right,
}

const myDirection = Directions.Up;

// СКОМПИЛИРОВАННЫЙ JS-КОД БУДЕТ ВЫГЛЯДЕТЬ ТАК:
// const myDirection = 0 /* Directions.Up */;
```

## Особенности и нюансы

- Главный плюс: отсутствие оверхеда в виде объекта в рантайме. Идеально для высокопроизводительных участков кода.
- Недостатки: из-за того, что объекта нет в рантайме, вы не можете итерироваться по ключам/значениям такого Enum-а с помощью `Object.keys()` или `Object.values()`.
- Также вы не можете использовать вычисляемые свойства внутри `const enum`.
- В некоторых системах сборки (например, Babel или esbuild) с настройкой `--isolatedModules`, `const enums` могут вызвать проблемы и работают некорректно, так как эти сборщики обрабатывают файлы по одному, не имея полного контекста программы.
