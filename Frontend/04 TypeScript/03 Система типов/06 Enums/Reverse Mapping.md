# Reverse Mapping

## Описание

> [!info]
> Reverse Mapping (Обратное отображение) — это особенность числовых Enum-ов, благодаря которой скомпилированный JavaScript-объект содержит не только маппинг из имен в значения, но и из значений обратно в имена.

Это позволяет легко получать строковое имя константы, если у вас есть только её числовое значение.

## Примеры использования

```typescript
enum Status {
  Success = 200,
  NotFound = 404,
}

// Прямое обращение (имя -> значение)
console.log(Status.Success); // 200

// Обратное обращение (значение -> имя)
console.log(Status[200]); // "Success"
console.log(Status[404]); // "NotFound"

/* 
Примерно так выглядит скомпилированный код:
var Status;
(function (Status) {
    Status[Status["Success"] = 200] = "Success";
    Status[Status["NotFound"] = 404] = "NotFound";
})(Status || (Status = {}));
*/
```

## Особенности и нюансы

- Reverse mapping **работает ТОЛЬКО для числовых Enum-ов**.
- Строковые Enum-ы не генерируют свойства для обратного поиска, так как предполагается, что строковое значение уже само по себе достаточно информативно.
- Стоит быть осторожным при итерации по числовому Enum-у через `Object.keys()`, так как вы получите как строковые ключи ("Success"), так и числовые ("200"). Чтобы получить только имена, придется отфильтровать ключи, которые конвертируются в числа.
