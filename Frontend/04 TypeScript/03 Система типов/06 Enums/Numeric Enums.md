# Numeric Enums

## Описание

> [!info]
> Numeric Enums (Числовые перечисления) — это способ задать набор именованных констант, где каждое значение ассоциировано с числом. По умолчанию значения начинаются с 0 и увеличиваются на 1.

В отличие от большинства других возможностей TypeScript, Enums — это не только сущность уровня типов. После компиляции они превращаются в реальные JavaScript-объекты, которые можно использовать в рантайме.

## Примеры использования

```typescript
// Автоматическая нумерация (Up = 0, Down = 1, Left = 2, Right = 3)
enum Direction {
  Up,
  Down,
  Left,
  Right,
}

// Задание начального значения (Up = 1, Down = 2, Left = 3, Right = 4)
enum DirectionStartedAtOne {
  Up = 1,
  Down,
  Left,
  Right,
}

// Явное задание значений
enum StatusCodes {
  OK = 200,
  BadRequest = 400,
  Unauthorized = 401,
}

const status: StatusCodes = StatusCodes.OK;
```

## Особенности и нюансы

- В отличие от строковых Enums, числовые Enums поддерживают обратное отображение (Reverse Mapping) — вы можете получить имя по значению: `Direction[0] // "Up"`.
- До TypeScript 5.0 числовые энамы были не очень безопасны: вы могли присвоить им любое число без ошибки (например, `const d: Direction = 99;` было валидным кодом, хотя `99` нет в `Direction`). В TS 5.0 это поведение исправили, и теперь `Direction` работает как Union всех своих числовых значений.
- Вычисляемые значения: члены энама могут быть результатами выражений (`Math.random()`), но тогда следующие за ними члены должны быть инициализированы явно.
