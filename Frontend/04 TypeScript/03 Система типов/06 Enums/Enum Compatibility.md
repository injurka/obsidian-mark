# Enum Compatibility

## Описание

> [!info]
> Совместимость перечислений (Enum Compatibility) в TypeScript описывает правила того, как значения перечислений взаимодействуют с другими типами данных (числами, строками) и между собой.

Понимание этих правил важно, так как TypeScript ведет себя по-разному для числовых и строковых Enum-ов.

## Примеры и правила

**1. Числовые Enum-ы и числа совместимы**
Числовые Enum-ы совместимы с типом `number`, и тип `number` совместим с числовыми Enum-ами. (Хотя с TS 5.0 передача любого числа в Enum стала выдавать ошибку, если это не Union всех значений, совместимость со стороны Enum-а к числу осталась).

```typescript
enum Status { Ready, Waiting }
let x: number = Status.Ready; // OK
```

**2. Значения из разных Enum-ов НЕ совместимы**
Даже если значения из разных Enum-ов одинаковы, они несовместимы друг с другом.

```typescript
enum Status { Ready, Waiting }
enum Color { Red, Blue }

let myStatus = Status.Ready;
// myStatus = Color.Red; // Ошибка!
```

**3. Строковые Enum-ы несовместимы с обычными строками**
Как упоминалось ранее, строковые Enum-ы номинативны. Вы не можете присвоить обычную строку переменной типа строкового Enum-а.

```typescript
enum StringDir { Up = "UP" }
let dir: StringDir;
// dir = "UP"; // Ошибка! Type '"UP"' is not assignable to type 'StringDir'
dir = StringDir.Up; // Только так
```

## Особенности и нюансы

- Номинативность строковых Enum-ов часто является причиной разочарования новичков, особенно когда данные приходят с бэкенда в виде обычных строк. Приходится либо использовать приведение типов (`as StringDir`), либо отказываться от Enum-ов в пользу Union Types.
- Эта разница в совместимости — еще одна причина, почему сообщество предпочитает Union Types, так как их совместимость полностью структурна и более предсказуема.
