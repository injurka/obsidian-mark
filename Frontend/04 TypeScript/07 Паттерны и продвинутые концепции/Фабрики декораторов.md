> [!info]
> **Фабрика декораторов (Decorator Factory)** — это функция, которая возвращает функцию-декоратор. Она позволяет передавать пользовательские параметры для настройки поведения декоратора при его применении к классам, методам или свойствам.

## Суть концепции

В TypeScript декораторы — это функции, которые вызываются в процессе определения класса. Однако часто возникает необходимость настроить поведение декоратора, передав ему аргументы. Для этого используется паттерн **Фабрика декораторов**. 

Фабрика — это просто обертка, которая принимает параметры и возвращает саму функцию декоратора, замыкая эти параметры в своей области видимости. Это делает декораторы переиспользуемыми и гибкими.

### Legacy декораторы (experimentalDecorators) vs Новые декораторы (TS 5.0)

В старом стандарте (`experimentalDecorators: true`) фабрики декораторов возвращали функции с сигнатурами, зависящими от типа декоратора (цель, имя свойства, дескриптор).
В новом стандарте декораторов (ECMAScript stage 3, начиная с TypeScript 5.0) фабрики работают аналогично, но возвращаемый декоратор принимает новые аргументы: `value` (само декорируемое значение) и объект `context` с метаданными.

## Примеры кода на TypeScript

### Пример 1: Простая фабрика декоратора класса (Новый стандарт TS 5.0+)

```typescript
// Фабрика декоратора
function WithTemplate(template: string, hookId: string) {
  // Возвращаем функцию-декоратор (новый стандарт)
  return function <T extends { new (...args: any[]): { name: string } }>(
    originalClass: T,
    context: ClassDecoratorContext
  ) {
    if (context.kind === 'class') {
      return class extends originalClass {
        constructor(...args: any[]) {
          super(...args);
          const hookEl = document.getElementById(hookId);
          if (hookEl) {
            hookEl.innerHTML = template;
            hookEl.querySelector('h1')!.textContent = this.name;
          }
        }
      };
    }
  };
}

@WithTemplate('<h1>Мой шаблон</h1>', 'app')
class Person {
  name = 'Максим';
  constructor() {
    console.log('Создание объекта Person...');
  }
}
```

### Пример 2: Фабрика декоратора метода (Legacy стандарт)

```typescript
// Фабрика декоратора для логирования с заданным префиксом
function LogMethod(prefix: string) {
  // Возвращаем сам декоратор
  return function (
    target: any, 
    propertyName: string, 
    descriptor: PropertyDescriptor
  ) {
    const originalMethod = descriptor.value;

    descriptor.value = function (...args: any[]) {
      console.log(`[${prefix}] Вызов метода ${propertyName} с аргументами:`, args);
      return originalMethod.apply(this, args);
    };
  };
}

class Calculator {
  @LogMethod('CALC_DEBUG')
  add(a: number, b: number) {
    return a + b;
  }
}

const calc = new Calculator();
calc.add(2, 3); // Выведет: [CALC_DEBUG] Вызов метода add с аргументами: [2, 3]
```

## Нюансы и подводные камни
- **Порядок выполнения**: Если к одному элементу применено несколько фабрик декораторов, сами фабрики (внешние функции) вызываются **сверху вниз** (в порядке их написания), а вот возвращаемые ими функции-декораторы — **снизу вверх**.
- **Типизация**: При использовании новых декораторов TypeScript 5.0, фабрика должна возвращать правильный тип (например, `ClassDecoratorContext`, `MethodDecoratorContext`), чтобы компилятор мог корректно вывести типы.
