> [!info]
> **Виды декораторов** — это классификация декораторов в TypeScript в зависимости от того, к какому элементу класса они применяются: к самому классу, его методам, свойствам, аксессорам (геттерам/сеттерам) или параметрам методов.

## Суть концепции

Декораторы предоставляют способ изменения классов и их членов во время определения класса. В зависимости от места применения, декоратор получает различные аргументы и способен по-разному модифицировать поведение целевого элемента. 

Основные виды декораторов:
- **Декораторы классов (Class Decorators)**: применяются к конструктору класса и используются для изменения или подмены самого класса.
- **Декораторы методов (Method Decorators)**: применяются к методам класса. Позволяют изменить реализацию метода, добавить логирование, ограничить доступ и т.д.
- **Декораторы свойств (Property Decorators)**: применяются к полям класса. Часто используются для отслеживания изменения свойств или добавления метаданных.
- **Декораторы аксессоров (Accessor Decorators)**: применяются к геттерам и сеттерам.
- **Декораторы параметров (Parameter Decorators)**: применяются к аргументам методов. Часто используются во фреймворках (например, NestJS) для внедрения зависимостей.

### Legacy декораторы (experimentalDecorators) vs Новые декораторы (TS 5.0)

Исторически TypeScript использовал экспериментальную реализацию декораторов (Legacy). С версии TypeScript 5.0 была введена поддержка стандартных декораторов ECMAScript (Stage 3). 
- **Главное отличие:** В новых декораторах контекст (метаданные и функции для работы с элементом) передается в объекте `context`, а само значение (например, функция метода) передается первым аргументом `value`.
- **Важно:** Новые декораторы TS 5.0 пока **не поддерживают декораторы параметров**. Если вам нужно декорировать параметры (как в NestJS или Angular), вы всё ещё должны использовать `experimentalDecorators: true`.

## Примеры кода на TypeScript (Новый стандарт)

### Декоратор метода
Декоратор, который логирует вызов метода:

```typescript
function Log(originalMethod: any, context: ClassMethodDecoratorContext) {
  const methodName = String(context.name);

  return function (this: any, ...args: any[]) {
    console.log(`Вызов метода ${methodName} с аргументами: ${args.join(', ')}`);
    return originalMethod.apply(this, args);
  };
}

class User {
  @Log
  greet(name: string) {
    return `Hello, ${name}!`;
  }
}

const user = new User();
user.greet('World'); // Выведет: Вызов метода greet с аргументами: World
```

### Декоратор свойства
Автоматическая инициализация значения:

```typescript
function DefaultValue(value: string) {
  return function (target: undefined, context: ClassFieldDecoratorContext) {
    return function (initialValue: any) {
      return initialValue !== undefined ? initialValue : value;
    };
  };
}

class Settings {
  @DefaultValue('dark')
  theme?: string;
}

const settings = new Settings();
console.log(settings.theme); // "dark"
```
