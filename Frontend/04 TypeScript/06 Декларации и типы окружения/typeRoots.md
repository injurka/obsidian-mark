# typeRoots

> [!info]
> **typeRoots** — это опция в `tsconfig.json`, которая позволяет переопределить директории, в которых TypeScript компилятор ищет глобальные декларации типов (`.d.ts` файлы) и npm-пакеты с типами.

## Суть концепции

По умолчанию TypeScript автоматически включает все пакеты, находящиеся в директории `node_modules/@types` (например, `@types/react`, `@types/jest`), во всем проекте. Их глобальные и модульные декларации становятся доступны компилятору.

Однако в некоторых ситуациях разработчикам необходимо:
1. Хранить собственные локальные глобальные типы в отдельной папке.
2. Полностью отключить автоподключение типов из `node_modules/@types`.
3. Подключить типы из кастомного монорепозитория или другой директории.

Именно для этого используется опция `typeRoots`.

### Пример использования `typeRoots`

```json
{
  "compilerOptions": {
    "typeRoots": [
      "./node_modules/@types", // Возвращаем стандартное поведение для пакетов
      "./src/types"            // Указываем компилятору искать наши глобальные типы здесь
    ]
  }
}
```

Если вы указываете `typeRoots`, стандартное поведение (поиск только в `node_modules/@types`) **отключается**. Поэтому важно явно указывать `"./node_modules/@types"`, если вы по-прежнему хотите использовать типы сторонних библиотек.

### Ambient Context и Strict Mode
Опция `typeRoots` крайне важна для работы с `declare` (ambient-декларациями). Если вы определяете глобальный модуль для нетипизированной библиотеки в своем `.d.ts` файле, TypeScript должен знать, где найти этот файл.
В условиях **Strict Mode** правильная настройка `typeRoots` избавляет от ошибок вида "Could not find a declaration file for module 'x'", гарантируя, что компилятор видит все ваши кастомные типы.
