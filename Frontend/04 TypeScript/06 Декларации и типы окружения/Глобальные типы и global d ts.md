# Глобальные типы и global.d.ts

> [!info]
> **Глобальные типы** — это типы или интерфейсы, доступные в любой части TypeScript-проекта без необходимости их явного импорта. Обычно они определяются в файле (или файлах) `global.d.ts`.

## Суть концепции

В TypeScript файлы без ключевых слов `import` или `export` автоматически считаются **глобальными скриптами** (script files), и их декларации становятся доступны везде. Если файл содержит `import` или `export`, он становится **модулем**, у которого есть собственная изолированная область видимости.

Чтобы добавить глобальные типы из файла-модуля, необходимо использовать конструкцию `declare global { ... }`.

### Пример использования глобальных деклараций

#### 1. Файл без модулей (традиционный `global.d.ts`)

```typescript
// src/types/global.d.ts
// Здесь нет ни export, ни import. Файл является скриптом.
type UserID = string | number;

interface Window {
    __REDUX_DEVTOOLS_EXTENSION__: any; // Расширение глобального объекта Window
}
```

#### 2. Расширение глобальной области из модуля

Если вам нужно использовать импорты внутри `global.d.ts`, файл становится модулем, и требуется явно расширять глобальную область видимости (Ambient Context):

```typescript
// src/types/global.d.ts
import { AppState } from './store';

declare global {
    interface Window {
        initialState: AppState;
    }
    
    // Глобальная переменная
    var IS_DEV: boolean;
}

export {}; // Делаем файл модулем
```

### Связь со Strict Mode и опциями
Глобальные типы необходимы для удовлетворения требований **Strict Mode**. Если вы попытаетесь обратиться к `window.__INITIAL_STATE__`, TypeScript со `strict: true` немедленно выдаст ошибку, так как такого свойства не существует в стандартном интерфейсе `Window`. Использование `declare global` и `.d.ts` файлов позволяет легализовать это использование, сохраняя строгую типизацию. Настраивается поиск таких файлов в `tsconfig.json` через опцию `typeRoots`.
