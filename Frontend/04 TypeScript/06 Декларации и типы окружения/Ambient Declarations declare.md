# Ambient Declarations declare

> [!info]
> **Ambient Declarations (Окружающие декларации)** — это способ сообщить компилятору TypeScript о существовании объектов, переменных, классов или модулей, которые инициализируются вне текущего кода (например, предоставляются браузером, внешним скриптом или плагином). Обозначаются ключевым словом `declare`.

## Суть концепции

Слово `declare` позволяет описать интерфейс внешнего окружения. Когда вы пишете `declare var jQuery: any;`, вы обещаете компилятору: "Поверь мне, эта переменная существует в среде исполнения, я просто описываю её тип, не генерируй для неё JavaScript-код". Это называется ambient контекстом.

Обычно ambient-декларации помещаются в специальные файлы `.d.ts` (Декларационные файлы), где все объявления по умолчанию считаются "окружающими".

### Примеры использования

#### 1. Декларация глобальной переменной

Если в HTML-файле подключен внешний скрипт, добавляющий переменную в глобальную область видимости:

```typescript
// Файл: globals.d.ts
declare const API_URL: string;
declare function showModal(id: string): void;
```

#### 2. Декларация внешнего модуля

Если вы импортируете не-JS ресурсы (например, картинки, CSS-модули) через Webpack, TypeScript по умолчанию выдаст ошибку, так как не понимает такие модули.

```typescript
// Файл: images.d.ts
declare module "*.png" {
    const value: string;
    export default value;
}

// Теперь можно делать: import logo from './logo.png';
```

#### 3. Декларация сторонней библиотеки без типов

```typescript
declare module "some-untyped-lib" {
    export function doSomething(param: string): void;
    export const version: number;
}
```

### Связь со Strict Mode
Ambient-декларации тесно связаны со **Strict Mode** (особенно с флагом `noImplicitAny`). Без строгого режима компилятор мог бы проигнорировать неизвестный импорт, но в строгом режиме он потребует явного `declare module`. 
Важно понимать, что `declare` не создает саму сущность, это исключительно тайпинг-контракт для компилятора TypeScript.
