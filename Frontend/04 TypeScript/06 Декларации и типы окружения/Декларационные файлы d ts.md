# Декларационные файлы d ts

> [!info]
> **Декларационные файлы (Declaration Files)** с расширением `.d.ts` — это файлы TypeScript, которые содержат исключительно информацию о типах, интерфейсах и сигнатурах функций, и не содержат никакого исполняемого JavaScript-кода.

## Суть концепции

Файлы `.d.ts` служат "мостом" между обычным JavaScript и TypeScript. Они описывают форму объектов и API. В процессе компиляции TypeScript полностью игнорирует (удаляет) типы, а `.d.ts` файлы не компилируются в JavaScript — они используются компилятором исключительно на этапе статического анализа для проверки типов и автокомплита в IDE.

### Зачем они нужны?

1. **Типизация внешних JS-библиотек**: Если вы используете библиотеку, написанную на JavaScript (например, jQuery или Lodash), файл `.d.ts` опишет ее API для TypeScript.
2. **Экспорт собственных типов**: При компиляции TypeScript-библиотеки с флагом `"declaration": true`, `tsc` автоматически сгенерирует `.d.ts` файлы вместе с `.js` файлами для потребителей библиотеки.
3. **Глобальные типы**: Создание глобальных типов (ambient context) для всего проекта.

### Пример декларационного файла `math.d.ts`

```typescript
// Это только описание, здесь нет реализации { return a + b; }
export declare function add(a: number, b: number): number;
export declare function subtract(a: number, b: number): number;

export interface Point {
    x: number;
    y: number;
}
```

### Ambient Context (`declare`) и Strict Mode
Внутри `.d.ts` файлов все объявления по умолчанию находятся в "окружающем" (ambient) контексте. Ключевое слово `declare` используется для описания переменных, модулей или классов, реализация которых уже существует где-то в среде выполнения (например, глобальная переменная `window`).
При включенном **Strict Mode** (в `tsconfig.json`) наличие точных `.d.ts` деклараций критически важно, так как `noImplicitAny` запретит использование неизвестных JS-модулей без явного описания их типов.
