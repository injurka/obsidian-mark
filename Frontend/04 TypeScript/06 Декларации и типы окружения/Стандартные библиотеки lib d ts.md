# Стандартные библиотеки lib.d.ts

> [!info]
> **lib.d.ts (Standard Library Declarations)** — это набор встроенных декларационных файлов TypeScript, описывающих типы для встроенных объектов JavaScript (таких как `Array`, `Map`, `Math`) и API окружения (таких как DOM `window`, `document`).

## Суть концепции

Поскольку TypeScript компилируется в JavaScript и исполняется в определенной среде (Браузер, Node.js), ему необходимо знать о "базовых" объектах среды выполнения. Пакет TypeScript поставляется с множеством `.d.ts` файлов (начинающихся с `lib.`), которые содержат все эти ambient-декларации. 

По умолчанию `tsc` подключает определенный набор библиотек в зависимости от опции `target` в `tsconfig.json`. Разработчик может переопределить это, явно указав параметр `lib`.

### Настройка `lib` в `tsconfig.json`

Опция `lib` позволяет точечно указать, какие стандарты и API доступны.

```json
{
  "compilerOptions": {
    "target": "ES5",
    "lib": [
      "DOM",             // Включает типы для браузера: Window, Document, HTMLElement
      "DOM.Iterable",    // Итераторы для DOM элементов (например, NodeList)
      "ES2022",          // Включает синтаксис и методы ES2022 (например, Array.prototype.at)
      "WebWorker"        // Если пишем Web Worker, DOM не нужен, подключаем WebWorker API
    ]
  }
}
```

### Взаимодействие со Strict Mode и Ambient Context
Все определения в файлах `lib.d.ts` написаны с использованием `declare` — это массивный ambient-контекст, предоставляемый самим языком. 
В **Strict Mode** (особенно с флагом `strictNullChecks`), стандартные библиотеки обеспечивают строгие типы возвращаемых значений. Например, `document.getElementById('app')` вернет `HTMLElement | null`. Без строгих проверок это вернуло бы `HTMLElement`, что могло бы привести к потенциальной ошибке `null reference` в рантайме.
