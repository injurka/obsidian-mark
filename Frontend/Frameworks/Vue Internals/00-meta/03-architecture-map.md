# Карта архитектуры (Architecture Map)

Архитектура исходного кода Vue 3 построена на принципе монорепозитория, разбитого на независимые пакеты.

## Основные пакеты (Packages)

### 1. Ядро (Core)
- **`@vue/reactivity`**: Независимая система реактивности на основе Proxy. Можно использовать без остального Vue.
- **`@vue/runtime-core`**: Платформонезависимое ядро рантайма. Содержит логику компонентов, VDOM, алгоритм patch.
- **`@vue/runtime-dom`**: Браузерная реализация рантайма. Содержит манипуляции с реальным DOM (API браузера).

### 2. Компилятор (Compiler)
- **`@vue/compiler-core`**: Платформонезависимое ядро компилятора (Парсер, Трансформер, Генератор кода).
- **`@vue/compiler-dom`**: Браузерный компилятор шаблонов.
- **`@vue/compiler-sfc`**: Компилятор однофайловых компонентов (`.vue` файлов). Разбирает `<template>`, `<script>` и `<style>`.

### 3. Сборка (Entry points)
- **`vue`**: Главный пакет, объединяющий рантайм и компилятор в различные сборки (esm, cjs, global).
- **`@vue/server-renderer`**: Пакет для серверного рендеринга (SSR).

## Диаграмма зависимостей
*Компилятор и Рантайм разделены. В production-сборках (без встроенного компилятора) используется только пакет рантайма.*
