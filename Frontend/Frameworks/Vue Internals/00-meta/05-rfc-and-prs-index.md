# Индекс RFC и Pull Requests (RFC & PRs Index)

Список важных исторических документов и обсуждений, объясняющих архитектурные решения Vue.

## Vue RFCs (Request for Comments)
Официальный репозиторий с обсуждением новых фич: [vuejs/rfcs](https://github.com/vuejs/rfcs)

### Ключевые RFC:
- **[RFC-0042] Composition API**: Описание мотивации перехода к Composition API и его дизайна.
- **[RFC-0013] Teleport**: Предложение компонента `<Teleport>` для рендеринга элементов вне текущего дерева DOM.
- **[RFC-0027] Custom Elements Interop**: Изменения в интеграции с Web Components.
- **[RFC-0040] Script Setup**: Дизайн синтаксиса `<script setup>` для улучшения эргономики Composition API в SFC.
