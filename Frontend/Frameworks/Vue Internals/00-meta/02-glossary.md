# Глоссарий (Glossary)

Словарь терминов и аббревиатур, часто встречающихся в исходном коде Vue.

- **VNode (Virtual Node)**: JavaScript объект, описывающий узел DOM. Основа виртуального DOM.
- **AST (Abstract Syntax Tree)**: Абстрактное синтаксическое дерево. Представление HTML-шаблона в виде дерева объектов на этапе компиляции.
- **Track**: Процесс регистрации зависимости реактивного эффекта от определенного свойства объекта.
- **Trigger**: Процесс уведомления всех зависимых эффектов об изменении свойства, что вызывает их повторное выполнение.
- **Reactive Effect (Эффект)**: Функция, которая должна быть выполнена повторно при изменении реактивных данных, от которых она зависит (например, render-функция компонента или `watch`).
- **Patch**: Алгоритм сравнения двух деревьев VNode и применения минимально необходимого количества изменений к реальному DOM.
- **SFC (Single-File Component)**: Однофайловый компонент Vue (файлы `.vue`).
- **Hydration (Гидратация)**: Процесс, при котором клиентский JavaScript "оживляет" статический HTML, отрендеренный на сервере (SSR), привязывая к нему обработчики событий и реактивность.
