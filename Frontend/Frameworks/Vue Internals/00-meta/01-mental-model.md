# Ментальная модель Vue (Mental Model)

Этот документ описывает высокоуровневые концепции того, как "мыслит" и работает фреймворк Vue.js.

## Формула UI
Vue можно концептуально представить как уравнение: `UI = f(State)`.
Где `f` — это render-функция (скомпилированный шаблон), которая на основе состояния `State` генерирует описание интерфейса.

## Три кита Vue
Внутреннее устройство Vue базируется на трех основных системах, которые работают вместе:
1. **Реактивность (Reactivity Module)**: Отслеживает зависимости и оповещает об изменениях состояния.
2. **Компилятор (Compiler Module)**: Превращает HTML-подобные шаблоны в JavaScript render-функции, извлекая подсказки для оптимизации.
3. **Рендерер (Renderer Module)**: Отвечает за отрисовку виртуального DOM в реальный DOM браузера и эффективное обновление при срабатывании реактивности.

## Цикл обновления
1. Во время первого рендеринга компонента, вызывается render-функция.
2. Доступ к реактивным данным отслеживается (Track) в виде зависимостей.
3. При изменении данных вызывается триггер (Trigger), который ставит обновление компонента в очередь (NextTick).
4. Render-функция выполняется снова, создавая новое дерево VNodes.
5. Рендерер сравнивает новое дерево со старым (Patching) и точечно обновляет реальный DOM.
