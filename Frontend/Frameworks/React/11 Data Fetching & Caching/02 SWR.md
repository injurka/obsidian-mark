# SWR (Stale-While-Revalidate)

SWR — это библиотека для получения данных (Data Fetching), созданная командой Vercel (создателями Next.js). Название происходит от HTTP-заголовка кэширования `stale-while-revalidate`.

## 1. Философия SWR
Концепция крайне проста:
1. Сначала мгновенно вернуть данные из кэша (Stale - устаревшие).
2. Параллельно (в фоне) отправить запрос на сервер для проверки (Revalidate).
3. Прийти с новыми данными и обновить UI, если данные изменились.

Пользователь почти никогда не видит спиннеров загрузки при повторных заходах на страницу.

## 2. Базовое использование
```jsx
import useSWR from 'swr';

// Fetcher - это любая функция, возвращающая Promise
const fetcher = (...args) => fetch(...args).then(res => res.json());

function Profile() {
  // '/api/user' — это и URL, и уникальный КЛЮЧ кэша одновременно!
  const { data, error, isLoading } = useSWR('/api/user', fetcher);

  if (error) return <div>Ошибка загрузки</div>;
  if (isLoading) return <div>Загрузка...</div>;
  return <div>Привет, {data.name}!</div>;
}
```

## 3. Главные фичи "Из коробки"
- **Focus Revalidation:** Если пользователь ушел на другую вкладку браузера, а потом вернулся на вашу, SWR автоматически сделает фоновый запрос, чтобы обновить данные на экране (отлично подходит для дашбордов и соцсетей).
- **Network Recovery:** Если пропал интернет, а затем появился — SWR автоматически перезапросит данные.
- **Polling (Интервалы):** Легко настроить запрос данных каждые `X` секунд (`refreshInterval: 1000`).

## 4. SWR против TanStack Query (Кого выбрать?)
В 2026 году расстановка сил такая:

**Выбирайте SWR, если:**
- У вас легкое приложение или блог (особенно на Next.js).
- Вам нужно быстро набросать прототип.
- Вам не нужны сложные цепочки мутаций, и вы в основном только *читаете* данные.
- Вы хотите минимальный размер бандла.

**Выбирайте TanStack Query, если:**
- Вы пишете Enterprise CRM, сложную админку или магазин.
- Вам нужен жесткий контроль над сборщиком мусора (`gcTime`).
- У вас много сложных мутаций, связанных друг с другом (инвалидация десятков ключей по шаблону).
- Вам нужна поддержка Infinite Scroll (Бесконечной прокрутки) — в TanStack Query API для этого реализован намного лучше и мощнее.
