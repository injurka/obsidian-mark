# Vapor Mode (Без Virtual DOM)

**Vapor Mode** — это альтернативная стратегия компиляции, разрабатываемая для Vue 3, которая позволяет компилировать Vue-компоненты напрямую в вызовы DOM API, минуя использование Virtual DOM. Этот подход вдохновлен фреймворком Solid.js.

## Основные особенности Vapor Mode:

1. **Отказ от Virtual DOM:** Вместо создания виртуального дерева узлов и его последующего сравнения (diffing), компилятор генерирует код, который напрямую создает и обновляет реальные DOM-элементы на основе реактивных зависимостей.
2. **Увеличение производительности:** Исключение накладных расходов на создание и сравнение Virtual DOM делает инициализацию компонентов быстрее и снижает потребление памяти.
3. **Меньший размер бандла:** Поскольку компонентам в Vapor Mode не нужна среда выполнения Virtual DOM, размер итогового кода становится меньше. Компоненты тянут за собой только те функции Vue (например, `ref`, `computed`, функции работы с DOM), которые они реально используют.
4. **Opt-in (по желанию):** Vapor Mode не является заменой текущего механизма Vue. Это режим, который разработчики могут включать выборочно для определенных компонентов (например, критичных для производительности), при этом они будут бесшовно работать в одном приложении со стандартными Virtual DOM компонентами.
5. **Ограничения:** На начальном этапе Vapor Mode поддерживает только Composition API (в частности, `<script setup>`). Options API в этом режиме недоступен.

## Как это работает под капотом

В обычном режиме шаблон Vue компилируется в функцию `render`, которая возвращает VNode (виртуальный узел). При обновлении реактивного состояния функция `render` вызывается снова, создается новое дерево VNode, которое сравнивается со старым, и разница применяется к DOM.

В Vapor Mode шаблон компилируется в код, который:
- Создает DOM-элементы при первом рендеринге (используя `document.createElement`, `cloneNode` и т.д.).
- Навешивает эффекты (`effect` или `watchSyncEffect`) напрямую на те части DOM, которые зависят от реактивных переменных.

При изменении переменной обновляется только конкретный текстовый узел или атрибут в реальном DOM, без необходимости перерисовывать весь компонент или сравнивать деревья.

## Заметки
* Vapor Mode отлично подходит для высоконагруженных компонентов (например, больших таблиц, списков), где Virtual DOM становится бутылочным горлышком.
