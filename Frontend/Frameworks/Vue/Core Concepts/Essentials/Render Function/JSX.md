
**JSX (JavaScript XML)** — это синтаксическое расширение для JavaScript, позволяющее писать HTML-подобную разметку прямо внутри JS-кода. 

В контексте Vue, JSX — это не самостоятельная технология, а **синтаксический сахар над Render-функцией `h()`**. При сборке проекта (через Vite или Webpack) специальный плагин компилирует JSX-теги в вызовы `h()`, возвращающие Virtual DOM узлы.

---

## 1. Зачем использовать JSX вместо `<template>`?

Хотя шаблоны (SFC, Single-File Components) являются стандартом во Vue, у них есть ограничения. Шаблоны статичны и требуют использования директив для управления логикой.

JSX дает **всю мощь JavaScript** для рендеринга:
1. **Сложная динамика:** Если структура компонента сильно меняется в зависимости от пропсов (например, рекурсивные деревья, динамические заголовки, конструкторы таблиц), JSX позволяет избежать «лапши» из `v-if`.
2. **Строгая типизация (TSX):** TypeScript изначально понимает TSX. Вы получаете идеальный автокомплит, проверку типов для пропсов, событий и слотов без необходимости сложных настроек Language Server (как в случае с `.vue` файлами).
3. **Паттерны из React:** JSX позволяет легко использовать функциональные компоненты, Render-пропсы и возвращать массивы элементов без корневого узла (фрагменты).

---

## 2. Ключевое отличие: Распаковка `ref`

Самая частая ошибка при переходе с шаблонов на JSX — забыть про `.value`.
Шаблоны Vue автоматически «распаковывают» реактивные ссылки. В JSX **магии нет**, это обычный JavaScript, поэтому к значению `ref` нужно обращаться явно:

```tsx
import { defineComponent, ref } from 'vue'

export default defineComponent({
  setup() {
    const count = ref(0)
    
    // В шаблоне мы бы написали {{ count }}, но в JSX:
    return () => <div>Счетчик: {count.value}</div>
  }
})
```

## 3. Замена директив на JavaScript

Базовые структурные директивы в JSX не работают, они заменяются нативными конструкциями языка. 

* **`v-if` / `v-else`:** Заменяется на тернарный оператор или логическое И (`&&`).
* **`v-for`:** Заменяется на `Array.prototype.map()`.

```tsx
return () => (
  <ul>
    {isLoading.value && <p>Загрузка...</p>}
    
    {items.value.length > 0 
      ? items.value.map(item => <li key={item.id}>{item.name}</li>)
      : <li>Список пуст</li>
    }
  </ul>
)
```

## 4. Специфичные фичи Vue в JSX (Плагин Бабеля)

Хотя JSX пришел из React, официальный плагин Vue для JSX (или встроенный в Vite esbuild) добавляет **собственный синтаксический сахар**, чтобы разработчикам не приходилось страдать без удобных Vue-фич.

### `v-model`
Плагин позволяет использовать `v-model` прямо в JSX. Более того, поддерживаются аргументы и модификаторы (через массив):
```tsx
// Обычный v-model
<input v-model={text.value} />

// v-model с аргументом (v-model:title)
<CustomComponent v-model:title={pageTitle.value} />

// v-model с модификаторами (v-model.trim.lazy)
<input v-model={[text.value, ['trim', 'lazy']]} />
```

### Модификаторы событий (`.prevent`, `.stop`)
Вместо `@click.prevent` в JSX используется подчеркивание:
```tsx
<form onSubmit_prevent={() => submitData()}>
  <button onClick_stop={handleClick}>Клик</button>
</form>
```

### `v-show`
Директива `v-show` поддерживается из коробки, так как под капотом она просто управляет CSS-свойством `display`:
```tsx
<div v-show={isVisible.value}>Контент</div>
```

## 5. Работа со Слотами

Слоты — это самая сложная часть при переходе на JSX, так как концепция HTML-тегов меняется на вызов функций.

### Как отрендерить слот (внутри компонента)
Слоты передаются в `setup` через контекст. Слот — это функция, которую нужно вызвать, чтобы получить VNode.
```tsx
export default defineComponent({
  setup(props, { slots }) {
    return () => (
      <div class="card">
        <header>{slots.header ? slots.header() : 'Дефолтный заголовок'}</header>
        <main>{slots.default?.()}</main>
      </div>
    )
  }
})
```

### Как передать слот (при использовании компонента)
В JSX слоты передаются в компонент как **объект с функциями**, а не как вложенные теги `<template>`.
```tsx
<MyCard>
  {{
    default: () => <p>Основной текст</p>,
    header: () => <h1>Заголовок</h1>,
    // Scoped слот (слот с данными)
    footer: (slotProps) => <span>Данные из компонента: {slotProps.id}</span>
  }}
</MyCard>
```
*Примечание: Если компонент принимает только один `default` слот, можно передать элементы напрямую между тегами, как в React, плагин сам обернет их в объект.*

## 6. Классы и Стили

В React свойство `class` называется `className`, а стили принимают только объекты.
Во Vue JSX вы используете стандартный `class` и можете передавать те же удобные массивы и объекты, к которым привыкли в `<template>`:

```tsx
<div 
  class={['container', { 'is-active': isActive.value }]}
  style={[{ color: 'red' }, dynamicStyles.value]}
>
```

## Резюме для самопроверки

1. **Суть:** JSX — это синтаксический сахар для функции `h()`. Идеально подходит для сложной логики и интеграции с TypeScript.
2. **Без магии:** В JSX нужно явно обращаться к `.value` у `ref` переменных.
3. **Директивы:** `v-if` и `v-for` заменяются на `? :` и `.map()`.
4. **Магия плагина:** Официальный инструмент сборки Vue JSX сохраняет поддержку `v-model`, `v-show` и модификаторов событий (`onClick_prevent`).
5. **Слоты:** Это просто функции. В компоненте они вызываются (`slots.default()`), а извне передаются как объект с функциями между тегами компонента.
