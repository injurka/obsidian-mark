
# Мультимедиа в HTML (Аудио и Видео)

Основой работы с медиафайлами в современном HTML являются теги `<audio>` и `<video>`. Они имеют схожий синтаксис (API), но решают разные задачи. Оба тега являются парными, и текст, помещенный между открывающим и закрывающим тегом, будет показан только в том случае, если браузер **не поддерживает** данный элемент (fallback-контент).

---

## 1. Тег `<audio>` (Аудио)

Используется для встраивания звукового контента: музыки, подкастов, звуковых эффектов.

**Базовый пример:**
```html
<audio src="music.mp3" controls>
  Ваш браузер не поддерживает тег audio. Пожалуйста, обновите браузер.
</audio>
```

### Основные атрибуты:
* `controls` — отображает стандартную панель управления браузера (кнопка Play/Pause, таймлайн, громкость). Без этого атрибута плеер будет **невидим** на странице.
* `autoplay` — заставляет аудио начать воспроизведение автоматически сразу после загрузки страницы. *(См. раздел про политику Autoplay ниже).*
* `loop` — зацикливает воспроизведение. Когда трек заканчивается, он начинается заново.
* `muted` — по умолчанию отключает звук (устанавливает громкость на 0).
* `preload` — подсказывает браузеру, как загружать файл при открытии страницы. Имеет три значения:
  * `none` — не загружать файл до нажатия на Play (экономит трафик пользователя).
  * `metadata` *(рекомендуемое)* — загрузить только метаданные (длительность трека), чтобы корректно отобразить таймлайн.
  * `auto` — загрузить весь файл целиком вместе со страницей.

---

## 2. Тег `<video>` (Видео)

Используется для встраивания видеороликов. Обладает всеми атрибутами тега `<audio>`, но имеет несколько своих, специфичных для визуального контента.

**Базовый пример:**
```html
<video src="promo.mp4" width="800" controls poster="preview.jpg">
  Извините, ваш браузер не поддерживает встроенные видео.
</video>
```

### Специфичные атрибуты `<video>`:
* `poster` — ссылка на изображение, которое будет показываться до того, как пользователь нажмет кнопку Play (превью/обложка). Если не указать, браузер возьмет первый кадр видео, что может занять время на загрузку или кадр окажется просто черным экраном.
* `width` и `height` — ширина и высота видеоплеера в пикселях. (В современной разработке их чаще задают через CSS).
* `playsinline` — **критически важный атрибут для мобильных устройств** (особенно iOS). Указывает браузеру воспроизводить видео прямо на странице, не разворачивая его автоматически в полноэкранный режим.

## 3. Тег `<source>` (Кроссбраузерность и форматы)

Разные браузеры могут поддерживать разные кодеки. Чтобы гарантировать, что видео или аудио запустится у всех пользователей, используется тег `<source>`. Он позволяет указать **несколько вариантов одного и того же файла**. 

Браузер читает список `<source>` сверху вниз, проверяет атрибут `type` и скачивает **первый поддерживаемый формат**, игнорируя остальные.

```html
<video controls poster="cover.jpg" width="640">
  <!-- Сначала предлагаем современный и легкий формат -->
  <source src="video.webm" type="video/webm">
  <!-- Затем универсальный, но более тяжелый вариант -->
  <source src="video.mp4" type="video/mp4">
  <!-- Текст для очень старых браузеров -->
  <p>Ваш браузер не поддерживает HTML5 видео. Скачайте его <a href="video.mp4">по ссылке</a>.</p>
</video>
```

### Рекомендуемые форматы на сегодняшний день:
**Для Видео:**
1. `MP4` (кодеки H.264 / H.265) — абсолютный стандарт, работает везде (99.9% устройств).
2. `WebM` (кодеки VP9 / AV1) — формат от Google, обеспечивает лучшее сжатие при аналогичном качестве, отлично работает в Chrome/Edge/Firefox. Современный кодек `AV1` сегодня является стандартом для стриминговых платформ.

**Для Аудио:**
1. `MP3` — поддерживается всеми браузерами, классика.
2. `AAC` (`.m4a`) — лучшее качество при меньшем размере, работает в экосистеме Apple и других современных браузерах.
3. `Ogg` / `WebM` (кодек Opus) — открытые форматы с отличным сжатием, используются в основном веб-приложениями и играми.

## 4. Тег `<track>` (Субтитры и Доступность)

Для видеоконтента крайне важно обеспечивать доступность (Accessibility / a11y) с помощью субтитров. Для этого внутрь `<video>` добавляется одиночный тег `<track>`. Он подключает текстовый файл в формате `WebVTT` (`.vtt`).

```html
<video controls>
  <source src="movie.mp4" type="video/mp4">
  
  <!-- Русские субтитры по умолчанию -->
  <track kind="subtitles" src="ru-subs.vtt" srclang="ru" label="Русский" default>
  <!-- Английские субтитры -->
  <track kind="subtitles" src="en-subs.vtt" srclang="en" label="English">
</video>
```

### Атрибуты `<track>`:
* `kind` — тип дорожки. Основные значения: `subtitles` (субтитры с переводом) и `captions` (скрытые субтитры для слабослышащих, включающие описание звуков, например `[звук взрыва]`).
* `srclang` — язык субтитров (например, `ru`, `en`).
* `label` — название дорожки, которое пользователь увидит в меню плеера.
* `default` — указывает, что эта дорожка должна быть включена по умолчанию.

## 5. Политика Autoplay (Автовоспроизведение)

> [!WARNING] Важно для разработки
> В современных браузерах (Chrome, Safari, Firefox) действуют строгие **Autoplay Policies**. Браузер **заблокирует** автоматическое воспроизведение видео или аудио, если в нём есть звук, а пользователь еще не взаимодействовал со страницей (не кликал по ней).

**Как правильно сделать фоновое видео (Background Video), которое запустится автоматически:**
Вы обязаны добавить атрибут `muted`. Фоновое видео обычно зацикливают и запрещают переход в полноэкранный режим на iOS.

```html
<video src="background.mp4" autoplay loop muted playsinline>
</video>
```
*Запомните комбо: `autoplay loop muted playsinline` — стандарт для фоновых видео на сайтах.*

## 6. JavaScript API (HTMLMediaElement)

Браузерные плееры по умолчанию (`controls`) выглядят по-разному в каждом браузере (в Chrome — одни кнопки, в Safari — другие) и не поддаются глубокой стилизации через CSS. 

Поэтому в современной разработке атрибут `controls` убирают, рисуют собственные красивые кнопки на HTML/CSS и управляют видео/аудио через **JavaScript API**.

Оба элемента (`<audio>` и `<video>`) наследуют интерфейс `HTMLMediaElement` и предоставляют мощный функционал:

### Основные методы и свойства:
```javascript
const myVideo = document.querySelector('video');

// Методы
myVideo.play();  // Запустить воспроизведение
myVideo.pause(); // Приостановить

// Свойства
myVideo.volume = 0.5;      // Установить громкость на 50%
myVideo.currentTime = 10;  // Перемотать на 10-ю секунду
console.log(myVideo.duration); // Получить общую длину в секундах
```

### Основные события:
* `play` / `pause` — срабатывают при запуске и остановке.
* `timeupdate` — срабатывает постоянно (несколько раз в секунду) по мере воспроизведения. Используется для отрисовки кастомной полосы прокрутки (таймлайна).
* `ended` — срабатывает, когда медиафайл доиграл до конца.

```javascript
// Пример: обновляем текст с текущим временем
myVideo.addEventListener('timeupdate', () => {
  document.getElementById('timer').innerText = Math.floor(myVideo.currentTime) + ' сек';
});
```
