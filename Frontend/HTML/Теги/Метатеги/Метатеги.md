# Метатеги

Метатеги (теги `<meta>`) располагаются внутри секции `<head>` HTML-документа. Они не отображаются непосредственно на странице, а передают браузерам, поисковым роботам и сторонним сервисам техническую, навигационную и маркетинговую информацию.

---

## 1. Технические метатеги

Эти теги обязательны для корректного рендеринга и индексации любого современного сайта.

### 1.1. Кодировка документа
```html
<meta charset="utf-8">
```
Должен быть объявлен первым в `<head>`, чтобы браузер сразу корректно отображал символы (особенно кириллицу).

### 1.2. viewport (Адаптивность)
```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```
Заставляет браузер сопоставлять ширину области просмотра (viewport) с физической шириной экрана устройства. Без этого мобильные браузеры отрендерят страницу в десктопном разрешении (около 980px) и сожмут её, сделав текст нечитаемым.

### 1.3. robots (Индексация)
```html
<meta name="robots" content="index, follow">
```
Инструкции для поисковых краулеров.
*   `index` / `noindex` — разрешить/запретить индексацию страницы.
*   `follow` / `nofollow` — разрешить/запретить переход по ссылкам на этой странице.

## 2. SEO Метатеги

Помогают поисковым системам корректно формировать сниппет в поисковой выдаче.

*   **Description (Описание страницы):**
    ```html
    <meta name="description" content="Подробные обучающие заметки для Senior/Lead фронтенд-разработчика по архитектуре, CSS и JS.">
    ```
    Рекомендуемая длина: 150-160 символов.
*   **Keywords (Устарело):**
    ```html
    <meta name="keywords" content="frontend, html, css, js">
    ```
    Современные поисковые системы (включая Google) полностью игнорируют этот метатег из-за злоупотреблений спамом в прошлом. Использовать его не нужно.

## 3. Социальные метатеги: Open Graph и Twitter Cards

Когда вы делитесь ссылкой в мессенджере (Telegram, WhatsApp, Slack) или соцсети, сервис запрашивает HTML-код страницы и ищет в нем специальные теги для формирования красивого превью (карточка с картинкой, заголовком и описанием).

### 3.1. Open Graph (Протокол от Facebook)
Все теги имеют префикс `og:`:

```html
<meta property="og:title" content="База знаний фронтенд-разработчика">
<meta property="og:description" content="Все современные паттерны и технологии в одном месте.">
<meta property="og:image" content="https://myapp.com/assets/preview.jpg">
<meta property="og:url" content="https://myapp.com/current-page">
<meta property="og:type" content="website">
```

### 3.2. Twitter Cards (Специфика X/Twitter)
Если теги Twitter отсутствуют, сервис использует аналогичные теги Open Graph. Но для тонкой настройки (например, размера картинки) пишут отдельные теги:

```html
<meta name="twitter:card" content="summary_large_image"> <!-- Карточка с большим фото -->
<meta name="twitter:title" content="База знаний фронтенд-разработчика">
<meta name="twitter:description" content="Все паттерны и технологии.">
<meta name="twitter:image" content="https://myapp.com/assets/preview.jpg">
```
