# Списки (ul, ol, dl)

Списки используются для группировки связанных элементов информации. В HTML есть три основных типа списков.

---

## 1. Типы списков

### 1.1. Маркированный список (`<ul>`)
Используется, когда порядок элементов не имеет значения (Unordered List). Дочерними элементами могут быть только `<li>` (List Item).

```html
<ul>
  <li>Хлеб</li>
  <li>Молоко</li>
</ul>
```

### 1.2. Нумерованный список (`<ol>`)
Используется при важности последовательности шагов (Ordered List).

```html
<ol start="1" type="1">
  <li>Шаг 1: Смешать ингредиенты</li>
  <li>Шаг 2: Выпекать 30 минут</li>
</ol>
```

#### Полезные атрибуты `<ol>`:
*   `type` — стиль нумерации (`1` — цифры, `a`/`A` — буквы, `i`/`I` — римские цифры).
*   `start` — число, с которого начнется отсчет (например, `start="5"`).
*   `reversed` — включает обратный отсчет (сверху вниз).

### 1.3. Список описаний (`<dl>`)
Используется для связи пар "имя - значение" (Description List).
*   `<dt>` (Description Term) — термин или имя.
*   `<dd>` (Description Details) — описание или значение.

```html
<dl>
  <dt>HTML</dt>
  <dd>Язык гипертекстовой разметки.</dd>
  
  <dt>CSS</dt>
  <dd>Каскадные таблицы стилей.</dd>
</dl>
```
*Кейсы использования:* глоссарии, словари, списки технических характеристик товара (например, "Вес: 1.2 кг").

---

## 2. Доступность списков в Safari (Важная деталь для Lead)

В CSS часто сбрасывают дефолтные маркеры списков:
```css
ul, ol {
  list-style: none;
}
```
> [!WARNING]
> Браузер Safari (WebKit) при применении `list-style: none` **полностью удаляет семантическую роль списка** из дерева доступности (Accessibility Tree). Скринридер перестает объявлять пользователю: "Список, 3 элемента", воспринимая его как обычный набор разрозненных блоков.

### Решение:
Если вам нужно сбросить визуальные маркеры, но сохранить доступность для скринридеров, принудительно возвращайте роль в HTML:
```html
<ul role="list">
  <li>Элемент</li>
</ul>
```
