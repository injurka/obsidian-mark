
# Связь HTML с другими языками

HTML никогда не работает в вакууме. Сам по себе он является лишь языком разметки (не языком программирования!). Его главная задача — описать структуру данных. Чтобы превратить эту структуру в полноценное, красивое и интерактивное веб-приложение, HTML тесно взаимодействует с другими языками и технологиями.

В веб-разработке существует классическая аналогия **«Строительство дома»**:
* **HTML (Каркас):** Фундамент, стены, крыша, дверные проемы. То, из чего состоит дом.
* **CSS (Дизайн):** Обои, краска, мебель, размер окон. То, как дом выглядит.
* **JavaScript (Коммуникации):** Электричество, водопровод, умный дом. То, как дом функционирует и реагирует на действия жильцов.

## 1. HTML и CSS (Каскадные таблицы стилей)

CSS отвечает за визуальное представление HTML-документа. Он указывает браузеру цвета, шрифты, отступы, анимации и расположение элементов на экране.

### Как связать HTML и CSS?
Есть три способа внедрить CSS в HTML. В современной разработке правильным считается только один — внешний.

1. **Inline (Встроенный) — Плохая практика:**
   Стили пишутся прямо в теге через атрибут `style`. Ломает принцип разделения ответственности, код тяжело поддерживать.
   ```html
   <h1 style="color: red; font-size: 24px;">Заголовок</h1>
   ```

2. **Internal (Внутренний) — Допустимо для маленьких страниц:**
   Стили пишутся внутри тега `<style>` в блоке `<head>`.
   ```html
   <head>
     <style>
       h1 { color: red; }
     </style>
   </head>
   ```

3. **External (Внешний файл) — Стандарт:**
   HTML только дает ссылку на файл `.css`.
   ```html
   <head>
     <link rel="stylesheet" href="styles.css">
   </head>
   ```

### Мосты между HTML и CSS: Классы и ID
Чтобы CSS понимал, к какому именно HTML-тегу применить стиль, используются атрибуты `class` и `id`. Это главные "мосты" между двумя языками.
```html
<!-- HTML -->
<button class="btn-primary" id="login-btn">Войти</button>
```
```css
/* CSS */
.btn-primary { background-color: blue; } /* Обращение по классу */
#login-btn { margin-top: 10px; }         /* Обращение по ID */
```

## 2. HTML и JavaScript (Интерактивность)

JavaScript (JS) — это полноценный язык программирования, который "оживляет" страницу. С его помощью можно валидировать формы, отправлять запросы на сервер без перезагрузки страницы, создавать сложные анимации и попапы.

### Как JS "видит" HTML? (DOM-дерево)
Когда браузер читает HTML-код, он преобразует его в специальную объектную модель — **DOM (Document Object Model)**. Для JavaScript HTML-страница — это гигантский объект `document`, состоящий из узлов (нод), которыми можно манипулировать.

### Как связать HTML и JS?
Аналогично CSS, есть три способа:

1. **Атрибуты событий (Inline) — Плохая практика:**
   ```html
   <button onclick="alert('Привет!')">Кликни меня</button>
   ```
2. **Внутренний скрипт:**
   ```html
   <script>
     console.log('Скрипт выполнен');
   </script>
   ```
3. **Внешний файл — Стандарт:**
   ```html
   <script src="app.js" defer></script>
   ```
   *(Атрибут `defer` гарантирует, что JS выполнится только после того, как браузер полностью построит DOM-дерево из HTML).*

### Пример взаимодействия:
HTML предоставляет элемент, JS находит его и заставляет работать:
```html
<!-- HTML -->
<div id="counter">0</div>
<button id="add-btn">+1</button>
```
```javascript
// JavaScript
const btn = document.getElementById('add-btn');
const counterDisplay = document.getElementById('counter');
let count = 0;

btn.addEventListener('click', () => {
  count++;
  counterDisplay.innerText = count; // JS меняет содержимое HTML!
});
```

## 3. HTML и Современные Фреймворки (React, Vue, Angular)

В современных Single Page Applications (SPA) грань между HTML и JavaScript стирается. Фреймворки используют шаблонизацию, чтобы писать HTML прямо внутри JavaScript логики.

* **В React (технология JSX):** HTML-подобный синтаксис пишется прямо внутри JS-функций.
  ```jsx
  function Welcome({ name }) {
    return <h1 className="title">Привет, {name}!</h1>;
  }
  ```
* **В Vue.js (Директивы):** Используются специальные атрибуты в HTML, которые Vue компилирует в JS.
  ```vue
  <template>
    <!-- v-if и v-for — это Vue-директивы внутри HTML -->
    <ul v-if="isVisible">
      <li v-for="item in items">{{ item.name }}</li>
    </ul>
  </template>
  ```

## 4. HTML и Backend (Серверные языки)

Серверные языки, такие как **PHP, Python, Ruby, Java, Node.js**, не запускаются в браузере. Они работают на сервере (компьютере, где лежит сайт).

Их главная задача — сгенерировать HTML-код "на лету" (взяв данные из базы данных) и отправить готовый текстовый файл браузеру пользователя. Этот процесс называется **Server-Side Rendering (SSR)**.

### Пример (шаблонизатор Blade для PHP):
Бэкенд-разработчик пишет шаблон, смешивая HTML и серверный код:
```html
<div class="user-profile">
  <h1>Добро пожаловать, {{ $user->name }}!</h1>
  @if($user->isAdmin)
    <button>Панель администратора</button>
  @endif
</div>
```
Когда пользователь запрашивает страницу, сервер вместо этих переменных подставит реальные данные (например, имя "Иван") и отдаст браузеру чистый, валидный HTML, в котором нет ни следа PHP.

## 5. WebAssembly (Wasm)

В последние годы HTML научился косвенно взаимодействовать с такими языками, как **C++, Rust, C# и Go**.
Технология WebAssembly позволяет компилировать код, написанный на этих языках, в бинарный формат, который исполняется в браузере с почти нативной скоростью. Wasm не умеет напрямую работать с HTML/DOM, но он взаимодействует с JavaScript, который в свою очередь уже меняет HTML. Это используется для портирования тяжелых 3D-игр, видеоредакторов или CAD-систем в браузер.

> [!NOTE] Архитектурное правило (Separation of Concerns)
> Идеальный код — это код, в котором HTML отвечает **только** за смысл и структуру контента, CSS **только** за красоту, а JS **только** за логику. Чем меньше они перемешаны друг с другом на уровне синтаксиса (inline-стили, inline-скрипты), тем проще тестировать, масштабировать и поддерживать проект.
