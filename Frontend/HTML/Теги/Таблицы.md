# Таблицы (table)

Таблицы в HTML предназначены исключительно для отображения табличных структурированных данных. Верстка сетки сайта с помощью таблиц (табличная верстка) строго запрещена и осталась в 90-х годах.

---

## 1. Семантическая структура таблицы

Правильная таблица должна разделять заголовок, тело и подвал данных.

```html
<table>
  <caption>Средние зарплаты фронтендеров в 2026 году</caption>
  
  <thead>
    <tr>
      <th scope="col">Квалификация</th>
      <th scope="col">Зарплата (руб)</th>
    </tr>
  </thead>
  
  <tbody>
    <tr>
      <th scope="row">Junior</th>
      <td>100 000</td>
    </tr>
    <tr>
      <th scope="row">Senior</th>
      <td>350 000</td>
    </tr>
  </tbody>
  
  <tfoot>
    <tr>
      <td>Средняя:</td>
      <td>225 000</td>
    </tr>
  </tfoot>
</table>
```

### Ключевые теги и доступность:
*   `<th>` — ячейка заголовка (выделяется жирным).
*   `<td>` — обычная ячейка с данными.
*   **Атрибут `scope="col/row"`:** Явно указывает, к чему относится данный заголовок: к колонке (`col`) или к строке (`row`). Это критично для скринридеров, чтобы они могли корректно зачитать ячейку данных на пересечении осей.

---

## 2. Объединение ячеек: rowspan и colspan

Если ячейка должна занимать несколько колонок или строк, используются атрибуты:

*   **`colspan`** — объединение по горизонтали (колонки).
*   **`rowspan`** — объединение по вертикали (строки).

```html
<tr>
  <!-- Объединяем две ячейки по горизонтали -->
  <td colspan="2">Итоговые показатели за год</td>
</tr>
```

---

## 3. Адаптивность таблиц

Широкие таблицы ломают мобильную верстку, вылезая за границы экрана смартфона.

### Способ 1: Горизонтальный скролл (Простой)
Оборачиваем таблицу в контейнер с горизонтальной прокруткой:
```css
.table-wrapper {
  width: 100%;
  overflow-x: auto;
  -webkit-overflow-scrolling: touch; /* плавная прокрутка на iOS */
}
```

### Способ 2: CSS-трансформация строк (Продвинутый)
На мобильных экранах мы превращаем каждую строку таблицы в независимый блок (Card), а ячейки выстраиваем друг под другом:

```css
@media (max-width: 600px) {
  table, thead, tbody, th, td, tr {
    display: block;
  }
  
  /* Скрываем шапку таблицы */
  thead tr {
    position: absolute;
    top: -9999px;
    left: -9999px;
  }
  
  td {
    position: relative;
    padding-left: 50%; /* Сдвигаем значение вправо */
  }
  
  /* Подставляем заголовки колонок из data-атрибутов через псевдоэлемент */
  td::before {
    content: attr(data-label);
    position: absolute;
    left: 10px;
    width: 45%;
    font-weight: bold;
  }
}
```
*В HTML ячейка пишется как:* `<td data-label="Зарплата">350 000</td>`.
