
**Unit-тестирование (Модульное тестирование)** — это процесс тестирования мельчайших, изолированных частей кода (функций, классов, или отдельных компонентов), чтобы убедиться, что каждая из них работает правильно по отдельности. Зависимости (базы данных, API) обычно заменяются заглушками (моками/стабами).

Модульные тесты выполняются очень быстро и составляют основу "Пирамиды тестирования".

---

## Jest
Jest — популярный фреймворк для тестирования от Facebook (Meta), долгое время был стандартом в экосистеме React и JavaScript в целом.

**Особенности:**
- Концепция "Все включено" (Zero config): из коробки включает assertion library (функции проверки вроде `expect().toBe()`), test runner (запускатель), систему мокинга, и анализ покрытия кода (coverage).
- Поддерживает Snapshot testing (снимки компонентов/объектов для сравнения изменений).
- Хорошо работает, но может быть медленным при запуске в современных ESM/TypeScript проектах, так как требует компиляции файлов через Babel или `ts-jest` (т.к. сам Jest написан под CommonJS).

---

## Vitest
Vitest — современный фреймворк для модульного тестирования, созданный специально для экосистемы **Vite**.

**Особенности:**
- **Быстрая скорость работы:** Vitest использует конвейер сборки Vite. Если ваше приложение собирается на Vite, Vitest моментально переиспользует те же плагины и конфигурации (поддержка TS, JSX, Vue/React плагинов).
- Поддержка ESM (ECMAScript Modules) из коробки.
- API почти полностью совместимо с Jest. Переход с Jest на Vitest часто сводится к замене импортов (например, замена `jest.fn()` на `vi.fn()`).
- Встроенный режим "Watch Mode" с мгновенной перезагрузкой HMR (как в Vite).

**Пример теста (Vitest/Jest):**
```javascript
import { describe, it, expect } from 'vitest' // в Jest эти функции глобальны
import { add } from './math.js'

describe('Функция add()', () => {
  it('должна правильно складывать два числа', () => {
    const result = add(2, 3)
    expect(result).toBe(5)
  })

  it('должна обрабатывать отрицательные числа', () => {
    expect(add(-1, 1)).toBe(0)
  })
})
```

## Что выбрать?
- Если вы используете сборщик **Vite** (что сейчас является стандартом для Vue и активно используется в React), однозначно выбирайте **Vitest**.
- Если у вас старый проект на Webpack/Babel или CRA (Create React App), то **Jest** всё ещё отличный выбор.
