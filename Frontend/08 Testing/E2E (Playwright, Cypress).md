
**E2E-тестирование (Сквозное тестирование)** проверяет работу всего приложения целиком, от пользовательского интерфейса до базы данных (если есть интеграция), имитируя реальные действия пользователя в настоящем браузере. Это самый "дорогой" и медленный вид тестирования, но он дает наибольшую уверенность в том, что приложение работает корректно с точки зрения пользователя.

---

## Cypress
Cypress — долгое время был стандартом де-факто для E2E в мире фронтенда.

**Особенности:**
- Выполняется непосредственно **внутри браузера**, в том же цикле событий (Event Loop), что и само приложение. Это дает мгновенный доступ к DOM, состоянию приложения (Window, Vue/React instance).
- Очень удобный визуальный интерфейс (Cypress Studio/Runner) для отладки, Time Travel (позволяет смотреть скриншоты каждого шага).
- Автоматическое ожидание (Automatic Waiting) — не нужно писать `sleep` или дожидаться появления элемента, Cypress делает это сам.

**Минусы:**
- Долгое время не поддерживал работу с несколькими вкладками (tabs) и окнами.
- Ограниченная поддержка iframe.
- Сложнее тестировать сценарии, требующие перехода на другие домены (cross-origin).

## Playwright
Playwright — современный фреймворк для E2E тестирования от Microsoft. Он быстро набирает популярность и становится новым стандартом.

**Особенности:**
- Работает через протокол отладки браузеров (CDP / WebDriver BiDi), вне браузера.
- **Поддержка множества контекстов:** Легко тестировать приложения с несколькими вкладками, окнами и iFrames. Позволяет симулировать несколько пользователей в одном тесте.
- Отличная скорость выполнения и параллелизация из коробки.
- Мощный генератор тестов (codegen) — можно прокликивать приложение, и Playwright сам напишет код теста.
- Нативная поддержка WebKit (Safari), Chromium и Firefox.

**Пример теста (Playwright):**
```typescript
import { test, expect } from '@playwright/test';

test('Пользователь может войти в систему', async ({ page }) => {
  await page.goto('https://myapp.com/login');
  
  await page.fill('input[name="username"]', 'admin');
  await page.fill('input[name="password"]', 'secret');
  await page.click('button[type="submit"]');

  // Ожидаем перенаправления на дашборд
  await expect(page).toHaveURL(/.*dashboard/);
  await expect(page.locator('h1')).toContainText('Добро пожаловать');
});
```

## Что выбрать?
На сегодняшний день (для новых проектов) **Playwright** часто является более предпочтительным выбором из-за своей гибкости, скорости, отсутствия ограничений Cypress (вкладки, iFrames) и мощной поддержки от Microsoft.
