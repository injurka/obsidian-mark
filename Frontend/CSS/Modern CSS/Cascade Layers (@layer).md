# Cascade Layers (@layer)

**Cascade Layers (Каскадные слои)** — это инструмент CSS, позволяющий явно группировать стили в именованные слои и гибко настраивать приоритеты их применения, решая проблему специфичности селекторов (Selector Specificity).

---

## 1. Зачем нужны каскадные слои?

В традиционном CSS приоритет стиля определяется специфичностью селектора (например, `#app .main-btn` тяжелее, чем `.btn`). Это приводит к «войнам специфичности»: разработчики вынуждены городить длинные селекторы или использовать `!important` для перезаписи стилей сторонних UI-библиотек (Bootstrap, Tailwind).

Каскадные слои позволяют явно задать иерархию приоритетов: **любое правило в более приоритетном слое побеждает правило в менее приоритетном слое, независимо от веса их селекторов**.

---

## 2. Синтаксис и управление приоритетами

### Шаг 1: Объявляем слои и их порядок (в самом начале файла)
Порядок объявления определяет приоритет. Чем позже объявлен слой, тем он приоритетнее:

```css
/* base имеет самый низкий приоритет, components — самый высокий */
@layer reset, framework, components;
```

### Шаг 2: Группируем стили по слоям
```css
/* Слой сброса стилей */
@layer reset {
  a {
    color: black;
    text-decoration: none;
  }
}

/* Слой стилей внешней библиотеки */
@layer framework {
  /* Тяжелый специфичный селектор */
  body #app .button {
    color: blue;
    background-color: lightgray;
  }
}

/* Слой наших компонентов */
@layer components {
  /* Легкий селектор */
  .button {
    color: white;
    background-color: green; /* ПОБЕДИТ! */
  }
}
```

Несмотря на то, что селектор `body #app .button` в слое `framework` имеет гораздо большую специфичность, браузер применит стили из класса `.button` из слоя `components`, так как этот слой объявлен позже и имеет более высокий приоритет.

---

## 3. Важные особенности каскадных слоев

### 3.1. Стили вне слоев (Unlayered Styles)
Стили, написанные без указания `@layer` (обычный CSS), всегда имеют **наивысший приоритет** в каскаде. Они перекроют любые стили, находящиеся внутри любых слоев `@layer`.

```css
@layer components {
  p { color: red; }
}

/* Обычный стиль вне слоя побеждает */
p {
  color: blue; 
}
```

### 3.2. Работа `!important` в слоях
Использование `!important` переворачивает логику приоритетов с ног на голову. 
*   В обычных стилях `!important` увеличивает приоритет.
*   При сравнении слоев: **`!important` в МЕНЕЕ приоритетном слое перебивает `!important` в более приоритетном слое**, а также перебивает `!important` во внеслоевых стилях. Это сделано для того, чтобы базовые слои могли гарантировать критические сбросы.
