# Flexbox (Flexible Box Layout)

**Flexbox** — это одномерный (1D) метод раскладки элементов по строкам или колонкам. Он ориентирован на простое распределение пространства между элементами и удобное выравнивание, даже когда их размеры динамические.

---

## 1. Свойства Flex-контейнера

Контейнер активируется свойством `display: flex`. Он задает **главную ось** (main axis) и **поперечную ось** (cross axis).

```css
.flex-container {
  display: flex;
  /* Направление главной оси: row (слева направо) или column (сверху вниз) */
  flex-direction: row;
  
  /* Разрешаем перенос элементов на следующую строку */
  flex-wrap: wrap;
  
  /* Выравнивание по главной оси */
  justify-content: space-between;
  
  /* Выравнивание по поперечной оси (для одной строки) */
  align-items: center;
}
```

---

## 2. Свойства Flex-элементов (Flex Items)

Параметры гибкости настраиваются индивидуально для дочерних элементов:

### 2.1. `flex-grow` (растяжение)
Определяет пропорцию, в которой элемент расширяется, заполняя свободное место в контейнере. 
*   `0` (дефолт) — элемент не растягивается.
*   Если у всех элементов `flex-grow: 1`, они поровну разделят пустоту.

### 2.2. `flex-shrink` (сжатие)
Определяет способность элемента сжиматься при недостатке места.
*   `1` (дефолт) — элемент сжимается.
*   `0` — элемент сохраняет свой базовый размер и не сжимается (может вызвать переполнение контейнера).

### 2.3. `flex-basis` (базовый размер)
Задает начальный размер элемента перед распределением свободного пространства. Может быть в `px`, `%` или `auto` (дефолт — размер по контенту).

### Сокращенная запись `flex`
Рекомендуется использовать сокращенный синтаксис:
```css
.sidebar {
  /* grow=0 (не растет), shrink=0 (не сжимается), basis=250px (фиксированный размер) */
  flex: 0 0 250px;
}

.main-content {
  /* grow=1 (забирает всё свободное место), shrink=1, basis=auto */
  flex: 1 1 auto;
}
```

## 3. Полезные трюки и особенности Flexbox

### 3.1. `margin: auto` во флекс-элементах
В отличие от блочной верстки, во Flexbox свойство `margin: auto` работает по обеим осям.
*   Если задать элементу `.login-btn { margin-left: auto; }`, он отодвинется максимально вправо, забрав все свободные маргины слева (отличный способ прижать кнопку к краю меню).
*   Конструкция `margin: auto;` на дочернем элементе центрирует его идеально по вертикали и горизонтали внутри флекс-контейнера.

### 3.2. Проблема переполнения текстом (`min-width: 0`)
По умолчанию флекс-элементы имеют свойство `min-width: auto`. Это значит, что они не сожмутся меньше размера своего контента. Если внутри флекс-ячейки лежит длинная строка текста с `text-overflow: ellipsis`, она не будет обрезаться, а растянет весь флекс-элемент наружу.
*   *Решение:* Принудительно задайте флекс-элементу, содержащему длинный текст:
    ```css
    .flex-item-with-text {
      min-width: 0;
    }
    ```
