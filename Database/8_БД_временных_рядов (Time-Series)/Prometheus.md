# Prometheus

Популярная open-source система мониторинга и алертинга, являющаяся стандартом де-факто в экосистеме Kubernetes и Cloud-Native. Содержит встроенную Time-Series БД.

## Особенности
- **Pull-модель (Scraping)**: В отличие от многих систем (где приложения сами пушат метрики в БД), Prometheus сам периодически ходит по HTTP эндпоинтам (например, `/metrics`) приложений и забирает (pull) текущие значения метрик.
- **Многомерная модель данных**: Метрики идентифицируются именем метрики и набором пар ключ-значение (лейблов, labels), например: `http_requests_total{method="GET", status="200"}`.
- **PromQL**: Очень мощный и выразительный язык запросов для агрегации метрик, вычисления рейт-ов (скорости изменения) и написания правил алертинга.
- **Alertmanager**: Встроенный компонент для обработки, группировки и отправки уведомлений (в Slack, Email, PagerDuty).

## Применение
- Сбор метрик с микросервисов, Linux серверов (через Node Exporter), баз данных и инфраструктуры. Отрисовка графиков обычно происходит в связке с Grafana.
