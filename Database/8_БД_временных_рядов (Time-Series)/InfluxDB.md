# InfluxDB

Ведущая специализированная база данных для временных рядов (Time-Series Database, TSDB).

## Особенности
- **Оптимизация под временные ряды**: Написана на Go (изначально, позже ядро переписано на Rust/C++ в InfluxDB IOx), идеально подходит для записи миллионов метрик в секунду.
- **Хранение (TSM Tree)**: Использует специализированный движок хранения Time-Structured Merge Tree, который сжимает данные временных рядов (timestamp, значения) невероятно эффективно, экономя дисковое пространство.
- **Flux / InfluxQL**: Собственные языки запросов. InfluxQL похож на SQL, а Flux — это мощный функциональный язык для работы с потоками данных (с версии 3.0 также возвращена мощная поддержка обычного SQL).
- **Retention Policies**: Встроенные механизмы автоматического удаления старых данных (политики хранения) и даунсэмплинга (Continuous Queries) — агрегации старых детальных данных в более редкие точки (например, из посекундных в почасовые) для экономии места.

## Применение
- Мониторинг инфраструктуры, IoT датчики, финансовые котировки в реальном времени.
