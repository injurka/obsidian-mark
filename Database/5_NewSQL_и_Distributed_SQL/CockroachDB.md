# CockroachDB

Распределенная реляционная база данных (NewSQL / Distributed SQL), созданная с акцентом на глобальную масштабируемость и высочайшую отказоустойчивость (отсюда название "таракан" - выживает при любых условиях).

## Особенности
- **Wire-совместимость с PostgreSQL**: Понимает протокол и многие запросы Postgres, что облегчает миграцию приложений.
- **СУБД без мастера (Masterless)**: Любой узел может принять запрос. Данные (диапазоны, Ranges) реплицируются через консенсусный алгоритм **Raft**.
- **Глобальное распределение**: Позволяет привязывать определенные строки к конкретным дата-центрам или регионам (Geo-partitioning) для снижения задержек и соблюдения законов о локализации данных.
- **Строгая консистентность**: Гарантирует Serializable уровень изоляции транзакций распределенно по всему кластеру (использует гибридные логические часы HLC).

## Применение
- Системы, критичные к потере данных, требующие распределения по разным дата-центрам (Multi-Region, Multi-Cloud).
- Облачные (Cloud-Native) приложения.
