# Google Cloud Spanner

Первая в мире полностью управляемая реляционная база данных, которая обеспечивает строгую согласованность при глобальном распределении. Является эталоном NewSQL.

## Особенности
- **TrueTime API**: Ключевая технология Spanner. Использует атомные часы и GPS-приемники в дата-центрах Google для синхронизации времени с предсказуемой погрешностью. Это позволяет упорядочивать глобальные транзакции без блокировок.
- **Масштабируемость**: Горизонтально масштабируется до тысяч серверов прозрачно для пользователя.
- **Модель данных**: Реляционная модель (с таблицами), но внутри данные хранятся в NoSQL-подобном распределенном хранилище. Строки дочерних таблиц могут физически перемежаться со строками родительских (Interleaved tables) для ускорения JOIN-ов.
- **Уровень изоляции**: Внешняя согласованность (External Consistency), превосходит стандартный Serializable.

## Применение
- Высоконагруженные транзакционные системы глобального масштаба.
- Финансы, инвентаризация, системы биллинга (где нельзя жертвовать ни консистентностью, ни доступностью).
