# TiDB

Distributed SQL база данных с открытым исходным кодом, реализующая гибридную обработку транзакций и аналитики (HTAP).

## Архитектура
- **TiDB Server**: Stateless узел, отвечающий за парсинг SQL (совместим с MySQL-протоколом), оптимизацию и генерацию распределенного плана выполнения.
- **TiKV**: Распределенное Key-Value хранилище на базе RocksDB и протокола Raft. Используется для транзакционных (OLTP) нагрузок (строко-ориентированное).
- **TiFlash**: Колоночное хранилище, синхронизирующееся с TiKV в реальном времени. Используется для аналитических (OLAP) нагрузок.
- **PD (Placement Driver)**: Управляет метаданными кластера, планирует балансировку данных и выдает глобально уникальные timestamp-ы транзакций.

## Особенности
- Умный оптимизатор запросов сам решает, куда отправить запрос: в TiKV (если это точечный селект) или в TiFlash (если это агрегация миллионов строк).
- **Бесшовная масштабируемость**: При нехватке места или CPU можно просто добавить новые узлы TiKV, и система сама перебалансирует данные.
- Отличная альтернатива для проектов, переросших один сервер MySQL.
