# Greenplum

Реляционная MPP (Massively Parallel Processing) система управления базами данных, созданная специально для хранилищ данных (Data Warehouse) и аналитики.

## Архитектура
- Базируется на исходном коде PostgreSQL (Postgres-based).
- **Shared-Nothing**: Данные распределены по множеству независимых сегментов (Segment nodes), каждый из которых имеет свои собственные CPU, память и диски.
- **Master Node**: Координирует работу кластера. Принимает запросы от клиентов, строит план распределенного выполнения, отправляет задачи на сегменты и собирает результаты.
- **Interconnect**: Высокоскоростная сеть между сегментами для обмена данными при выполнении сложных запросов (например, JOIN-ов больших таблиц, требующих перераспределения данных - Shuffle).

## Особенности
- Поддерживает ANSI SQL и возможности PostgreSQL (включая функции, триггеры, типы данных).
- Полиморфное хранение: таблицы могут быть строковыми (Row-oriented, лучше для частых обновлений) или колоночными (Column-oriented, лучше для аналитики и сжатия).
- Интеграция с Python/R/Java для In-Database машинного обучения и сложной аналитики (Apache MADlib).
