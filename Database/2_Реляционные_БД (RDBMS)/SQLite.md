# SQLite

Встраиваемая (embedded) легковесная реляционная база данных, которая хранит все данные в одном обычном локальном файле.

## Особенности
- **Бессерверная (Serverless)**: Не имеет отдельного фонового процесса (демона) или сервера. Приложение напрямую читает и пишет в файл БД.
- **Zero Configuration**: Не требует установки, настройки или администрирования.
- **Типизация**: Использует динамическую типизацию (манифестную) — тип значения ассоциируется с самим значением, а не с колонкой, в которой оно хранится.
- **ACID**: Полностью поддерживает транзакции (Атомарность, Согласованность, Изолированность, Долговечность).

## Применение
- Мобильные приложения (iOS, Android часто используют её по умолчанию).
- Локальное хранение данных в десктопных приложениях (браузеры, мессенджеры).
- IoT устройства и встраиваемые системы.
- Прототипирование, тестирование и разработка (легко поднять в памяти: `sqlite3 :memory:`).

## Минусы
- Не подходит для высоких конкурентных нагрузок на запись (часто блокирует весь файл при записи).
- Отсутствие системы пользователей и прав доступа.
