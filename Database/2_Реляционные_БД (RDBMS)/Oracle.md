# Oracle Database

Одна из старейших, мощнейших и самых дорогих коммерческих реляционных СУБД. Широко используется в крупных корпорациях и энтерпрайз-сегменте (банки, телеком).

## Особенности
- **PL/SQL**: Мощный процедурный язык расширения SQL, позволяющий писать сложную бизнес-логику прямо в базе данных.
- **RAC (Real Application Clusters)**: Технология кластеризации, обеспечивающая высочайшую доступность и отказоустойчивость. Позволяет нескольким экземплярам серверов обращаться к одной БД.
- **Управление ресурсами**: Тонкая настройка распределения CPU, памяти и I/O между разными запросами и пользователями.
- **MVCC**: Глубоко интегрированный механизм многоверсионности, обеспечивающий высокую консистентность чтения без блокировок.

## Плюсы
- Способность обрабатывать огромные объемы данных и транзакций с высочайшей надежностью.
- Непревзойденные возможности по настройке, тюнингу и резервному копированию (RMAN).
- Богатый встроенный функционал (аналитика, JSON, XML, пространственные данные).

## Минусы
- Огромная стоимость лицензирования и технической поддержки.
- Высокий порог входа: требует наличия высококвалифицированных администраторов (DBA).
- Громоздкость системы.
