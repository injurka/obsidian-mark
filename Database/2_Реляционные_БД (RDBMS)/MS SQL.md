# MS SQL Server

Коммерческая реляционная система управления базами данных (RDBMS) от Microsoft.

## Особенности
- **Интеграция с экосистемой Microsoft**: Идеально подходит для проектов, использующих .NET, C#, Azure и операционные системы Windows (хотя с 2017 года поддерживается и Linux).
- **T-SQL (Transact-SQL)**: Мощное процедурное расширение языка SQL, включающее обработку ошибок, локальные переменные и функции работы со строками/датами.
- **Инструментарий**: Поставляется с SQL Server Management Studio (SSMS) — одним из лучших графических инструментов для управления БД.
- **Аналитика и BI**: Включает встроенные сервисы для аналитики (SSAS), интеграции данных (SSIS) и отчетности (SSRS).

## Плюсы
- Высокая производительность и надежность энтерпрайз-уровня.
- Отличная документация и поддержка (в платных версиях).
- Продвинутый оптимизатор запросов.

## Минусы
- Высокая стоимость лицензий для Enterprise-версий.
- Исторически сильная привязанность к ОС Windows (несмотря на поддержку Linux, большинство установок все еще на Windows).
