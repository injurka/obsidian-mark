# Amazon DynamoDB

Полностью управляемая (Serverless) проприетарная NoSQL база данных типа "ключ-значение" и широкая колонка (Wide-Column) от Amazon Web Services (AWS).

## Особенности
- **Serverless**: Нет серверов для управления. Автоматическое масштабирование пропускной способности (Read/Write Capacity Units) в зависимости от нагрузки.
- **Производительность**: Гарантирует задержки (latency) в однозначных миллисекундах (single-digit millisecond) на любом масштабе.
- **Доступность**: Данные синхронно реплицируются в нескольких зонах доступности (Availability Zones) внутри региона AWS.
- **Global Tables**: Позволяет создавать глобально распределенные таблицы (Multi-region) с репликацией Active-Active.

## Модель данных и запросы
- Базируется на Primary Key, который может быть простым (только Partition Key) или составным (Partition Key + Sort Key).
- Как и в Cassandra, запросы строго привязаны к Primary Key. Доступны вторичные индексы (LSI и GSI) для дополнительных паттернов доступа.
- Не поддерживает `JOIN`.

## Применение
- Serverless-архитектуры в AWS (в связке с AWS Lambda, API Gateway).
- Игровые профили, сессии пользователей, корзины интернет-магазинов, кэширование.
- Системы, где нужна предсказуемая низкая задержка при неограниченном масштабировании.
