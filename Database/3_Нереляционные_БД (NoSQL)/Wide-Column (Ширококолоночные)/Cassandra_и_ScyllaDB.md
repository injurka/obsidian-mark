# Cassandra и ScyllaDB

Ширококолоночные распределенные базы данных, оптимизированные для высочайшей доступности и производительности (особенно на запись).

## Apache Cassandra
- **Архитектура**: Masterless (все узлы равны, нет единой точки отказа) с использованием консистентного хеширования (Ring-топология).
- **Модель данных**: Wide-Column. Данные организованы в партиции (Partition) по Partition Key, внутри которых лежат строки, отсортированные по Clustering Key.
- **CAP-теорема**: Является **AP-системой** (доступность + устойчивость к разделению). Согласованность настраивается (Tunable Consistency) на уровне каждого запроса.
- **Хранение**: Использует LSM-Tree, что делает запись невероятно быстрой.
- **Запросы (CQL)**: Похож на SQL, но сильно ограничен: нельзя делать `JOIN`, сложные агрегации или фильтровать по колонкам без индекса. Запросы должны строиться строго вокруг паттернов доступа.

## ScyllaDB
- Переписанная на C++ (изначально Cassandra написана на Java) версия, полностью совместимая с Cassandra (по протоколу и языку CQL).
- **Преимущества над Cassandra**:
    - Исключает проблемы сборщика мусора (Garbage Collector) Java.
    - Архитектура Share-Nothing: каждый поток работает со своим ядром CPU, памятью и сетевым адаптером.
    - Выше пропускная способность, ниже и стабильнее задержки (Tail Latency).
