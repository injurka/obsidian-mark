# Sphinx и Manticore Search

Поисковые серверы, обеспечивающие высокую скорость полнотекстового поиска и тесную интеграцию с реляционными базами данных (MySQL, PostgreSQL).

## Sphinx
- **Особенности**: Очень быстрый, потребляет мало ресурсов (по сравнению с Lucene-based решениями вроде ES). Отлично индексирует данные напрямую из SQL-баз (Data sources).
- **SphinxQL**: Язык запросов, синтаксически очень похожий на SQL, что сильно снижает порог входа для разработчиков.
- **Состояние**: В настоящее время проект Sphinx практически не развивается (заморожен).

## Manticore Search
- **Форк Sphinx**: Был создан как современное продолжение Sphinx с активным развитием.
- **Улучшения**: 
    - Полностью переписанная поддержка Real-Time индексов (вставка документов напрямую в Manticore через SQL/JSON без необходимости периодической переиндексации из основной БД).
    - Встроенная репликация кластеров.
    - Интеграция с современным стеком (Logstash, Kibana).
    - Колоночное хранилище для быстрой аналитики и агрегации (Manticore Columnar Library).
- **Применение**: Легковесная и очень быстрая альтернатива Elasticsearch для поиска по каталогам, форумам и небольшим аналитическим задачам.
