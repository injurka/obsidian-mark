# Elasticsearch

Самый популярный распределенный поисковый и аналитический движок, основанный на библиотеке Apache Lucene.

## Особенности
- **Inverted Index (Обратный индекс)**: Основа быстрого полнотекстового поиска. Хранит маппинг слов к документам, в которых они встречаются.
- **RESTful API**: Все взаимодействие идет через JSON по HTTP (индексирование, поиск, управление).
- **Schemaless (условно)**: Принимает JSON-документы без строгой предварительной схемы, пытаясь угадать типы полей (Dynamic mapping), хотя для продакшена настоятельно рекомендуется задавать схему (Mapping) явно.
- **Анализ текста**: Включает мощные инструменты стемминга, токенизации, фильтрации стоп-слов и работы с синонимами для десятков языков.
- **ELK Stack**: Центральная часть стека Elastic (Elasticsearch, Logstash, Kibana), де-факто стандарта для централизованного сбора и анализа логов.

## Применение
- Полнотекстовый поиск по сайту/приложению (с опечатками, синонимами).
- Хранение и анализ логов, метрик и событий ИБ (SIEM).
- Агрегация данных.
