**Реализация Модулей Передвижения** с использованием Gameplay Abilities и взаимодействием с Character Movement Component.

**Задача:** Создать `GameplayAbility` (GA) для каждого модуля передвижения (Крюк-Кошка, Ранец, Лазание, Подкат), привязать их к соответствующим `InputID`, реализовать их логику через взаимодействие с `CharacterMovementComponent` и настроить их выдачу через `ChassisSlotManagerComponent`.

**Зачем:** Реализовать одну из ключевых особенностей *Frame Forge* - получение продвинутых опций передвижения как награды за исследование, а не как базовых способностей Шасси.

**GAS Компоненты и Механизмы UE:** `UGameplayAbility` (наследуемся от `FrameForgeGameplayAbility`), `UCharacterMovementComponent`, `AbilityTask_WaitTargetData`, `AbilityTask_WaitInputRelease`, `AbilityTask_WaitDelay`, `GameplayEffect` (Cost/Cooldown), `LaunchCharacter`, `SetMovementMode`, `SetGravityScale`, `MovementModuleItemData` (новый Data Asset), `ChassisSlotManagerComponent`.

**Подробная Реализация Шага:**

**Шаг 12.1: Создание Data Asset `MovementModuleItemData` (C++)**

Нам нужен специализированный Data Asset для модулей передвижения.

1.  **Создайте новый C++ класс**:
    *   Родитель: `FrameForgeItemData`.
    *   Имя: `MovementModuleItemData`.
    *   Путь: `FrameForge/Source/FrameForge/Public/Items/Data/`.
2.  **`MovementModuleItemData.h`**:
    ```cpp
    #pragma once

    #include "Items/Data/FrameForgeItemData.h"
    #include "Core/AbilityInputID.h" // Для InputID
    #include "MovementModuleItemData.generated.h"

    UCLASS(BlueprintType)
    class FRAMEFORGE_API UMovementModuleItemData : public UFrameForgeItemData
    {
        GENERATED_BODY()
    public:
        UMovementModuleItemData()
        {
            // Устанавливаем тип слота по умолчанию для этого типа данных
            CompatibleSlotType = ESlotType::Movement;
        }

        // Класс Gameplay Ability, который будет выдан при экипировке
        UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category = "Item|GAS")
        TSubclassOf<class UFrameForgeGameplayAbility> GrantedAbilityClass;

        // InputID, к которому будет привязана эта способность передвижения
        // Обычно это EAbilityInputID::MovementAbility или EAbilityInputID::Jump
        UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category = "Item|GAS")
        EAbilityInputID AbilityInputID = EAbilityInputID::MovementAbility;
    };
    ```
3.  **`MovementModuleItemData.cpp`**: Может оставаться пустым.
4.  **Скомпилируйте C++ проект.**

**Шаг 12.4: Реализация Логики Способностей (Event Graph)**

**A. `GA_Module_Movement_GrappleHook`**

1.  **Class Defaults:**
    *   `Ability Tags`: `Ability.Module.Movement.GrappleHook`
    *   `Activation Owned Tags`: `State.Movement.Grappling`
    *   `Activation Blocked Tags`: `State.Dead`, `State.Stunned`, `Cooldown.Module.Movement.GrappleHook`
    *   `Cooldown Gameplay Effect Class`: `GE_Cooldown_GrappleHook`
    *   `Cost Gameplay Effect Class`: (Опционально, если есть стоимость активации)
2.  **Event Graph (`Event ActivateAbility`):**
    *   `Commit Ability` -> `Branch` (True):
        *   `AbilityTask_WaitTargetData`:
            *   `Targeting Preset`: `Use Provided Targeting Parameters`.
            *   `Targeting Parameters`: Создайте новый ассет `GameplayTargetingPreset` (ПКМ -> Miscellaneous -> Data Asset -> Gameplay Targeting Preset). В нем настройте `Target Actor Class` = `GameplayAbilityWorldReticle` (или кастомный), `Trace Profile` = `Visibility`, `Max Range` = (например, 3000.0). Назначьте этот пресет.
            *   `Confirmation Type`: `Instant` (Срабатывает сразу при активации).
        *   От выхода `Valid Data`:
            *   Получите `Target Data Handle` -> `Get Hit Result from Target Data` (Index 0).
            *   `Break Hit Result` -> Получите `Location` (это точка попадания крюка).
            *   `Get Frame Forge Character from Actor Info` (Назовем `OwnerCharacter`).
            *   `Get Character Movement` (Назовем `OwnerMovement`).
            *   `Set Movement Mode`: `MOVE_Flying`.
            *   `Set Gravity Scale`: `0.0`.
            *   **(Логика Притягивания - Вариант 1: Launch)**
                *   Рассчитайте вектор направления: `Hit Location` - `OwnerCharacter Location`.
                *   Рассчитайте скорость (можно использовать `Suggest Projectile Velocity Custom Arc`, но проще): `Normalize`(вектор направления) * `Grapple Speed` (новая переменная, например, 4000.0).
                *   `Launch Character` (Target: `OwnerCharacter`, Velocity: рассчитанная скорость, XYOverride: true, ZOverride: true).
                *   `AbilityTask_WaitDelay`: `Delay` = Рассчитанное время полета (Дистанция / `Grapple Speed`) или фиксированное максимальное время.
                *   От выхода `On Finish`: Вызовите `End Ability`.
            *   **(Логика Притягивания - Вариант 2: Ability Task)** (Более сложный, но плавный)
                *   Создайте кастомный `AbilityTask_MoveToLocationSmooth` (C++). Он будет плавно перемещать персонажа к цели в `Tick()`, управляя скоростью.
                *   Вызовите этот таск.
                *   От выхода `On Reached Target` / `On Failed`: Вызовите `End Ability`.
        *   От выхода `Cancelled` (из `WaitTargetData`): `End Ability`.
    *   От выхода `Branch` (False): `End Ability`.
3.  **Переопределите `EndAbility`:**
    *   Вызовите `Super::EndAbility`.
    *   `Get Frame Forge Character from Actor Info` -> `Get Character Movement`.
    *   `Set Movement Mode`: `MOVE_Walking` (или `MOVE_Falling`, если нужно проверить состояние).
    *   `Set Gravity Scale`: `1.0` (или ваше стандартное значение).

**C. `GA_Module_Movement_WallClimb`**

1.  **Class Defaults:**
    *   `Ability Tags`: `Ability.Module.Movement.WallClimb`
    *   `Activation Owned Tags`: `State.Movement.WallClimbing`
    *   `Activation Blocked Tags`: `State.Dead`, `State.Stunned`, `State.OnGround`.
    *   `Cost Gameplay Effect Class`: (Нет начальной стоимости, только дрейн).
2.  **Переменные (Blueprint):**
    *   `WallCheckDistance` (float, default: 100.0)
    *   `MinWallSteepness` (float, default: 75.0) - Минимальный угол наклона стены
    *   `WallClimbSpeed` (float, default: 300.0)
3.  **Event Graph (`Event ActivateAbility`):**
    *   `Commit Ability` -> `Branch` (True):
        *   `Get Frame Forge Character from Actor Info` (OwnerCharacter).
        *   `Get Character Movement` (OwnerMovement).
        *   **Проверка Стены:**
            *   `Line Trace By Channel`: Start = `OwnerCharacter Location`, End = `OwnerCharacter Location` + (`OwnerCharacter Forward Vector` * `WallCheckDistance`). Trace Channel: Visibility. Actors to Ignore: Self.
            *   `Break Hit Result` -> `Branch` (Condition: `Blocking Hit`).
                *   **(Если Попал):** `Branch` (Condition: `Normal.Z` < `Sine`(Degrees to Radians(`90 - MinWallSteepness`))). *Это проверяет, достаточно ли стена вертикальна.*
                    *   **(Если Стена Подходит):**
                        *   `Set Movement Mode`: `MOVE_Flying`.
                        *   `Set Gravity Scale`: `0.0`.
                        *   `Stop Movement Immediately` (Опционально, чтобы остановить инерцию).
                        *   `Set Velocity`: `New Vel` = (0, 0, `WallClimbSpeed`).
                        *   **Применить Эффект Расхода Выносливости:** `Apply Gameplay Effect to Owner`: `Gameplay Effect Class` = `GE_Cost_WallClimb_Drain`.
                        *   `AbilityTask_WaitInputRelease`.
                        *   От выхода `On Release`: `End Ability`.
                    *   **(Если Стена Не Подходит):** `End Ability`.
                *   **(Если Не Попал):** `End Ability`.
    *   От выхода `Branch` (False из Commit): `End Ability`.
4.  **Переопределите `EndAbility`:**
    *   Вызовите `Super::EndAbility`.
    *   `Get Frame Forge Character from Actor Info` -> `Get Character Movement`.
    *   `Set Movement Mode`: `MOVE_Falling`.
    *   `Set Gravity Scale`: `1.0`.
    *   **Удалить Эффект Расхода Выносливости:** `Get Ability System Component from Actor Info` -> `Remove Active Gameplay Effect by Source Effect`: `Gameplay Effect` = `GE_Cost_WallClimb_Drain`, `StacksToRemove` = -1.
    *   **(Опционально) Отталкивание от стены:** `Launch Character` с небольшим вектором от стены (`Hit Normal` из трассировки, если сохранили).
