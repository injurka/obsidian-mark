**Инициализация GAS и Атрибутов**.

**Задача:** Реализовать логику инициализации GAS на сервере и клиенте, связав `AbilitySystemComponent` (ASC) с его владельцем (`PlayerState`) и аватаром (`Character/Chassis`). Применить базовые `GameplayEffect` (GE) для установки начальных значений атрибутов в зависимости от выбранного Шасси.

**Зачем:**
*   **Связывание ASC:** `InitAbilityActorInfo` сообщает ASC, кем он управляет (Аватар) и кому принадлежит (Владелец). Без этого вызовы способностей, применение эффектов и получение атрибутов работать не будут.
*   **Начальные Статы:** Каждый тип Шасси должен начинать игру со своими уникальными характеристиками (здоровье, энергия, скорость и т.д.). Применение GE - это стандартный и гибкий способ установить эти начальные значения в GAS.
*   **Сервер/Клиент Синхронизация:** Инициализация должна произойти как на сервере (который авторитативен), так и на всех клиентах, чтобы все "знали" о связи ASC-Аватар-Владелец. Начальные статы применяются *только* на сервере, но их результат (изменение атрибутов) будет реплицирован клиентам благодаря настройкам из шага 5.

**GAS Компоненты и Механизмы UE:** `AbilitySystemComponent::InitAbilityActorInfo`, `UGameplayEffect`, `TSubclassOf<UGameplayEffect>`, `FGameplayEffectContextHandle`, `FGameplayEffectSpecHandle`, `ApplyGameplayEffectSpecToSelf`, `ACharacter::PossessedBy`, `ACharacter::OnRep_PlayerState`.

6.  **Реализуйте `GrantInitialAbilitiesAndEffects` (Только Сервер)**:
    ```cpp
    void AFrameForgeCharacter::GrantInitialAbilitiesAndEffects()
    {
        // Эта функция должна выполняться ТОЛЬКО на сервере.
        if (GetLocalRole() != ROLE_Authority)
        {
            return;
        }

        // Получаем необходимые компоненты
        AFrameForgePlayerState* PS = GetPlayerState<AFrameForgePlayerState>();
        if (!PS) return;

        UAbilitySystemComponent* ASC = PS->GetAbilitySystemComponent();
        if (!ASC) return;

        // Предотвращаем повторное применение эффектов (например, при респавне без смены PlayerState)
        if (bASCEffectsApplied)
        {
            // UE_LOG(LogTemp, Log, TEXT("AFrameForgeCharacter::GrantInitialAbilitiesAndEffects: Effects already applied for %s."), *GetName());
            return;
        }

        // --- Применение Начальных Атрибутов ---
        if (IsValid(InitialStatsEffect)) // Проверяем, что класс GE указан в наследнике BP
        {
            // Создаем контекст и спецификацию эффекта
            FGameplayEffectContextHandle EffectContext = ASC->MakeEffectContext();
            EffectContext.AddSourceObject(this); // Указываем персонажа как источник

            // Уровень эффекта (обычно 1 для начальных статов)
            const float EffectLevel = 1.0f;
            FGameplayEffectSpecHandle SpecHandle = ASC->MakeOutgoingSpec(InitialStatsEffect, EffectLevel, EffectContext);

            if (SpecHandle.IsValid())
            {
                // Применяем эффект к себе (т.к. ASC принадлежит PlayerState, но Аватар - это мы)
                FActiveGameplayEffectHandle ActiveGEHandle = ASC->ApplyGameplayEffectSpecToSelf(*SpecHandle.Data.Get());

                if(ActiveGEHandle.WasSuccessfullyApplied())
                {
                    UE_LOG(LogTemp, Log, TEXT("AFrameForgeCharacter::GrantInitialAbilitiesAndEffects: Applied InitialStatsEffect %s to %s"), *InitialStatsEffect->GetName(), *GetName());
                     bASCEffectsApplied = true; // Устанавливаем флаг, что эффекты применены

                else
                {
                     UE_LOG(LogTemp, Error, TEXT("AFrameForgeCharacter::GrantInitialAbilitiesAndEffects: Failed to apply InitialStatsEffect %s to %s"), *InitialStatsEffect->GetName(), *GetName());
                }
            }
            else
            {
                 UE_LOG(LogTemp, Error, TEXT("AFrameForgeCharacter::GrantInitialAbilitiesAndEffects: Failed to make spec for InitialStatsEffect %s on %s"), *InitialStatsEffect->GetName(), *GetName());
            }
        }
        else
        {
            UE_LOG(LogTemp, Warning, TEXT("AFrameForgeCharacter::GrantInitialAbilitiesAndEffects: InitialStatsEffect is not set for %s! Check Blueprint Defaults."), *GetName());
        }
    ```

**Шаг 6.3: Создание Gameplay Effects для Начальных Статов (в Редакторе)**

Теперь нам нужно создать сами ассеты `GameplayEffect` в редакторе Unreal Engine.

1.  **Откройте Unreal Editor**.
2.  Перейдите в Content Browser, в папку, где вы храните ассеты GAS (например, `Content/Features/Chassis/GAS/GameplayEffects/Initialization/`).
3.  **Кликните правой кнопкой мыши -> Blueprint Class**.
4.  В окне "Pick Parent Class" разверните "All Classes" и найдите `GameplayEffect`. Выберите его.
5.  Назовите новый ассет, например, `GE_Chassis_Typhon_Stats`.
6.  **Повторите** для других Шасси: `GE_Chassis_Phantom_Stats`, `GE_Chassis_Vector_Stats`, `GE_Chassis_Technic_Stats`.
7.  **Откройте каждый созданный GE** (например, `GE_Chassis_Typhon_Stats`) для редактирования.
8.  **Настройте его свойства:**
    *   **Duration Policy:** Установите `Instant`. Начальные статы применяются один раз.
    *   **Modifiers:** Это самая важная часть. Нажмите `+` рядом с `Modifiers`, чтобы добавить модификатор для каждого атрибута, который вы хотите установить:
        *   **Attribute:** Выберите атрибут из вашего `BaseAttributeSet` (например, `BaseAttributeSet.MaxHealth`).
        *   **Modifier Op:** Выберите `Override`. Мы хотим *установить* начальное значение, а не добавить к существующему (которое равно 0).
        *   **Magnitude:** Установите нужное начальное значение для этого Шасси (например, для Тифона `MaxHealth` = 150). Используйте `Scalable Float`.
        *   **Повторите** для `Health` (установите равным `MaxHealth`), `MaxEnergy`, `Energy`, `Armor`, `MovementSpeed` и т.д., задавая уникальные значения для каждого типа Шасси в его соответствующем GE.
    *   **Granted Abilities:** Оставьте пустым на этом шаге.
    *   **Gameplay Cues:** Оставьте пустым.
    *   **Tags:**
        *   **Granted Tags:** Можно добавить тег, идентифицирующий Шасси (например, `Chassis.Type.Typhon`), если это нужно для других систем.
        *   **Asset Tags:** Добавьте тег для организации, например, `Chassis.Initialization.Stats`.
9.  **Сохраните** каждый ассет GE.

**Шаг 6.4: Назначение GE в Blueprint'ах Шасси**

1.  **Откройте Blueprint-наследника** вашего Шасси (например, `BP_PlayerChassis_Typhon`, который наследуется от `AFrameForgeCharacter`).
2.  Перейдите в **Class Defaults**.
3.  Найдите секцию `GAS|Initialization` (или как вы назвали категорию).
4.  В поле **Initial Stats Effect** выберите соответствующий GE, который вы создали (например, `GE_Chassis_Typhon_Stats`).
5.  **Повторите** для каждого Blueprint'а Шасси, назначая ему свой уникальный GE с начальными статами.
6.  **Скомпилируйте и Сохраните** Blueprint'ы.

**Шаг 6.5: Компиляция и Тестирование**

1.  **Пересоберите (Rebuild) C++ проект**, если вы вносили изменения в код.
2.  **Запустите игру** в режиме "Play As Client" (2 игрока).
3.  **Проверка:**
    *   **Логи:** Проверьте Output Log на наличие сообщений "ASC Initialized..." и "Applied InitialStatsEffect...".
    *   **Атрибуты:** Используйте консольную команду `showdebug abilitysystem` (выбрав персонажа в мире или нажав `~` и вводя команду). В отладочной информации найдите секцию Attributes и убедитесь, что значения `Health`, `MaxHealth`, `Energy` и т.д. соответствуют тем, что вы установили в GE для выбранного Шасси. Проверьте и на сервере, и на клиенте. Значения должны совпадать.
    *   **InitActorInfo:** В той же отладочной информации убедитесь, что `OwnerActor` и `AvatarActor` для AbilitySystemComponent установлены правильно (Owner = PlayerState, Avatar = Character).
