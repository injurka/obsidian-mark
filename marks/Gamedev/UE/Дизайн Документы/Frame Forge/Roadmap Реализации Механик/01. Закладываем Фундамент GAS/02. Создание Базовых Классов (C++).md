**Создание Базовых Классов C++**.

**Задача:** Создать базовые C++ классы для Персонажа (`AFrameForgeCharacter`), Контроллера Игрока (`AFrameForgePlayerController`), Состояния Игрока (`AFrameForgePlayerState`), GameMode (`AFrameForgeGameMode`) и GameState (`AFrameForgeGameState`).

**Зачем:**
*   **Надежная Основа:** C++ классы обеспечивают более стабильную и производительную базу по сравнению с чисто Blueprint-решениями для основных систем игры.
*   **GAS Интеграция:** Эти классы будут содержать или взаимодействовать с компонентами Gameplay Ability System (`AbilitySystemComponent`, `AttributeSet`).
*   **Правильное Владение (Ownership):** Для корректной работы GAS в мультиплеере крайне важно правильно определить, какой класс "владеет" `AbilitySystemComponent` и `AttributeSet`. **Рекомендуемый и наиболее распространенный подход — размещать их в `APlayerState`**, так как `APlayerState` существует для каждого игрока на сервере и всех клиентах и реплицируется автоматически. Персонаж (`ACharacter`) может быть уничтожен и пересоздан (при смерти/респавне), а `APlayerController` существует только на сервере и у владеющего клиента, что усложняет репликацию GAS для других клиентов.
*   **Расширяемость:** Создание базовых классов позволяет легко добавлять общую функциональность для всех производных классов (например, всех типов Шасси).

**GAS Компоненты (в контексте этого шага):** Пока мы только **готовим** эти классы. Сами компоненты GAS (`AbilitySystemComponent`, `AttributeSet`) будут добавлены на *следующем* шаге. Сейчас мы создаем "контейнеры" для них.

**Подробная Реализация Шага:**

Мы будем использовать встроенные инструменты Unreal Engine для создания этих классов.

**Процесс Создания (повторяется для каждого класса):**

1.  **Откройте Unreal Editor** вашего проекта `FrameForge`.
2.  Перейдите в меню: **Tools -> New C++ Class...**
3.  В открывшемся окне выберите **родительский класс (Parent Class)**:
    *   Для `FrameForgeCharacter`: Выберите `Character`.
    *   Для `FrameForgePlayerController`: Выберите `Player Controller`.
    *   Для `FrameForgePlayerState`: Выберите `Player State`.
    *   Для `FrameForgeGameMode`: Выберите `Game Mode Base` (это более современный и легковесный базовый класс, чем `Game Mode`).
    *   Для `FrameForgeGameState`: Выберите `Game State Base` (соответствует `Game Mode Base`).
4.  Нажмите **Next**.
5.  Введите **Имя (Name)** нового класса:
    *   `FrameForgeCharacter`
    *   `FrameForgePlayerController`
    *   `FrameForgePlayerState`
    *   `FrameForgeGameMode`
    *   `FrameForgeGameState`
6.  Убедитесь, что **Путь (Path)** установлен в основную папку исходного кода вашего проекта (обычно `[ProjectName]/Source/[ProjectName]`).
7.  Нажмите **Create Class**.
8.  Unreal Engine автоматически создаст файлы `.h` (заголовочный) и `.cpp` (исходный код) для вашего класса, добавит их в проект и попытается скомпилировать код (это может занять некоторое время). Visual Studio или Rider должны автоматически обновиться, отобразив новые файлы.

**6. FrameForgePlayerState.cpp**

```cpp
// FrameForge/Source/FrameForge/FrameForgePlayerState.cpp

#include "FrameForgePlayerState.h"
#include "AbilitySystemComponent.h"      // <--- !!! Включаем СРАЗУ
#include "BaseAttributeSet.h" // <--- !!! ВКЛЮЧИТЕ ЗДЕСЬ .h ВАШЕГО AttributeSet, КОГДА СОЗДАДИТЕ ЕГО

AFrameForgePlayerState::AFrameForgePlayerState()
{
    // --- GAS Components Creation ---
    // Создаем Ability System Component. Устанавливаем режим репликации.
    AbilitySystemComponent = CreateDefaultSubobject<UAbilitySystemComponent>(TEXT("AbilitySystemComponent"));
    AbilitySystemComponent->SetIsReplicated(true);
    // Режим репликации Mixed подходит для персонажей, управляемых игроком.
    // Full подходит для AI или объектов мира, управляемых сервером.
    AbilitySystemComponent->SetReplicationMode(EGameplayEffectReplicationMode::Mixed);

    // Создаем Attribute Set. Он будет автоматически зарегистрирован в AbilitySystemComponent.
    // ЗАМЕНИТЕ UBaseAttributeSet на имя вашего класса AttributeSet!
    AttributeSet = CreateDefaultSubobject<UBaseAttributeSet>(TEXT("AttributeSet")); // <--- ЗАМЕНИТЕ UBaseAttributeSet

    // Устанавливаем PlayerState как OwnerActor для ASC. AvatarActor будет установлен позже (это будет Персонаж).
    // Это важно для правильной работы GAS.
    AbilitySystemComponent->SetOwnerActor(this);

    // Увеличиваем NetUpdateFrequency для более отзывчивой репликации атрибутов и эффектов.
    // Значение по умолчанию (обычно 2) может быть слишком низким для быстрой игры.
    // Экспериментируйте со значениями (например, 50-100).
    NetUpdateFrequency = 100.0f;
}

// Реализация GetAbilitySystemComponent из интерфейса IAbilitySystemInterface
UAbilitySystemComponent* AFrameForgePlayerState::GetAbilitySystemComponent() const
{
    return AbilitySystemComponent;
}

// Геттер для Attribute Set (реализация будет выглядеть так)
/* ЗАМЕНИТЕ UBaseAttributeSet на имя вашего класса AttributeSet!
UBaseAttributeSet* AFrameForgePlayerState::GetAttributeSet() const
{
    return AttributeSet;
}
*/

void AFrameForgePlayerState::BeginPlay()
{
	Super::BeginPlay();

	// Проверка, что AttributeSet не нулевой (важно для отладки)
	if (!AttributeSet)
	{
		UE_LOG(LogTemp, Error, TEXT("AFrameForgePlayerState::BeginPlay: AttributeSet is null for %s"), *GetName());
	}
}
```
