# Цзюнь Шань Инь Чжэнь (Серебряные иглы с горы Цзюнь)

* **Категория:** Желтый чай / Сорта Желтого чая
* **Происхождение:** Провинция Хунань, остров Цзюньшань (озеро Дунтин)

## Описание
Король желтых чаев и один из самых знаменитых чаев Китая. Изготавливается исключительно из отборных, плотных почек. При заваривании в высоком бокале почки совершают «танец», несколько раз всплывая вертикально и опускаясь на дно.

## Вкус и аромат
Многогранный, со сливочно-хлебными тонами, нотами сушеной груши, нежного меда и едва уловимым благородным оттенком томления.
