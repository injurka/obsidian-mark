# Wish, if only и would rather

**Wish + Past Simple** выражает сожаление о настоящем: *I wish I had more time.* **Wish + Past Perfect** — сожаление о прошлом: *I wish I had called earlier.* **Wish + would** часто показывает раздражение или желание, чтобы кто-то изменил повторяющееся поведение: *I wish it would stop raining.*

**If only** усиливает сожаление или желание: *If only we had booked sooner!* **Would rather** выражает предпочтение: *I’d rather stay home.* Если субъект меняется, употребляется Past Simple для предпочтения относительно настоящего/будущего: *I’d rather you came tomorrow.*

Не путайте прошедшую форму в wish-конструкции с прошедшим временем по факту. См. [[🧪 Условные предложения Second Conditional]].
