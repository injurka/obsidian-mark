# Каузативные конструкции: make, let, have, get, help

**Make + object + голый инфинитив** — заставить/побудить: *The teacher made us rewrite it.* В пассиве появляется *to*: *We were made to rewrite it.* **Let + object + голый инфинитив** — позволить: *Let me explain.*

**Have + object + past participle** — организовать услугу (*have the car serviced*); **have + person + base verb** — поручить человеку (*I had the assistant call*). **Get + person + to-infinitive** — добиться, чтобы кто-то сделал (*I got him to help*). После *help* возможны формы с *to* и без него.

Запоминайте структуру вместе со значением и типом дополнения. См. [[🛠️ Have something done и Get something done]].
