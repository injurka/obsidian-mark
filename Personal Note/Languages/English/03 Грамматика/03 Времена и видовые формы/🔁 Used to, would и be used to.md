# Used to, would и be used to

**Used to + глагол** описывает прежнюю привычку или состояние, которого больше нет: *I used to live near the sea.* Отрицание и вопрос обычно строятся с *did*: *Did you use to play? I didn’t use to drink coffee.*

**Would + глагол** может описывать повторявшиеся действия в прошлом, но обычно не длительные состояния: *Every summer we would visit my aunt.*

**Be used to + существительное или -ing** означает «быть привычным к»: *I’m used to cold weather; She’s used to working late.* После *to* здесь нужна герундийная форма, потому что *to* — предлог. **Get used to** — постепенно привыкать: *You’ll get used to the schedule.*
