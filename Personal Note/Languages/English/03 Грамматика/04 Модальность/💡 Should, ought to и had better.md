# Should, ought to и had better

**Should** даёт совет, ожидание или мягкое обязательство: *You should get some rest; The parcel should arrive today.* После него идёт базовая форма глагола без *to*.

**Ought to** близко по смыслу к *should*, но используется реже и звучит несколько формальнее: *We ought to check the details.* **Had better + глагол** обозначает настоятельный совет с подразумеваемым последствием: *You’d better save a copy.* Отрицание: *You’d better not wait.*

Не путайте совет с обязанностью: для жёсткого правила могут подойти *must/have to*. Сравните силу формулировки с адресатом и ситуацией. См. [[🚦 Must, have to и need to]].
