# Приложения и цифровые инструменты

Инструмент полезен, когда закрывает конкретную задачу: словарь — значение и произношение; диктофон — анализ речи; интервальные карточки — повторение; субтитры — разбор аудио. Не путайте время в приложении с освоенным навыком.

Соберите небольшой устойчивый набор: один источник курса, один словарь, один инструмент для повторения и удобное аудио. Настройте уведомления так, чтобы они поддерживали практику, а не отвлекали.

Раз в месяц спрашивайте себя: использовал ли я этот инструмент для реальной задачи? Если нет, упростите систему. См. [[🃏 Карточки Anki для слов и фраз]].
