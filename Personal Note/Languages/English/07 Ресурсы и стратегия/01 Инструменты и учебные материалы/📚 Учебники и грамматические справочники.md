# Учебники и грамматические справочники

Выбирайте пособие по уровню, цели и типу практики: курс для последовательного освоения, грамматический справочник для ответа на точный вопрос, рабочая тетрадь для закрепления. Посмотрите пример главы до покупки и проверьте, есть ли аудио и ключи.

Не ведите несколько основных курсов одновременно. Выберите один маршрут и дополняйте его материалом для чтения и аудирования. Когда объяснения расходятся, проверьте уровень, вариант английского и значение конструкции.

После теории выполните упражнение, затем составьте три своих примера и вернитесь к ним через несколько дней. См. [[🎯 Диагностика уровня и постановка целей]].
