# Часто путаемые написания

Похожие слова проще запоминать контрастом и коротким примером.

| Пара | Различие | Пример |
|---|---|---|
| *their / there / they’re* | принадлежность / место / *they are* | *Their car is there.* |
| *your / you’re* | принадлежность / *you are* | *You’re welcome.* |
| *its / it’s* | принадлежность / *it is* | *It’s lost its label.* |
| *then / than* | последовательность / сравнение | *Then it was cheaper than now.* |
| *lose / loose* | потерять / свободный, незатянутый | *Don’t lose the loose screw.* |
| *affect / effect* | обычно глагол / обычно существительное | *It affects the effect.* |

Проверка: подставьте развёрнутую форму (*it is*) или близкий синоним. Учите пару в предложении, а не изолированно.
