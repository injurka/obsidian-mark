# 💼 Фразовые глаголы для работы и общения

Эти сочетания помогают вести рабочие обсуждения. Часть глаголов неформальна; выбирайте вариант под канал общения.

| Выражение | Значение |
|---|---|
| `follow up on a request` | вернуться к запросу |
| `carry out a review` | провести проверку |
| `point out a risk` | указать на риск |
| `set up a meeting` | организовать встречу |
| `hand in a report` | сдать отчёт |
| `work out a solution` | найти решение |
| `bring up a topic` | поднять тему |
| `write down an action item` | записать поручение |

> [!example] В контексте
> “I’ll follow up on the issue and write down the next steps.”

Учите выражения целиком, проговаривайте их вслух и подставляйте свои детали. Учитывайте вежливость и ситуацию: один и тот же перевод может требовать разных английских формулировок.
