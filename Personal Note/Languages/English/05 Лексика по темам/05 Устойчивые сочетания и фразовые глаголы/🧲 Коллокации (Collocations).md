# 🧲 Коллокации (Collocations)

Коллокация — типичное соседство слов, которое помогает речи звучать естественно. Записывайте глагол с существительным и прилагательное с существительным, а не отдельный перевод.

| Выражение | Значение |
|---|---|
| `make a decision` | принять решение |
| `take a break` | сделать перерыв |
| `strong coffee` | крепкий кофе |
| `heavy rain` | сильный дождь |
| `raise a concern` | озвучить опасение |
| `meet a deadline` | успеть к сроку |
| `highly unlikely` | крайне маловероятно |
| `keep in touch` | поддерживать связь |

> [!example] В контексте
> “We need to make a decision before we meet the deadline.”

Учите выражения целиком, проговаривайте их вслух и подставляйте свои детали. Учитывайте вежливость и ситуацию: один и тот же перевод может требовать разных английских формулировок.
