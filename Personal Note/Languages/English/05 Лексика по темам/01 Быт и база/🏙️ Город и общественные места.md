# 🏙️ Город и общественные места

Городскую лексику полезно учить с глаголами движения и предлогами: *go to the library, walk past the bank, wait at the entrance*.

| Выражение | Значение |
|---|---|
| `town hall` | ратуша, мэрия |
| `public library` | публичная библиотека |
| `post office` | почтовое отделение |
| `health centre` | поликлиника |
| `pedestrian crossing` | пешеходный переход |
| `city centre / downtown` | центр города |
| `public square` | общественная площадь |
| `opening hours` | часы работы |

> [!example] В контексте
> “The library is across from the town hall, next to the bus stop.”

Учите выражения целиком, проговаривайте их вслух и подставляйте свои детали. Учитывайте вежливость и ситуацию: один и тот же перевод может требовать разных английских формулировок.
