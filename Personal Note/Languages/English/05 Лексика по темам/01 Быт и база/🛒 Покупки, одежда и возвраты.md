# 🛒 Покупки, одежда и возвраты

В магазине уточняйте размер, наличие и условия возврата. Для одежды называйте размер и посадку, а при возврате объясните причину и предъявите чек.

| Выражение | Значение |
|---|---|
| `try something on` | примерить |
| `a size up / down` | на размер больше / меньше |
| `a loose fit` | свободная посадка |
| `a fitting room` | примерочная |
| `out of stock` | нет в наличии |
| `proof of purchase` | подтверждение покупки |
| `return an item` | вернуть товар |
| `get a refund` | получить возврат денег |

> [!example] В контексте
> “Could I return this? It doesn’t fit, and I still have the receipt.”

Учите выражения целиком, проговаривайте их вслух и подставляйте свои детали. Учитывайте вежливость и ситуацию: один и тот же перевод может требовать разных английских формулировок.

<!-- expanded study note -->

## Когда эта лексика нужна

В магазине уточняйте размер, посадку, наличие и условия обмена. Fit описывает посадку или размер, suit — насколько вещь подходит человеку по стилю. При возврате назовите дату покупки, причину и желаемое решение. Сроки и правила зависят от продавца и страны, поэтому фразы помогают спросить об условиях, но не задают их.

## Естественные модели и примеры

| Выражение | Пример | Значение |
|---|---|---|
| Could I try this on? | Could I try this on in a medium, and perhaps one size up? | Можно примерить размер M и на размер больше? |
| It doesn’t fit properly. | The jacket doesn’t fit properly around the shoulders. | Пиджак плохо сидит в плечах. |
| I’d like to return this. | I’d like to return this because the item is damaged. | Я хотел(а) бы вернуть эту вещь, потому что она повреждена. |
| Do you have the receipt? | I still have the receipt; I bought it last Saturday. | Чек у меня есть; я купил(а) это в прошлую субботу. |

## Мини-диалог

A: Can I help you find a size?
B: This one is too tight around the waist.
A: We have the next size up.
B: Great. Could I try it on before I decide?

## Тонкости и типичные ошибки

Clothes — неисчисляемое слово; one item of clothing — одна вещь. Fit the size — подходить по размеру; suit someone — идти человеку. Return — вернуть товар, exchange — обменять, refund — возврат денег.

## Практика

Смоделируйте покупку: уточните размер и примерку. Затем попросите возврат по конкретной причине, упомяните чек и желаемое решение.
