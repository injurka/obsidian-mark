# 🛒 Покупки, одежда и возвраты

В магазине уточняйте размер, наличие и условия возврата. Для одежды называйте размер и посадку, а при возврате объясните причину и предъявите чек.

| Выражение | Значение |
|---|---|
| `try something on` | примерить |
| `a size up / down` | на размер больше / меньше |
| `a loose fit` | свободная посадка |
| `a fitting room` | примерочная |
| `out of stock` | нет в наличии |
| `proof of purchase` | подтверждение покупки |
| `return an item` | вернуть товар |
| `get a refund` | получить возврат денег |

> [!example] В контексте
> “Could I return this? It doesn’t fit, and I still have the receipt.”

Учите выражения целиком, проговаривайте их вслух и подставляйте свои детали. Учитывайте вежливость и ситуацию: один и тот же перевод может требовать разных английских формулировок.
