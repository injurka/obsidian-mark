# 🆘 Экстренные ситуации

В экстренной ситуации сначала назовите, что случилось, где вы находитесь и какая помощь нужна. Короткое прямое сообщение лучше сложной фразы.

| Выражение | Значение |
|---|---|
| `Call emergency services.` | Вызовите экстренную службу. |
| `I need help.` | Мне нужна помощь. |
| `There has been an accident.` | Произошла авария. |
| `I’m lost.` | Я заблудился/заблудилась. |
| `I can’t find my passport.` | Я не могу найти паспорт. |
| `Please call an ambulance.` | Пожалуйста, вызовите скорую. |
| `Is there a hospital nearby?` | Поблизости есть больница? |
| `I don’t speak much English.` | Я не очень хорошо говорю по-английски. |

> [!example] В контексте
> “I need help. My friend has fallen near the station. We’re at the north entrance.”

Учите выражения целиком, проговаривайте их вслух и подставляйте свои детали. Учитывайте вежливость и ситуацию: один и тот же перевод может требовать разных английских формулировок.
