# 💪 Спорт, хобби и досуг

Хобби обычно сочетается с глаголом *do, play, go* или *take up*. Выучите типичную пару: *play tennis, go hiking, do yoga*.

| Выражение | Значение |
|---|---|
| `play a team sport` | заниматься командным спортом |
| `go hiking` | ходить в походы |
| `do yoga` | заниматься йогой |
| `take up photography` | начать заниматься фотографией |
| `spend time outdoors` | проводить время на улице |
| `read for pleasure` | читать для удовольствия |
| `a live performance` | живое выступление |
| `be into something` | увлекаться чем-либо |

> [!example] В контексте
> “I’m really into hiking, especially day trips in the mountains.”

Учите выражения целиком, проговаривайте их вслух и подставляйте свои детали. Учитывайте вежливость и ситуацию: один и тот же перевод может требовать разных английских формулировок.
