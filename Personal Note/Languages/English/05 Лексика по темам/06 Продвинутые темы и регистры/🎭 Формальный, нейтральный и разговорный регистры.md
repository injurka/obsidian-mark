# 🎭 Формальный, нейтральный и разговорный регистры

Регистр — выбор слов и грамматики под отношения, канал и цель. Не существует одного «самого правильного» регистра для всех ситуаций.

| Выражение | Значение |
|---|---|
| `ask / request` | спросить / запросить |
| `help / assist` | помочь / оказать содействие |
| `find out / determine` | выяснить / определить |
| `a lot of / numerous` | много / многочисленные |
| `I’m sorry / I apologise` | извините / приношу извинения |
| `Could you…? / Would you be able to…?` | можете…? / не могли бы вы…? |
| `kids / children` | дети (разговорно / нейтрально) |
| `Thanks / Thank you for your assistance` | спасибо (разговорно / формально) |

> [!example] В контексте
> В дружеском чате “Can you send it?” естественно; в официальном запросе подойдёт “Could you please send the document by Friday?”

Учите выражения целиком, проговаривайте их вслух и подставляйте свои детали. Учитывайте вежливость и ситуацию: один и тот же перевод может требовать разных английских формулировок.
