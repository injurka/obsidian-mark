# 💰 Экономика, бизнес и финансы

Финансовые новости требуют различать факты, оценки и прогнозы. Терминология меняется по стране и типу организации; сверяйте определения с контекстом.

| Выражение | Значение |
|---|---|
| `gross domestic product (GDP)` | валовой внутренний продукт |
| `interest rate` | процентная ставка |
| `cost of living` | стоимость жизни |
| `supply and demand` | предложение и спрос |
| `market share` | доля рынка |
| `revenue and profit` | выручка и прибыль |
| `budget deficit` | дефицит бюджета |
| `a return on investment` | окупаемость инвестиций |

> [!example] В контексте
> “Revenue increased, but profit fell because operating costs rose.”

Учите выражения целиком, проговаривайте их вслух и подставляйте свои детали. Учитывайте вежливость и ситуацию: один и тот же перевод может требовать разных английских формулировок.
