# 🤝 Встречи, проекты и командная работа

На встрече полезно кратко назвать цель, владельца задачи и срок. В конце проверьте, кто что делает дальше.

| Выражение | Значение |
|---|---|
| `set an agenda` | составить повестку |
| `share an update` | сообщить о ходе работы |
| `raise a concern` | озвучить проблему |
| `follow up on an action item` | вернуться к поручению |
| `take the lead` | взять на себя руководство |
| `be on track` | идти по плану |
| `run behind schedule` | отставать от графика |
| `let’s recap the next steps` | давайте подведём итоги следующих шагов |

> [!example] В контексте
> “I’ll update the draft today; could you review it by Thursday?”

Учите выражения целиком, проговаривайте их вслух и подставляйте свои детали. Учитывайте вежливость и ситуацию: один и тот же перевод может требовать разных английских формулировок.
