# 💻 Компьютер, программирование и IT

В техническом разговоре называйте действие и объект точно. Не заменяйте все глаголы на *do*: используйте *install, update, deploy, debug*.

| Выражение | Значение |
|---|---|
| `install a package` | установить пакет |
| `update the application` | обновить приложение |
| `deploy a release` | развернуть релиз |
| `reproduce a bug` | воспроизвести ошибку |
| `check the logs` | проверить логи |
| `push a change` | отправить изменение в репозиторий |
| `roll back a release` | откатить релиз |
| `the service is unavailable` | сервис недоступен |

> [!example] В контексте
> “I can reproduce the bug locally, but it doesn’t appear in production.”

Учите выражения целиком, проговаривайте их вслух и подставляйте свои детали. Учитывайте вежливость и ситуацию: один и тот же перевод может требовать разных английских формулировок.

## Когда эта лексика нужна

В техническом общении называйте объект и наблюдаемое поведение: приложение закрывается при загрузке, запрос завершается ошибкой, пакет не устанавливается. Отделяйте факт от гипотезы. Если известны версия, сообщение об ошибке и шаги воспроизведения, добавьте их. Точная формулировка помогает коллегам или поддержке повторить проблему.

## Естественные модели и примеры

| Выражение | Пример | Значение |
|---|---|---|
| The build is failing. | The build is failing after the dependency update; I’ve attached the log. | Сборка падает после обновления зависимости; лог приложен. |
| Could you reproduce the issue? | Could you reproduce the issue in a clean browser session? | Можете воспроизвести проблему в чистой сессии браузера? |
| The request timed out. | The request timed out after thirty seconds, but the service recovered. | Запрос завершился по тайм-ауту через 30 секунд, но сервис восстановился. |
| We rolled back the release. | We rolled back the release while investigating the data issue. | Мы откатили релиз, пока разбирались с проблемой данных. |

## Мини-диалог

A: Are you seeing the same error?
B: Yes, but only when a large file is uploaded.
A: Can you share the exact steps?
B: I’ll send the steps and the console output.

## Тонкости и типичные ошибки

Issue может быть проблемой или задачей в трекере; bug — дефект программы. Update — обновить, upgrade — перейти на более новую/мощную версию. Data часто употребляется как неисчисляемое в обычной технической речи.

## Практика

Опишите неисправность: устройство/версия, действие пользователя, ожидаемое и фактическое поведение, шаг воспроизведения. Пометьте, какие объяснения пока являются гипотезами.
