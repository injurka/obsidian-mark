# 💻 Компьютер, программирование и IT

В техническом разговоре называйте действие и объект точно. Не заменяйте все глаголы на *do*: используйте *install, update, deploy, debug*.

| Выражение | Значение |
|---|---|
| `install a package` | установить пакет |
| `update the application` | обновить приложение |
| `deploy a release` | развернуть релиз |
| `reproduce a bug` | воспроизвести ошибку |
| `check the logs` | проверить логи |
| `push a change` | отправить изменение в репозиторий |
| `roll back a release` | откатить релиз |
| `the service is unavailable` | сервис недоступен |

> [!example] В контексте
> “I can reproduce the bug locally, but it doesn’t appear in production.”

Учите выражения целиком, проговаривайте их вслух и подставляйте свои детали. Учитывайте вежливость и ситуацию: один и тот же перевод может требовать разных английских формулировок.
