# 🎓 Университет и обучение

В учебном контексте пригодятся слова для расписания, заданий и обратной связи. Различайте *course* как курс и *degree* как дипломную программу/степень.

| Выражение | Значение |
|---|---|
| `enrol in a course` | записаться на курс |
| `lecture / seminar` | лекция / семинар |
| `coursework` | учебные задания |
| `assignment deadline` | срок сдачи задания |
| `office hours` | часы консультации преподавателя |
| `submit an essay` | сдать эссе |
| `give feedback` | дать обратную связь |
| `a degree in biology` | степень по биологии |

> [!example] В контексте
> “Could I ask for an extension on the assignment?”

Учите выражения целиком, проговаривайте их вслух и подставляйте свои детали. Учитывайте вежливость и ситуацию: один и тот же перевод может требовать разных английских формулировок.
