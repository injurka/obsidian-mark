# 🆚 Know, learn и find out

**Know** — уже обладать знанием; **learn** — получать знание или навык; **find out** — выяснить конкретный факт.

| Выражение | Значение |
|---|---|
| `know the answer` | знать ответ |
| `know someone well` | хорошо знать кого-либо |
| `learn a language` | изучать язык |
| `learn how to drive` | научиться водить |
| `find out the price` | узнать цену |
| `find out what happened` | выяснить, что произошло |
| `learn from a mistake` | извлечь урок из ошибки |
| `get to know someone` | познакомиться поближе |

> [!example] В контексте
> “I found out where the class is, but I don’t know the teacher yet.”

Учите выражения целиком, проговаривайте их вслух и подставляйте свои детали. Учитывайте вежливость и ситуацию: один и тот же перевод может требовать разных английских формулировок.
