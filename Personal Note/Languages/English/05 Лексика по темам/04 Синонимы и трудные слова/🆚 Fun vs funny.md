# 🆚 Fun vs funny

**Fun** описывает приятное занятие или человека, с которым интересно; **funny** обычно означает «смешной», иногда «странный».

| Выражение | Значение |
|---|---|
| `have fun` | хорошо провести время |
| `a fun activity` | интересное занятие |
| `a fun person` | компанейский человек |
| `a funny story` | смешная история |
| `That’s funny.` | Это забавно / странно. |
| `look funny` | выглядеть странно |
| `make fun of someone` | высмеивать кого-либо |
| `a funny feeling` | странное ощущение |

> [!example] В контексте
> “We had fun at the party, and Dan told a really funny story.”

Учите выражения целиком, проговаривайте их вслух и подставляйте свои детали. Учитывайте вежливость и ситуацию: один и тот же перевод может требовать разных английских формулировок.
