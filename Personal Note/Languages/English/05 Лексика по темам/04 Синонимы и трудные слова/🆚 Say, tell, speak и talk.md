# 🆚 Say, tell, speak и talk

Эти глаголы связаны с речью, но имеют разные модели управления. Запоминайте пример целиком, особенно после *tell*.

| Выражение | Значение |
|---|---|
| `say something` | сказать что-либо |
| `say hello to someone` | поздороваться с кем-либо |
| `tell someone a story` | рассказать кому-либо историю |
| `tell the truth` | говорить правду |
| `speak to a manager` | поговорить с менеджером |
| `speak English` | говорить по-английски |
| `talk about a problem` | говорить о проблеме |
| `talk to/with a friend` | разговаривать с другом |

> [!example] В контексте
> “She told me that she had spoken to Alex about the plan.”

Учите выражения целиком, проговаривайте их вслух и подставляйте свои детали. Учитывайте вежливость и ситуацию: один и тот же перевод может требовать разных английских формулировок.
