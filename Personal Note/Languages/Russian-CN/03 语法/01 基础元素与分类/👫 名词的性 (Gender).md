## 🤯 引言：为什么这很重要（而且很奇怪）
汉语名词没有语法性。桌子（桌子 - zhuōzi）就只是桌子。但在俄语中，**每一个名词**都有性。这是它的基本属性，就像一个内置标签（内置标签），永远不会改变。

> [!important] 请记住
> 语法性不等于生物性别！这只是一个语法范畴。不必思考为什么桌子是「男性」——这是历史沿革的结果。

名词的性决定了与之相关的词语的形式：
*   **形容词：** красив**ый** стол / красив**ая** книга
*   **代词：** Мой стол / Мо**я** книга
*   **过去时动词：** Стол стоя**л** / Книга лежа**ла**

**如何判断性？看词的最后一个字母！**

## 1. 👨 阳性（阳性 - yángxìng）
阳性对应「ОН」（他 / 它）。

| 规则 | 示例 | 译文 |
| :--- | :--- | :--- |
| **1. 以辅音结尾**（辅音） | Сто**л**, горо**д**, телефо**н**, студен**т** | 桌子, 城市, 手机, 学生 |
| **2. 以 -Й 结尾** | Музе**й**, ча**й**, трамва**й** | 博物馆, 茶, 有轨电车 |
| **3. 以 -Ь（软音符）结尾** | Словар**ь**, учител**ь**, ден**ь** | 词典, 老师, 天 |

---

## 2. 👩 阴性（阴性 - yīnxìng）
阴性对应「ОНА」（她 / 它）。

| 规则 | 示例 | 译文 |
| :--- | :--- | :--- |
| **1. 以 -А 结尾** | Книг**а**, комнат**а**, машин**а**, вод**а** | 书, 房间, 汽车, 水 |
| **2. 以 -Я 结尾** | Семь**я**, песн**я**, земл**я** | 家庭, 歌曲, 土地 |
| **3. 以 -Ь（软音符）结尾** | Тетрад**ь**, ноч**ь**, двер**ь**, площад**ь** | 练习本, 夜晚, 门, 广场 |

---

## 3.  neuter. 中性（中性 - zhōngxìng）
中性对应「ОНО」（它）。俄语中，中性常用于抽象概念和某些物品。

| 规则 | 示例 | 译文 |
| :--- | :--- | :--- |
| **1. 以 -О 结尾** | Окн**о**, письм**о**, молок**о**, неб**о** | 窗户, 信, 牛奶, 天空 |
| **2. 以 -Е 结尾** | Мор**е**, солнц**е**, здани**е**, упражнени**е** | 大海, 太阳, 楼, 练习 |
| **3. 以 -МЯ 结尾（例外组）** | Вре**мя**, и**мя** | 时间, 名字 |

## 4. 🚨 陷阱与例外（陷阱与例外）

### 1. 陷阱1：以 -А / -Я 结尾的「男性词」
某些表示男性的词以 -А 或 -Я 结尾。这种情况下**语义优先于词尾**！它们属于阳性。

*   **Папа**（爸爸）—— 阳性 ➡ Мой папа（不是 *моя папа*！）
*   **Дедушка**（爷爷）—— 阳性
*   **Дядя**（叔叔/舅舅）—— 阳性
*   **Мужчина**（男人）—— 阳性

### 2. 陷阱2：软音符（-Ь）之谜
以**-Ь**结尾的词可能是阳性，也可能是阴性。没有简单的规则，**必须逐词记忆！**

> [!example]- 记忆示例：
> **阳性（-Ь）：**
> *   Слова**рь**（词典）
> *   Дож**дь**（雨）
> *   Де**нь**（天）
> *   Учител**ь**（老师）
> *   Рубл**ь**（卢布）
> 
> **阴性（-Ь）：**
> *   Тетра**дь**（练习本）
> *   Но**чь**（夜晚）
> *   Две**рь**（门）
> *   Жиз**нь**（生活/生命）
> *   Любов**ь**（爱）

### 3. 陷阱3：「咖啡」
词**кофе**（咖啡）看起来像中性（以 -Е 结尾），但它是**阳性**。
*   ✅ 正确：Вкусн**ый** чёрн**ый** кофе.
*   *（口语中越来越常见「вкусное кофе」，但在考试中这是错误的！）*

## 5. 判断性的算法小抄
当你看到一个新词时：
1.  **先检查它是否是例外**（папа, время, кофе）。
2.  **看最后一个字母：**
    *   **辅音 / -Й** ➡ 阳性
    *   **-А / -Я** ➡ 阴性
    *   **-О / -Е** ➡ 中性
3.  **如果最后一个字母是 -Ь**，请查词典并记住。

| 最后一个字母 | 性 |
| :--- | :---: |
| 辅音 | **阳性（Он）** |
| -Й | **阳性（Он）** |
| -А | **阴性（Она）** |
| -Я | **阴性（Она）** |
| -О | **中性（Оно）** |
| -Е | **中性（Оно）** |
| -Ь | **阳性或阴性（需要记忆！）** |
