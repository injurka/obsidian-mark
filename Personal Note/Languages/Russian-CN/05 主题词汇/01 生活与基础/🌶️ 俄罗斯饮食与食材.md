## 🤯 引言：忘掉炒菜与酱油
对于习惯了米饭、炒菜、丰富的香料和酱油的中国胃来说，俄罗斯饮食（Русская кухня）初尝可能显得单一。俄罗斯烹饪的核心在于**煮、烤、炖**，很少有爆炒。

> [!important] 俄罗斯餐桌的三大底色
> 1.  **没有大米也能活**：主食是面包和土豆。
> 2.  **汤是神圣的**：在俄罗斯，汤被称为“第一道菜”（Первое），是一顿正餐的灵魂。
> 3.  **冷食文化**：俄罗斯人吃大量的冷盘沙拉和凉菜，甚至还有冷汤。喝凉水或冰牛奶是常态（没有“喝热水”的习惯）。

## 🍞 1. 俄罗斯饮食的三大基石 (Базовые продукты)

如果一个俄罗斯人家里只剩下三样东西，那一定是面包、土豆和荞麦。

*   **Хлеб (面包)**：俄罗斯人对面包充满敬意。没有面包就不能叫吃饭。最著名的是**Чёрный хлеб (黑面包 / 黑麦面包)**，口感微酸、扎实，极具营养。
*   **Картошка / Картофель (土豆)**：被称为“第二面包”。它可以是土豆泥 (Пюре)、炸土豆 (Жареная картошка) 或水煮土豆。
*   **Гречка (荞麦)**：俄罗斯的“国民救命粮”。一种棕色的谷物，通常用水煮熟，加黄油或牛奶吃，或者作为肉类的配菜（Гарнир）。*（留学生最开始可能会觉得像在吃草，但习惯后会觉得很香！）*

## 🍲 2. 汤是信仰 (Супы)
在俄罗斯餐厅，菜单的第一页永远是汤。

| 俄语名称 | 中文翻译 | 核心食材与特色 |
| :--- | :--- | :--- |
| **Борщ** | **罗宋汤 (红菜汤)** | 俄罗斯的国汤。**注意：** 与上海那种橘红色、番茄味的甜味罗宋汤完全不同！正宗的 Борщ 是深紫红色的，因为主要食材是**甜菜根 (Свёкла)**。吃的时候一定要加一大勺酸奶油。 |
| **Щи** | **白菜汤** | 主要由白菜（有时是酸白菜）、土豆和肉熬制而成。俄罗斯俗语：“Щи да каша — пища наша” (白菜汤和粥就是我们的饭)。 |
| **Солянка** | **酸辣杂拌汤** | 极具风味的浓汤。里面有各种香肠、熏肉、酸黄瓜、橄榄和柠檬。味道咸、酸、微辣（由于胡椒），是极好的解酒汤。 |
| **Уха** | **鱼汤** | 传统的清炖鱼汤，通常含有土豆和胡萝卜，适合在郊外钓鱼时用篝火煮。 |
| **Окрошка** | **夏日冷汤** | **中国学生的终极挑战！** 这是一种**冰凉的汤**，里面有切碎的黄瓜、萝卜、火腿和煮鸡蛋，然后倒入克瓦斯（发酵饮料）或开菲尔酸奶。味道又酸又凉又冲。 |

## 🥟 3. 主菜与中俄“撞脸”美食
有些食物你在中国很熟悉，但在俄罗斯，它们的吃法会让你大开眼界。

### Пельмени (俄式饺子)
*   **区别**：形状通常像个小圆帽子（把两端捏在一起）。馅料通常是纯肉（猪肉、牛肉、羊肉），**没有大白菜或韭菜**！
*   **吃法震惊**：俄罗斯人不蘸醋和酱油！他们吃饺子通常配**酸奶油 (Сметана)**，或者放一块黄油，再撒上大量的莳萝 (Укроп)。

### Блины (俄式薄饼)
*   类似于法国的可丽饼（Crepes）或中国的煎饼。是“谢肉节 (Масленица)”的绝对主角。
*   **甜吃**：加果酱 (Варенье)、炼乳 (Сгущёнка) 或蜂蜜。
*   **咸吃**：卷入肉末、蘑菇，或者最奢华的吃法——配**红鱼子酱 (Красная икра)**。

### Шашлык (高加索烤肉串)
*   虽然源自高加索地区，但已成为俄罗斯夏季（达恰）文化的灵魂。
*   肉块比中国的新疆烤肉大得多，通常用洋葱、醋或矿泉水腌制，在炭火上烤熟，配着生洋葱和番茄酱吃。

## 🌿 4. 灵魂伴侣：神奇的佐料
如果没有这两样东西，俄罗斯菜就不完整。

> [!danger] 留学生的噩梦：莳萝 (Укроп)
> **Укроп (莳萝 / 茴香叶)** 是一种带有浓烈特殊气味的绿色香草。
> 俄罗斯人对它有着狂热的爱：他们把它撒在汤里、土豆上、沙拉里、饺子上，甚至把它放进黄瓜薯片里。如果你受不了这个味道，点菜时一定要说：*«Без укропа, пожалуйста» (请不要加莳萝)*。

> [!tip] 万能的酸奶油 (Сметана)
> **Сметана (酸奶油)** 不是甜的！它是一种微酸、浓郁的乳制品。
> 它可以加在罗宋汤里、拌在沙拉里、抹在薄饼上、蘸饺子吃。它是俄罗斯餐桌上的“老干妈”，什么都能搭。

## 🥤 5. 传统饮品 (Напитки)
*   **Квас (克瓦斯)**：由黑面包发酵制成的碳酸饮料。颜色像可乐，味道微甜微酸，带有烤面包的香气。夏天在街头有冰镇出售。
*   **Кефир (开菲尔酸奶)**：一种发酵乳饮料。**警告：它完全不甜！** 味道非常酸，很多初来乍到的留学生以为是甜酸奶买回家，喝一口就崩溃了。但它对肠胃极好。
*   **Компот (果盘水 / 糖水)**：用水煮各种水果和浆果（苹果、樱桃、杏干等）制成的甜味饮料，冷热皆宜。食堂必备。
*   **Чёрный чай (红茶)**：俄罗斯人极其爱喝茶（通常是红茶）。他们喝茶时一定要配糖、柠檬和一堆甜点（蛋糕、巧克力）。

## 📖 6. 实用指南：如何看懂餐厅菜单
去食堂 (Столовая) 或餐厅 (Ресторан) 时，菜单通常按以下顺序排列：

| 菜单分类 (Меню) | 说明 | 常见菜品 |
| :--- | :--- | :--- |
| **Салаты / Закуски** | 沙拉与冷盘前菜 | Оливье (奥利维耶沙拉), Сельдь под шубой (穿皮草的鲱鱼) |
| **Супы / Первое** | 汤类 (第一道菜) | Борщ (罗宋汤), Солянка (酸辣汤) |
| **Горячие блюда / Второе**| 热菜主食 (第二道菜) | Котлета (俄式肉饼), Мясо по-французски (法式焗肉), Курица (鸡肉) |
| **Гарниры** | 配菜（主菜旁边的碳水）| Пюре (土豆泥), Гречка (荞麦), Макароны (通心粉), Рис (米饭) |
| **Десерты** | 甜点 | Медовик (蜂蜜蛋糕), Наполеон (拿破仑蛋糕), Мороженое (冰淇淋) |
| **Напитки** | 饮料 | Кофе (咖啡), Чай (茶), Морс (浆果汁) |

### 🗣️ 点菜生存口语 (Survival Phrases)
*   **«Дайте, пожалуйста, меню.»** — 请给我菜单。
*   **«Я буду борщ и пюре с котлетой.»** — 我要一份罗宋汤和土豆泥配肉饼。 *(用 Я буду... / I will have...)*
*   **«Мне, пожалуйста, вот это.»** — 请给我（做手势指着菜单）这个。 *(万能救场句！)*
*   **«Можно счёт?»** — 可以结账吗？
*   **«С собой, пожалуйста.»** — 请打包带走 (Takeaway)。
