## 🤯 引言：俄罗斯人的亲戚没那么复杂！
对学习汉语的俄罗斯人来说，背诵“堂哥、表姐、大伯、小舅子”简直是地狱。好消息是：**俄语中的亲属关系要简单得多！**

在俄语中，**不区分父系和母系**（爷爷和外公是同一个词），也**不通过专有名词区分长幼**（哥哥和弟弟都叫“兄弟”）。所有的区分仅仅依靠附加的形容词。

---

## 1. 👨‍👩‍👧‍👦 核心家庭 (Близкие родственники)

| 俄语单词 | 重音与发音 | 翻译 | 备注说明 |
| :--- | :--- | :--- | :--- |
| **Семья́** | Семь-**я́** | 家庭 | 阴性名词。 |
| **Роди́тели** | Ро-**ди́**-те-ли | 父母 | 只有复数形式。 |
| **Мать / Ма́ма** | **Ма́**-ма | 母亲 / 妈妈 | “Мать”较为正式（母亲），“Мама”是日常称呼。 |
| **Оте́ц / Па́па** | О-**те́ц** / **Па́**-па | 父亲 / 爸爸 | > [!warning] **Папа** 是阳性名词，尽管以-А结尾！ |
| **Сын** | Сын | 儿子 | |
| **Дочь / До́чка** | Дочь / **До́ч**-ка | 女儿 | “Дочь”较正式，“Дочка”更口语、亲切。 |
| **Брат** | Брат | 兄弟 (哥/弟) | *见下文如何区分长幼。* |
| **Сестра́** | Се-с-**тра́** | 姐妹 (姐/妹) | |
| **Ребёнок / Де́ти** | Ре-**бё**-нок / **Де́**-ти| 孩子 / 孩子们 | 单复数词根完全不同（异形复数）。 |

### 📏 如何区分“哥哥”和“弟弟”？
由于没有单独的词，俄罗斯人使用形容词 **Ста́рший** (年长的) 和 **Мла́дший** (年幼的)。
*   **Ста́рший брат** — 哥哥
*   **Мла́дшая сестра́** — 妹妹
*   **Мла́дший сын** — 小儿子

## 2. 👵👴 祖父母与扩展家族 (Расширенная семья)
俄语不区分“爷爷”和“外公”，“奶奶”和“外婆”。全都是一样的！

| 俄语单词 | 翻译 | 对应中国亲属称谓 |
| :--- | :--- | :--- |
| **Де́душка** | 祖父 / 外祖父 | 爷爷, 外公 |
| **Ба́бушка** | 祖母 / 外祖母 | 奶奶, 外婆 |
| **Внук / Вну́чка** | 孙子 / 孙女 | 孙子, 外孙 / 孙女, 外孙女 |
| **Дя́дя** | 叔/伯/舅/姑父/姨父 | 叔叔, 伯伯, 舅舅, 姑父, 姨父 |
| **Тётя** | 姑/姨/婶/伯母/舅妈 | 姑姑, 阿姨, 婶婶, 舅妈, 伯母 |
| **Племя́нник** | 侄子 / 外甥 | 侄子, 外甥 |
| **Племя́нница** | 侄女 / 外甥女 | 侄女, 外甥女 |

> [!danger] 语法陷阱：带-А/-Я结尾的男性！
> 词汇 **Папа** (爸爸), **Дедушка** (爷爷), **Дядя** (叔叔) 看起来像阴性（因为以 -а/-я 结尾），但它们是**阳性 (Он)**！
> ✅ **Мой** дедушка (我的爷爷)
> ❌ ~~Моя~~ дедушка

## 3. 👯‍♂️ 表亲与堂亲 (Двою́родные родственники)
如何表达“表哥”或“堂妹”？俄语中有一个神奇的形容词：**Двою́родный** (字面意思：第二层血缘的)。
你只需要把它加在“兄弟”或“姐妹”前面即可，同样不分父系母系。

*   **Двою́родный брат** — 堂兄/弟，表兄/弟 (Cousin - male)
*   **Двою́родная сестра́** — 堂姐/妹，表姐/妹 (Cousin - female)

*进阶：如果有“表叔”这样的第三层关系，就是 Трою́родный (брат/сестра)。*

## 4. 💍 姻亲：最危险的区域 (Родственники мужа и жены)
俄罗斯人对于配偶的父母有非常精确的词汇，而且这些词汇承载着巨大的文化意义（尤其是笑话！）。

*   **Муж** (丈夫)
*   **Жена́** (妻子)

### 对于丈夫来说（妻子的父母）：
*   **Тёща** (岳母 / 丈母娘) —— 💥 **文化密码！** Тёща 是俄罗斯笑话（анекдоты）中绝对的常客。在刻板印象中，岳母总是不喜欢女婿，经常来家里挑刺。
*   **Тесть** (岳父 / 老丈人) —— 通常在笑话里是和女婿一起喝酒的“好战友”。

### 对于妻子来说（丈夫的父母）：
*   **Свекро́вь** (婆婆) —— 另一个婆媳冲突的经典角色。
*   **Свёкор** (公公)

> [!tip] 留学生生存技巧
> 如果你记不住这些复杂的词，完全可以直接使用描述性的说法：
> *   Тёща = **Ма́ма жены́** (妻子的妈妈)
> *   Свекровь = **Ма́ма му́жа** (丈夫的妈妈)
> 所有人都能听懂，而且语法完全正确！

## 5. 💔 婚姻状况 (Семе́йное положе́ние)
注意！在俄语中，男人和女人的“结婚”动词是**完全不同**的。

| 状态 | 对于男性 (Мужчина) | 对于女性 (Женщина) |
| :--- | :--- | :--- |
| **单身** | Он **холоста́й** (单身汉) / не жена́т | Она **не за́мужем** (未婚) |
| **已婚** | Он **жена́т** (字面：娶了妻的) | Она **за́мужем** (字面：在丈夫背后的) |
| **怎么问？** | Вы женаты? (您结婚了吗？) | Вы замужем? (您结婚了吗？) |
| **离婚** | Он **разведён** | Она **разведена́** |

*(关于结婚动词的详细语法，通常归类于 B1 级别的词汇陷阱，但记住这个状态描述对于填表和日常交流足够了)。*

## 🚨 常见语法错误与复数陷阱
家庭词汇是俄语中最古老的一批词，因此它们的**复数形式（Множественное число）几乎全是例外**，需要死记硬背：

*   Брат ➡ **Бра́тья** (兄弟们) — *不是 браты*
*   Сын ➡ **Сыновья́** (儿子们) — *不是 сыны*
*   Муж ➡ **Мужья́** (丈夫们) 
*   Дочь ➡ **До́чери** (女儿们) — *出现了隐藏的 -ер-*
*   Мать ➡ **Ма́тери** (母亲们) — *同样出现了隐藏的 -ер-*
*   Ребёнок ➡ **Де́ти** (孩子们) — *完全变了一个词*

*(详细复数规则请复习：[[➕ 复数]])*
