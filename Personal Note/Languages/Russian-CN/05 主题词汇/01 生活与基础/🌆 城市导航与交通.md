## 🤯 引言：俄罗斯城市的出行逻辑
在中国，你习惯了扫码乘车、共享单车和高德地图。在俄罗斯，虽然数字化程度同样很高（非现金支付普及率极高），但交通工具的分类、问路的习惯以及地址的表达方式却有着自己独特的逻辑。

最重要的一点：在俄语中，**“步行去”和“乘车去”是两个完全不同的词**！如果你对路人说“Как **дойти** до Пекина?”（我怎么**走**到北京去？），路人会以为你在开玩笑，因为那需要坐飞机或火车（доехать / долететь）。

## 🚇 1. 交通工具全家桶 (Виды транспорта)
回答“乘坐什么交通工具”时，必须使用 **НА + 第6格 (前置词格)**。

| 俄语词汇 | 读音 / 词性 | 翻译 | 乘坐该交通工具 (На чём?) |
| :--- | :--- | :--- | :--- |
| **Метро** | [ме-тро́] / 中性, *不变格* | 地铁 | Ехать **на метро** |
| **Автобус** | [ав-то́-бус] / 阳性 | 公交车 | Ехать **на автобусе** |
| **Трамвай** |[трам-ва́й] / 阳性 | 有轨电车 | Ехать **на трамвае** |
| **Троллейбус** | [трол-ле́й-бус] / 阳性 | 无轨电车 | Ехать **на троллейбусе** |
| **Такси** |[так-си́] / 中性, *不变格* | 出租车 | Ехать **на такси** |
| **Поезд** | [по́-езд] / 阳性 | 火车 | Ехать **на поезде** |
| **Самолет** | [са-ма-лё́т] / 阳性 | 飞机 | Лететь **на самолете** |

> [!danger] 留学生的经典语病
> 在汉语中，我们说“**坐**地铁”。很多初学者会直译为 “Сидеть метро” (Сидеть = to sit / 坐在椅子上)。
> ❌ ~~Я сижу метро.~~ (意思是：我正坐在地铁的某把椅子上)。
> ✅ **Я еду на метро.** (我乘地铁去某地)。

## 🚐 2. 俄罗斯特色：小巴 (Маршрутка)
**Маршрутка** (Маршрутное такси / 小巴、招手停) 是一种极具东欧特色的交通工具。它通常是一辆黄色或白色的中型面包车。

**小巴生存指南：**
1. **招手即停：** 在公交站看到你需要的小巴，必须像打车一样向它招手，否则它可能直接开走。
2. **传车费 (Передайте за проезд)：** 如果你坐在后排够不到司机，你可以把钱或公交卡递给前面的乘客，并说：*«Передайте, пожалуйста» (请帮忙传一下)*。整个车厢的人会接力把你的钱传给司机，再把找零传回来。
3. **下车靠喊：** 小巴不一定每站都停。快到你的目的地时，你必须在车厢里大喊：
   * *«Остановите на остановке, пожалуйста!»* (请在下一站停一下！)
   * *«Остановите здесь!»* (请在这里停！)

## 🗺️ 3. 问路与指路 (Как дойти / доехать?)

在街上迷路时，如何礼貌地向俄罗斯人求助？

### 步骤 1：礼貌地引起注意
*   — **Извините, пожалуйста...** (请问 / 打扰一下...)
*   — **Подскажите, пожалуйста...** (请告诉我 / 请指点一下...)

### 步骤 2：提出问题 (3种核心句型)
1.  **Где находится...?** (……在哪里？/ 静态位置)
    *   *Где находится станция метро?* (地铁站在哪？)
    *   *Где находится ближайшая аптека?* (最近的药店在哪？)
2.  **Как дойти до...?** (怎么**走**去……？/ 步行，+ 第2格)
    *   *Как дойти до Красной площади?* (怎么走到红场？)
3.  **Как доехать до...?** (怎么**乘车**去……？/ 乘车，+ 第2格)
    *   *Как доехать до аэропорта?* (怎么乘车去机场？)

### 步骤 3：听懂对方的指路 (方向词汇)
如果对方开始噼里啪啦说一堆，你只需要抓住这几个核心方向词：
*   ⬆️ **Прямо** [пря́-мо] — 直走
*   ⬅️ **Налево**[на-ле́-во] — 向左转
*   ➡️ **Направо** [на-пра́-во] — 向右转
*   🔙 **Назад** [на-за́д] — 向后，掉头
*   📍 **Здесь / Тут** [здесь / тут] — 在这里
*   📍 **Там** [там] — 在那里
*   🛑 **Остановка** [ас-та-но́в-ка] — 车站 / 公交站

> [!tip] 对话示例
> — Извините, как дойти до метро? *(打扰一下，请问地铁站怎么走？)*
> — Идите прямо, потом направо. Это недалеко. *(一直走，然后右转。不远。)*

## 🎫 4. 乘车与买票 (Оплата проезда)

俄罗斯主要城市的公共交通支付非常发达。大部分公交车和地铁都支持直接刷银行卡 (Банковская карта) 或使用交通卡。

*   **Тройка (三套车卡)：** 莫斯科的通用交通卡。
*   **Подорожник (车前草卡)：** 圣彼得堡的通用交通卡。

**核心词汇：**
*   **Билет** — 票 (Купить билет / 买票)
*   **Проездной (билет)** — 交通月票 / 通票
*   **Турникет** — 闸机 (地铁进站口的挡板)
*   **Пересадка** — 换乘 (Делать пересадку / 换乘)
*   **Конечная (станция)** — 终点站

## 📍 5. 俄罗斯的地址逻辑 (Адреса)

俄罗斯的地址书写顺序与中国**完全相反**。
中国：从大到小（国家 ➡ 省 ➡ 市 ➡ 街 ➡ 门牌号）。
俄罗斯：从小到大（人名 ➡ 门牌号 ➡ 街 ➡ 市 ➡ 国家）。

当你打车或找路时，你经常会看到这样的地址：
**ул. Ленина, д. 10, корп. 2, строен. 1, кв. 15**

这是什么意思？
*   **ул. = Улица** (街道)。例如：ул. Пушкина (普希金街)。
*   **пр. = Проспект** (大道)。比街道宽得多，通常是城市主干道。例如：Невский проспект (涅瓦大街)。
*   **д. = Дом** (楼号 / 门牌号)。例如：д. 10 (10号楼)。
*   **корп. = Корпус** (栋 / 建筑群中的副楼)。俄罗斯由于冬天寒冷，很多建筑是连在一起的庞大建筑群，主楼是 дом，旁边连着的副楼就是 корпус。
*   **строен. = Строение** (建筑物 / 院子里的附属建筑)。
*   **кв. = Квартира** (公寓号 / 房间号)。例如：кв. 15 (15室)。

## 📱 6. 必备数字生活工具 (Yandex 全家桶)
要像本地人一样在俄罗斯城市穿梭，你需要下载这两个APP：

1.  **Яндекс Карты (Yandex Maps) / Яндекс Метро:** 俄罗斯版的“高德/百度地图”。极其精准，能实时显示公交车在哪条街上移动，甚至告诉你地铁应该坐在哪节车厢换乘最快。
2.  **Яндекс Go (Yandex Taxi):** 俄罗斯版的“滴滴”。价格非常透明且相对便宜。
    *   *Эконом (经济型)* — 便宜，通常是现代或起亚。
    *   *Комфорт (舒适型)* — 略贵，车更好，司机更安静。
    *   *Комфорт+ (舒适+)* — 适合长途或需要大空间。

> [!info] 俄罗斯司机闲聊预警
> 如果你打了 Yandex Taxi，坐在了副驾驶（前排），司机（往往来自中亚国家）有很大概率会开始跟你聊天：“Откуда ты?” (你从哪来？)，“Как тебе Россия?” (觉得俄罗斯怎么样？)。如果你不想聊天，**请坐在后排**，然后看着手机即可。
