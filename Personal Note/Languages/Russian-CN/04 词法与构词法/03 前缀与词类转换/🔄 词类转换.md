## 🤯 引言：省略的艺术
在汉语中，词类转换非常灵活，几乎不需要改变词形。例如，“翻译”既可以是动词（我翻译），也可以是名词（我是翻译）。

在俄语中，词类有着极其严格的界限和不同的词尾。动词就是动词，名词就是名词。但有一种极其普遍的现象叫做 **Субстантивация（名词化）** —— **形容词或形动词“偷走”了名词的身份，直接作为名词在句子中使用。**

> [!info] 它是怎么发生的？
> 历史上，俄语中有很多固定的修饰搭配，比如 «столовая комната»（用来吃饭的房间）。后来，人们为了说话省力，把真正的名词 «комната» 去掉了，只留下了形容词 «столовая»。久而久之，«столовая» 就变成了“食堂”这个名词本身。

掌握这些词，你就能理解为什么有些“名词”长着一副形容词的面孔！

## 1. 🍽️ 场所与食物（原形是形容词）
这是初学者最早接触到的一批“伪装者”。它们在词典里被标注为名词，但实际上完全保留了形容词的词形。

| 名词化的词 (长得像形容词) | 它的本来面目 (省略了的名词) | 翻译 |
| :--- | :--- | :--- |
| **Столовая** (阴性) | Столовая *комната* | 食堂 |
| **Ванная** (阴性) | Ванная *комната* | 浴室 |
| **Мороженое** (中性) | Мороженое *молоко* (冰冻的牛奶) | 冰淇淋 |
| **Животное** (中性) | Животное *существо* (活着的生物) | 动物 |
| **Горячее** (中性) | Горячее *блюдо* (热的菜肴) | 热菜 / 主菜 |
| **Шампанское** (中性) | Шампанское *вино* (香槟酒) | 香槟 |

## 2. 👨‍⚕️ 称呼与身份（原形是形容词/形动词）
俄语中有一大批用来指代“人”的名词，它们实际上是表示该人特征或状态的形容词/形动词。

| 词汇 | 性别 (可根据自然性别变化) | 翻译 | 说明 |
| :--- | :--- | :--- | :--- |
| **Больной / Больная** | 阳性 / 阴性 | 病人 | 原意：生病的人 |
| **Взрослый / Взрослая** | 阳性 / 阴性 | 成年人 | 原意：长大的人 |
| **Учёный** | 阳性 | 科学家 / 学者 | 原意：被教导过的人 (形动词) |
| **Знакомый / Знакомая** | 阳性 / 阴性 | 熟人 | 原意：认识的人 |
| **Учащийся** | 阳性 (-ся 结尾) | 学生 / 学习者 | 原意：正在学习的人 (形动词) |
| **Русский / Русская** | 阳性 / 阴性 | 俄罗斯人 | 注意！这是国籍中唯一一个形容词形式的名词 (其他如 китаец 是纯名词)。 |

>[!tip] 灵活的性别
> 这些表示人的词，可以根据对象的实际性别自由切换结尾：
> *   Он мой **знакомый**. (他是我的男熟人)
> *   Она моя **знакомая**. (她是我的女熟人)
> *   Они мои **знакомые**. (他们是我的熟人们)

## 3. ⏳ 抽象概念（中性词）
当我们想把某种特征或时间状态作为一个整体概念来谈论时，通常使用**中性形容词 (-ое / -ее)**。

*   **Будущее** (未来) — *Мы верим в светлое будущее.* (我们相信光明的未来。)
*   **Прошлое** (过去) — *Не надо жить прошлым.* (不要活在过去。)
*   **Настоящее** (现在) — *Он ценит настоящее.* (他珍惜现在。)
*   **Главное** (最重要的事情) — *Главное — это здоровье.* (最重要的是健康。)
*   **Новое** (新事物) — *Узнать что-то новое.* (了解一些新事物。)

## 4. 🚨 变格陷阱：它们该怎么变格？
这是词类转换带来最大的语法难点！

> [!danger] 核心法则
> 即使这些词在句子中履行名词的职责（作主语或宾语），**它们的变格方式依然 100% 遵循形容词的变格规则！**

**对比错误与正确形式：**
*   **Столовая (食堂 - 阴性)**
    *   ❌ *Я иду в столовую.* (错！不能按 -А 变 -У 的名词规则)
    *   ✅ **Я иду в столовую.** (对！按 -АЯ 变 -УЮ 的形容词规则)
    *   ✅ *Мы обедали в столов**ой**.* (第六格：在食堂里)
*   **Мороженое (冰淇淋 - 中性)**
    *   ❌ *Я хочу морожена.* (错！不能按第二格名词变 -А)
    *   ✅ **Я хочу мороженного.** (对！按中性形容词第二格变 -ОГО)
*   **Больной (病人 - 阳性有生命)**
    *   ✅ *Врач смотрит больн**ого**.* (第四格有生命：医生在看病人)
    *   ✅ *Подойти к больн**ому**.* (第三格：走向病人)

## 5. 🎭 双重特工：视语境而定
许多词至今保留着“双重身份”。在不同的句子里，它们一会儿是修饰名词的形容词，一会儿又是独立的名词主角。

| 词汇 | 作为形容词 (什么样的？) | 作为名词 (谁？/ 什么？) |
| :--- | :--- | :--- |
| **Русский** | Это **русский** язык. (这是*俄语*语言) | Он **русский**. (他是*俄罗斯人*) |
| **Больной** | **Больной** ребёнок спит. (*生病的*孩子在睡觉) | **Больной** спит. (*病人*在睡觉) |
| **Взрослый** | Это **взрослая** жизнь. (这是*成年的*生活) | Билет для **взрослых**. (给*成年人*的票) |
| **Дежурный** | **Дежурный** врач здесь. (*值班的*医生在这) | **Дежурный** слушает! (*值班员*在听！- 接电话时) |

## 📊 总结与自测

**判断题：如何正确地填入“食堂” (столовая) 和“冰淇淋” (мороженое) 的正确格？**

1. Около университета нет хорошей (_______). -> *столовой* (第二格，形容词阴性词尾)
2. Дети очень любят (_______). -> *мороженое* (第四格无生命，中性形容词词尾与第一格相同)
3. Я дал лекарство (_______). -> *больному* (第三格，给病人，形容词阳性词尾)
4. Мы говорили о (_______). -> *будущем* (第六格，关于未来，形容词中性词尾)
