## 🤯 引言：扩充词汇量的“作弊码”
在汉语中，如果你想表达相反的意思，通常只需在词前加一个**“不”**或**“无”**（开心→ 不开心，条件→ 无条件），或者使用完全不同的词（好→ 坏）。

俄语的构词法非常强大。只需在原词前面“粘”上一个特定的前缀（Приставка），你就能创造出一个全新的反义词。这意味着：**如果你记住了一个词根和几个前缀，你的词汇量就会自动翻倍！**

---

## 1. 🙅‍♂️ 前缀 НЕ- (相当于“不 / 非”)
这是最基础、最常见的前缀。它直接赋予词语相反的含义。最常用于形容词、副词和名词。

### 📌 构词模式
`НЕ + 原词 = 相反的概念`

| 原词 (肯定) | 翻译 | 加前缀后 (否定) | 翻译 (反义词) |
| :--- | :--- | :--- | :--- |
| **Дорогой** | 贵的 | **Не**дорогой | 便宜的 / 不贵的 |
| **Красиво** | 漂亮地 | **Не**красиво | 难看地 / 不漂亮地 |
| **Правда** | 真相 / 事实 | **Не**правда | 谎言 / 假话 |
| **Счастье** | 幸福 | **Не**счастье | 不幸 / 灾祸 |
| **Сложный** | 复杂的 | **Не**сложный | 简单的 |

> [!danger] 陷阱：连写还是分开写？(Слитно или раздельно?)
> 这是连俄罗斯人都会犯错的语法重点（ТРКИ 必考）！
> *   **连写 (当作前缀)：** 当它构成一个具有新含义的词，且没有对比时。
>     *   *Это **неплохой** ресторан.* (这是一家不错的/挺好的餐厅。)
> *   **分开写 (当作否定语气词)：** 1. 当句子中有带“а”的强烈对比时；2. 在动词前面！
>     *   *Это **не** плохой ресторан, **а** очень хороший.* (这**不是**坏餐厅，**而是**好餐厅。)
>     *   *Я **не** знаю.* (我不知道。——**动词前面永远分开写！**)

## 2. 🚫 前缀 БЕЗ- / БЕС- (相当于“无 / 没有”)
这个前缀的含义是“缺乏某物”。它通常与名词词根结合，生成一个形容词（表示“没有...的”）。

> [!important] 拼写黄金法则：З 还是 С？
> 这个前缀有一个变色龙般的特性。它的拼写取决于它后面的字母：
> 1.  如果后面是**元音**或**浊辅音** (Б, В, Г, Д, Ж, З, Л, М, Н, Р)，写 **БЕЗ-**。
> 2.  如果后面是**清辅音** (П, Ф, К, Т, Ш, С, Х, Ц, Ч, Щ)，写 **БЕС-**。
> *(为了发音顺畅，清辅音会把 З 强行同化成 С)。*

| 名词词根 | 加前缀后 | 翻译 | 拼写逻辑 |
| :--- | :--- | :--- | :--- |
| Опасность (危险) | **Без**опасный | 安全的 | 元音 **О**，所以用 БЕЗ |
| Вкус (味道) | **Без**вкусный | 无味的 / 品味差的 | 浊辅音 **В**，所以用 БЕЗ |
| Ум (智力/理智) | **Без**умный | 疯狂的 / 失去理智的 | 元音 **У**，所以用 БЕЗ |
| Шум (噪音) | **Бес**шумный | 无声的 / 静音的 | 清辅音 **Ш**，所以用 БЕС |
| Конец (尽头) | **Бес**конечный | 无尽的 / 无限的 | 清辅音 **К**，所以用 БЕС |
| Полезный (有用的) | **Бес**полезный | 无用的 / 徒劳的 | 清辅音 **П**，所以用 БЕС |

## 3. 🛡️ 前缀 АНТИ- / ПРОТИВО- (相当于“反 / 抗”)
这两个前缀通常用于科学、医学、政治和现代词汇中。

*   **АНТИ- (外来语前缀)：** 国际通用词汇。
    *   **Анти**вирус (杀毒软件 / 抗病毒)
    *   **Анти**герой (反英雄)
    *   **Анти**стресс (抗压)
*   **ПРОТИВО- (纯俄语前缀)：** 含义相同，但多用于传统俄语词根。
    *   **Противо**газ (防毒面具)
    *   **Противо**вирусный (抗病毒的 / 药剂)

## 4. 🔄 成对的绝对反义词 (Антонимы)
并非所有的反义词都能用前缀“偷懒”造出来。俄语中有许多核心词汇，它们的正反义是完全不同的词根。这些必须死记硬背！

| 肯定 / 正面 | 否定 / 负面 |
| :--- | :--- |
| **Хороший** (好的) | **Плохой** (坏的) |
| **Большой** (大的) | **Маленький** (小的) |
| **Горячий** (热的) | **Холодный** (冷的) |
| **Тяжёлый** (重的 / 艰难的) | **Лёгкий** (轻的 / 简单的) |
| **Начинать** (开始) | **Заканчивать** (结束) |
| **Белый** (白色的) | **Чёрный** (黑色的) |

> [!tip] 记忆小贴士
> 在制作 [[🃏 俄语 Anki 卡片]] 时，**永远不要孤立地背诵形容词**。
> 不要只背 `умный`（聪明的）。应该背词对：`умный - глупый`（聪明的 - 愚蠢的），或者结合前缀背 `умный - безумный`（聪明的 - 疯狂的）。这样大脑会建立联想网络，回忆速度会快两倍。
