## 🚀 Вызов HSK 3.0
Новый стандарт HSK 3.0 сильно увеличил количество лексики на начальных уровнях (например, в HSK 1 теперь 500 слов вместо прежних 150). Простое зазубривание списков больше не работает. Интервальные повторения в **Anki** — единственный способ удержать в памяти тысячи иероглифов.

---

## 🎨 1. Анатомия идеальной карточки
Не делайте простые двусторонние карточки. Карточка для китайского языка должна иметь структурированные поля.

### Рекомендуемые поля (Fields):
1.  **Hanzi:** Сам иероглиф (крупно, шрифт типа *Kaiti*).
2.  **Pinyin:** Запись чтения со знаками тонов.
3.  **Meaning:** Перевод на русский.
4.  **Audio:** Звуковой файл произношения.
5.  **Example:** Пример предложения (желательно с аудио).
6.  **HSK_Level:** Тег уровня (например, `HSK1`, `HSK3`).
7.  **Strokes:** Ссылка на анимацию написания черт.

> [!important] Золотое правило карточек
> Разделяйте распознавание и продукцию. У вас должно быть два типа карточек:
> 1.  `Hanzi ➔ Пиньинь + Перевод` (для чтения).
> 2.  `Перевод ➔ Написать иероглиф от руки` (для письма).

## 🔌 2. Топ-3 аддона для Anki (Маст-хэв)

Установите эти плагины через меню *Инструменты ➔ Дополнения (Add-ons)*:

### А. Chinese Support Redux
Автоматически заполняет поле `Pinyin` при вводе иероглифов, раскрашивает слоги в зависимости от тона, добавляет переводы и ссылки на словари.

### Б. AwesomeTTS (или HyperTTS)
Генерирует качественную озвучку текста (Text-to-Speech) с использованием голосов Microsoft Azure или Google. Больше не нужно искать MP3 файлы вручную.

### В. AnkiConnect
Позволяет отправлять слова в Anki в один клик прямо из словаря Pleco на телефоне или из плагинов Obsidian.

## 🌈 3. Цветовое кодирование тонов (Tone Colors)
Визуальная память на цвета работает отлично. Используйте стандартную цветовую схему китайских словарей (Pleco):

*   🔴 **1-й тон (Ровный):** Красный (высокий, ровный).
*   🟢 **2-й тон (Восходящий):** Зеленый.
*   🔵 **3-й тон (Низкий/Нисходяще-восходящий):** Синий.
*   🟣 **4-й тон (Падающий):** Фиолетовый / Розовый.
*   ⚫ **Нейтральный тон:** Серый / Черный.

---

## ⚙️ 4. Параметры интервалов для китайского
Китайские иероглифы забываются быстрее, чем европейские слова. Рекомендуется немного сократить интервалы повторений в настройках колоды (Deck Options):

*   **Шаги изучения (Learning steps):** `1m 10m 1d` (вместо стандартных 1м 10м).
*   **Интервал легкого ответа (Easy interval):** `3d` (чтобы карточка не улетала сразу на неделю).
*   **Максимум отзывов в день (Max reviews/day):** Не ставьте лимитов, иначе скопится «хвост» забытых слов.
