## ☕ Тема: Заказ кофе

Эта тема поможет вам уверенно чувствовать себя в китайских заведениях. Вы научитесь выбирать напитки, общаться с бариста и указывать свои предпочтения при заказе.

### 📚 Словарь дня

| Иероглифы |   Пиньинь    | Перевод            |
| :-------: | :----------: | :----------------- |
|  **咖啡馆**  |  kāfēiguǎn   | кофейня            |
|  **拿铁**   |    nátiě     | латте              |
| **美式咖啡**  | měishì kāfēi | американо          |
|   **点**   |     diǎn     | заказывать         |
|  **打包**   |    dǎbāo     | с собой (на вынос) |
|  **牛奶**   |    niúnǎi    | молоко             |
|   **糖**   |     táng     | сахар              |

### 💬 Разбор примеров (STPMVO)

<details class="stpmvo-dropdown">
  <summary>💡 Напоминание формулы STPMVO (нажмите, чтобы раскрыть)</summary>
  <div class="stpmvo-content">
    <b>S</b> (Subject / Подлежащее) + <b>T</b> (Time / Время) + <b>P</b> (Place / Место) + <b>M</b> (Manner / Образ действия, с кем) + <b>V</b> (Verb / Глагол) + <b>O</b> (Object / Дополнение)
  </div>
</details>

<div class="grammar-card">
  <div class="grammar-title">1. Базовая структура (S + V + O)</div>
  <div class="grammar-example">
    <span class="cn-text">我点拿铁。</span>
    <span class="py-text">Wǒ diǎn nátiě.</span>
    <span class="ru-text">Я заказываю латте.</span>
  </div>
  <div class="grammar-breakdown">
    <b>Разбор:</b> Здесь работает ядро формулы. <b>S</b> (我 - я) + <b>V</b> (点 - заказываю) + <b>O</b> (拿铁 - латте).
  </div>
</div>

<div class="grammar-card">
  <div class="grammar-title">2. Добавляем время и место (S + T + P + V + O)</div>
  <div class="grammar-example">
    <span class="cn-text">我们今天在咖啡馆点美式咖啡。</span>
    <span class="py-text">Wǒmen jīntiān zài kāfēiguǎn diǎn měishì kāfēi.</span>
    <span class="ru-text">Сегодня мы заказываем американо в кофейне.</span>
  </div>
  <div class="grammar-breakdown">
    <b>Разбор:</b> В русском мы можем поставить место куда угодно, но в китайском оно строго перед глаголом. <b>S</b> (我们 - мы) + <b>T</b> (今天 - сегодня) + <b>P</b> (在咖啡馆 - в кофейне) + <b>V</b> (点 - заказываем) + <b>O</b> (美式咖啡 - американо).
  </div>
</div>

<div class="grammar-card">
  <div class="grammar-title">3. Образ действия и определения (S + T + M + P + V + O)</div>
  <div class="grammar-example">
    <span class="cn-text">明天我跟朋友在咖啡馆点打包的拿铁。</span>
    <span class="py-text">Míngtiān wǒ gēn péngyou zài kāfēiguǎn diǎn dǎbāo de nátiě.</span>
    <span class="ru-text">Завтра я с другом в кофейне закажу латте на вынос.</span>
  </div>
  <div class="grammar-breakdown">
    <b>Разбор:</b> <br>
    • <b>T</b> (明天 - завтра) <br>
    • <b>S</b> (我 - я) <br>
    • <b>M</b> (跟朋友 - с другом) <br>
    • <b>P</b> (在咖啡馆 - в кофейне) <br>
    • <b>V</b> (点 - закажу) <br>
    • <b>O</b> (打包的拿铁 - латте на вынос. <i>«打包的» выступает как определение</i>).
  </div>
</div>
