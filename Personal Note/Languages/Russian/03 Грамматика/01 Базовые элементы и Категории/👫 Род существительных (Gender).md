## 🤯 Введение: Почему это важно (и странно)
В китайском языке у предметов нет грамматического рода. Стол (桌子 - zhuōzi) — это просто стол. В русском языке **У КАЖДОГО СУЩЕСТВИТЕЛЬНОГО** есть род. Это его фундаментальное свойство, как встроенная метка (内置标签), которая никогда не меняется.

> [!important] Запомните
> Грамматический род — это не биологический пол! Это просто грамматическая категория. Не нужно думать, почему стол — это «мужчина». Так сложилось исторически.

Род существительного определяет, какую форму будут иметь связанные с ним слова:
*   **Прилагательные:** красив**ый** стол / красив**ая** книга
*   **Местоимения:** Мой стол / Мо**я** книга
*   **Глаголы в прошлом:** Стол стоя**л** / Книга лежа**ла**

**Как определить род? По последней букве слова!**

## 1. 👨 Мужской род (阳性 - yángxìng)
Мужской род — это «ОН» (他 / 它).

| Правило | Пример | Перевод |
| :--- | :--- | :--- |
| **1. Заканчивается на согласную** (辅音) | Сто**л**, горо**д**, телефо**н**, студен**т** | 桌子, 城市, 手机, 学生 |
| **2. Заканчивается на -Й** | Музе**й**, ча**й**, трамва**й** | 博物馆, 茶, 有轨电车 |
| **3. Заканчивается на -Ь (мягкий знак)** | Словар**ь**, учител**ь**, ден**ь** | 词典, 老师, 天 |

---

## 2. 👩 Женский род (阴性 - yīnxìng)
Женский род — это «ОНА» (她 / 它).

| Правило | Пример | Перевод |
| :--- | :--- | :--- |
| **1. Заканчивается на -А** | Книг**а**, комнат**а**, машин**а**, вод**а** | 书, 房间, 汽车, 水 |
| **2. Заканчивается на -Я** | Семь**я**, песн**я**, земл**я** | 家庭, 歌曲, 土地 |
| **3. Заканчивается на -Ь (мягкий знак)** | Тетрад**ь**, ноч**ь**, двер**ь**, площад**ь** | 练习本, 夜晚, 门, 广场 |

---

## 3.  neuter. Средний род (中性 - zhōngxìng)
Средний род — это «ОНО» (它). В русском языке этот род часто используется для абстрактных понятий и некоторых предметов.

| Правило | Пример | Перевод |
| :--- | :--- | :--- |
| **1. Заканчивается на -О** | Окн**о**, письм**о**, молок**о**, неб**о** | 窗户, 信, 牛奶, 天空 |
| **2. Заканчивается на -Е** | Мор**е**, солнц**е**, здани**е**, упражнени**е** | 大海, 太阳, 楼, 练习 |
| **3. Заканчивается на -МЯ (группа исключений)** | Вре**мя**, и**мя** | 时间, 名字 |

## 4. 🚨 Ловушки и Исключения (陷阱与例外)

### 1. Ловушка №1: «Мужчины» на -А / -Я
Некоторые слова, обозначающие людей мужского пола, заканчиваются на -А или -Я. В этом случае **смысл важнее, чем окончание**! Они относятся к мужскому роду.

*   **Папа** (爸爸) — м.р. ➡ Мой папа (не *моя папа*!)
*   **Дедушка** (爷爷) — м.р.
*   **Дядя** (叔叔/舅舅) — м.р.
*   **Мужчина** (男人) — м.р.

### 2. Ловушка №2: Загадка Мягкого Знака (-Ь)
Если слово заканчивается на **-Ь**, оно может быть и мужского, и женского рода. Простого правила нет. **Эти слова нужно запоминать!**

> [!example]- Примеры для запоминания:
> **Мужской род (-Ь):**
> *   Слова**рь** (词典)
> *   Дож**дь** (雨)
> *   Де**нь** (天)
> *   Учител**ь** (老师)
> *   Рубл**ь** (卢布)
> 
> **Женский род (-Ь):**
> *   Тетра**дь** (练习本)
> *   Но**чь** (夜晚)
> *   Две**рь** (门)
> *   Жиз**нь** (生活/生命)
> *   Любов**ь** (爱)

### 3. Ловушка №3: «Кофе»
Слово **кофе** (咖啡) выглядит как средний род (заканчивается на -Е), но это **мужской род**.
*   ✅ Правильно: Вкусн**ый** чёрн**ый** кофе.
*   *(В разговорной речи всё чаще можно услышать «вкусное кофе», но на экзаменах это ошибка!)*

## 5. Шпаргалка-алгоритм для определения рода
Когда вы видите новое слово:
1.  **Посмотрите, не является ли оно исключением** (папа, время, кофе).
2.  **Посмотрите на последнюю букву:**
    *   **Согласная / -Й** ➡ Мужской род
    *   **-А / -Я** ➡ Женский род
    *   **-О / -Е** ➡ Средний род
3.  **Если последняя буква -Ь**, проверьте в словаре и запомните.

| Последняя буква | Род |
| :--- | :---: |
| Согласная | **Мужской (Он)** |
| -Й | **Мужской (Он)** |
| -А | **Женский (Она)** |
| -Я | **Женский (Она)** |
| -О | **Средний (Оно)** |
| -Е | **Средний (Оно)** |
| -Ь | **Мужской или Женский (Нужно запомнить!)** |
