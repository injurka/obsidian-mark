## 🤯 Логика системы
В русском языке окончание слова показывает его **роль** в предложении.
Чтобы выбрать правильное окончание, нужно знать три вещи:
1.  **Падеж** (Вопрос).
2.  **Род** (Он, Она, Оно).
3.  **Число** (Один или Много).

---

## 1️⃣ Единственное число (Singular)

Это самая сложная часть. Здесь окончания зависят от рода.

### 🛡️ Сводная таблица (Существительные)

| Падеж | Вопрос | 👨 Мужской (Он)<br>*(Стол, Музей)* | 👶 Средний (Оно)<br>*(Окно, Море)* | 👩 Женский (Она)<br>*(Мама, Неделя)* | 👩 Женский (ь)<br>*(Ночь)* |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **1. Именительный**<br>(Nom) | Кто? Что? | **—** / й / ь | **о / е** | **а / я** | **ь** |
| **2. Родительный**<br>(Gen) | Нет кого/чего? | **а / я** | **а / я** | **ы / и** | **и** |
| **3. Дательный**<br>(Dat) | Дать кому? | **у / ю** | **у / ю** | **е** | **и** |
| **4. Винительный**<br>(Acc) | Вижу... | *= Им.п (неодуш)*<br>*= Род.п (одуш)* | **о / е** | **у / ю** | **ь** |
| **5. Творительный**<br>(Instr) | С кем/чем? | **ом / ем** | **ом / ем** | **ой / ей** | **ью** |
| **6. Предложный**<br>(Prep) | О ком/чем? | **е** | **е** | **е** | **и** |

### 🕵️ Хаки для запоминания (Ед.ч.)

1.  **Правило «О-А» (Мужской и Средний):**
    *   В Родительном падеже они любят букву **А/Я** (Стол**а**, Окн**а**).
    *   В Дательном они любят букву **У/Ю** (Стол**у**, Окн**у**).
2.  **Правило «Е» (Предложный):**
    *   Почти все слова в Предложном падеже (О ком? Где?) заканчиваются на **-Е**.
    *   *Исключение:* Слова на **-ИЯ, -ИЙ, -ИЕ** (Росс**ия** -> В Росс**ии**) и Женский род на **-Ь** (Ночь -> В ноч**и**).
3.  **Женская драма (Ы/И):**
    *   Родительный падеж для женского рода («Нет мамы») требует **-Ы** или **-И**.
4.  **Винительный падеж (Анимация):**
    *   Если предмет **Неживой** (Стол) → Он не меняется! (Вижу стол).
    *   Если предмет **Живой** (Брат) → Он надевает маску Родительного падежа (Вижу брат**а**).
    *   *Женский род меняется всегда:* Мам**у**, Машин**у**.

## 2️⃣ Множественное число (Plural)

Здесь наступает счастье. Род почти не важен (кроме Именительного и Родительного падежей).
Для Дательного, Творительного и Предложного окончания **одинаковые для всех**!

### 🛡️ Сводная таблица (Множественное)

| Падеж | Вопрос | Окончания (Для ВСЕХ родов) | Пример |
| :--- | :--- | :--- | :--- |
| **1. Именительный** | Кто? Что? | **-ы / -и / -а / -я** | Стол**ы**, Мам**ы**, Окн**а** |
| **2. Родительный** | Нет... | **-ов / -ей / — (0)** | Стол**ов**, Гост**ей**, Мам_ |
| **3. Дательный** | Кому? | **-ам / -ям** | Стол**ам**, Люд**ям** |
| **4. Винительный** | Вижу... | *= Им.п (неодуш)*<br>*= Род.п (одуш)* | Вижу стол**ы**<br>Вижу люд**ей** |
| **5. Творительный** | С кем? | **-ами / -ями** | Стол**ами**, Люд**ьми** |
| **6. Предложный** | О ком? | **-ах / -ях** | О стол**ах**, О люд**ях** |

### 🧟‍♂️ Босс-уровень: Родительный Множественный
Это самая сложная тема в русском языке.

1.  **Мужской род (согласная):** Добавляем **-ОВ**. (Парк -> Парк**ов**).
2.  **Ж/М род (на -а/я):** Отрезаем окончание (Нулевое). (Мама -> Мам, Папа -> Пап).
3.  **Мягкий знак / Шипящие (ж, ш, ч, щ):** Добавляем **-ЕЙ**. (Ночь -> Ноч**ей**, Врач -> Врач**ей**).

## ⚠️ Зона опасности: ИЙ / ИЯ / ИЕ
Слова, которые заканчиваются на эти сочетания, ведут себя как аристократы — не подчиняются общим правилам.

| Слово (Им. п.) | Предложный (Где?) | Ошибка новичка (НЕ НАДО!) |
| :--- | :--- | :--- |
| **Россия** (-ия) | В Росси**и** | ~~В Россие~~ |
| **Лекция** (-ия) | На лекци**и** | ~~На лекцие~~ |
| **Гений** (-ий) | О гени**и** | ~~О гение~~ |
| **Здание** (-ие) | В здани**и** | ~~В здание~~ |

> [!summary] Шпаргалка "Золотая Тройка Множественного"
> Если говорите о МНОГИХ предметах, запомните три звука для конца таблицы:
> *   Дательный = **М** (ам)
> *   Творительный = **МИ** (ами)
> *   Предложный = **Х** (ах)
