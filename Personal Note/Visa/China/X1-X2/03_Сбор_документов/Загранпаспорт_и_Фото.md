# Требования к загранпаспорту и фото

### 🛂 Заграничный паспорт
- **Срок действия:** Действителен не менее 12 месяцев (1 года) на момент подачи документов.
- **Пустые страницы:** Минимум 2 чистые страницы для визы.
- **Состояние:** Без повреждений, порванных страниц, пятен или отслоений ламината.
- **Копии:** Понадобится копия главной страницы (разворот с фото) + копии прошлых китайских виз (если были).

### 📸 Фотография для визы
- **Размер:** ровно 33 x 48 мм.
- **Цветность:** Цветная, на чисто белом фоне.
- **Давность:** Сделана в течение последних 6 месяцев.
- **Внешний вид:**
  - Лицо строго анфас, уши полностью открыты.
  - Без очков (или в тонкой оправе без бликов, если глаза видны четко).
  - Без головных уборов (кроме религиозных соображений, не закрывающих лицо).
  - Без украшений (серьги, цепочки, пирсинг необходимо снять).
  - Одежда темная, контрастирующая с белым фоном (не белая, не светлая).
