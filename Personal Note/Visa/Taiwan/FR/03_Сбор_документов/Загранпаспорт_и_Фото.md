# Требования к загранпаспорту и фотографиям для визы на Тайвань

Консульский отдел ТМКК и Миграционная служба Тайваня предъявляют строгие требования к заграничным паспортам и биометрическим фотографиям заявителей.

---

## 🛂 Требования к заграничному паспорту

* **Срок действия:** Паспорт должен действовать **не менее 6 месяцев** с даты предполагаемого въезда на Тайвань.  
  * *Рекомендация:* Если вы планируете учиться 6–12 месяцев и оформлять ВНЖ (ARC), срок действия паспорта должен составлять **не менее 1.5–2 лет**, чтобы не пришлось менять паспорт через консульские учреждения во время учебы.
* **Чистые страницы:** Минимум **2–3 полностью чистые страницы** (для вклейки визового стикера и простановки въездных/выездных штампов).
* **Физическое состояние:** Отсутствие повреждений страниц, пятен, отклеивающегося ламината или замятых уголков.
* **Наличие второго действующего загранпаспорта:** Законодательство РФ позволяет иметь два действующих загранпаспорта. Настоятельно рекомендуется оформить второй загранпаспорт перед поездкой на случай утери первого или сдачи на продление визы.

---

## 📸 Спецификация визовых фотографий (Стандарт BOCA)

Для тайваньской визовой анкеты и последующих регистрационных процедур требуются фотографии строжайшего образца:

```
          ┌───────────────────────────┐
          │ <------- 35 мм ------->   │
          │                           │
          │         ┌───────┐         │ ▲
          │        /  ...    \        │ │
          │       │  (o) (o)  │       │ │ 32–36 мм
          │       │     ▲     │       │ │ (70-80% кадра)
          │        \  └───┘  /        │ │
          │         \_______/         │ ▼
          │        /         \        │ 
          │       /           \       │ 45 мм
          │      /             \      │
          │                           │
          └───────────────────────────┘
```

### Параметры фотографии:
- [ ] **Размер:** **3.5 × 4.5 см** (35 × 45 мм) или стандарт **2 × 2 дюйма**.
- [ ] **Свежесть:** Фотография сделана **не ранее 6 месяцев назад** (не должна совпадать с фото в старом паспорте, выданном несколько лет назад).
- [ ] **Фон:** **Идеально белый** (без теней, серого или голубоватого оттенка).
- [ ] **Размер лица:** Лицо должно занимать **70–80%** высоты снимка (высота головы от подбородка до макушки — от 32 до 36 мм).
- [ ] **Открытое лицо:** Лоб и брови должны быть открыты (челку убрать), **уши должны быть четко видны**.
- [ ] **Выражение лица:** Нейтральное, взгляд прямо в камеру, рот закрыт, без широкой улыбки.
- [ ] **Очки и аксессуары:** Очки в массивной оправе, цветные линзы или блики на стеклах **запрещены** (рекомендуется фотографироваться без очков). Головные уборы не допускаются (кроме религиозных по письменному обоснованию).
- [ ] **Одежда:** Темная или контрастная одежда (не надевайте белую рубашку или футболку, сливающуюся с белым фоном).
- [ ] **Количество:** Подготовьте **2 распечатанные фотографии** для наклеивания на анкету BOCA и сохраните **цифровой файл JPG** для загрузки на портал языкового центра.
