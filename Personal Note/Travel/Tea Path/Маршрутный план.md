# Маршрутный план: Чайный путь и морской бриз

Общая сводка маршрута по провинции Фуцзянь (Юго-Восток Китая).

| День | Локация | Главные события |
|---|---|---|
| **01** | Уишань | Прибытие, заселение, чайные туманы |
| **02** | Уишань | Сплав на плотах по Реке Девяти Излучин |
| **03** | Уишань | Чайные плантации, родина Да Хун Пао |
| **04** | Фучжоу | Скоростной поезд (1ч), квартал Саньфан Цисян |
| **05** | Фучжоу | Парки баньянов, фуцзяньская кухня |
| **06** | Цюаньчжоу | Скоростной поезд (1.5ч), старый порт и архитектура Миннань |
| **07** | Цюаньчжоу | Храм Кайюань, мечеть Цинцзин, перекресток религий |
| **08** | Цюаньчжоу | Морской музей, старые улочки, наследие Шелкового пути |
| **09** | Сямэнь | Скоростной поезд (40м), вечерние прогулки и море |
| **10** | Сямэнь (Гуланъюй) | Паром на остров, колониальные виллы |
| **11** | Сямэнь (Гуланъюй) | Скала Солнечного Света, пляжи, музыкальные аллеи |
| **12** | Сямэнь | Ботанический сад, велопрогулка по набережной |
| **13** | Сямэнь | Арт-деревня Цзэнцоань, морской стритфуд, закат |
| **14** | Сямэнь | Вылет домой |

**Транспортная специфика:**
Весь маршрут идеально покрыт сетью высокоскоростных железных дорог, идущих с севера на юг провинции. Перемещения занимают минимум времени.

**Лучшее время для поездки:** 
Весна (апрель-май) — время сбора свежего чая, или осень (октябрь-ноябрь) — идеальный баланс температуры. Летом может быть слишком жарко и влажно, возможны тайфуны.
