# ✅ Чек-листы поездки по Японии

## Перед оплатой

- [ ] Заменить рабочие даты на даты фактического авиабилета.
- [ ] Выбрать open-jaw: прилёт NRT, вылет KIX.
- [ ] Проверить требования для гражданства и транзитных стран.
- [ ] Забронировать отели с бесплатной отменой, если цена ещё не зафиксирована.
- [ ] Сверить прилив Миядзимы и часы храмов/музеев.

## Перед выездом

- [ ] Заполнить Visit Japan Web.
- [ ] Купить SmartEX для Odawara ➔ Kyoto и Osaka ➔ Hiroshima.
- [ ] Проверить бронирование Hiroshima ➔ Himeji ➔ Shin-Osaka на день 13.
- [ ] Проверить oversized-baggage area для крупного чемодана.
- [ ] Заказать Takkyubin по цепочке Kyoto ➔ Namba ➔ Miyajima ➔ Shin-Osaka либо подтвердить камеры хранения.
- [ ] Сохранить офлайн адреса отелей и номера бронирований.

## Навигация

- [ ] NRT: N'EX до Shibuya/Shinjuku.
- [ ] KIX: Haruka/JR West из Shin-Osaka.
- [ ] Suica/PASMO пополнена, наличные иены есть.
- [ ] План B на дождь/закрытие Hakone Ropeway записан в телефоне.
