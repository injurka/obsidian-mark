# 🧋 Кофейно-чайная экспедиция по Тайваню

*TAIWAN · COFFEE & TEA · НОЯБРЬ 2026*

Гид для прогулок: узнавать вывески, пробовать разные вкусы и иногда специально заходить в интересное место. Это подборка известных сетей и местных специалитетов по городам нашей поездки, а не полный перечень заведений острова или рейтинг по продажам.

> [!info]- Цены и пересчёт в рубли
> **Проверка источников: 29.10.2026.** «Чек» ниже — ориентир на человека за один напиток без еды, а не статистический средний чек. Для пересчёта принят **условный бюджетный курс 1 TWD = 3 ₽**: это удобный счёт в уме, не проверенный курс обмена. В меню `$` / `NT$` означает тайваньские доллары. Цены зависят от размера, региона и филиала; ориентиры и цены доставки отмечены отдельно.

## 🎯 Шесть первых вкусов

- **50嵐:** классический молочный чай с тапиокой — точка отсчёта для остальных.
- **KEBUKE:** чистый чёрный чай, чтобы почувствовать саму чайную основу.
- **MACU:** виноградный напиток с сырной пенкой — почти десерт в стакане.
- **Simple Kaffa:** отдельная остановка ради хорошего кофе в Тайбэе.
- **源興御香屋:** грейпфрутовый зелёный чай в Цзяи.
- **Chun Shui Tang 四維創始店:** баблти в историческом заведении Тайчжуна, уже предусмотренном маршрутом 24 ноября.

## 🍵 03 / Местные чайные истории

### Хуалянь — 廟口紅茶, Miaokou Black Tea

![廟口紅茶 · прежний фасад, Хуалянь; объявлено временное закрытие|640](https://pic.pimg.tw/james2003/1677545154-2526010805-g.jpg)

**Заказ:** 紅茶 — традиционный сладкий чёрный чай. **Ориентир: от 25 TWD ≈ 75 ₽**, без еды; цена из местного материала, а не актуального официального меню.

Чай поступает с верхнего этажа к стойке через стальные трубы — ради этой детали сюда уже интересно заглянуть. Туристический сайт Хуаляня указывает **成功街218號**. Это старое чайно-завтрачное место, не современная баблтишная.

**Статус:** по сообщению TVBS от 27.08.2026, заведение объявило временное закрытие с **9 сентября 2026** для перестройки. Подтверждения возобновления работы здесь нет; на ноябрь посещение не планировать без нового объявления. Фотография показывает прежний фасад. [Сообщение о закрытии](https://news.tvbs.com.tw/life/4013552).

### Цзяи — 源興御香屋, Yuan Xing Yu Xiang Wu

![源興御香屋 · фасад у фонтана, Цзяи|640](https://img.bigmouthblog.tw/2017/07/1499877675-48180849378ece1c88272cf63637e64a.jpg)

*源興御香屋 · фасад у фонтана, Цзяи · [Источник фото](https://bigmouthblog.tw/blog/post/44744659).*

**Заказ:** 葡萄柚綠茶 — зелёный чай с грейпфрутовой мякотью. **70 TWD ≈ 210 ₽** по двум обзорам 2026; обычно один размер. Свежий цитрусовый профиль — хороший контраст молочным напиткам.

**Где:** **中山路321號**, у фонтана; есть также точка на 中正路329號. Это известная местная остановка с очередями. В старых статьях фигурируют 55–65 TWD: для бюджета используем более свежие 70.

**По маршруту:** вечер **13 ноября**, день 10, если успеваем до закрытия. Не задерживать ради очереди ужин и отдых перед горным переездом.

![Chun Shui Tang · оригинальная чайная 四維創始店, Тайчжун|640](https://www.thepoortraveler.net/wp-content/uploads/2020/04/Chun-Shui-Tang-Original-Shop-Taichung-1042x586.jpg)

*Chun Shui Tang · оригинальная чайная 四維創始店, Тайчжун · [Источник фото](https://www.thepoortraveler.net/chun-shui-tang-bubble-milk-tea/).*

**Заказ:** 珍珠奶茶 — классический pearl milk tea. **Бюджет 90–200 TWD ≈ 270–600 ₽** за напиток: в меню другого тайчжунского филиала маленький холодный стоит 90, средний жасминовый 170, средний горячий 200 TWD. Это ориентир сети, не проверенный прайс Siwei.

**Где:** **四維街30號**. Историческая чайная, которую посещают ради истории баблти и старого интерьера. Chun Shui Tang — один из претендентов на изобретение напитка; не стоит считать авторство бесспорным.

**По маршруту:** уже стоит утром **24 ноября**, день 21. Хорошее место для сравнения с базовым 50嵐: платим также за посадку и атмосферу, еда отдельно.

## 🗣️ Шпаргалка заказа

**Стартовая формула:** 珍珠奶茶，微糖，少冰 — «молочный чай с тапиокой, немного сахара, мало льда».

| На меню | Значение |
| --- | --- |
| 無糖 / wú táng | Без добавленного сахара; топпинги или готовая основа могут оставаться сладкими |
| 微糖 / wēi táng | Мало сахара; часто около 30%, но шкала зависит от сети |
| 半糖 / bàn táng | Половина стандартного сахара |
| 少冰 / shǎo bīng | Мало льда |
| 去冰 / qù bīng | Без льда; не обязательно комнатной температуры |
| 熱的 / rè de | Горячий вариант, если доступен |
| 珍珠 / 波霸 | Тапиоковые шарики; различия размера зависят от сети |
| 椰果 | Кокосовое желе |
| 奶蓋 / 芝芝 | Молочная / сырная пенка |
| 鮮奶 / 拿鐵 | Свежее молоко / latte; в чайной это может быть чай с молоком, без кофе |
| 奶茶 | Молочный чай; молочная основа может быть сливками или кремером |
| 芋頭 / 芋泥 | Таро / паста из таро |
| 手沖 / 美式 | Фильтр ручного заваривания / американо |

Для первого чистого улуна можно взять 無糖、少冰. Для фруктового напитка — 微糖、少冰, если рецепт допускает изменения. Для фиксированных десертных рецептов показывать название: настройка доступна не всегда.

## 💰 Свой дегустационный бюджет

Пример: **10 уличных напитков × 70 TWD + 3 кофе × 200 TWD + Chun Shui Tang 170 TWD = 1 470 TWD ≈ 4 410 ₽** за поездку. Это 14 остановок, без еды и Цзюфэня. Бюджетный сценарий, а не сумма счетов из меню; расходы могут уже частично входить в ежедневное питание, поэтому автоматически прибавлять всё к общему бюджету не нужно.
