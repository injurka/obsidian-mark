# ✍️ Travel Itinerary Enricher: Обогащение и Оформление Дневных Заметок

Этот навык обучает агента превращать сырой список достопримечательностей в захватывающий, кинематографичный и предельно практичный путеводитель в Obsidian.

---

## 🎨 1. Анатомия Эталонного Дневного Файла

Каждый дневной файл строится из 5 обязательных слоев с четким правилом позиционирования коллаутов:

```markdown
# 🗓️ День DD: ДеньНедели (🌴 Отпуск / 💻 Воркейшн / 🐢 Уикенд)

> **Локация:** <Цепочка локаций через стрелочки ➔>.
> **Фаза тура:** <Описание фазы, хайлайты дня>.
> **Проживание:** <Отель, цена за ночь в ₽, номер ночи в городе>.
> **Ключевой хайлайт:** <1-2 ярких предложения о главном впечатлении дня>.

---

> [!IMPORTANT] Билеты, карточки, правила входа, тайминг переезда
> * **Какой поезд / транспорт:** <Название, номер поезда, время в пути, стоимость>.
> * **Как бронировать:** <Сайт/приложение, сроки, способ валидации>.
> * **Где сидеть:** <Панорамная сторона, отсеки для чемоданов>.

> [!CAUTION] Критические запреты, штрафы, безопасность
> ...

## 💰 Финансовые затраты на день (на 1 чел)
* <Транспорт>: `~XXX ₽`.
* <Билеты / Активности>: `~XXX ₽`.
* <Питание / Ночной рынок>: `~XXX ₽`.
* **Итого за день (без отеля):** около `~X XXX ₽`.
```

> [!IMPORTANT] 📌 Правило позиционирования Callouts:
> 1. **В блоке «Важная подготовка»** размещаются только глобальные системные правила дня: `[!IMPORTANT]` (билеты, тайминги, логистика переезда, бронь отеля) и `[!CAUTION]` / `[!WARNING]` (таможня, строгие запреты, безопасность на побережье).
> 2. **Коллауты `[!TIP]` размещаются строго контекстно ПОД АКТИВНОСТЬЮ** — прямо под пунктом маршрута, смотровой, рестораном или хайкингом, к которому относится совет (очередь в кафе, правильный ракурс, упаковка рюкзака, выбор столика, формула заказа блюда).

## 🛠️ 2. Стандарты Интерактивных Элементов

### А. Встраивание Карт Google Maps
Для каждой ключевой остановки, отеля, вокзала или рынка генерируется связка:
1. Текстовая ссылка на Google Maps.
2. Встроенный responsive iframe (350px, border-radius 8px, lazy loading):

```markdown
* _Ссылка на локацию_: [Google Maps: Taipei 101](https://maps.google.com/?q=Taipei+101)<iframe src="https://maps.google.com/maps?q=Taipei+101&output=embed" style="width: 100%; min-width: 100%; height: 350px; display: block; border: 0; border-radius: 8px; margin-top: 10px; margin-bottom: 15px;" loading="lazy"></iframe>
```

### Б. Сворачиваемая Галерея Изображений
Картинки оборачиваются в свернутый callout `[!INFO]- Картинки`, чтобы не перегружать чтение текста:
```markdown
> [!INFO]- Картинки
> ![[01_dihua_street.jpg]]
> ![[Pasted image 20260825142540.png]]
```

### В. Бейджи Рейтингов в Заметках (`01 - Заметки`)
Для списков Must-See мест используются кастомные HTML-бейджи:
```html
- <span class="tp-rate r-top"><b class="tp-score">9.7</b><span class="tp-tag">MUST</span></span> **Название локации:** Описание...
```
