# 📋 Спецификация Парсера Obsidian-Importer

В этой таблице сведены точные регулярные выражения и шаблоны, используемые в кодовой базе `tools/obsidian-importer/src/parsers/*`:

## 1. Дневной таймлайн (`src/parsers/activity.ts`)
- **Регулярное выражение строки активности:**
  `^[*-]\s*\*\*(\d{1,2}:\d{2})\+?\s*(?:[-–—]\s*(\d{1,2}:\d{2}))?\+?\*\*\s*(?:[-–—:]\s*)?(.*)$`
  - Пример: `* **09:00 - 11:30** — **Название активности**:`
  - Если конечное время не указано, автоматически добавляется +1 час к начальному.
  - Активность завершается при встрече заголовков `# `, `## `, `### `, разделителя `---` или следующего таймкода.

## 2. Инфо-бейджи дня (`src/parsers/day-meta.ts`)
- **Регулярное выражение Callout:**
  `/>\s*\[!([\w-]+)\]-?\s*([^\n]*)\n((?:[ \t]*>[^\n]*\n?)*)/g`
  - Любые коллауты до первой активности (`09:00`) парсятся в интерактивные плашки `day.meta`.
  - Заголовок с разделителями `—`, `–` или `: ` автоматически делит бейдж на `title` и `subtitle`.
  - Коллауты `[!INFO]- Картинки` игнорируются для бейджей (идут в медиа).

## 3. Бронирования отелей (`src/parsers/booking.ts`)
- **Таблица отелей:**
  Строки вида `| 01–04 | Тайбэй | [Hotel Name](https://...) | 3 | 3 200 ₽ | 9 600 ₽ |`
  - Колонка 1: диапазон ночей (`01–04` или `09`).
  - Колонка 2: локация.
  - Колонка 3: ссылка на отель в markdown формате `[Название](URL)`.
  - Колонка 5: цена за ночь в ₽.
  - Колонка 6: общая цена за локацию в ₽.
- **Каталог отелей:**
  `*\s*\*\*№?1?\s*\(?(?:Основной|Флагманский выбор|Основной выбор)?\)?:\*\*\s*\[?([^\]\n*]+)\]?(?:\(([^)]+)\))?`

## 4. Смета финансов (`src/parsers/finances.ts`)
- Распознаются секции по эмодзи в заголовках:
  - `✈️` или `авиаперелет` ➔ `cat-flights`
  - `🚗` / `🚄` / `поезд` / `транспорт` ➔ `cat-transport`
  - `🏨` / `проживани` / `отел` ➔ `cat-housing`
  - `🍜` / `питани` / `еда` ➔ `cat-food`
  - `🎟️` / `билет` / `активност` ➔ `cat-entertainment`
  - `🎁` / `сувенир` / `шопинг` ➔ `cat-shopping`
- Табличные строки с суммой: `| Статья | 1 500 ₽ | Заметка |`

## 5. Чек-листы (`src/parsers/checklist.ts`)
- Чекбокс: `^- \[[ xX]\] (.*)$`
- Сумма в скобках: `\((?:💰|~)?\s*([~≈]?\s*(?:\d[\s\d]*[–—\-]\s*\d+|\d[\s\d]*)\s*(?:TWD|NT\$|[₽$€¥₩]|USD|EUR|CNY|KRW)(?:\s*\/[^)]+)?)\)`
- Локация: `\*(?:Где пробовать|Локация|Место|Где искать|Где купить):\*\s*([^;\n)]+)`
