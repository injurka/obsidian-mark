# 🚀 Travel Importer Compatibility: Стандарты Совместимости с Obsidian-Importer

Этот навык обучает агента создавать и проверять тревел-заметки Obsidian так, чтобы они **без единой ошибки и с максимальным обогащением данных** импортировались в веб-платформу Trip Scheduler через `tools/obsidian-importer`.

---

## 🧭 Ключевые требования obsidian-importer к структуре

Парсер `obsidian-importer` ожидает строго выверенную таксономию:

```text
-- <Название Путешествия>/
├── <Название Путешествия>.md           # Корневой хаб: title, краткое описание, даты
├── 02 - Маршрутный план/
│   ├── Маршрутный план.md              # Сводка маршрута
│   ├── 01 <Город> (<дн>) ...md         # Дневной файл
│   └── 02 <Город> (<дн>) ...md
├── 03 - Бронирования/
│   ├── Отели.md                        # Таблица броней отелей и каталог
│   ├── Авиаперелеты.md                 # Hero-коллаут, сегменты перелетов, Mermaid TD
│   └── Транспорт.md                    # Таблица трансферов/поездов, Mermaid flowchart
├── 04 - Финансы/
│   └── Финансы.md                      # Смета с категориями ✈️, 🚗, 🏨, 🍜, 🎟️, 🎁
├── 05 - Полезная информация/
│   └── 05 - Полезная информация.md
├── 06 - Чек лист/
│   ├── 06 - Чек лист.md                # Хаб чек-листов
│   ├── Чек-лист подготовки и сборов.md # Документы, IT, аптечка, гардероб
│   └── Что попробовать и купить (Must-Try & Must-Buy).md
└── _/                                  # Фотографии и вложения (_/all/, _/01/...)
```

---

## 🎯 1. Главный Хаб `<Название>.md`

Парсер извлекает:
1. **Название тура:** берется из заголовка `# <Название>` или имени файла.
2. **Краткое описание (descriptionShort):** извлекается строго из раздела:
   ```markdown
   ## 📝 Краткое описание
   Емкий абзац текста на 2–4 предложения. Обязателен заголовок именно с эмодзи 📝 или текстом "Краткое описание".
   ```
3. **Города и даты:** распознаются из таблицы мастер-плана и имен файлов `02 - Маршрутный план/`.

## 📅 2. Дневные заметки (`02 - Маршрутный план/*`)

### А. Заголовок и метаданные дня:
```markdown
# 🗓️ День 01: Суббота (🌴 Отпуск)

> **Локация:** Тайбэй.
> **Фаза тура:** 100% Отпуск. Погружение в колорит старого города.
> **Проживание:** Morwing Hotel, ~3 200 ₽ / ночь.
> **Ключевой хайлайт:** Неоновые огни Taipei 101 и стритфуд рынка Раохэ.
```
> [!IMPORTANT]
> `> **Фаза тура:**` и `> **Ключевой хайлайт:**` автоматически склеиваются парсером в поле `day.description`!

### Б. Подготовка и Бейджи (`day.meta`):
Любые коллауты в блоке до первой активности парсер преобразует в интерактивные чипы `day.meta`:
* `> [!IMPORTANT]` — системные требования (билеты, брони).
* `> [!CAUTION]` / `> [!WARNING]` — штрафы, безопасность, запреты.
* `> [!TIP]` — полезные советы.

**Ключевые слова для иконок бейджей:**
* `лотерея` / `lucky` / `приз` ➔ `mdi:gift-outline` (золотистый)
* `велосипед` / `youbike` ➔ `mdi:bike`
* `миграционная` / `twac` / `запрет` / `штраф` ➔ `mdi:alert-octagon-outline` (красный)
* `метро` / `поезд` / `mrt` / `thsr` / `tra` ➔ `mdi:subway-variant`
* `онсэн` / `термальные` ➔ `mdi:hot-tub`
* `дождь` / `погода` ➔ `mdi:weather-rainy`
* `черепахи` / `кораллы` ➔ `mdi:turtle` (зеленый)
* `аптечка` / `лекарства` ➔ `mdi:pill`
* `чай` / `еда` / `ланч` ➔ `mdi:food`

### В. Активности и Таймлайн:
Формат строки времени строго обязателен:
```markdown
* **09:30 - 11:30** — **Название активности (Локация)**:
    * *Контекст*: Историко-культурная справка.
    * *Маршрут*: Инструкции по проезду.
    * _Ссылка на локацию_: [Google Maps: Название](https://maps.google.com/?q=Запрос)<iframe src="https://maps.google.com/maps?q=Запрос&output=embed" style="width: 100%; min-width: 100%; height: 350px; display: block; border: 0; border-radius: 8px; margin-top: 10px; margin-bottom: 15px;" loading="lazy"></iframe>

> [!TIP]
> Локальный совет к этой активности.

> [!INFO]- Картинки
> ![[фото.jpg]]
```
* Время: **двузначные часы и минуты** через двоеточие: `09:30 - 11:30` (не `9:30`, не `09.30`).
* Автоматическая классификация тегов:
  - `transport`: перелет, поезд, метро, mrt, thsr, tra, трансфер, grab, uber, автобус, паром.
  - `food`: завтрак, обед, ужин, стритфуд, кофе, чай, ресторан, кафе, рынок.
  - `walk`: прогулка, хайкинг, пешком, подъем, треккинг, набережная, тропа.
  - `attraction`: храм, музей, небоскреб, мемориал, водопад, смотровая, парк.
  - `relax`: отель, заселение, бассейн, пляж, онсэн, спа, отдых.

### Г. Посуточные финансы:
В конце дневного файла:
```markdown
## 💰 Финансовые затраты на день (на 1 чел)
* Транспорт: `~250 ₽`.
* Еда: `~1 200 ₽`.
* **Итого за день (без отеля):** около `~1 450 ₽`.
```

## 🏨 3. Бронирования (`03 - Бронирования/*`)

### `Отели.md`:
1. Сводная таблица обязательна:
   ```markdown
   | Ночи | Локация | Отель №1 (Основной выбор) | Ночей | Цена / ночь | Итого за локацию |
   |:---:|:---|:---|:---:|:---:|:---:|
   | 01–04 | Тайбэй | [Morwing Hotel Fairy Tale](https://www.trip.com/w/...) | 3 | 3 200 ₽ | 9 600 ₽ |
   ```
2. Подробные секции:
   ```markdown
   ### 🏙️ Тайбэй (Ночи 01–04)
   * **№1 (Основной выбор):** [Morwing Hotel](https://...)
   * **Особенности:** Wi-Fi 250 Мбит/с, рабочий стол, 3 мин от станции MRT.
   ```

### `Авиаперелеты.md`:
* Hero Callout:
  ```markdown
  > [!SUCCESS]+ 🥇 Выбранный авиаперелет: **China Eastern Airlines** (~58 000 ₽ туда-обратно)
  ```
* Таблица сегментов с датами, номерами рейсов, вылетом и прилетом.

## 💰 4. Финансы (`04 - Финансы/Финансы.md`)

Разделы с обязательными иконками для автоматического сопоставления категорий:
* `### ✈️ 1. Международный авиаперелет` ➔ категория `Авиабилеты`
* `### 🚄 2. Поезда и междугородний транспорт` ➔ категория `Транспорт`
* `### 🏨 3. Проживание (Отели)` ➔ категория `Жильё`
* `### 🍜 4. Питание и стритфуд` ➔ категория `Еда и напитки`
* `### 🎟️ 5. Входные билеты и активности` ➔ категория `Развлечения`
* `### 🎁 6. Сувениры, чай и подарки` ➔ категория `Покупки`

Каждая строка таблицы парсится в транзакцию:
```markdown
| Статья расхода | Стоимость в ₽ | Примечание |
| :--- | :---: | :--- |
| Билеты на скоростной поезд THSR | 4 200 ₽ | Тайбэй ➔ Гаосюн |
```

## ✅ 5. Чек-листы (`06 - Чек лист/*`)

В файле `Что попробовать и купить (Must-Try & Must-Buy).md`:
```markdown
### 🏮 1. Легендарный стритфуд ночных рынков
- [ ] **Сяолунбао (Soup Dumplings)** — Тончайшее тесто с горячим бульоном. *(💰 ~150 TWD)*. *Локация:* [Din Tai Fung](https://maps.google.com/...)
```
* Стоимость в скобках `*(💰 ~150 TWD)*` или `*(~500 ₽)*` автоматически извлекается в поле `cost`.
* Локация `*Локация:* ...` или `*Где пробовать:* ...` автоматически извлекается в поле `location`.
* Ссылка `[...]` извлекается в поле `link`.

## 🔎 Чек-лист самопроверки перед импортом
1. [ ] Имя корневой папки начинается с `-- ` (или выбрано явно через `-d`).
2. [ ] В корне лежит `<Название>.md` с разделом `## 📝 Краткое описание`.
3. [ ] В дневных файлах тайминги активностей имеют формат `* **HH:MM - HH:MM** — **Заголовок**:`.
4. [ ] Все Google Maps имеют responsive iframe `style="width: 100%; min-width: 100%; height: 350px; display: block; border: 0; border-radius: 8px; margin-top: 10px; margin-bottom: 15px;" loading="lazy"`.
5. [ ] В `Отели.md` есть сводная таблица с колонками `| Ночи | Локация | Отель ... |`.
6. [ ] В `Финансы.md` заголовки содержат эмодзи ✈️, 🚄, 🏨, 🍜, 🎟️, 🎁.
