# 🏨 Критерии Подбора Воркейшн-Отелей, Wi-Fi и Спешелти-Кофеен

## 1. Чек-лист проверки отеля для воркейшна

Перед включением отеля в список бронирований для рабочих дней проверь:
- [ ] **Скорость Wi-Fi:** Отзывы на Booking/Trip.com с тестами скорости (желательно >150 Мбит/с).
- [ ] **Рабочая зона в номере:** Наличие физического стола и удобного стула (не журнального столика у кровати).
- [ ] **Розетки у стола:** Доступность розеток без необходимости двигать мебель.
- [ ] **Уровень шума:** Расположение отеля в тихом переулке или звукоизолированные стеклопакеты, этажи выше 4-го.
- [ ] **Коворкинг-холл / Лобби:** Наличие просторного общественного пространства в отеле на случай смены обстановки или раннего чекаута.
- [ ] **Транспортная доступность:** В пешей доступности (до 5–7 мин) от станции метро/поезда.

## 2. Формат описания кофеен для работы

В заметках и дневных планах кофейни оформляются по структуре:
- **Название (на англ. и местном языке):** например, *The Factory Mojocoffee (台中)*.
- **Специфика:** Микролоты светлой обжарки, зерно Single Origin, пуровер V60 / Aeropress / фильтр-кофе.
- **Инфраструктура:** Наличие розеток, стабильный интернет, атмосфера для работы с ноутбуком.
- **Ссылка на Google Maps с iframe-виджетом.**
